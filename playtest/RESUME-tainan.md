#### G · Bug/异常
- **无 console 报错**：cutscene 播放全程无 JS 错误。✅
- **⚠ P2 赶集触发与故事触发耦合问题**：调用 Engine.fairBuy() 购买物品后，
  fair_bought 增量立即触发 checkStory → qingwen_plot，但此时商店 UI
  仍在前台。节点的 onArrive 设置了 pendingEvent 后 body.story-on 激活，
  覆盖了商店层。虽然视觉上切换流畅（商店消失、cutscene 出现），
  但如果玩家快速连购多件，可能在第一件触发故事后，后续购买操作被吞。
  - **修复建议**：在 `js/engine.js` fairBuy() 末尾，如果 checkStory
    触发了新 pendingEvent，应先 close fair UI 再 play story。
    或在 UI.openFair() 中加一个"故事触发后自动关闭"的 listener。
- **state 一致性**：storyStage=20, qingwen_seen=true, xianhui_due=21，
  pendingEvent=null，与预期一致。✅
