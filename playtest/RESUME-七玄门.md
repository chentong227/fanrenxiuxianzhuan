## §2 八维观察（截至 storyStage=6）

### A 难度曲线
- 突破练气四层第一次失败：修为-44、气血-20、心魔滋长。有挫败但成本可读，属"输在准备"，暂不违反爽文契约。
- **切磋事件敌人境界远超玩家**（练气三层时来了个练气八层"周牧"讨教），结算却只是"点到即止互有进益"——数值上无伤害但体感荒诞（见 H）。

### B 节奏 / 繁琐度（本段最大问题）
- **P1「闭关至本层圆满」几乎永远闭不满**：随机事件（心魔幻梦/登门切磋/邀约秘境/灵药成熟）每 1~3 个月就打断一次闭关，玩家要反复重开「闭关修炼→至本层圆满」菜单，同样两次点击重复了 6+ 次。建议：闭关被打断后弹一个「继续闭关？」快捷按钮，或事件处理完自动续闭。
- **P1 闭关中断无前台反馈**：中断原因只写进"见闻"日志（心魔幻梦"原拟闭关16月，实修7月"），主界面毫无提示，玩家第一反应是"是不是 bug 没执行"。建议：闭关结束（无论到期/中断）弹结算条：闭了几月、修为+多少、为何中止。
- 修炼/突破/打坐的主循环本身节奏尚可，"距本层圆满约需 N 月"的预估直观好用。

### C 缺道具 / 缺提示
- **P2 突破成败无前台结算**：冲关失败（-44 修为）和成功（升层）都只有日志一行，主界面无弹窗无 toast（或 toast 一闪即逝在截图节奏下不可见）。境界突破是最大的正反馈时刻，静默处理浪费了爽点。
- 「距本层圆满约需 N 月」与「尝试突破可用性」口径存在错位感：3年5月提示"修为尚浅必败"，3年8月（仅3个月后）就"心魔已伏可顺势冲关"，玩家无法自行推算，只能反复点尝试突破试探。

### D 移动端 UI（430×932）
- **P1 「见闻·全录」底部 sheet 的关闭 × 定位逃逸**：`ui.js openSheet()` 的 `.sheet-close` 是 `position:absolute`，但 `.bottom-sheet` 没有 `position:relative`，× 锚到了视口右上角（被顶栏遮住），sheet 打开后点不到关闭按钮、点遮罩也不关，玩家被困在日志页（本次靠刷新页面逃出）。修法：`.bottom-sheet` 加 `position:relative`，并给 `#sheet-overlay` 加"点遮罩关闭"。
- 顶栏「舆图/⋯」+ 底栏「舆图/行动/状态」布局正常；行动按钮尺寸合适（≥44px）。
- 小瓶面板"培育中…"文案换行成"培育 中…"（竖排挤压），小瑕疵。
- 剧情心声框有一处把立绘头部整个盖住（墨大夫"资质平平"心声段），文本框定位偏高。

### E 美术 / 演出
- 序章/赴考/七玄门山门/药庐场景图质量高，绿瓶 CG（韩立托瓶）非常出彩。
- **P2 演武厅场景缺图**：「同门之谊」打出地点题字"演武厅"，背景仍是药庐图。
- **P2 厉飞雨立绘裁切生硬**：大笑张开的双臂在图片矩形边缘被直切，抠图矩形边可见（对比韩立/墨大夫/张铁立绘的干净头身像明显违和）。
- 角色立绘与人设对位正确（张铁憨厚/墨大夫枯瘦阴鸷/厉飞雨爽朗）。

### F 游戏性 / 战斗手感
- **P1 打坐调息期的遭遇战全部黑箱结算**：登门切磋（李恒/周牧）、邀约闯秘境（王矮子）选"应战/同往"后没有任何战斗界面或探索界面，直接跳月出结果，且结果只在见闻日志里。玩家感知＝"点了没反应"。练气前期轻量化可以理解，但至少要有结果弹窗；秘境（"机缘与凶险并存"）给纯黑箱更可惜。
- 小瓶双槽种植（灵乳灵药/千年灵草两条谱法）+滴液催熟的取舍设计意图清晰，"换灵石的财路——一两棵便够换楼上一件法器"的钩子文案好。
