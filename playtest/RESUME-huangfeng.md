## 三、Bug 清单

### P1 — 突破系统死循环
- **现象**: 练气六层尝试突破时，心魔·墨大夫心战的 `combatQuickResolve()` 完全无效。突破失败后心魔值递增（61+），导致突破成功率持续下降（-15.25% 惩罚），形成不可逆的负反馈循环
- **复现**: 在 realmIndex=5 时反复调用 `Engine.attemptBreakthrough()`，观察心魔值和成功率变化
- **影响**: 玩家可能永远无法突破到练气七层及以上，阻断主线进程
- **建议**: 
  1. 修复 `combatQuickResolve()` 对 mind 类型战斗的处理
  2. 增加心魔衰减机制（随时间/修炼降低）
  3. 考虑突破保底（连续失败 N 次后降低门槛）

### P2 — 剧情战斗速战速决无效
- **现象**: chen_rescue 的陆云风战（`luyunfeng_fight`）中，速战速决按钮不推进战斗
- **复现**: 进入 chen_rescue 战斗后点击速战速决
- **影响**: 玩家必须手动每回合操作，但 UI 仍显示速战速决按钮（误导）
- **建议**: 如果剧情战设计上不允许速战速决，应在剧情战中隐藏该按钮

### P3 — jindi_meeting 选项索引偏移
- **现象**: 选择"踏入血幕"时 `UI.storyChoose()` 无法正确触发 resolve
- **复现**: 在 jindi_meeting 选择界面调用 `UI.storyChoose(0)` 或 `UI.storyChoose(1)`
- **影响**: 轻度——玩家通过 GUI 点击按钮可正常推进
- **建议**: 检查 storyChoose 索引映射是否将"临战准备"状态面板计入了选项序列

## 二、【专题】墨蛟 BOSS 演出分析（维度 E 重点）

> **用户特别要求**：「墨蛟这种妖兽BOSS适当增加压迫感，不仅仅是立绘变大，还应该做出该有的演出等等」

### 当前状态

墨蛟 BOSS 战的演出**严重欠缺压迫感**，具体表现：

| 演出要素 | 当前状态 | 问题 |
|---------|---------|------|
| **入场演出** | ❌ 无 | 直接进入战斗界面，无墨蛟苏醒/出水/咆哮的过场动画 |
| **BOSS 立绘** | 仅为白色蛟龙 sprite | 尺寸与普通敌人接近，**未体现"巨兽"体量**。缺少独立的 BOSS 级立绘/battler |
| **背景切换** | ❌ 无 | 战场背景沿用通用血色禁地 CG，未切换为洞窟深处/水潭巢穴专属背景 |
| **屏幕特效** | ❌ 无 | 无屏幕震动、无镜头推拉、无暗角/压迫感滤镜 |
| **音效/BGM** | ❌ 无变化 | 未切换 BOSS 战专属 BGM，无墨蛟咆哮/水流激荡音效 |
| **攻击预告** | ✅ 有 | 黄字提示"「横扫」将席卷第21~23步（约20伤）"、"「蚀骨」锁定而来（约26伤）"——**这是目前唯一的压迫感来源** |
| **phase 切换** | ❌ 无 | 270 HP 全程同一模式，无 50%/25% 生命值时的狂暴化/技能变化 |
| **击杀演出** | 未测试 | HP=1 进战，3 回合后阵亡，未能击杀墨蛟 |

### 改进建议

1. **入场 cutscene**：墨蛟从深潭中升起 → 镜头拉远显示体型 → 咆哮震动（`Engine.screenShake()`） → 战斗开始
2. **专属 battler**：墨蛟应占据战场右侧 60% 空间，蛇身盘绕，体现"巨兽"压迫
3. **专属背景**：切换为洞窟深潭场景（暗绿色水面 + 岩壁 + 磷光），区别于通用禁地红调
4. **屏幕特效**：墨蛟攻击时全屏震动（`Engine.screenShake()`）；HP 低于 50% 时屏幕边缘暗角加重
5. **BOSS 战 BGM**：切换为低沉鼓点 + 水流涌动的紧张配乐
6. **Phase 机制**：HP 50% 时咆哮 + 全屏震动 + 技能强化（横扫范围扩大、蚀骨伤害提升）
7. **攻击演出**：水矢攻击时有水花粒子特效；横扫时有尾巴横扫的动画帧

## 三、战斗系统观察（维度 F 补充）

### 三动行动系统

战斗每回合提供三种行动点：
- **出手×1**：主动攻击（御剑刺 10 伤、火蛇符 22 伤等）
- **瞬发×1**：即时法术（长寒护体 +22 护盾、长春吐纳 +15 HP、凝息回元恢复灵力）
- **身法×1**：移动/闪避

这套系统**设计出色**——每回合有 3 次有意义的决策，且互不冲突（攻击+护盾+走位可同回合执行）。

### 战术提示系统

黄字警告条（如「横扫」将席卷第21~23步）是**血色禁地战斗的亮点**：
- 明确告知攻击类型、范围、伤害
- 给出应对建议（"拉出区间，或硬扛"/"护体法术可挡"）
- 使战斗从纯数值对抗提升为位置+技能的策略博弈

### 商言砖 / 蒋古骥

- 蒋古骥（NPC 同伴）HP=96，全程辅助战斗
- 商言砖（法宝）可用但未测试效果
- 同伴系统为长期 BOSS 战提供了存活空间，但同伴 AI 行为不透明（不知道同伴做了什么）

## 四、血色禁地 Bug 清单（续）

### P2 — 封岳巡逻 soft-lock
- **现象**: 击败封岳后 HP=1，巡逻立刻刷新。二次遭遇必死，无法推进
- **复现**: 击败封岳 → 向 zhongtan 方向移动 → 封岳巡逻在 zhongtan 再次拦截
- **影响**: 中等——可通过等待 patrolIdx 轮转 4 次绕路解决，但新手玩家大概率卡死
- **建议**: 封岳被击败后设置 cooldown 或标记 `fengyue_defeated` flag，至少 10 clock 内不再触发

### P3 — 战斗 HP 与全局 State 不同步
- **现象**: 战斗中 `长春吐纳` 回血后 HP=16/100，但侧边栏人物面板仍显示 `气血1`
- **复现**: 进入墨蛟战斗 → 使用长春吐纳 → 观察侧边栏
- **影响**: 轻度——仅影响显示，不影响实际战斗逻辑
- **建议**: 战斗回合结束后同步 `State.data.hp = combat.player.hp`

### P3 — 洞窟缺少进度/小地图
- **现象**: 27 格洞窟无法得知当前位置或剩余格数
- **影响**: 轻度——降低探索体验
- **建议**: 底部添加 `pos/total` 进度条（如 "21/27"）

## 七、结论（更新）

黄枫谷篇的叙事质量极高，血色禁地的舆图探索系统设计精巧。但**深入禁地后的体验存在三个关键问题**：

1. **封岳巡逻 soft-lock（P2）**：击败后立即重刷，HP=1 必死
2. **墨蛟演出严重不足（P1 体验）**：作为本章最终 BOSS，缺少入场动画、专属背景、屏幕震动、Phase 切换等所有 BOSS 级演出。当前的墨蛟战和打一只普通小怪**无任何视觉差异**，完全不匹配"妖兽 BOSS"的定位
3. **难度曲线断层**：封岳→墨蛟之间无回血机会，导致玩家以 HP=1 进入 270HP 的 BOSS 战

修复优先级：**墨蛟演出 > 封岳 soft-lock > 洞窟进度条**
