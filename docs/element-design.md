# 克制系统设计（灵技 × 道基）

> 2026-06-11 用户裁决定稿：**克制设计成"灵技克制主修功法"**，同一套系统要能复用到
> 后期"韩立战玄骨"（辟邪神雷克鬼魔之物）。凡人武学不参与克制轴
> （99.99% 是修仙者争斗，武学只在阴冥之地等极少场合回归）。
> 本档案是 multiply-design.md 律一的第一个完整落地：五行引擎 v1。

---

## 一、核心模型：你打的不是肉身，是道基

修仙逻辑：护体灵力是主修功法所化。火法烧的不是金光上人的皮肉，
是他金刚诀凝出的护体灵光——**灵技行属 克 对方主修功法行属，事半功倍**。

```
攻击方：灵技 elem（=该法术的主灵气消耗系——你花什么气，招就是什么行，零新概念）
防御方：道基 elem（修士=主修功法 attr；妖兽=妖气行属；凡人=无，不参与）
```

### 判定表

| 关系 | 系数 | 飘字 | 确认直觉文案（首次） |
|------|------|------|----------------------|
| 灵技克道基 | ×1.25 | 克制！ | "火气灼金，他的护体灵光黯了一分。" |
| 灵技被道基克 | ×0.8 | 相抵 | "金气锐利，你的木灵之力难近其身。" |
| 任一方无行属 | ×1.0 | — | 凡人/武学不参与（修行者之间的语言） |

五行环：金克木 → 木克土 → 土克水 → 水克火 → 火克金。

**对称生效**：敌人的灵技同样克玩家道基。金光上人（金）天克长春功（木）——
动漫一致感：这一战韩立本就该靠毒、暗器与算计赢，正面斗法是找死。

## 二、特攻层（nature × slays）：辟邪神雷的提前布线

五行环之外的第二层克制：**物性特攻**。为后期"韩立能战玄骨"预留的一等公民字段。

```
敌方 nature：ghost（鬼魂/元神）| corpse（尸傀）| beast（妖兽）| 无（活人）
灵技 slays：{ nature: 倍率 } —— 特攻表
灵技/毒的物性无效：尸鬼无血脉经络，毒理不通
```

### 本篇兑现（七玄门试验田）

| 规则 | 修仙常识（零教学） | 改动 |
|------|--------------------|------|
| 镇魂 slays ghost ×1.5 | 神魂镇压本就是元神克星 | 余子童元神战的系统语言化 |
| 毒对 corpse/ghost 无效 | 尸无血脉、魂无肉身，毒往哪走？ | **一致感修复**：现在毒能毒死尸傀是 bug |
| 刀剑暗器对 ghost 无效 | 已有 soulOnly 实现 ✓ | 语义并入 nature=ghost |

### 后期复用（设计即兑现承诺）

- 辟邪神雷：slays ghost/corpse/demon ×1.5+ —— 韩立战玄骨的系统依据
- 青元剑罡：克魔气；佛门功法：克魔功 —— 全是同一张 slays 表，不加新系统

## 三、与情报面纱相乘（做功课的第二层回报）

行属情报是**挣来的**，不白给：

| 情报态 | 战斗中敌方行徽 | 来源 |
|--------|----------------|------|
| 未知 | 不显示 | 初遇 |
| 已揭示 | 显示行徽+克制关系提示 | ① 交手中克制/被克首次触发（打了就懂）② L2 买底细（开战即知）③ 异闻传闻点明（"金行妖王，木功修士慎入"） |

兑现链：**情报（知其功法行属）→ 集市备符（花钱备克制手段）→ 战斗兑现（×1.25）**
——情报 × 经济 × 克制三系统相乘。

## 四、符箓：把克制轴从"看脸"变成"可经营"

韩立四灵根缺土少火，本命法术全在木/水系——没有火技，金行强敌岂不是无解？
**答案是符箓**（修仙界通货，动漫考据：低阶符箓在凡人修仙界广泛流通）：

- 符箓 = 一次性法术底牌（**复用 pouch 底牌系统**，与毒草/暗器同区）
- 火灵符（elem 火，1 灵气甩出）→ 克金：金光上人/金行妖王的做功课答案
- 金灵符（elem 金）→ 克木：木行妖物的对策
- 渠道：集镇市场稀货 + 小算盘门路（贵——准备难，收益大）
- build 意义：灵根决定你的本命行属盘，**符箓是花钱补短板**——
  穷人靠本命，富人靠符箓，这就是修仙经济学。

## 六、平衡与校准

- 系数温和（×1.25 / ×0.8 / 特攻 ×1.5 / 毒对尸鬼 ×0），蒙特卡洛全量重跑。
- 金光上人战因对称克制变难（他金技对韩立 ×1.25）→ 用其 hp/atk 微调补偿，
  目标胜率区间不变（备毒备符做功课后 55~70%）。
- 散修战玩家用木技 ×1.25 变易 → 散修 hp 微上调对冲。
- 校准锚点照旧 encounter.bal.js / showdown.bal.js / tier.bal.js。

## 七、不做什么（边界）

- 场景行属（溪畔水旺）：留给黄枫谷新地图原生设计，本棒不做。
- 武学物性轴：不做（用户裁决：阴冥之地再议）。
- 敌人之间的克制（敌 vs 敌）：无此场景，不做。
- 克制表 UI 教学页：**永不做**——五行生克是文化常识（零教学红线），
  战斗内飘字+首次确认文案足矣。
