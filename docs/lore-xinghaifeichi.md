# 星海飞驰篇 · 考据档案

> **动漫年番2（第73~124集）为唯一剧情与情感锚点。** 原著只补大件/功法数值机制。
> 本档是 `xinghaifeichi-design.md` 的考据支撑——逐集节点、人物命途、大件来源、势力结构。
> **红线：先查档再搜索后设计，绝不凭模型记忆直接写设定。**

## 一、分集概要（73~124集·动漫脊柱）

### 序章（73~76集·2023-07-30首播）

- **73集**：韩立在海猿岛修炼四年，曲魂成功凝结煞丹。潜回小寰岛，意外得噬金虫幼体。
- **74~76集**：韩立定居天星城，遇见紫灵（汪凝长大），租借洞府，开始闭关。培育金雷竹，研究炼器与阵法。

### 正篇·蝎岛线（77~84集）

- **77~78集**：韩立将外星海妖兽材料交易给妙音门。紫灵邀请韩立担任妙音门名义长老。
- **79~81集**：蝎岛之战。妙音门结丹强者进攻蝎岛隐煞门据点。赵峥、符长老为妙音门客卿长老但暗中勾结极阴岛，紫灵联手隐煞门孙门主清除叛徒（80集）。乌丑（极阴祖师之徒·动画改编自原著孙子；极阴以附身/控制方式借乌丑行事）现身救援赵峥，紫灵真正目标=引出乌丑/极阴岛势力（81集）。
- **82集**：韩立杀赵峥后被结丹中期天都炼傀追杀。
- **83集**：极阴活捉孙门主，韩立和曲魂遁入海底躲避一月。
- **84集**：韩立受紫灵邀请任妙音门客卿长老，获天雷竹（三大神木之一）。紫灵向金魁交代蝎岛之战，金魁赐下虚天残图。韩立为渡大衍诀第三层红尘劫，准备入世。

### 正篇·红尘劫（85~87集）

- **85~87集**：韩立在天星城凡间开张"青竹小轩"店铺，入世渡红尘劫二十四年。卖符箓丹药给凡人/低阶修士，看人间疾苦。渡劫后炼制七十二口青竹蜂云剑作为本命法宝。

### 正篇·古修士洞府+玄骨（88~94集）

- **88~91集**：受金青邀请前往探索古修士遗址。与石蝶合力研究破阵。遭遇铁火蚁等妖兽。
- **92集**：石蝶香消，老胡玉殒——副本中的牺牲。
- **93集**：鬼骷髅现身，金青被秒杀。曲魂被玄骨上人控制，意识被夺。玄骨夺舍曲魂身躯，重获肉身。玄骨本名萧诧，是极阴祖师和极炫的师父，生前元婴后期修士，被徒弟陷害封印于此，改修鬼道后实力大幅下降。
- **94集**：玄骨（萧诧）忌惮雷神之威，与韩立各自离去。韩立跟随虚天残图指示进入虚天殿。**魔道三元婴登场**：极阴祖师（元婴初期顶峰·极阴岛岛主）、蛮胡子（元婴中期·魔道最强之一）、青易居士（元婴初期·南鹤岛散修）三位魔道元婴修士入场。

### 正篇·虚天殿外殿三关（95~110集）

- **95~98集**：韩立进入外殿第一关**鬼冤之地**，与紫灵一同闯关。结丹初期韩立对战阴灵兽/鬼王，使用辟邪神雷灭杀，为紫灵和元瑶解围。
- **99~104集**：韩立跟着玄骨（萧诧）寻找九曲灵参。进入第二关**冰火道**（分玄晶道与熔岩路）。**金魁暗中操控禁制增加难度**：熔岩路出现本不该有的铁火蚁，玄晶道出现银光鼠。噬金虫大战铁火蚁（奇虫榜第9名），大获全胜。青易居士凭青冥针斩杀银光鼠，万天明秒杀铁火蚁。
- **102集**：**极阴强收韩立为徒**——极阴发现韩立拥有血玉蜘蛛（可拉虚天鼎），与青易居士**争抢**收韩立为徒。玄骨（萧诧）建议韩立拜极阴（极阴更危险·不宜结仇）。韩立拜入极阴门下。两人都不是真心收徒，事后必定要干掉韩立夺血玉蜘蛛。玄骨帮韩立取得九曲灵参（可大幅提高进阶元婴几率）。
- **106集**：冰火道中韩立从铁火蚁群中救下元瑶。元瑶提出以身相许（被拒）、青火雷×3（魔道青阳门秘制火雷·每枚威力相当于元婴修士一击·被拒）。韩立表示对啼魂兽感兴趣，元瑶将**啼魂兽+鸣魂珠**一起给韩立。鸣魂珠=控制啼魂兽的关键，不炼化只能下简单命令。韩立带元瑶通过冰火道。
- **107~108集**：**三元婴赠宝**——极阴赠婆罗珠（安神定魂·过极妙幻境用）、青易居士赠青冥针符宝（攻击型符宝·防身用）、蛮胡子赠皇鳞甲（成名防御法宝·保命用）。蛮胡子此前在冰火道已先赠宝珠。三元婴各怀鬼胎拉拢韩立，三件宝物皆为利用。
- **107~108集**：**宝光阁**——冰火道后、极妙幻境前的奖励环节。四条路分别通向宝物/功法/丹药/直通第三关。韩立以噬金虫切断灵力进入能量罩，取五行环+血色披风等古宝。
- **109~110集**：韩立进入第三关**极妙幻境**，凭婆罗珠通过心性考验（动画原创回溯人生选择），进入内殿虚天塔。

### 正篇·虚天殿内殿·夺鼎·终战（111~118集）

- **111集**：万天明（万法门）用金丝蚕取虚天鼎失败，假装愤然离去（金魁暗中分化正魔两派·赐天机造物仪）。**正道取鼎失败**。**寒骊台破阵**——蛮胡子/极阴/青易居士分头找方位破阵，韩立跟随乌丑找第四方位·戏耍乌丑（对阵法的研究）·发现夹层喜提虚天殿地图。地图=后续逃命关键。
- **112集**：魔道三元婴合作，用韩立的血玉蜘蛛拉虚天鼎成功。**魔道取鼎成功**。万天明一行人闯入，双方大战。血玉蜘蛛被星宫长老盯上出手。
- **113集**：元婴大战（特效最强一集）。**皇鳞甲救韩立一命**（元婴修士一击不死）。
- **114集**：虚天鼎中爆出补天丹，元婴6人竞相争夺。
- **115集**：元婴心理战·勾心斗角博弈。玄骨发难杀乌丑（极阴线内部清算）。
- **116集**：韩立在元婴混战中浑水摸鱼，**智取虚天鼎**。
- **117集**：韩立与玄骨反目→玄骨融合修罗圣火但不稳定（结丹后期修为无法驾驭）→韩立利用漏洞让粘有修罗圣火的飞剑刺向玄骨再收回→玄骨粘上修罗圣火灰飞烟灭→修罗圣火瓦解→乾蓝冰焰汇聚成冰珠→韩立收虚天鼎+乾蓝冰焰→啼魂兽吸出金雷竹飞箭中残魂→韩立命啼魂吸收→玄骨下线。得虚天鼎、乾蓝珠（乾蓝冰焰）、玄阴经、狼首玉如意（银月）。
- **118集**：韩立利用传送阵从内殿传送至夹层，遇元瑶。元瑶在虚天殿获得养魂木，韩立要走一部分做成念珠同婆罗珠一同使用。虚天殿结束。

### 正篇·出殿·章末（119~124集）

- **119~120集**：韩立想离开南明岛，碰上温天仁（六道极圣之徒）看守离岛。韩立冒充青易居士徒弟蒙混过关（因青易曾赠青冥针符宝·有信物）。途中救下星宫双圣之女凌玉灵。
- **121~122集**：乱星海大战正式打响。极阴岛和万法门在奇渊岛打起来。
- **123集**：韩立在偏僻岛屿开辟洞府，整理战利品发现玄骨留下的完整版玄阴诀。岛屿外碰上妖兽化形及人类修士斩杀妖兽的场景。
- **124集**（星海飞驰最终回）：韩立闭关服下补天丹。四大势力（极阴/碧云门/万法门/星宫）追杀韩立。韩立轻松斩杀海王兽，得知有人假扮自己。韩立躲回岛屿闭关，准备二三十年不出。

## 三、大件来源考据

### 3.1 青竹蜂云剑

- **动漫来源**：第84集紫灵给天雷竹→第85~87集红尘劫渡过后用小绿瓶催熟的万年金雷竹炼制72口飞剑。
- **原著机制**（辅证）：天雷竹=三大神木之一（白雷竹/蓝雷竹/金雷竹年份分级）。小绿液催熟→6根万年金雷竹→72口青竹蜂云剑。
- **银月**（动漫核定）：虚天殿收获之一，以狼首玉如意形态获得（非炼剑时诞生）。
- **游戏化**：大件四问见 `xinghaifeichi-design.md` §3.3。战斗技已预实装（`SPELLS.qingzhu_jian` + `shenlei_fujian` + `shenlei_pi`，见 `fabao-design-template.md` §六 范例A）。

### 3.2 虚天鼎

- **动漫来源**：第112集韩立用血玉蜘蛛拉虚天鼎→第116集韩立在元婴混战中浑水摸鱼智取虚天鼎。
- **原著机制**（辅证）：通天灵宝·虚天殿镇殿之宝。内含补天丹+乾蓝冰焰（乾蓝珠守护）。后续需修习通宝决方可完全炼化。
- **游戏化**：大件四问见 `xinghaifeichi-design.md` §3.4。

### 3.3 乾蓝冰焰/乾蓝珠

- **动漫来源**：第117集玄骨终战后，修罗圣火瓦解，乾蓝冰焰汇聚成冰珠，韩立收取。
- **原著机制**（辅证）：至阴寒焰·虚天鼎中守护寒焰。韩立约252岁完全炼化，可化为紫罗极火（与辟邪神雷并列为韩立两大杀招）。
- **游戏化**：远期大件·本篇只入手不炼化。

### 3.4 啼魂兽

- **动漫来源**：第106集冰火道中韩立从铁火蚁群中救下元瑶。元瑶提出以身相许（被拒）、青火雷×3（被拒），韩立表示对啼魂兽感兴趣。元瑶将啼魂兽+鸣魂珠一起给韩立。
- **原著机制**（辅证）：天生克鬼物（吞噬精魂）。鸣魂珠=控制啼魂兽的关键法器，不炼化只能下简单命令。韩立杀玄骨时啼魂的作用=吸出金雷竹飞箭中残魂+吞食残魂（非正面攻击手段）。
- **游戏化**：SideUnit + slays 表（克鬼物×1.5~2.0）。

### 3.5 补天丹

- **动漫来源**：第114集虚天鼎中爆出→第124集韩立外星海闭关服下。
- **原著机制**（辅证）：提升寿元+改善灵根。韩立服后灵根提升（缺金属性·动漫细节）。
- **游戏化**：服食=灵根提升→修炼速度加快。flag `butian_dan_taken`。

### 3.6 玄阴经/玄阴诀

- **动漫来源**：第117~118集杀玄骨后得遗物→第123集整理战利品发现完整版。
- **原著机制**（辅证）：魔道功法·玄骨上人遗留。含秘术（部分与第二元婴/法体双修相关）。
- **游戏化**：外星海闭关修炼内容·远期Build路线前置。

### 3.7 养魂木

- **动漫来源**：第118集虚天殿内殿夹层遇元瑶。元瑶在虚天殿获得养魂木，韩立要走一部分做成念珠同婆罗珠一同使用。
- **原著机制**（辅证）：养魂木=可温养神魂之物。元瑶为复活妍丽所需。
- **游戏化**：与元瑶分得·因果账本种因（`xutian_yuanyao_deal`）。

### 3.8 九曲灵参

- **动漫来源**：第95~99集虚天殿外殿与萧诧协作获取。
- **原著机制**（辅证）：可大幅提高进阶元婴几率。
- **游戏化**：远期大件·本篇只入手。

## 五、章末钩子（下一篇＝外海风云篇）

- **四大势力追杀**：极阴/碧云门/万法门/星宫四路追杀韩立（虚天鼎消息泄露）。
