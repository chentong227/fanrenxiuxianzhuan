# 离门远行章 · 考据与详案（旅途章首跑）

> 2026-06-11 动漫考据核定（风起天南 7~9 集 + 多源交叉）。红线：动漫版为唯一情感锚点。
> 章节类型：旅途章（world-architecture §4.1）——大陆层+旅途卷轴+因果账本的验收场。
> 起点：七玄门篇通关（arc1_complete）；终点：凭升仙令入黄枫谷（衔接驻地章）。
> **制作度（用户裁决 2026-06-11）：细节不是全做，但要有世界的活感**——
> 名场面与抉择做足（账本级内容），其余以氛围笔触带活（轻行动+风闻+人间气），
> 不做全细节复刻（每站不超过三幕主线+一两个轻量自由行动）。

## 一、考据定稿（每条已核）

### 站一 · 嘉元城墨府（岚州第一城）【v44 考据修正版】
- 墨大夫本名**墨居仁**，岚州三霸之一**惊蛟会**创办人，滞留七玄门图谋夺舍。
  遗书逼韩立去墨家：**解寒毒（暖阳宝玉）+ 妥善安顿墨家**。
- **考据修正（用户核定）**：动漫线嘉元城**没有欧阳飞天之战**（独霸山庄是原著线）。
  动漫里墨府之敌是**五色门**——韩立在**燕家堡**（特别篇）重逢墨彩环得知墨府之难，
  **京城篇**（魔道争锋 32~36 话）遇五色门易容之事、墨彩环身死，
  36 话**杀五色门主（王管事，黑煞教邪教中人）为墨彩环报仇**——
  "谢谢你，出现在我微不足道的生命里"（33 话）。**严格按动漫篇章编排，不前移。**
- 嘉元城站的危机感只做氛围：宵小夜探（轻事件）→ 引出"墨府需要一道不走的影子"
  → **曲魂留府为固定剧情**（动漫线+铺曲魂远线：再别天南被御灵宗结丹夺舍者占据，
  韩立胜后得**奇虫榜玉简**——噬金虫的知识源）。
- 动漫**三女合一**：墨府只有**墨彩环**。
- 流程（已实装 v43/v44）：投信（彩环骗萦香丸）→ 宵小夜探 → 嫁妆赠玉
  （"我不成亲，便不需要嫁妆"）→ 凡人之问 → 曲魂留府 → 太南小会线索。
- 情感核：墨彩环之问——**"凡人不能修仙吗？"**（韩立记了一生）。
- 后日谈（按动漫篇章兑现，本章只种因）：燕家堡重逢（知墨府之难）→
  京城篇报仇（杀五色门主）；墨彩环终身等候、凡尘老去——仙界篇暗示紫灵为其转世。

### 站二 · 回乡（青牛镇五里沟）
- 顺序考据：嘉元城事了 → **路遇万小山结伴同行** → "决定在远行之前回家看看，
  做最后的告别" → 回村。
- 内容：拜别父母（此去修仙路远，归期无定）；小妹亲事（心魔伏笔）；
  留银安家。已实装的探家事件（v41）升级为本章正式节点。

### 站三 · 太南小会（岚州最南，广贵城西四十里太南山）
- **万小山**：修仙家族出身的散修，心善不谙世事——为韩立讲解修仙常识
  （修仙界新手引导的剧情化身）。
- 集市内容（考据）：以丹药换购**《长春功》后篇全本**（韩立激动；卖家"你给多了，
  我们不占便宜"）、咒书、下阶符纸、**菡云芝的制符笔**、遮挡灵气的残宝
  （可配合小绿瓶掩息）。
- **青纹道人**：同行的"古灵精怪神偷"吴九指随行——青纹有阴谋被韩立揭穿后离开太南山
  （二人后来投黑煞教，越京篇再登场——长线伏笔，本章只埋）。
- 初见**菡云芝**（御灵宗女修，亲切）；陈巧倩在小会**惊鸿一瞥**（不交名——
  正式结识留给黄枫谷师姐线，兼容两源）。

### 站四 · 升仙大会（七派联合收徒）
- 灵根测试：韩立**四属性伪灵根，未通过**（当众落选的屈辱）。
- 台上注意到**结丹女修南宫婉**（远观，传说态登场——三态模型第一格）。
- **万小山之死**：大会后，韩立在森林发现万小山被三名散修谋财追杀致死——
  **韩立灭杀其二**（复仇名场面；其一逃逸）。
- 凭**升仙令**入黄枫谷（落选者的底牌——"考不上，但我有保送名额"）。

## 二、游戏化设计

### 节点与锚（锚-帆模型）
| 节点 | 锚型 | 内容 |
|------|------|------|
| 嘉元城 | 地点锚（主线） | 墨府三幕：投信入府 → 独霸山庄上门（战斗：欧阳飞天）→ 宝玉解毒+曲魂抉择 |
| 青牛镇 | 地点锚 | 拜别爹娘（v41 探家升级：告别版文案+小妹亲事伏笔+心魔种子） |
| 太南谷 | 地点锚（限时：小会有会期） | 修仙集市（长春功后篇/符纸/制符笔/残宝）+万小山引导+青纹阴谋 |
| 升仙大会 | 日历锚（小会后自动排期） | 灵根测试演出（注定落选）→ 万小山之死与复仇 → 亮升仙令入谷 |

### 关键抉择与账本
1. **曲魂去留**（嘉元城尾声）：
   - 留墨府护卫（动漫线）：失去侧位单位；账本 `quhun_left_mo`——
     远雷：燕家堡重逢墨彩环时墨府安然+关系深厚；五色门之祸有曲魂可挡一阵。
   - 带走（玩家私心）：保留侧位；账本 `quhun_kept`——远雷：墨府之祸更重（负因也是内容）。
2. **万小山的善意**（太南小会）：他热心讲解、邀你同游——多与他往来（对话/同逛集市）
   写 `wan_friend`，复仇一幕的情感重量随之变化（远雷点名："他曾把第一张符纸让给你。"）
3. **复仇程度**（升仙大会后）：灭二人后，第三人跪地求饶——杀（果决+煞名）/
   放（留患？长线伏笔）——账本分支。

### 战斗
- 欧阳飞天（独霸山庄庄主，凡俗武人巅峰+粗浅练气？考据：凡俗三霸=凡人武林，
  但墨居仁会仙法——定为"粗通吐纳的武人"（qiLayer 1，elem 无），
  战斗定位：贾天龙级别强化版+护院群战（waves）。
- 追杀散修 ×3（升仙大会后）：练气 2~3 层散修——玩家此时约练气 6~7 层，
  优势局（复仇就该赢得干脆——爽文契约），看点在情感不在难度。
