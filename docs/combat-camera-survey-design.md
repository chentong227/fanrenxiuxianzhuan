# 战斗导演镜头 · 全景观阵设计

> 2026-06。用户裁决：**大战场是刻意的，不缩战场、不缩间距**。前期"敌人慢慢走近、
> 玩家等回合"本质是**给主角排兵布阵留窗口**（布阵法／摆傀儡／设伏／蓄势）——只是
> 前期剧情还没有这些系统内容，所以暂时显得空等。真正要解决的只是手机端"看不全战场"
> 的可读性：靠**导演镜头/全景预览**（拉远看全局），而非改战场尺寸。

---

## 一、设计目标

1. **保住"大战场"气势**——W=15 的宽轴、玩家与敌人初始相隔很远、敌人逐回合压近，
   这套"两军对垒、徐徐接战"的张力是刻意的，**不动**。
2. **给玩家随时看清全局的能力**——一键"观阵"，相机拉到容纳全战场，
   我方/敌方/阵旗/傀儡/热点一屏尽收。看完再点回到跟随态。
3. **为后续排兵布阵系统铺路**——观阵态下落阵/摆傀儡/择远点更直观（一眼选准远处的格）。

## 二、与现有相机的关系（不破坏跟随态）

现有统一相机（`js/ui.js` renderCombat 内，v89）：
- 宽轴 `c.W > 13` 时启用"宽死区跟随"：`V=13` 格视野，cam 跟玩家+锁定目标，宽死区防抖。
- 一组镜头数（zoom/lift/cam）同帧派发世界层/中景/远景，近缩多远缩少=真透视。
- 参数快照存 `this._camParts`（fx 分拍演出 _camPeek 沿用）。

**观阵态 = 在此之上叠加的临时取景**，不改跟随态默认逻辑：
- 进入观阵：`V' = c.W`（视野=全战场），`zoom' = 容纳缩放`（按 W 与容器宽算，越宽缩越多，
  下限保护避免人物过小到看不清），`cam' = 0`（从最左铺到最右）。
- 退出观阵：清除临时态，下一次 renderCombat 用回跟随态的 V/zoom/cam。
- 观阵是**纯视觉取景切换**，不耗回合、不改任何战斗状态。

## 三、交互

| 入口 | 行为 |
|------|------|
| 操作台「观阵 ◉」按钮（战斗 console 行动区新增） | 切观阵态（全景）↔ 跟随态（再点收回） |
| 观阵态下点任意单位/格 | 该次点选照常生效（择敌/落阵），并自动收回跟随态 |
| 落阵/摆傀儡类法术上膛时 | 可自动切观阵态（择地一目了然）——保留位，后续阵法系统接 |

## 四、实现要点（落地清单）

1. **状态位**：`UI._surveyMode`（true=观阵）。renderCombat 读它决定 V/zoom/cam。
2. **V/zoom 计算**（renderCombat 宽轴分支内）：
   ```
   if (UI._surveyMode) {
     V = c.W;                                  // 全战场入画
     // 容纳缩放：屏宽 / (W 个格 × 单格目标宽)，并夹在 [0.5, 跟随zoom] 之间
     zoom = clamp(surveyFit(c.W), 0.5, followZoom);
     cam = 0;                                  // 从最左
   }
   ```
   单格目标宽与容器宽实测（fieldEl 宽 / V），保证 W 格恰好铺满一屏。
3. **按钮**：`index.html` combat-actions 加 `<button id="combat-survey">观阵</button>`；
   `main.js` 绑 `UI.toggleSurvey()`；`UI.toggleSurvey()` 翻 `_surveyMode` + renderCombat。
4. **自动收回**：armSpell 择敌/择地的点选回调里，若 `_surveyMode` 则置 false（点完回跟随）。
5. **HUD 提示**：观阵态在战场角落显一行"观阵 · 全景"，并把缩放标识出来（可选）。
6. **性能**：观阵=一次 transform 切换，无新增每帧开销；手机端注意 zoom 过小时立绘别糊
   （下限 0.5 兜底）。

## 五、排兵布阵窗口（用户本意 · 后续篇章兑现）

"敌人慢慢压近的前几回合"= 战略准备期。后续篇章补齐这些**布置手段**后，等待回合自然有价值：
- **阵法**：开战前/前几回合落阵旗，敌人踏入阵中受控/受伤（择地→观阵态选远格最顺）。
- **傀儡**：布尸傀/灵宠到前排挡线、卡位、先手缠住压近的敌人。
- **设伏/蓄势**：埋符、蓄力、布陷阱——用接战前的空窗换开战后的爆发。
- **地形/热点**：战场预置的采集点/掩体/机关（箱庭探索已有 hotspots，可引入战斗）。

→ 这些是后续 build 系统（剑道/丹道/阵法三路）落地时的内容，本设计先把"看得清全战场"
的相机基座做好，布阵系统来了即用。

## 六、验收

- W=15 双敌战：点「观阵」→ 两个敌人 + 韩立 + 全场一屏可见；再点 → 回跟随态。
- 不影响跟随态默认行为（不点观阵=和现在完全一致）。
- `node test/combat.test.js` + `node test/scale.bal.js` 全绿。
- iPhone 14 Pro Max 视口：观阵态人物不糊、布局不溢出。
