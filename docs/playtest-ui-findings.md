## ⬜ 待定（需用户拍板，多涉及系统级或美术）

### 1. 多敌宽战场·手机端看不全战场（可读性）——✅ 已定方向：导演镜头全景预览
- **现象**：万小山复仇战（W=15，玩家 pos1 vs 双散修 pos13/14），手机视口 V=13 格，
  开局看不全敌人（pos14 的敌人在屏幕外）；前 ~10 回合敌人在画外慢慢接近，玩家够不着也看不见。
- **⚠ 用户裁决（2026-06，重要）**：**大战场是刻意设计，不缩战场、不缩间距**。
  - 前期"敌人慢慢走近、玩家等回合"**本质是为玩家排兵布阵留窗口**（布阵法 / 摆傀儡 / 设伏 / 蓄势）。
  - 只是**前期剧情还没有阵法/傀儡这些系统内容**，所以现在显得"空等"。后续篇章补上这些
    布置手段后，等待回合 = 战略准备期，价值自然显现。
  - **真正要解决的只是"看不全战场"的可读性**——靠**导演镜头/全景预览**（拉远看全局），
    不靠改战场尺寸。
- **方案：战斗内「观阵」全景预览**（保大战场 + 解决看不全）：
  - 战斗操作台加一个「观阵 ◉」按钮（或长按战场空白）：切到**全景态**——
    相机拉到 V=W（容纳所有单位）+ 自动缩放，让整个战场（我方/敌方/阵旗/傀儡/热点）一屏可见。
  - 全景态只供"看清局势 + 落阵/布置点选"，不强制；再点一次（或点单位/格）回到跟随态。
  - 复用现有统一相机（_camParts / cam / zoom），只是把 V 临时设为 W、zoom 取容纳缩放。
  - 落阵/布傀儡的择地（armSpell cell 模式）在全景态下更直观——一眼选远点。
- **注意**：相机是 depth-design.md 精调系统，改前读 §六/§七；新增"全景态"为叠加层，
  不动跟随态默认行为；改后跑 combat.test.js + scale.bal.js。
- **落地见**：`docs/combat-camera-survey-design.md`（导演镜头全景预览设计）。
