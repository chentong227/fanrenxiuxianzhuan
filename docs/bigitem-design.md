## 一、大件的本质：不是奖品，是节点

**范式（青竹蜂云剑标准）**：

```
听闻（惦记产生）
  → 获取（剧情赠予/机缘/锻造，忠于动漫考据）
  → 开轴（大件自带新的可肝成长轴：控剑数随神识增长 1→9→36→72）
  → 轴上里程碑（每一格都是嗑瓜子：神识+N → 多控一把剑 → 战斗肉眼可见变强）
  → 轴尽头 = 下一个大件的入口（72剑齐御 → 解锁大庚剑阵的"路子"）
```

四段缺一不可。**拿到不是终点，是新一轮肝的起点；肝到头不是空虚，是下一个惦记。**
这是嗑瓜子正反馈（轴上每格）与质变时刻（节点兑现）的缝合点，大件链条因此成为永动机。

## 二、大件设计四问（每个大件立项前必答）

1. **它开什么轴？**（控剑数/毒性纯度/剑意层数/灵宠成长……轴=可肝维度）
2. **轴上多少格、每格喂什么？**（神识/材料/实战次数——格子明牌，际遇栏可见进度）
3. **轴尽头通向哪？**（下一个大件的入口，或一个扬名时刻）
4. **落在战力公式哪个区？**（power-design：加区=数值段位 / 特区=特攻·行动经济·速度·免死）

答不全四问的大件不立项——避免做成"背包里多一行字"的死奖品。

## 三、人界篇大件链总图（蓝图框架，逐项以动漫版考据后定稿）

> 考据红线：动漫版为唯一基准；下表含用户记忆与待核实项，开工各篇前逐集核对，

### 七玄门篇（现行）
- 《长春功》（剧情授予）→ 开"过目不忘"暗轴（习功法/辨药效率）
- 《眨眼剑法》（厉飞雨赠）→ 开"剑意"轴（实战积累）→ 大成解锁「连环眨眼」→ 通向黄枫谷剑修路子
- 小绿瓶（机缘）→ 开"催熟"轴（药圃经营）→ 通向自炼丹药的一切根基
- 曲魂（收服铁奴）→ 傀儡/底牌原型 → 通向后篇傀儡路子

### 黄枫谷篇
- 筑基丹 ×N（让丹屈辱起点 → 血色禁地取药 → 地火之屋自炼）→ 三段式突破超大件
- 《青元剑诀》（筑基后李化元授）→ 剑修主轴开启
- 玉蜘蛛（灵宠，名称/获取以动漫为准）→ 灵宠养成轴
- 青竹蜂云剑炼制之法 → 锻造链开启（材料分步收集，每步有剧情）

### 乱星海衔接与乱星海篇

- 辟邪神雷（特攻区大件：克魔功）→ 与蜂云剑双底牌 → 以下克上打玄骨（爽点验收战）
- 金雷竹 → 风雷翅（速度均势区大件：协助紫灵九死一生任务线，用户钦点的获取体验范本）

### 重返天南篇
- 大庚剑阵（控剑轴尽头兑现）

### 妖材→法宝链（2026-06-12 用户裁决：妖兽掉"材"不掉成品，掉落经济衔接大件）

**三层掉落法度（v81 数据已落）**：
1. **普通妖兽 → 普通妖材**：皮/骨/牙（langya_fang、shougu_bone、xuesha_jing…）——
   硝制贩卖（万宝楼 sell 字段自动收购）、炼器打底。零碎钱+炼制底料，不掉成品。
2. **高阶/开智妖兽（妖王级）→ 妖丹**（yaodan_1 一阶妖丹…按阶分级）——
   炼药入丹/炼器淬火/坊市硬通货三用。妖丹=妖兽一生修为，是妖材经济的锚定物。
3. **异闻妖王 → 传闻链条触发 + 伏诛掉具名稀有材**：传闻（_maybeBeastRumor 异闻投放）
   → 入深山寻猎 → 伏诛 → 具名材（金纹虎皮/铁背甲壳/赤焰狼皮/墨蛟角皮鳞）——
   **稀有材即大件链条的入口**：材料本身写明去向（item desc 标注"小大件链"），
   玩家拿到的不是奖品，是下一段路的钥匙。

**首条范本（黄枫谷篇收尾→魔道争锋篇兑现，考据：动漫/原著燕家堡代工）**：
- 墨蛟之角 → **乌龙夺**（攻击法宝）；墨蛟之皮+鳞 → **神风舟**（飞行法器——空层
  2.5D 的 canFly 载具，与战斗空中层直接咬合）。
- 四问速答：想要（飞行+重击双痒点，desc 早早种草）／准备苦（妖王传闻→寻猎→伏诛
  三段）／过程险（boss 战不可速决）／到手蜕变（神风舟开飞行=探索与战斗双升维）。
- 炼制落地：魔道争锋篇燕家堡线代工（人情/报酬剧情化），≥2 源核实细节后实装。
- ※ 妖丹炼药/炼器配方挂丹房与锻造链，随对应篇章开；当前先成立"卖得掉、留得值"。

## 四、与各系统的咬合（收拢索引）

| 系统 | 咬合点 |
|---|---|
| 嗑瓜子正反馈 | 轴上每一格都是顺手涨的条 |
| 强度物理学 | 四问之四：每个大件在加区/特区有明确落点，兑现=面板可见位移 |
| 情报面纱 | 大件的下落本身是情报（L0听说有此物→L2知道在谁手里/怎么炼） |
| 暗流涟漪 | 传承现世/遗物入市=计划外大件入口（随机供给侧） |
| 道途年表+前路 | 大件兑现=年表浓墨；未解锁大件=前路剪影（明牌惦记） |
| 洞府家底 | 大件实体陈列（剑架/丹炉/碑林），投入有形化 |
| 扬名时刻 | 大件首秀战=名声兑付的法定场合 |
| 突破三段式 | 筑基丹等"突破型大件"=准备难的实体 |
| 爽文契约 | 获取过程"九死一生"是叙事皮，进度不清空、兑现必丰厚是机制核 |
