# 战斗 / 突破系统设计（五行灵气 · 回合制）

> 灵感来自《觅长生》战斗的核心思路（由玩家口述提炼，非逐项复刻）：
> 每回合按灵根/丹药生成「五行灵气」，总量与比例每回合浮动；每个法术消耗不同的灵气；
> 一回合内可连续施法直到灵气用尽，由此产生海量战斗组合。**突破复用同一套战斗系统**。
>
> 本设计在此基础上，结合《凡人修仙传》七玄门篇做成自洽系统。待玩家确认后再扩展。

## 一、核心资源：五行灵气

五种灵气：**金 木 水 火 土**（jin / mu / shui / huo / tu）。

- 每个**回合开始**，角色获得一份灵气池（5 种各若干点）。
- **总量 + 各元素比例** 由以下决定：
  - **灵根**：决定你能产出哪些元素、各占多少权重、以及每回合总量。
  - **丹药 / 状态 buff**：临时改变总量或某元素比例（韩立靠小绿瓶的灵药做文章）。
  - **境界 / 功法**：随修为提升总量、解锁元素。
- **比例每回合随机浮动**（在权重附近波动），所以同样的牌库每回合手感不同 → 临场决策。
- **用尽即回合结束**：一回合内可连续施放多个法术，直到灵气不足支付任何法术、或主动结束。**未用完的灵气回合结束清空**（用进废退，逼你规划连招）。

### 韩立的四灵根（忠于设定）
四灵根 = 伪灵根，**缺一种元素、且总量偏低**。本作设定韩立拥有 **金·木·水·火**，**缺「土」**，
其中 **木最旺**（呼应木属性《长春功》）。

- 后果：韩立打不出依赖「土」的厚盾/重击，灵气总量也低 → 正面硬拼吃亏。
- 出路：靠**毒**（持续伤害、低消耗）、**眨眼剑法**（廉价高闪避）、丹药临时补灵气、以及算计 → 以弱胜强。
  这正是"凡人靠准备与智计赢强敌"的机制化表达。

## 二、角色战斗属性

| 属性 | 作用 |
|------|------|
| 气血(HP) | 归零即败 |
| 灵气产出(profile) | 每回合五行灵气的权重与总量 |
| 神识 | 法术命中/威力、抵御神魂类攻击（如余子童元神夺舍） |
| 身法 | 闪避 |
| 护体(shield) | 临时护盾，吸收伤害，回合衰减 |
| 心境 | 突破/神魂战中的"道心血条"；过低则突破失败、易入心魔 |

### 状态效果（status）
中毒(每回合掉血) / 封灵(降低灵气产出) / 定身(跳过一次行动) / 凝神(下回合灵气+) 等。

## 三、法术（法术库，七玄门篇·练气期）

> 每个法术标注**消耗灵气**与**效果**。韩立缺「土」，故依赖土的法术他用不了（敌人可用）。

| 法术 | 消耗 | 类型 | 效果 |
|------|------|------|------|
| 眨眼剑法 | 金3 | 攻击 | 伤害 9，本回合自身闪避+30%（廉价灵活，韩立招牌） |
| 火球术 | 火4 | 攻击 | 伤害 14 |
| 寒冰诀 | 水4 | 攻击 | 伤害 8，使敌下回合灵气产出-30% |
| 用毒 | 木2 水1 | 减益 | 给敌叠加中毒 5/回合（持续3回合），可叠加（韩立核心杀招） |
| 长春诀 | 木3 | 回复 | 回气血 12（木/生，源自《长春功》） |
| 水盾术 | 水3 | 防御 | 获得护体 14 |
| 凝神诀 | 木1 | 辅助 | 心境/心魔回稳，下回合灵气总量+2 |
| 土山压 | 土5 | 攻击 | 伤害 20（**韩立无土，用不了**；敌方傀儡/对手可用） |

> 后续章节再扩充：御剑、符箓、傀儡（曲魂）协战、虫术等。

## 四、敌人与「决战墨大夫」编排（三阶段，忠于剧情）

1. **墨大夫**：会用毒、基础术法；**怕毒**（凡人之躯）。
2. 当墨大夫气血 < 40% → **铁奴(张铁尸傀)登场**：高护体、力大，**免疫中毒**（已是死物），
   逼你不能只靠毒，得用眨眼剑法/火球正面解决或硬扛。
3. 墨大夫死后 → **余子童元神**出窍夺舍：高闪避，攻击你的**心境/神识**；
   **毒/物理近乎无效**，唯有以**神识(功力)**强攻才能镇灭 → 对应"靠功力胜余子童"。

胜利 = 三阶段敌人全灭。失败（气血或心境归零）= 重伤退场，需回去苦修/备药再战（体现"靠准备"）。

## 五、突破 = 复用战斗系统

突破不再是单纯掷骰子，而是一场**与「瓶颈/心魔」的战斗**：

- 敌人 = **瓶颈心魔**，它的"血条" = 突破阻力（境界越高越厚）。
- 你用同一套五行灵气 + 法术去**冲击瓶颈**（攻击法术削减其血条）。
- 每回合瓶颈施加**心魔反噬**（伤害你的心境），且**回合数有限**；拖久必败。
- **准备的意义**（决定开局优势）：
  - 灵力/修为越满 → 瓶颈血条越薄；
  - 服食丹药 → 改善灵气产出、加护盾、压心魔；
  - 心魔越低 → 可战回合数越多。
- 冲垮瓶颈血条 = 突破成功；回合耗尽未破 = 失败（损修为、受伤、心魔涨），与原有惩罚一致。

> 这样"战斗"与"突破"共用引擎，玩家练熟的连招在突破时同样有用，正是你说的"设计精妙"之处。

## 六、实现与验证

- 引擎 `js/combat.js` 为**纯逻辑**（不依赖 DOM），便于无头测试与复用（战斗+突破共用）。
- UI 层单独渲染战斗界面。
- 每次改动先跑 `node test/combat.test.js` 验证：灵气生成、连招消耗、毒叠加、三阶段编排、突破胜负、韩立无土限制等。
