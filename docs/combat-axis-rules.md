## 0. 三条军规

1. **不是什么都走格子**——分层结算：一个篇章约 70% 的仗按"速决"一键蒙特卡洛出战报，
   只有强敌/剧情战/异闻妖王才展开对阵轴（见 §8）。
2. **一维 = 工程可控**——没有寻路、没有地形图、没有相机；战场就是一行 flex 格子，
   单位是立绘小图。新敌人 = 填一张 JSON 表，不写代码。
3. **单回合操作 ≤ 2 次点击**——选格（移动）+ 选牌（行动）。深度来自三轴交织
   （距离 × 法力 × 读招），不来自操作复杂度。

## 1. 战场

- 一条横轴：杂兵 7 格 / 标准 9 格 / 大战 11 格。
- 每格至多 1 个单位；我方左端入场，敌方右端。
- **距离 = 格差**；距离 1 = 贴身。
- 我方编队：韩立 + 侧位单位。同场侧位上限 = 神识档（练气 1 / 筑基 2 / 结丹 3——
  大衍诀另加 1）。敌方同构。
- 侧位单位开轴时间线（考据红线）：尸傀（七玄门尾声，曲魂随后留墨府）→
  **同道**（黄枫谷起：南宫婉并肩战为首演）→ 灵宠（魔道争锋·血玉蜘蛛）→
  **傀儡**（筑基后期：叶师叔事件得《大衍诀》后自炼，魔道争锋前线首用）→
  啼魂兽/傀儡量产（乱星海）。

## 2. 回合流

每回合三段：

1. **亮意图**：敌方单位头顶亮意图图标（突进/对轰/蓄势/全力/遁走）。
   神识不弱于对方 → 看到具体目标；买过情报 → 额外显示解法提示。
2. **行动**：按速度序（身法定速度）。每单位 = **移动（≤move 格）+ 1 主行动**；
   另可打 **1 张瞬发牌**（不占主行动，每回合限 1）。
3. **结算**：盾衰减、毒/灼烧跳数、阵法格生效、冷却 -1。

**主行动菜单（韩立）**
| 行动 | 说明 |
|---|---|
| 御使法器 | 低耗常态攻击，射程内每回合可用 |
| 全力催动 | 高耗 + 冷却，大伤/特效（法器第二段） |
| 法术 | 土墙=盾 / 火弹=补刀 / 控制系 |
| 蓄势（神通） | 蓄 2~3 回合：移动即中断、受击概率中断；蓄满质变 |
| 形态令 | 灵宠切形态（虫云↔虫甲↔兵刃） |
| 凝息 | 回法力 15，**亮破绽标记**（受击伤害 +30%） |
| 遁走 | 在己方边缘格发动，下回合脱离战斗 |

**瞬发牌**：符箓（火蛇/定身/护身）、丹药（回元丹/疗伤丹）、底牌（天雷子/金光砖/灵乳）。

| 手段 | 射程 | 备注 |
|---|---|---|
| 武学 / 偷袭 | 1 | 贴身专属，**不耗法力** |
| 法术 | 1-2 | |
| 御使法器 | 1-3 | 神念所及（考据：法宝离体过远威力大减） |
| 全力催动 | 1-4 | |
| 符箓 | 1-4 | |
| 弓矢 / 水箭类 | 2-5 | **贴身哑火** |
| 神通（蓄势类） | 全场 | |

**贴身规则**（核心张力）：距离 1 时御使法器威力 -30%（神念施展不开——法修怕近身，
韩立练武防身的原著逻辑）；武学只在贴身可用且零耗。
→ 武修敌死命贴脸，法修拉距风筝；**每回合的移动都是决策**。

## 4. 法力经济

**池深公式（2026-06-11 用户裁决：灵力上限严格随功法×境界×突破水准×特殊境遇）**

```
mpMax = (境界基数 + 层数×层成长) × 功法品阶系数 + poolBonus
  境界基数/层成长：练气 40+6L → 筑基 130+12L（灵海跳档）→ 结丹 360+24L → 元婴 800+45L
  功法品阶系数：黄 1.0 / 玄 1.1 / 地 1.2 / 天 1.3（换主修功法=池立涨的质变体感）
  poolBonus（永久累计，绝对值直加）：
    · 突破水准：顺势水到渠成 +3 / 心战道心圆满（余裕≥70%）+4 / 普通 +2 / 险胜 +1（大境界×2）
    · 特殊境遇：天材地宝/灵泉淬体/筑基品质等内容事件直加（万年灵乳类）
```

- 开战水位 = 池深 ×（当前灵力/灵力上限）——没调息满就开战，法力池就不满；
  战后按比例回写灵力（连战共享一池，打坐/丹药是真实续航）。
- 法力池整场不自动恢复。恢复链：凝息 +14（亮破绽）/ 回元丹 +40（瞬发）/
  聚灵阵格每回合 +8 / 万年灵乳全回（稀世底牌，乱星海后）。
- 耗尽 = 法器法术全哑火，只剩：瞬发丹药、贴身武学、傀儡灵宠（自驱动）、遁走。
- 敌人同规则——**把敌人耗到蓝尽是合法胜利**（拖毒、逼大招、放血傀儡）。
  敌蓝尽时 AI 转：孤注一掷 / 遁走 / 求饶。

## 5. 八个核心机制

1. **盾墙**：护身法器=自动盾（衰减慢）；法术盾（衰减快）。硬解牌（天雷子）无视盾。
2. **挡线**：近战/冲撞**必须打相邻** → 占格单位 = 真墙；御物攻击可越格点名（飞剑会绕），
   但敌 AI 会优先清高威胁侧位。挡线者随篇章换代：黄枫谷=韩立与同道互为掩护
   （谁顶前排是每场的站位决策）→ 筑基后期起=傀儡。傀儡 = 有血条消耗品：
   HP 归零 → 破损（战后材料+时间修复）；被过量斩杀（溢出伤 ≥ 上限一半）
   或特定敌技 → 彻底击碎永失。
3. **蓄势-打断**：神通/大招蓄 2~3 回合，敌 AI 必扑 → 拿前排挡、拿控制符保 →
   蓄满战局质变。（坠魔谷"剑阵被近身逼弃"名场面的系统化；受击中断为概率判定。）
4. **阵法格**：阵旗（消耗品）铺 2~3 格区间：聚灵（站上回蓝）/ 困足（敌入格停步）/
   迷踪（区间内命中下降）。阵法型敌人也会铺，可拆（攻击阵旗）。
5. **形态令**：灵宠多形态切换=主行动。范本：噬金虫三态（乱星海后开轴）——
   虫云（独立单位上轴缠斗）/ 虫甲（附身：盾+反伤）/ 兵刃（强化御使伤害）。
   **秘术法诀 = 形态解锁钥匙**（虫甲术考据）。前期灵宠（血玉蜘蛛）单形态起步。
6. **读招**：意图明牌但粗略；神识与情报让它变细。读准 = 拆解（定身拆大招、
   举盾吃突进、抢节奏打蓄势）。
7. **遁走与追击**：敌残血/蓝尽会逃——追（战利品多、可能有伏）或放（仇恨记账，江湖再见）。
8. **破绽**：凝息/蓄势/形态切换均亮破绽（受击 +30%）——"敢不敢当他面回蓝"是每场都有的小赌局。

## 5.5 攻击三型与行动经济（2026-06-11 用户增量裁决）

> 用户：手段要有区分度——有的锁头、有的打格子、有的范围；消耗的法力与行动力
> 各不相同；一回合能动几下靠遁速差；能操控的傀儡灵虫看神识——NPC 也会操傀儡，
> 但神识不一定有韩立强（大衍诀=玩家的爽感之一）。

**攻击三型（剪刀石头布的攻防语言）**

| 型 | 代表 | 机制 | 应对 |
|---|---|---|---|
| **锁头**（lock） | 御使飞剑、法器互轰 | 神念锁定，移动躲不掉；护体盾/护甲全额生效 | **防御法术/护身法器**硬挡 |
| **打格子**（cell） | 金光砖砸落、妖兽扑击、巨剑斩地 | 意图阶段**亮出目标格**；执行时你已移开=完全落空；命中则不掷闪避 | **移动走位**躲开（身法的主场） |
| **范围**（zone） | 大庚剑阵、毒雾、怒涛 | 预告一段区间，区间内**全体**结算（侧位也吃） | 拉出区间 / 硬吃 / 打断蓄势 |

- 锁头打防御、格子打走位、范围打站位——三型对三种资源（盾/身法/阵型），
  build 与敌型的克制关系由此立体化。
- 法器（锁头常态）/ 法宝（高威能锁头+格子重击）/ 符箓（瞬发轻手）/
  阵法（铺格改区间）——四类手段的区分度落在攻击型+消耗+时机上。

**行动经济（遁速差=多动）**

- 每回合基础：移动 ≤move 格 + 1 主行动 + 1 瞬发。
- **遁速优势**（Balance.initiative）：玩家遁速明显高于敌方 → 概率获得**第二主行动**
  （风雷翅时代的具象）；反之高速强敌可能一回合连动两次（高阶压迫感的数值来源）。
- **行动力消耗分档**：轻手 actCost 1；重型大杀招 actCost 2（一招吃掉整回合的行动）——
  "快而轻"与"慢而重"成为 build 语言。
- 蓄势大杀招（青竹蜂云剑·剑诀齐射/辟邪神雷/大庚剑阵）：蓄 2~3 回合 + zone 型
  释放——引擎已留 charge 钩子，内容随篇章解锁。

**意图诚实原则（2026-06-12 用户验收修正：狼在七格外不许预告扑咬）**

- 敌方选招必须过**可达性判定**：本回合移动之后仍够不着的招不进意图池——
  全部够不着时意图=「逼近」（亮"近"气泡、不亮危险格，纯赶路回合）。
- 逼近途中被挡线者拦住：近战系顺势撕咬挡路者（挡线的代价照旧）。
- 玩家收益明确：看到"近"=白拿的先手回合（输出/布置/拉距）。

**2026-06-12 验收修正汇总（用户实玩反馈）**

| 反馈 | 修正 |
|---|---|
| "一直退出战斗" | ① 遁走阈值收紧：血<一成才起遁意（55%概率），蓝尽也须血残；② **结算卡**：胜/逐/遁/败大字+每个敌人下场（伏诛/走脱）+关键手复盘+战利清单，点「收功」才离开 |
| 弹幕太快看不清 | 一条条出（750ms 间隔）、挂 7 秒、同屏限 3 条；完整战录=右上「录」角标 |
| "法力"无感 | 全文案统一「灵力」（字段名 mp 不动） |
| 移动/技能效果弱 | 出手身法（贴身大步前冲/远程前倾）+受击白闪+移动滑步 |
| 人物悬空/与背景割裂 | **接触阴影**（脚下椭圆投影+呼吸同步）+地面融合暗带+战斗背景强制横版战场图（bt_* 下半幅开阔地面构图）+敌我全身战斗立绘（battlers/） |
| 战斗 BGM 激昂割裂 | 普通战斗=低强度对峙轨（中速拉锯无唢呐）；激昂只给 boss/妖王/**越级2层+**（选轨已实装；combat 轨重生成待 Lyria 限流解除） |
| 妖王走脱≠伏诛 | 异闻不闭环、专属战利不掉——它带伤会回来 |

**躲闪三角（2026-06-11 用户出题：后躲有亏损了，前躲的博弈怎么做）**

| 应对 cell/zone | 收益 | 亏损 |
|---|---|---|
| 后躲 | 最安全 | 输出回合归零（射程外）；**扑击系落空有惯性（lunge）——敌冲进落点格**，距离没拉开还得再躲；退多了被逼到阵脚 |
| 前躲（钻怀里） | 落空敌亮**趁虚窗口（_whiffed）：它下次行动前受击×1.3**——只有前躲者在射程内吃得到；贴身武学全额 | 御物贴身-30%（build 抉择）；下回合站在它横扫射程里 |
| 原地举盾 | 不耗移动，盾换血（cell 命中盾甲照常结算） | 耗法力；破绽期会被放大 |

- 扑击惯性还制造**换位**：前躲穿身后敌我位置互换——绕背反击的画面感与战术几何。
- **追踪修正（track）**：稀有高阶敌技，落点追你一格——一步躲不开，逼出第二层决策
  （两步走位/打断/硬扛）。boss 专属压迫工具，杂兵不用。
- 趁虚与"趁蓄力"同语言（×1.3、同一行文案体系），侧位单位也会抓窗口。

**神识=操控上限（敌我对称的不对称）**

同场侧位上限=神识档。敌方傀儡师/御灵修士同样受此限——他们神识不及你
（大衍诀碾压），所以**你能带三个他只能带一个**：玩家在"多线操控"上的天赋碾压，
是凡人式爽感的系统兑现。

## 6. 敌人 build 七型谱（情报系统的根基）

按原著战例归纳 + 设计推演。开局不知对面是哪型 → 站位带牌就会吃亏 → 情报值钱。

| 型 | 原著原型 | 轴上行为 | 解法 |
|---|---|---|---|
| 法修标准型 | 陆云风/封岳 | 中距对轰 + 护身法器盾 | 硬解破盾 / 耗蓝 |
| 武修突进型 | 七玄门武师/温天仁 | move 2 死命贴身，贴身重击 | 困足阵 + 风筝 |
| 远程狙击型 | 弓修/水妖 | 射程 5 炮台，贴身哑火 | 突进压脸 |
| 妖兽冲撞型 | 墨蛟/白虎 | 突进 + 贴身 AOE 横扫（高阶者带位移技） | 前排挡线 |
| 召唤型 | 御灵宗修士/金鼓原前线傀儡师 | 放灵虫傀儡占格耗你 | 越格斩首 or 先清场 |
| 阵法型 | 叶师叔流 | 开场铺阵改写区间 | 拆阵旗 / 抢中路 |
| 毒系消耗型 | 于子桐流 | 拖回合磨蓝放毒 | 速攻强压 |

同型不同人再做差分（装备组、底牌、神通各异）——封岳=标准型+踏云靴（会逃），
陆云风=标准型+符宝（爆发）。**敌人卡片全数据驱动**：`{hp, mp, move, gear, skills, intents}`。

## 7. 速度与行动顺序

速度 = 基础 + 身法（御风诀/踏云靴/风雷翅）。同速玩家先手。
身法另给 move 加成——身法是"轴上自由度"的成长线。

## 8. 分层结算（军规一的落地）

| 层 | 判定 | 体验 |
|---|---|---|
| 威压 | 境界压制（已有系统） | 不进战斗，对面直接跪 |
| 速决 | 战力领先 ≥ 1 档的遭遇战 | 「速战」一键蒙特卡洛，一行战报 + 战利品（可选手动） |
| 对阵 | 强敌 / 剧情战 / 异闻妖王 / 越阶挑战 | 展开对阵轴，全深度 |

速决войны也走同一套轴引擎（无头跑），所以平衡只调一处。

## 9. 纸面推演

数值为推演用代表值（贴近现版游戏），平衡以蒙特卡洛为准。

## 10. 工程评估

| 模块 | 内容 | 规模 |
|---|---|---|
| combat2.js | 轴引擎纯逻辑（无 DOM，可无头测试） | ≈800 行 |
| UI | flex 横轴 + 单位立绘 + 意图图标 + 手牌区 | ≈400 行 CSS/JS |
| AI | 意图权重表（数据驱动，七型谱共用一个解释器） | ≈200 行 |
| 数据 | world.js 敌人卡加字段：move/range/intents/gear | 填表工作 |
| 平衡 | 蒙特卡洛管线适配轴模拟（速决也靠它） | ≈200 行 |

- 不需要：寻路、地形、相机、canvas。
- 全量复用：五行克制、情报面纱、底牌经济、装备三槽、心魔具象、同道叙事。
- 预估 3 个版本周期；旧战斗并行在线直至一次性切换（用户已拍板一步到位）。

## 11. 画面呈现方案（2026-06-11 用户拍板：觅长生式立绘战场）

> 参照觅长生战斗画面：静态全身立绘 + 特效层，**无骨骼/帧动画**——
> 立体感来自高质量立绘、景深与特效运动。全部落在已有技术栈上。

| 层（z 序由低到高） | 内容 | 实现 |
|---|---|---|
| 背景 | 现有场景图（战斗发生地的场景复用，竖版 `_p` 管线现成） | 已有 |
| 战场地面 | 淡水墨"步位"刻度（格子的含蓄视觉化），格号→屏幕 x 坐标映射 | CSS 定位 |
| 单位立绘 | 每单位一张透明底全身立绘，脚底对齐地平线；移动=横向滑动（transition）；待机=微浮动；受击=震动+红闪（复用剧情演出动画） | genart 管线已通 |
| 悬浮装饰 | 已装备法器小图悬浮于身侧（上下浮动）；护盾=半透明径向渐变罩 | CSS |
| 特效层 | 御使=法器 PNG 沿轴 translate+旋转；符箓=符纸飞出爆开；蓄势=脚下光环逐回合变亮；中毒/灼烧=色调粒子；命中=爆闪 | CSS keyframes ≈十余种 |
| 头顶 UI | 敌方意图气泡（图标）、破绽标记、伤害飘字 | DOM |
| 状态 UI | 顶部双方血条/法力/状态图标排；底部主行动牌+瞬发牌+法力池；回合数 | combat-overlay 重构 |

- 多单位＝多 sprite：同道/傀儡/灵宠/敌方召唤物各一张立绘按格站位——
  挡线、包夹、前后排画面上一眼可读，站位即叙事。
- 竖屏适配：战场横轴整体缩放+立绘缩小，手牌区固定底部（拇指热区）；
  横屏=觅长生式全宽战场。
- 美术排期（genart 批量）：有名敌人每人一张全身立绘；杂兵按七型谱共用类型图
  （妖兽/散修/武修/傀儡师等）；法器与特效贴图十余张小图。
- 工作量定调：画面层合计 ≈1 个版本周期（程序侧），不是瓶颈；
  瓶颈在敌人立绘的生图排期，可与引擎开发并行。

**傍身资产层（2026-06-12 用户立项，随内容解锁实装）**：法宝/神通的"傍身可见"——
- 现状：au-orbit 悬浮装备印（字符小方块）为 v0 占位。
- 升级路线：每件大件法宝配一张**傍身小图**（透明底，genart 批量）——青竹蜂云剑=
  数口青色小剑绕身悬浮（剑阵雏形随数量成长 36→72 口视觉递进）、风雷翅=背后银弧
  雷翅微张（雷遁 blink 的视觉来源）、金光砖=金砖虚影；战斗中傍身图随蓄势/释放
  有状态变化（剑群射出=御使、翅展=雷遁瞬移残影）。
- 原则：傍身即成长可见——大件链每进一步，韩立站在轴上的"排场"肉眼可见地变。
