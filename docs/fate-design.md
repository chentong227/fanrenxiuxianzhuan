# 故人命途设计（仙凡有别 · 同路人 · 转机）

> 2026-06-11 用户对谈定稿方向：仙凡有别是一大魅力；"乱星海归来陈师姐已死"是原著
> 一大遗憾——游戏里应允许玩家挣来不一样的转机，真正见到筑基的同门师兄妹。
> 本档案回答：故人的命运是否可改、怎么改、代价是什么、不改的遗憾如何呈现。
> 依赖底座：npcsim（已有）、因果账本（world-architecture §3）、地区回访/回乡
> （world-architecture §4）、日历锚（§2）。

---

## 〇、设计公理：遗憾是默认，转机是挣来的

仙凡有别的魅力恰恰来自不可逆——如果随手能救所有人，"人人都活"的世界没有遗憾，
也就没有珍惜。但玩家要的也不是旁观注定的悲剧，而是"**我有机会出手，我出手了，
所以她活下来**"的故事。与爽文契约同构：

- **默认命途 = 原著结局**（考据红线的延伸：玩家不动手，世界就是原著）
- **转机 = 真实投入换来的扳道**（代价必须疼，才配得上重逢）
- **救一人需倾力，救不了所有人**（资源在单周目内不可能全救——救谁是真选择）

## 一、命途系统（fate track）

每位重要故人一条命途：按原著默认走向推演的事件序列 + 若干**道岔**（玩家可介入点）。

### 陈巧倩线（范本 · 2026-06-11 考据修正版）

**考据定稿**（多源核定 2026-06-11 增补）：黄枫谷陈家（谷中三大修仙家族）修士。
道侣**陆云风**为攀附董萱儿（求入其师红拂门下）兼筑基丹之争，对她暗下杀手——
坊市归途被韩立撞见所救，**韩立事后喂她忘尘丹**（利己谨慎：抹去牵连），但丹力未全效，
她依稀记着恩人；血色禁地再遇险再被救，**又一颗忘尘丹**——她的情路自始就被韩立
亲手封存。为筑基丹参加血色试炼，**筑基成功**。七派大战、围剿黑煞教两度重逢；
白菊山表白被"恭喜"二字婉拒；联姻的秦家投魔、婚事作罢，自此性情冷淡、终身未嫁。
**始终未能结丹，筑基寿元二百载将尽前患怪病而逝**——韩立结婴归来（200余岁）
才从其兄陈巧天口中得知死讯，怔立当场。

**游戏化新道岔（忘尘丹之择——救人之后那一下）**：动漫线默认喂忘尘丹（账本记
`chen_wangchen`）；玩家可选**不喂**（`chen_remember`）——她记得你、记得那夜，
命途的"郁结"参数自始不同。这是比白菊山更早、更隐秘的改命起点：
你抹掉的不是她的记忆，是她唯一一段被人拼命护过的证据。

```js
FATES.chenqiaoqian = {
  // 默认命途 = 原著（玩家不动手，世界就是原著）
  default: ["陆师兄暗害·韩立救(黄枫谷篇既有节点)", "血色试炼", "筑基", "白菊山表白被拒",
            "联姻告吹·心结郁结", "结丹无望", "怪病", "寿尽(你在乱星海)"],
  switches: [
    // 救命之恩是默认剧情（考据），账本只记你救后的"多走一步"

      cost:"赴约。不必许诺什么——见一面，把当年救她的事认下来",
      effect:"心结不郁结：命途参数「郁结」清除（怪病诱因之一）", ledger:"met_chen_baiju" },
    { id:"yi_zhi",      window:"她患病初期（魔道入侵后·你尚在天南/书信可达）",
      cost:"墨大夫传承的医术+你的药理熟练度+珍稀药材——亲诊或遥寄药方",
      effect:"怪病得治：不死于病，寿尽线后移", ledger:"healed_chen" },
    { id:"jiedan_zi",   window:"乱星海期间托人捎回（或结婴归来时未过寿尽线）",
      cost:"结丹资粮（造化丹级丹药/灵物——你在乱星海的收获分一份回天南）",
      effect:"冲击结丹的本钱：成则寿元五百载，败亦多撑些年头", ledger:"gave_chen_resource" },
  ],
  outcomes: {
    // 结算点：结婴归来回访天南（原著得知死讯的同一时点）
    turn:   "黄枫谷故地，一位鬓有霜色的筑基后期女修含笑迎来：「韩师弟，别来无恙。」"
          + "（若结丹成：一位结丹初期女修——她终于看到了结丹后的天。）",
    regret: "陈巧天面带古怪：「家妹并非结丹修士，早在百余年前得了一场怪病，就已去世。」"
          + "——你怔立当场。年表：白菊山那日，她等到了日落。",
```

### 三条铁律

1. **道岔有窗口**：医病须在病时、赠资须在寿尽前；窗口过了就是过了（日历锚的软窗口
   规则不适用于命途——人命不开补救径，这是命途与主线的根本区别，也是它重的原因）。
2. **代价必须真实**：亲诊=横跨大陆的旅途月数；结丹资粮=你在乱星海真金白银的收获
   分出去一份。无痛的善举不配改写命运。
3. **远雷点名出处**：重逢时她必须说出你做过什么——"白菊山那日你来了。这些年，
   我便没什么可怨的了。"（因果账本三律的复用）

## 二、三类故人，三种卖点（仙凡有别的精确化）

| 类 | 例 | 命途可扳？ | 卖点 |
|----|-----|-----------|------|
| **凡人故人** | 爹娘、小妹、韩家 | **不可扳**——寿元铁律是世界观地基 | **陪伴的窗口**：小妹出嫁你到场了吗？爹娘临终你回乡了吗？错过=年表永久空行。凡人线不卖改命，卖"你在的那几次" |
| **修仙同路人** | 陈巧倩、厉飞雨、同门师兄弟 | **可扳，代价真实** | **道途扶持**：资质平平者差的就是一颗丹、一句点拨、一次护道——你恰好给得起，但给不起所有人 |
| **大修士** | 南宫婉、李化元 | 不归你管（承重墙不可扶） | **关系**可经营，命运不可干预——他们的死活是世界的事 |

凡人线的"不可扳"必须守死：这是"修仙者眼看凡人老去"的全部重量来源。
游戏给的唯一温柔是**预告窗口**（见第三节故人钟）——让你来得及赶回去，
而不是让你救得了。

## 三、故人钟（系统底座 UI 化——设定变玩法的关键一笔）

npcsim 升级为**差速钟**：凡人 ~80 岁 / 练气 ~120 / 筑基 ~200+。

- 风云录新增「故人」区：每位已结识故人一根**寿元沙漏**（剩余年数的模糊表达：
  "余年尚多 / 鬓已星星 / 风烛残年"——不报数字，报体感）
- **大跳跃前的告别清单**：去乱星海（一去几十年）的船期日历锚亮起时，故人钟
  自动浮出："此去经年。谁的沙漏，等不到你回来？"——玩家亲眼看着名单，
  自己决定出海前最后办谁的事。这一眼，就是仙凡有别从设定变成玩法的瞬间。
- 回访结算：时间跳跃后回到退潮地区，按命途+沙漏结算谁还在、谁不在、
  谁变成了什么样（npcsim 推演 + 命途道岔判定）。

## 四、南宫婉线：正宫主线（2026-06-11 考据修正版）

> 用户裁决：南宫婉是正宫，一直陪韩立到飞升；韩立曾为她以命相护、正面硬刚远超
> 自身境界的强敌——这些是剧情高潮点，游戏必须让玩家亲手打出来。

**考据定稿（原著时间线）**：
1. **血色禁地**：她压制修为至炼气期入禁地（与你同阶！），联手杀墨蛟，因墨蛟淫囊
   结下夫妻之实——"我叫韩立，立碑的立"。
   ✅ **已实装（v71）**：story.js mojiao_after「潭边·不能说的，与记一辈子的」——
   淫囊破裂/迷毒暗转（含蓄处理）/醒来之约（"此生不得对第三人提起"）/名字桥段挪至
   离别反转。flag `nangongwan_bond` + 账本 `mojiao_oath` = 后续护道战与抢亲的因果根。
2. **魔道入侵后**：她为寻生死未卜的你，不顾旧伤独闯鬼灵门腹地遭追杀——
   **你以命相护方得脱险**（第一个高潮点：远超你境界的追兵，护道之战）。
3. **两百年分离**：你远遁乱星海结丹、结婴。
4. **掩月宗抢亲**：结婴归来，闻她将与他人成婚——赴掩月宗互表心意，当众将她带走
   （第二个高潮点：元婴期硬闯一宗）。
5. **封魂咒百年**：她遭阴罗宗暗算身中封魂咒，自我冰封修姹女天月诀——你为解咒
   奔走百年（火蟾内丹压制→寻得解法），灭阴罗宗四长老（第三个高潮点：为她而战的
   复仇与解救）。
6. **落云宗双修大典**：正式结为道侣，婚后将她安顿乱星海。
7. **飞升之别**：人界修为见顶，你独自飞升——她赠**六丁天甲符**，正是此符在飞升
   关头救你性命（她护了你最后一程）。

**游戏化设计**：
- 她不入命途系统（命运不可扳也无需扳——她自己就是大修士），她的线是**主线锚链**：
  上述 1~7 全部做成章节高潮节点，玩家亲手打：护道战（敌我境界差悬殊的"撑住N回合"
  型战斗）、闯掩月宗（扬名时刻的最高规格）、灭四长老（复仇箱庭）。
- **境界竞速**作为重逢张力保留：你先结婴、她随后（原著相差一年）——每次重逢
  互量一眼境界，台词随差距变化；她的修为推演独立走，大节点与原著对齐。
- 与命途线的供给彻底不同：命途线是"扶持同路人的恩义"，南宫婉线是"并肩者之间
  以命相托的浪漫"——绝不混轨（给她送丹是冒犯；为她拼命才是语言）。
- **以命相护的系统表达**：这几战允许"惨胜"乃至"败而不死"的特殊规则——
  护道战的目标不是杀敌是撑住，撑住即胜（爽文契约的变体：为她打的仗，
  狼狈也是英雄）。

## 五、厉飞雨线（七玄门篇的命途补铸）

动漫里他大比夺魁后随篇章淡出。游戏命途：
- 默认：野狼帮之乱中下落随门派沉浮（由七玄门篇账本+npcsim 推演：门派保住了他是
  执法堂首座；门派衰败他带残部出走）
- 道岔（已埋）：精元丹（你的药理）、眨眼剑法的切磋情分、决战前是否知会他
- 结算：筑基后回七玄门（回乡机制的门派版）——他已是凡俗武林的传奇，而你刚入仙门。
  同一句"韩立！陪我过两招！"，物是人非。
- 他是**凡人侧的镜子**：无灵根者的天花板就是武人巅峰——他活得越精彩，
  仙凡之别越锋利。

## 六、防御性设计（明确不做什么）

- **不对抗 SL**：单机游戏，玩家想读档救人是他的自由。我们只保证单周目内资源
  上"全救"不可能（筑基丹有数、闭关月数有数、窗口互斥），选择自然发生。
- **不做好感度数值条**：命途道岔是离散的"事"，不是刷出来的数值——
  刷好感是手游逻辑，恩义是叙事逻辑。
- **不给大修士/凡人开后门**：南宫婉不可救助、爹娘不可续命。两头守不住，
  中间的"同路人可扶"就没有重量。
