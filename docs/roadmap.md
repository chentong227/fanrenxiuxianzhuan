# 制作路线图（设计周期 → 版本号 → 验收点）

> 2026-06-11 与用户定稿。原则：**系统先在七玄门（现成试验田）跑通，
> 黄枫谷篇作为第一个"系统原生章节"带着系统一起出生**——不先写裸剧情（避免复制
> 七玄门"看完就空"的老毛病 + 避免返工）。
> 每周期含多次版本 bump，保证用户每天早上打开都有新东西可摸。
> 六份档案为本路线图的法源：bigitem / retention / power / world / art-direction / ui-reference。

## 周期一「开轴」 v30~v32 —— 让七玄门有惦记
- 剑意修行链（大件范式首demo：听闻→剑意轴N/100→悟剑攻坚→连环眨眼兑现→厉飞雨专属台词）
- 道途年表 +「前路」剪影（黄枫谷·筑基??/乱星海·金雷竹??——明牌惦记）
- NPC 称呼随境界/事迹变化（世界认出你，低成本高回响）
- 战后复盘一句话（操作价值被看见）
- **验收**：际遇栏常驻剑意进度，肝有方向；年表可回看可前瞻；突破后小算盘改口。

## 周期二「突破与藏拙」 v33~v35 —— 质变与扮猪吃虎
- 突破三段式 v1：备丹提率（准备难）→ 冲关玩法复用五行灵气珠引擎（过程难）
  → 黑场二字题+收益清单演出（收益巨大，抄"丹成"模板）
- 藏拙引擎 v1：显露境界 vs 真实境界、蓄势值、揭示时刻爆发+失态台词；
  接入夺舍之夜（墨大夫"什么?!你竟然——"史诗打脸）
- 杂学熟练度雏形（药理/剑意/探知——嗑瓜子条）
- **验收**：突破前要备货、过程要操作、成功起鸡皮疙瘩；决战打脸台词成立。

## 周期三「世界的真」 v36~v38 —— 一致感雏形
- 情报面纱 L0~L2（金光上人=首个可做功课的对手；图鉴剪影逐层点亮）
- 暗流涟漪链 2~3 条（七玄门规模：流言→确证→后果落地→可抓窗口）
- 风云榜 v1（门内高手榜+江湖人物榜，石碑式 UI）
- 「漂亮的赢」勋章（伏诛/以下克上/全身而退 → 入年表）
- **验收**：战前可打探敌情且情报有用；风云录读起来像活的；榜上有名字可惦记。

## 周期四「黄枫谷纸面工程」 与二/三并行，v39 收口
- 动漫版黄枫谷篇逐集考据 → docs/lore-黄枫谷篇.md
- 大件四问立项：筑基丹链 / 青元剑诀 / 玉蜘蛛 / 青竹蜂云剑炼制之法
- 章节节点图（让丹屈辱起点/药园差事/血色禁地/地火之屋，以动漫为准）
- 新地图/人物/场景美术清单与生成（黄枫谷山门/药园/坊市/血色禁地…）
- **验收**：蓝图齐备，黄枫谷篇开工无考据风险。

## 周期五「黄枫谷篇 v1」 v40+ —— 第一个系统原生章节
- 主线节点全量 + 筑基三段式为篇章主轴（准备难=丹链，过程难=冲关，收益=辟谷/御器/洞府）
- 大件链双线推进（筑基丹链 + 蜂云剑炼制法开篇）
- 洞府家底 v1（筑基后开洞府——考据正确的解锁时点；药圃/丹房/陈列雏形）
- 风云榜扩为越国修仙界榜；首位传说态背景强者登场
- **验收**：完整玩到筑基质变，"准备难·过程难·收益巨大"全程成立。

## 周期六+ （滚动规划）
- 流派构筑深化（毒师/暗器/稳健成型）、图鉴完成度百分比、事件总线 v1、
  乱星海考据与篇章、生存挑战战型（可遭遇态背景强者）……

## 节奏纪律
- 每周期结束：全测试绿 + bump ver.txt + push，用户手机即时可验。
- 每周期内容必须包含至少一个"打开就摸得到"的变化（反对纯底层重构周期）。
- 临时灵感/用户新裁决 → 先入档案，按"是否影响当前周期验收点"决定插队或排后。
