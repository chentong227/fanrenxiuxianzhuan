# 制作路线图（设计周期 → 版本号 → 验收点）

> 2026-06-11 与用户定稿。原则：**系统先在七玄门（现成试验田）跑通，
> 黄枫谷篇作为第一个"系统原生章节"带着系统一起出生**——不先写裸剧情（避免复制
> 七玄门"看完就空"的老毛病 + 避免返工）。
> 每周期含多次版本 bump，保证用户每天早上打开都有新东西可摸。
> 六份档案为本路线图的法源：bigitem / retention / power / world / art-direction / ui-reference。

## 周期一「开轴」 v30~v32 —— 让七玄门有惦记
- 剑意修行链（大件范式首demo：听闻→剑意轴N/100→悟剑攻坚→连环眨眼兑现→厉飞雨专属台词）
- 道途年表 +「前路」剪影（黄枫谷·筑基??/乱星海·金雷竹??——明牌惦记）
- NPC 称呼随境界/事迹变化（世界认出你，低成本高回响）
- 战后复盘一句话（操作价值被看见）
- **验收**：际遇栏常驻剑意进度，肝有方向；年表可回看可前瞻；突破后小算盘改口。

## 周期二「战斗平衡重设计」 v33~v34 —— 承重墙/build/爽/真实的精髓（用户钦点独立设计）
- 与用户对谈定稿 combat-balance-design.md 三节议题（乘区锚点表/敌人意图语言/灵气经济等）
- 实现：敌人意图脚本（每敌2~3招成"解谜题"）、护体对策化、操作浮动盘（读招奖励/底牌时机）
- 蒙特卡洛全覆盖校准（各境界×各流派×备牌梯度的胜率表）
- **验收**：无脑循环不存在；巧赢有奖励、碾赢也成立；战斗"每场都要想一下"。

## 周期二·五「突破与藏拙」 v35 —— 质变与扮猪吃虎 ✅（已交付）
- 突破三段式 v1：备丹提率（准备难）→ 冲关玩法复用五行灵气珠引擎（过程难，吃周期二平衡表）
  → 黑场二字题+收益清单演出（收益巨大，抄"丹成"模板）
- 藏拙引擎 v1：显露境界 vs 真实境界、蓄势值、揭示时刻爆发+失态台词；
  接入夺舍之夜（墨大夫"什么?!你竟然——"史诗打脸）
- 杂学熟练度雏形（药理/剑意/探知——嗑瓜子条）
- **验收**：突破前要备货、过程要操作、成功起鸡皮疙瘩；决战打脸台词成立。

## 周期三「世界的真」 v36 —— 一致感雏形 ✅（已交付）
- 情报面纱 L0~L2：传闻（免费）→ 招路（交手自动记招）→ 底细（小算盘灵石购买，
  实战回报=料敌必中看穿意图）；金光上人/贾天龙为首批可做功课对象
- 暗流涟漪链 3 条（老猎户失踪→无主药园 / 野狼帮劫镖→镖局悬赏 / 黑市赃丹→贱价采买；
  流言→确证→限时窗口，过期即逝）
- 风云榜 v1（彩霞山座次石碑：甲乙丙丁排位；fame 名声分=伏诛/勋章/扬名事迹累积，
  韩立攀榜可视化——藏拙者榜上无名，正合其意）
- 「漂亮的赢」勋章（全身而退/毒手药王/以下克上→首次入年表+名声，再犯计数）
- **验收**：战前可打探敌情且情报有用；风云录读起来像活的；榜上有名字可惦记。

## 周期三·五「克制与兵器谱」 v38 —— 战斗系统总架构落地 ✅（已交付）
- 用户裁决：克制=灵技克主修功法（打的是道基不是肉身），可复用至"辟邪神雷克鬼魔/韩立战玄骨"
- 完整调研韩立全生涯战斗手段 → combat-arsenal-design.md 六轴模型（法术/武学/底牌/侧位/法宝/神通）
- 五行克制引擎（element-design.md）：灵技elem×道基attr ×1.25/×0.8 对称生效；
  nature特攻层（镇魂slays鬼×1.5、尸鬼毒免疫=一致感修复）；情报门控行徽（打了才知道）
- 符箓底牌（轴3 v1）：火蛇符/寒冰符（集镇20两，任意1灵气点燃）——穷靠本命富靠符箓
- 符宝金光砖（杀金光战利品）：充能3次破甲重击，灵石回充——杀手的凶器成为你的底牌
- 侧位单位引擎 v0（轴4）：张铁尸傀随行（夺舍之夜后曲魂幡到手）——自动出击+30%挡刀+
  破损可修缮；灵宠（血玉蜘蛛）/傀儡量产将复用此架构
- 火弹术残页自悟（考据：神手谷口诀自修）——韩立的本命克金答案
- 校准：elem.bal.js 防回归（紧备置77% → 备符95% → 尸傀随行100%——做功课的价值可测量）
- **验收**：金光战做功课（买底细→知其金行→备火符→带尸傀）全链路成立；14 测试套全绿。
