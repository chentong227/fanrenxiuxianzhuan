# 制作路线图（设计周期 → 版本号 → 验收点）

> 2026-06-11 与用户定稿。原则：**系统先在七玄门（现成试验田）跑通，
> 黄枫谷篇作为第一个"系统原生章节"带着系统一起出生**——不先写裸剧情（避免复制
> 七玄门"看完就空"的老毛病 + 避免返工）。
> 每周期含多次版本 bump，保证用户每天早上打开都有新东西可摸。
> 六份档案为本路线图的法源：bigitem / retention / power / world / art-direction / ui-reference。

## 周期一「开轴」 v30~v32 —— 让七玄门有惦记
- 剑意修行链（大件范式首demo：听闻→剑意轴N/100→悟剑攻坚→连环眨眼兑现→厉飞雨专属台词）
- 道途年表 +「前路」剪影（黄枫谷·筑基??/乱星海·金雷竹??——明牌惦记）
- NPC 称呼随境界/事迹变化（世界认出你，低成本高回响）
- 战后复盘一句话（操作价值被看见）
- **验收**：际遇栏常驻剑意进度，肝有方向；年表可回看可前瞻；突破后小算盘改口。

## 周期二「战斗平衡重设计」 v33~v34 —— 承重墙/build/爽/真实的精髓（用户钦点独立设计）
- 与用户对谈定稿 combat-balance-design.md 三节议题（乘区锚点表/敌人意图语言/灵气经济等）
- 实现：敌人意图脚本（每敌2~3招成"解谜题"）、护体对策化、操作浮动盘（读招奖励/底牌时机）
- 蒙特卡洛全覆盖校准（各境界×各流派×备牌梯度的胜率表）
- **验收**：无脑循环不存在；巧赢有奖励、碾赢也成立；战斗"每场都要想一下"。

## 周期二·五「突破与藏拙」 v35 —— 质变与扮猪吃虎 ✅（已交付）
- 突破三段式 v1：备丹提率（准备难）→ 冲关玩法复用五行灵气珠引擎（过程难，吃周期二平衡表）
  → 黑场二字题+收益清单演出（收益巨大，抄"丹成"模板）
- 藏拙引擎 v1：显露境界 vs 真实境界、蓄势值、揭示时刻爆发+失态台词；
  接入夺舍之夜（墨大夫"什么?!你竟然——"史诗打脸）
- 杂学熟练度雏形（药理/剑意/探知——嗑瓜子条）
- **验收**：突破前要备货、过程要操作、成功起鸡皮疙瘩；决战打脸台词成立。

## 周期三「世界的真」 v36 —— 一致感雏形 ✅（已交付）
- 情报面纱 L0~L2：传闻（免费）→ 招路（交手自动记招）→ 底细（小算盘灵石购买，
  实战回报=料敌必中看穿意图）；金光上人/贾天龙为首批可做功课对象
- 暗流涟漪链 3 条（老猎户失踪→无主药园 / 野狼帮劫镖→镖局悬赏 / 黑市赃丹→贱价采买；
  流言→确证→限时窗口，过期即逝）
- 风云榜 v1（彩霞山座次石碑：甲乙丙丁排位；fame 名声分=伏诛/勋章/扬名事迹累积，
  韩立攀榜可视化——藏拙者榜上无名，正合其意）
- 「漂亮的赢」勋章（全身而退/毒手药王/以下克上→首次入年表+名声，再犯计数）
- **验收**：战前可打探敌情且情报有用；风云录读起来像活的；榜上有名字可惦记。

## 周期三·五「克制与兵器谱」 v38 —— 战斗系统总架构落地 ✅（已交付）
- 用户裁决：克制=灵技克主修功法（打的是道基不是肉身），可复用至"辟邪神雷克鬼魔/韩立战玄骨"
- 完整调研韩立全生涯战斗手段 → combat-arsenal-design.md 六轴模型（法术/武学/底牌/侧位/法宝/神通）
- 五行克制引擎（element-design.md）：灵技elem×道基attr ×1.25/×0.8 对称生效；
  nature特攻层（镇魂slays鬼×1.5、尸鬼毒免疫=一致感修复）；情报门控行徽（打了才知道）
- 符箓底牌（轴3 v1）：火蛇符/寒冰符（集镇20两，任意1灵气点燃）——穷靠本命富靠符箓
- 符宝金光砖（杀金光战利品）：充能3次破甲重击，灵石回充——杀手的凶器成为你的底牌
- 侧位单位引擎 v0（轴4）：张铁尸傀随行（夺舍之夜后曲魂幡到手）——自动出击+30%挡刀+
  破损可修缮；灵宠（血玉蜘蛛）/傀儡量产将复用此架构
- 火弹术残页自悟（考据：神手谷口诀自修）——韩立的本命克金答案
- 校准：elem.bal.js 防回归（紧备置77% → 备符95% → 尸傀随行100%——做功课的价值可测量）
- **验收**：金光战做功课（买底细→知其金行→备火符→带尸傀）全链路成立；14 测试套全绿。

## 周期七「演出地基 + 系统纵深」（2026-06-14 用户裁决 A–G；v134+ 滚动 bump）

> 定稿语境：用户给出 7 项设计裁决（A 优先级=先做地基引擎；B 演出脚本系统；C 符箓方案；
> D 随身灵圃；E 功法层数轴+初入巅峰；F 据点箱庭回填；G 装备位跟剧情）。
> 原则：**先建可复用引擎，内容随篇章填**——B 是 C/D/E/F/G 的演出载体，故 B 打头。
> 本周期所有改动遵守：动漫硬考据（authenticity §五）/ 乘法三律 / 不破存档 schema（惰性初始化优先）。
> ⚠ 修复批（E-batch bug）信息用户稍后给——到了按"是否影响当前验收点"插队（节奏纪律）。

### 阶段 1（头号·B 演出地基）docs/cutscene-design.md
- 新建 `js/cutscene.js` 演出推进器：解释 `text:[]` 演出原语（cam/actor/fx/sfx/wait/beat），
  特效委托 FX、声委托 audio、立绘委托 Art、镜头复用箱庭 L3——**不另起炉灶**，向后兼容旧剧情卡。
- **嘉元城打样**：据点节点图（exploremap 引擎据点风味配置）+ 首次抵达定场演出 + 一段交互 beat。
- **验收**：嘉元城与七玄门一眼不同；一个高潮幕跑通镜头+立绘入退场+特效+交互 beat；journey E2E 全绿、可跳、单屏。

### 阶段 2（F 据点回填）explore-redesign §P3.5
- 嘉元城跑顺后回填七玄门据点（地标/风物/抵达演出）；旧扁平 explore.js 据点逐步退役。
- **验收**：早期据点都有"到了另一座城"的地方感；复访见变迁（告示板/物价/残部）。

### 阶段 3（E 功法层数轴 + 初入/巅峰）technique-tiers §5
- `s.techLayers[techId]`（惰性初始化）；`grantSpells`→`layerUnlocks` 按层解锁（青元剑诀 3 剑芒/5 剑盾…）；
  `balance.spellPower` 加 `layerMul`；`State.realmStage` 派生初入/中坚/巅峰标签。升层=闭关肝条（大件范式）。
- **验收**：升层才出剑芒/剑盾；同境界巅峰>初入（tier.bal.js 增校验，梯度温和）；年表/天命栏显示层进度。

### 阶段 4（G 装备位·黄枫谷）combat-arsenal §3.8
- 接 E：黄枫谷剧情触发 → 发入门法器（烈阳剑等 treasure 招式）→ 装进法宝三位制（主/御/悬浮 UI）→ 招式按层解锁。
- 顺手：校正 chapters.js 黄枫谷陈旧标记（`stub/locked/nextChapter/startLocation` 与已写全剧情对齐）。
- **验收**：走到黄枫谷自然拿到并装备法器，战斗多一根法宝轴；存档迁移无回归。

### 阶段 5（C 符箓方案 + D 随身灵圃）combat-arsenal §3.7 / bigitem §小绿瓶v2
- C：符纸可买 + 符箓方案并入大件图鉴（沟通/购买/战胜解锁）+ 有方案+符纸+灵力即成（无绘画/无 grind）。
- D：小绿瓶"随身唤出"入口 + 多灵草谱 + 催熟产物价值随境界迁移。两者皆复用现成系统、不立新系统。
- **验收**：能自产已解锁方案的符；任意地点可唤出灵圃打理；图鉴点亮节奏成立。

## 节奏纪律
- 每周期结束：全测试绿 + bump ver.txt + push，用户手机即时可验。
- 每周期内容必须包含至少一个"打开就摸得到"的变化（反对纯底层重构周期）。
- 临时灵感/用户新裁决 → 先入档案，按"是否影响当前周期验收点"决定插队或排后。
- **乘法三律**（multiply-design.md，2026-06-11 用户裁决）：
  ① 新玩法先问"旧系统相乘可得否"，立新系统必须四问立项；
  ② 零教学红线——机制必须挂在修仙常识上（五行生克/寒热毒理/灵气环境），弹窗教学即重做；
  ③ 节拍器三规——探索每3步必有收获、月行动必有可见进度、远中近三层惦记任何时刻非空。
