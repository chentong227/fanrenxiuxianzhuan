### 1.2 考据要点

- **青竹蜂云剑炼制顺序**（动漫核定）：紫灵给天雷竹（84集）→ 小绿瓶催熟为万年金雷竹（84~87集）→ 红尘劫渡过后炼制72口飞剑（87集）。**不是先有剑后有红尘劫，而是红尘劫渡过后才炼成**。
- **虚天殿三关**（动漫核定）：第一关**鬼冤之地**（辟邪神雷灭杀鬼王/阴灵兽）→ 第二关**冰火道**（分玄晶道与熔岩路，内含铁火蚁遭遇+元瑶重逢+啼魂兽获取）→ **宝光阁**（奖励环节·四路选一·古宝选择）→ 第三关**极妙幻境**（心性考验·婆罗珠辅助·动画原创回溯人生选择）。韩立亲自打的只有关中遭遇+玄骨终战。
- **玄骨上人=萧诧**（动漫核定）：本名萧诧，极阴祖师和极炫的师父，生前元婴后期修士，被徒弟陷害封印于古修士洞府，改修鬼道后实力大幅下降（韩立评估约结丹后期·动画刻意隐藏精确境界）。夺舍曲魂身躯重获肉身。最终死因（117集·红袖读书+起点中文网双源核定）：**玄骨融合修罗圣火但不稳定（结丹后期修为无法驾驭）→韩立利用漏洞让粘有修罗圣火的飞剑刺向玄骨再收回→玄骨粘上修罗圣火灰飞烟灭→修罗圣火瓦解→乾蓝冰焰汇聚成冰珠→啼魂兽吸出金雷竹飞箭中残魂→韩立命啼魂吸收→玄骨下线**。**非辟邪神雷正面击杀，也非玄骨单纯自爆——韩立主动利用修罗圣火不稳定性反杀**。
- **温天仁**（动漫核定）：六道极圣（万法门主）的徒弟，结丹后期。在虚天殿出殿路口看守。**温天仁vs韩立的正面对决留在外海风云篇**（第137集），本篇只是初遇蒙混过关。
- **元瑶/妍丽线**（动漫核定）：元瑶为复活妍丽来虚天殿寻养魂木。韩立帮助元瑶得到养魂木。**还阳术留在外海风云篇**，本篇只到"得养魂木后分道扬镳"。
- **补天丹**（动漫核定）：虚天鼎中爆出，可提升寿元+改善资质。韩立在外星海闭关时服下。**改善灵根=补天丹效果，不是结丹本身的效果**。
- **曲魂结局**（动漫核定）：被玄骨上人夺舍身躯。玄骨死后曲魂身躯被修罗圣火烧毁——**曲魂线在此篇终结**，不是"救回曲魂"。
- **极阴祖师/乌丑**（动漫核定）：动画中乌丑是极阴祖师的**弟子**（原著为孙子，动画改编为师徒），且极阴以附身/控制方式借乌丑行事（萌次元·64集分析："通过他的说话能明显感觉到这不是出自他本心，而是出自另外一个人"）。两者关系=弟子+被附身。
- **极阴收徒**（动漫核定·102集·知乎+腾讯新闻+网易三源）：极阴因韩立拥有血玉蜘蛛（拉虚天鼎最佳灵兽），与青易居士**争抢**收韩立为徒。玄骨（萧诧）建议韩立拜极阴（极阴更危险·不宜结仇）。韩立拜入极阴门下。两人都不是真心收徒，事后必定要干掉韩立夺血玉蜘蛛。
- **魔道三元婴**（动漫核定）：虚天殿中三位魔道元婴修士围绕韩立展开精彩博弈：
  - **极阴祖师**（元婴初期顶峰·极阴岛岛主）：因韩立拥有血玉蜘蛛可拉虚天鼎，**强收韩立为徒**（102集）。赠婆罗珠（过极妙幻境用）。虚天殿中与蛮胡子/青易居士合作取鼎。玄骨上人之徒（玄骨是极阴的师父）。
  - **蛮胡子**（元婴中期·魔道最强之一）：先在冰火道赠宝珠，后赠皇鳞甲（成名防御法宝·在虚天殿祭坛替韩立承受元婴修士一击·**救命之恩**）。后被极阴暗算囚禁（远线：韩立返乱星海后救出·蛮胡子赠托天魔功+洞府珍藏后去世）。
  - **青易居士**（元婴初期·南鹤岛散修）：赠青冥针符宝（攻击型符宝·防身用）。与极阴争抢收韩立为徒（102集），表面关心韩立，实则利用血玉蜘蛛。韩立出殿时冒充青易居士徒弟蒙混过关（因有符宝信物）。
  - **三元婴共同点**：都盯上韩立的血玉蜘蛛→各怀鬼胎拉拢韩立→各送宝物→利用完即弃。韩立在三元婴之间藏拙求生、以智谋周旋。
- **啼魂兽获取**（动漫核定·106集·起点中文网+腾讯新闻+百度百科三源）：韩立从铁火蚁群中救下元瑶。元瑶提出以身相许（被拒）、青火雷×3（魔道青阳门秘制火雷·每枚威力相当于元婴修士一击·被拒）。韩立表示对啼魂兽感兴趣，元瑶将啼魂兽+鸣魂珠一起给韩立。鸣魂珠=控制啼魂兽的关键，不炼化只能下简单命令。韩立带元瑶通过冰火道。
- **金魁设陷阱**（动漫核定·106集·起点中文网）：金魁暗中操控冰火道禁制，熔岩路出现本不该有的铁火蚁，玄晶道出现银光鼠，增加闯关难度。青易居士凭青冥针斩杀银光鼠，万天明秒杀铁火蚁。
- **正道取鼎 vs 魔道取鼎**（动漫核定）：万天明（万法门）先用金丝蚕取鼎失败（金魁暗中分化正魔两派·赐天机造物仪），然后魔道三元婴用韩立的血玉蜘蛛取鼎成功。
- **寒骊台破阵·虚天殿地图**（动漫核定·111集）：蛮胡子/极阴/青易居士分头找方位破阵，韩立跟随乌丑找第四方位·戏耍乌丑（对阵法的研究）·发现夹层喜提虚天殿地图。地图=后续逃命关键。
- **内殿时间线**（动漫核定·B站逐帧解析+红袖读书+起点中文网多源）：111集正道取鼎失败+魔道取鼎+寒骊台破阵 → 112集血玉蜘蛛拉鼎+元婴大战开始 → 113集元婴大战（特效最强） → 114集补天丹出世 → 115集元婴心理战+玄骨杀乌丑 → 116集韩立智取虚天鼎 → 117集玄骨终战 → 118集虚天殿结束（养魂木）。
- **养魂木获取**（动漫核定·B站）：元瑶在虚天殿获得养魂木，韩立要走一部分做成念珠同婆罗珠一同使用。非"合作破阵分得"，而是韩立向元瑶要了一部分。
- **银月**（动漫核定）：虚天殿收获之一，以**狼首玉如意**形态获得（非青竹蜂云剑炼制时诞生）。银月为器灵，在虚天殿中作为古宝入手。

### 1.3 排除项

- 网文同人《凡人：人在天星城》全程不采。
- 原著与动漫冲突处（如虚天殿细节）一律以动漫为准。
- 风雷翅炼制属**外海风云篇**，本篇只有材料（风希斩雷鹏夺翅已在初入星海篇完成）。

## 二、章节结构（五幕）

> 节奏设计：蛰伏开篇（结丹后日常）→ 妙音门线（蝎岛之战·紫灵羁绊）→ 红尘劫（入世修心·大件炼成）→ 虚天殿（全书最精彩副本）→ 章末蛰伏（闭关·追杀·钩子）。

### 第一幕「金丹初成」（天星城日常→外海猎妖→材料交易）

- **集数对应**：73~78
- **玩法**：天星城主场景铺开（洞府/坊市/妙音门商会/外海航线）；结丹后日常——闭关修炼、外海猎妖取丹、噬金虫养成升级。
- **情绪曲线**：金丹大成的扬眉吐气 → 结丹初期的"能打但还不够强" → 妙音门线引入。
- **关键设计**：结丹后第一次打开面板——金丹图标、新法术位、法宝槽解锁。天星城坊市=灵石经济2.0（妖丹交易→灵石→买材料/功法）。

### 第二幕「蝎岛之战」（妙音门vs隐煞门→极阴现身→客卿长老）

- **集数对应**：79~84
- **玩法**：团战（妙音门结丹强者+韩立vs隐煞门）；紫灵智谋做局（剧情选择：是否配合紫灵的计划）；极阴附身乌丑的元婴级背景战（演出/观战）；逃亡段（天都炼傀追杀→白玉蜘蛛掩护→海底遁避）。
- **情绪曲线**：团战紧张 → 紫灵智谋的惊叹 → 极阴现身的压迫感 → 逃亡的狼狈 → 客卿长老的互利。
- **关键设计**：极阴=元婴级背景强者（"在场态"——玩家只能观战/逃跑，不能正面对抗）。紫灵做局=剧情选择节点（配合/质疑/独走，影响后续妙音门关系）。
- **魔道三元婴线**：极阴强收韩立为徒→三元婴各赠宝物拉拢→正道取鼎失败→魔道取鼎（血玉蜘蛛拉鼎）→寒骊台破阵（韩立戏耍乌丑获取地图）→元婴大战（韩立藏拙旁观·皇鳞甲救命）→玄骨杀乌丑→韩立杀玄骨。三元婴=虚天殿副本的核心NPC群，各怀鬼胎、利用韩立但也被韩立反利用。

### 第三幕「红尘劫」（青竹小轩→入世修心→青竹蜂云剑炼成）

- **集数对应**：85~87
- **玩法**：**独占玩法段**——在天星城凡人区开"青竹小轩"店铺，24年红尘劫（月回合制·加速推进）。卖符箓丹药给凡人/低阶修士，看人间疾苦。红尘劫=大衍诀第三层修炼要求（提振神识+巩固心境）。渡劫完成后催熟金雷竹→炼制青竹蜂云剑。
- **情绪曲线**：入世的新鲜感 → 凡人故事的感伤（情侣/穷修士/老者——呼应墨彩环凡人之命）→ 悟道破劫 → **本命法宝炼成的终极爽点**。
- **关键设计**：
  - 红尘劫=**时间跳跃节点**（gameplay-template §2.5）——24年弹指，每月一个凡人小故事/选择，不是24年逐月闭关。
  - 青竹蜂云剑炼成=**大件四问兑现节点**（bigitem-design §一）：想要（本命法宝·战力质变）→ 准备苦（天雷竹催熟需数十年·红尘劫渡劫在前）→ 过程险（炼器失败风险·材料唯一性）→ 到手蜕变（72口飞剑·辟邪神雷附剑·银月器灵·swordOrbit绕身剑阵）。
  - **零教学**：不弹"炼器教程"，炼制过程复用现有引擎（五行灵气池换皮 or 阵法解谜），会打架就会炼剑。

### 第四幕「虚天殿」（古修士洞府→玄骨夺曲魂→虚天殿三关→夺鼎→杀玄骨）

- **集数对应**：88~118
- **玩法**：**全书最精彩副本**——三层嵌套箱庭完全体（explore-redesign §五 范本二）。
  - **前奏**：金青邀约→古修士洞府（L1+L3练手）→玄骨现身→曲魂被夺（情感冲击·cutscene演出）。
  - **虚天殿**：L1+L2+L3三层嵌套，三关递进。
    - 第一关鬼冤之地：L1舆图+L3遭遇战（辟邪神雷灭杀鬼王/阴灵兽）。
    - 第二关冰火道：L1+L3（熔岩路/玄晶道选择·铁火蚁遭遇·噬金虫vs铁火蚁·元瑶重逢·啼魂兽获取）。
    - 宝光阁：L2歧路（四路选一·古宝选择·五行环+血色披风）。
    - 第三关极妙幻境：L2（心性考验·婆罗珠·动画原创回溯人生选择·非战斗）。
    - 内殿虚天塔：L3终局——正道取鼎失败（金丝蚕）→魔道取鼎（血玉蜘蛛拉鼎）→元婴大战（观战演出·皇鳞甲救命）→寒骊台破阵（韩立戏耍乌丑·获取虚天殿地图）→玄骨杀乌丑→**韩立杀玄骨终战**。
  - **魔道三元婴线**：极阴（强收韩立为徒·赠婆罗珠）+蛮胡子（赠皇鳞甲·救命）+青易居士（赠青冥针符宝·虚情假意）——三人各怀鬼胎利用韩立血玉蜘蛛，韩立在三者间藏拙周旋。
  - **虚天殿收获**：虚天鼎（通天灵宝）+ 乾蓝珠/乾蓝冰焰 + 玄阴经 + 养魂木（与元瑶分）+ 狼首玉如意（银月）+ 五行环 + 血色披风（宝光阁古宝）。
- **情绪曲线**：练手的轻松 → 曲魂被夺的震惊/愤怒 → 虚天殿的步步惊心 → 元婴混战的压迫 → **杀玄骨的终极爽点（以下克上·辟邪神雷+啼魂兽双底牌兑现）**。
- **关键设计**：
  - **韩立亲自打的只有**：玄骨终战 + 两场殿层遭遇战（用户裁决·explore-redesign §五）。
  - **元婴大战=观战演出**（L3演出段·cutscene DSL），韩立藏拙旁观/趁乱行事——与墨蛟洞观战段同构。皇鳞甲在此段救韩立一命（元婴修士一击不死）。
  - **魔道三元婴=虚天殿核心NPC群**：极阴（强收徒·赠婆罗珠）、蛮胡子（赠皇鳞甲·救命）、青易居士（赠青冥针符宝·虚情假意）。三人各怀鬼胎利用韩立血玉蜘蛛，韩立在三者间以智谋周旋。正道取鼎（万天明·金丝蚕）失败后，魔道取鼎（血玉蜘蛛）成功。
  - **寒骊台破阵**：韩立跟随乌丑找第四方位·戏耍乌丑·发现夹层获取虚天殿地图——韩立智谋展示节点。
  - **大限钟=虚天殿开启时限**（禁制关门=不可回头点）。
  - **曲魂之死=情感低谷**——从七玄门篇一路陪伴的尸傀/身外化身，在此终结。不是"救回"，是"失去"。cutscene演出：玄骨夺舍瞬间→韩立无力阻止→曲魂最后的眼神。

### 第五幕「星海飞驰」（出殿→温天仁→外星海闭关→章末钩）

- **集数对应**：119~124
- **玩法**：出殿遭遇温天仁（剧情选择：冒充/硬闯）；救凌玉灵（星宫关系线种子）；外星海闭关（时间跳跃·吃补天丹·修炼玄阴诀·噬金虫变异三色）；海王兽斩杀（战斗验证·结丹初期从容）；四大势力追杀（章末危机钩）。
- **情绪曲线**：出殿的如释重负 → 温天仁的紧张 → 闭关的沉淀 → 海王兽的从容 → **章末追杀的危机感**。
- **关键设计**：章末钩=四大势力追杀（极阴/碧云门/万法门/星宫），韩立躲入外星海闭关二三十年——**下一篇章"外海风云"的起点**。

### 7.2 玄骨终战设计（本篇最高潮战斗）

- **敌人**：玄骨上人（萧诧），生前元婴后期，改修鬼道后实力大幅下降（韩立评估约结丹后期），但拥有元婴级底牌**修罗圣火**（触之必死·即使元婴期也难扛）。夺舍曲魂身躯后重获肉身。
- **韩立底牌**：
  - 辟邪神雷（金雷竹法宝×辟邪神雷=克鬼物×1.8）
  - 啼魂兽（冰火道中从元瑶处获得·天生克鬼物·吞噬精魂）
  - 青竹蜂云剑（72口飞剑·swordOrbit绕身剑阵）
  - 噬金虫（虫群消耗）
- **战斗节奏**（动漫核定）：玄骨实力碾压→韩立消耗+辟邪神雷抵抗→**玄骨强行融合修罗圣火→失控→身体被烧毁**→韩立以为已胜→**啼魂察觉残魂藏于金雷竹小箭**→啼魂吞食残魂→玄骨彻底消亡。
- **关键**：杀死玄骨的不是韩立的正面攻击，而是**玄骨自己的修罗圣火失控**。啼魂的作用是**收尾发现+吞食残魂**，防止玄骨假死逃脱。辟邪神雷在战斗中用于对抗鬼道功法但非致命一击。
- **败有所得**：即使战斗中韩立被打残，玄骨因曲魂身躯限制+修罗圣火反噬→韩立总能撑到玄骨自毁。
- **cutscene演出**：修罗圣火失控→玄骨惊恐→身体崩塌→韩立松一口气→啼魂示警→金雷竹小箭中残魂暴露→啼魂吞食→"没想到……老夫一生算计，竟栽在一个结丹初期小子手里"→韩立默然。

### 7.3 元婴大战（观战演出·L3 cutscene）

- **内容**：万天明/极阴/青易居士/星宫甲长老等元婴修士争夺虚天鼎+补天丹。
- **玩家角色**：韩立藏拙旁观/趁乱行事——与墨蛟洞观战段同构（非韩立实战）。
- **演出系统**：cutscene DSL（数据驱动·镜头/台词/特效/交互beat）。
- **玩家参与**：选择何时出手偷鼎/是否救元瑶/是否暴露实力——选择影响后续仇恨和收获。
