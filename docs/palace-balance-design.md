# 皇宫三战场·平衡设计（demo 录制档 vs canon 主线档）

> 承 `balance-master-design.md`（方法论母文档）/ `combat-balance-design.md` / `teamfight-camera-design.md`（30 格大战场框架）。
> 本文专记「皇宫三组对位群战」（`engine.startSantuanFight`）的回合数平衡：怎么定档、怎么反解、为什么这么调。
> 用户裁决（2026-06-18）：**回合档锁文档现有值**——练气 5~6 / 筑基 8~12 / 结丹 12~16 / 元婴 15~25。

## 〇 问题陈述

用户在 14 Pro Max 实测皇宫战「难度低的发指、三回合就打死」。归因诊断（实测 + 读码）得两条根：

1. **demo 韩立过装**：`?demo=palace` 演武入口（录视频用）把韩立设为练气十一层（`main.js` `realmIndex=10`、hpMax 250），却塞了一身**越级法宝**——青竹蜂云剑（结丹本命 `driveRealm:2`）、神雷劈（range[1,10] 全场覆盖）、神雷附剑（伤 ×1.25）、金光砖（dmg42 穿甲）。这套火力**远胜 canon 筑基本色**（真实主线此时没有青竹蜂云剑——见 `balance-master-design.md §〇`）。
2. **血侍数值刻意压低**：`world.xueshi_zu` hp130/armor2，原设计是「群架·人多势众的干净利落 sweep」，不是耐战 boss。

用户裁决：**这身过装挺好、画面更酷**，那就把 demo 难度顺势调到**结丹对位档**（更长更耐看的录像）；**主线本身难度不动**（`santuan_fight` canon 入口一字不改）。

## 一 方法论（不堆血拍脑袋，蒙特卡洛反解）

按 `balance-master-design.md §四补`：TTK（击杀回合）是 (伤害 / 防御 / 护体 / 特效 / 法宝档 / 底牌) 的**涌现结果**，不是单挑一个数堆出来的。流程是**反向**的：

1. 先定回合数目标（demo 录制档 → 结丹 12~16）。
2. 用真实引擎 + 真实 demo loadout 跑蒙特卡洛（每配置 24 局自动战），量各旋钮对「回合数 / 胜率 / 玩家受伤 / 同袍阵亡」的影响。
3. 反解出落在目标带内、且胜率/体感都健康的旋钮组合。

仿真脚手架：直接驱动 `Engine._combat`（含 `_autoPlayerTurn` 自动战 AI + 真实同袍/血侍 AI），**完整复刻 demo loadout**（含 main.js 建好战斗后追加的 9 道神雷 + 神雷劈/附剑——这步使真实 demo 韩立比裸 `startSantuanFight` 强约 30%，必须计入，否则低估玩家火力）。校准：血侍原值 130/2 → 实测均值 5.9 回合，与浏览器实机 ~5.5 吻合。

## 二 关键发现：伤害是悬崖，唯「耐久」可安全调回合数

蒙特卡洛扫描（每行 24 局，真实 demo loadout）：

| 配置 | 血侍 hp/armor | 敌伤倍率 | 同袍 hp | 回合[min-max] 均值 | 胜率 | 玩家受伤 | 同袍阵亡率 |
|------|---------------|---------|---------|---------------------|------|---------|-----------|
| 当前 | 130/2 | ×1.0 | — | 3–8 · **5.9** | 100% | 0 | 1% |
| K1 | 260/5 | ×1.0 | +12% | 7–20 · 11.0 | 100% | 0 | 7% |
| **K2（采用）** | **300/6** | **×1.0** | **+12%** | **10–19 · 13.4** | **100%** | 0 | 15% |
| K3 | 330/6 | ×1.0 | +15% | 12–20 · 14.8 | 96% | 6 | 18% |
| ——伤害悬崖对照—— | | | | | | | |
| F4 | 175/4 | **×1.06** | +15% | 10–13 · 11.3 | **30%** | 175 | **64%** |
| A2 | 220/6 | ×1.4 | — | — | **0%** | 250 | 全灭 |

**结论**：敌人伤害**只要抬 +6%**，孱弱同袍（108~150 血）就被打崩 → 战线失守 → 无主之敌反扑滚雪球 → 胜率从 100% 暴跌到 30%、玩家也近乎暴毙。所以**伤害旋钮不可用**（系统对它极度敏感、是难度悬崖）。回合数只能靠**「耐久」（hp + armor）**这一安全旋钮拉长，并辅以**同袍兜底**（拉长后的鏖战才不会随机崩盘）。

这不是偷懒堆血：实测证明这场偏短**纯粹**是血侍太脆（被同袍 + 过装玩家合击秒），而文档方法下伤害旋钮被悬崖锁死，**耐久是唯一安全解**。

## 三 采用配置（K2）——仅 demo 演武入口

`main.js` `?demo=palace` 非高潮分支（`!climax`），在 `startSantuanFight` 建好战斗后追加加成：

```js
if (!climax) {
  Engine._combat.enemies.forEach(e => { e.hpMax = 300; e.hp = 300; e.armor = 6; });   // 血侍催至结丹对位之坚
  Engine._combat.sides.forEach(sd => { sd.hpMax = Math.round(sd.hpMax * 1.12); sd.hp = sd.hpMax; });  // 同袍 +12% 兜底
}
```

- **敌伤一律不碰**（避开悬崖）。
- 同袍 +12%：刘靖 138→155 / 宋蒙 150→168 / 钟卫娘 121（钟卫娘 108 最脆、是阵亡常客，兜底后鏖战不随机崩）。
- **实测复核（真实 demo 页，10 局）**：回合 [9,10,11,11,13,14,14,15,15,18]、**均值 13.0、胜率 100%**——正中结丹 12~16。同袍偶有阵亡（刘靖/钟卫娘），玩家照常取胜——这正是结丹档该有的鏖战与损耗感。

## 四 canon 主线档（不动，待真实进度复核）

`engine.startSantuanFight`（canon `santuan_fight` 事件入口 `engine.js:5316`）与 `world.xueshi_zu`（hp130/armor2）**一字不改**——主线难度不受 demo 录制档影响。

canon 复核留待此战真正接入主线进度时进行：届时韩立是 **canon 筑基 loadout（无青竹蜂云剑等越级法宝）**，目标锁**筑基 8~12 回合**。因 canon 玩家火力远低于 demo 过装版，血侍**多半无需抬到 300**——按 canon loadout 重跑本文 §一 的蒙特卡洛反解即可定值（很可能维持或仅小幅上调 `world.xueshi_zu`）。

## 五 后续项（item 10·拉扯感 / 玩家被威胁——本轮不展开）

实测暴露但本轮**未解**的两点（需引擎机制、非调数能解）：

1. **玩家全程 0 伤害**：血侍杀意被战线 aggro 锁在当面同袍身上，根本不碰韩立 → 玩家无威胁、无紧张感。
2. **战场拉扯感**：单波血侍一死该战线即了结，缺「来回拉锯」。现有 `_maybeSpawnWave` 是**全局波**（全灭才刷、且从右侧整堆入场、不认 fronts/锁线），不适合「按战线源源补员」的拉扯。

待引擎扩展（item 10）：①血侍被玩家攻击有概率「血煞反扑」点名韩立（给玩家威胁、避开「抬全局伤害」的悬崖）；②**按战线**的增援波（黑煞教从宫门源源补血侍到对应战线、续接锁线）——清掉一线会被新血侍顶回来，天然造「拉扯」+ 进一步拉长回合。此项独立成 PR。
