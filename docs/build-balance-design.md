# Build 三路平衡设计（剑道 / 丹道 / 阵法）

> 2026-06-20 立档。本文档定义韩立的三条 Build 路线——剑道、丹道、阵法——的
> **系统挂载点、效果、能力表、平衡框架**。三路跨篇章持续推进，与主线剧情正交。
>
> 配合阅读：power-design.md（战力公式）、technique-tiers.md（功法层数轴）、
> multiply-design.md（乘法三律）、chapter-systems-manifest.md（篇章推进表）。
>
> **设计铁律**：三条路不是三个伤害流派——它们填战力公式的不同格子（乘区 / 底牌 / 控场）。
> 平衡的本质是"同样 N 个月投入任一条路，对本章最难内容的通关概率提升相当"。

---

## 〇、战力公式回顾（power-design.md）

```
战力 = 境界基准（乘区） × build 浮动（1.0~2.0） + 特区（条件触发）
```

三条路各填一个格子：

| 路线 | 填的格子 | 力量类型 |
|------|---------|---------|
| 剑道 | 乘区 · layerMul（永久战斗伤害乘子） | 每一刀都更重 |
| 丹道 | 特区 · 底牌数量与质量（战前备牌 + 续航） | 打完还能打 |
| 阵法 | 乘区 · 洞府加成 + 特区 · 战前控场 | 你选在哪打 |

### 1.2 效果

- **战斗乘区**：所有剑系法术（`source:"art"` 且关联青元剑诀）吃 `layerMul`，层越高伤害越高

- **境界标签**：`State.realmStage(s)` 读主修功法层进度，派生"初入/中坚/巅峰"（technique-tiers §5.3）

| 层 | 解锁 | 战斗效果 | 闭关月数 | 修为消耗 |
|---|------|---------|---------|---------|
| 1 | 入门（吐纳/护体/凝神） | 基础内功三件套 | 习得即得 | — |
| 3 | **青元剑芒** + **巨剑术** | 主输出法术 + 大杀招 | 6 月 | 3×200×1.5 |
| 5 | **护体剑盾** | 防御法术（质变：攻守兼备） | 8 月 | 5×200×1.5 |

### 1.4 剑道的弱点（平衡代价）

- 不自给自足：丹药/符箓/阵旗全靠买，灵石开销大
- 无探索优势：禁地/秘境里没有提前控场能力
- 续航短：纯剑道型打长战容易灵力耗尽（没有自炼回灵丹的能力）

### 2.1 系统挂载

|------|---------|------|

### 2.2 效果

- **自给自足**：高丹道可自制原本只能买的丹药 → 省灵石、不依赖坊市窗口
- **战前备牌**：丹道决定你能带多少/多好的丹药底牌进战斗（power-design 特区）
- **命途资源**：治病救人的道岔需药理门槛（fate-design：医陈巧倩需"药理+珍稀药材"）
- **经济优势**：自炼 vs 买入的差价 = 灵石节约 → 可花在别处（法宝/符箓/情报）

### 2.3 能力解锁表（设计新增，复用 `s.skills.alchemy` 做门槛）

| 药理值 | 里程碑 | 效果 | 类型 |
|--------|--------|------|------|
| 10 | 辨药入门 | 采药识别概率 +10%，毒草出率 +5% | 被动 |
| 20 | **制丹·养元丹** | 洞府可自炼养元丹（不用去集镇买） | 新行动 |
| 30 | 辨毒通识 | 探索中毒类陷阱/毒雾减免；战斗淬毒 +15% | 被动 + 战斗 |
| 40 | **制丹·凝神丹** | 自炼凝神丹（恢复心境，原本稀缺） | 新行动 |
| 50 | **筑基丹增效** | 地火炼丹 alchemy 系数翻倍 | 强化现有 |
| 60 | **制丹·增力丹** | 可炼增力丹（战前用，单场功力 +10%） | 新底牌 |
| 80 | **独门秘丹** | 可制命途道岔特殊丹药（如陈巧倩治病药） | 命途解锁 |

**时间总账**：从 0 到 40（凝神丹）≈ 25-30 月丹道行动。

### 2.4 丹道的弱点（平衡代价）

- 无直接战斗加成：不像剑道有永久 layerMul，每场战斗的收益靠消耗品兑现（用完就没了）
- 前期见效慢：药理 20 才解锁第一个制丹能力，之前只有被动加成
- 不擅控场：禁地/探索中没有主动控制敌人行为的手段

### 2.5 实现要点

极小改动。在 `alchemy()` / `gather()` 等已有函数里加里程碑检查：
```js

if (s.skills.alchemy >= 20 && !s.flags.dan_yangyuan_unlocked) {
  s.flags.dan_yangyuan_unlocked = true;
  this.log("药理精进，养元丹配方了然于胸。", "good");
}
```
新行动按钮走现有 `UI.renderActions()` 体系，条件为 `s.flags.dan_xxx_unlocked`。

## 四、平衡框架

### 4.1 等效时间律（核心平衡原则）

**同样的 N 个月投入任一条路，对本章最难内容的通关概率提升必须相当。**

校准锚点（以黄枫谷篇为基准）：

```
10 个月投入剑道：
  → 青元剑诀 +1 层 → layerMul 约 +0.03
  → 所有剑系法术永久 +3% 伤害
  → 通关概率 +ΔS

10 个月投入丹道：
  → 药理 +12 → 接近自炼养元丹门槛
  → 每场战斗可多带 ~2 瓶丹药底牌
  → 通关概率 +ΔA ≈ ΔS

10 个月投入阵法：
  → 阵法 +12 → 困足阵旗持续更长 + 接近自制门槛
  → 探索中可控住 1 次巡逻敌
  → 通关概率 +ΔF ≈ ΔS
```

### 4.2 三个校准旋钮

#### 旋钮 1：月收益系数（数值侧）

每条路到达"第一个质变里程碑"的月数必须在同一量级：

| 路线 | 第一质变 | 目标月数 |
|------|---------|---------|
| 剑道 | 青元剑诀 3 层（剑芒+巨剑术） | ~6 月（筑基后） |
| 丹道 | 药理 20（自炼养元丹） | ~20 月 |
| 阵法 | 阵法 20（自制困足阵旗） | ~18 月 |

> 注：剑道的 6 月看似短，但有"筑基后才开轴"的前置门槛；丹道从入谷起即可积累。
> 等效起算点 = 三条路各自开轴的时间点。

**调参方法**：如果某条路里程碑耗时偏高 → 提高该路行动的每次增量（如采药从 +1 改 +2）。

#### 旋钮 2：内容侧发挥场景（设计侧）

每章的关键遭遇必须设计三种解法。以血色禁地为例：

```
封岳追杀：
  剑道解法 → 正面击退（layerMul 够高 → 伤害压制）
  丹道解法 → 服增力丹 + 淬毒飞剑（底牌爆发）
  阵法解法 → 预布困足阵旗 → 封岳被困 → 趁机偷袭/逃脱

墨蛟战：
  剑道解法 → 剑盾撑住横扫 + 剑芒持续输出
  丹道解法 → 多带养元丹续航 + 凝神丹恢复心境 → 耗死
  阵法解法 → 布聚灵阵旗回灵 → 配合南宫婉在阵中长战
```

**审计规则**：每章的 boss/关键遭遇，必须有 ≥2 种 build 解法是可行的。
写入 chapter-systems-manifest.md 表 A "与主线的乘法点"列强制填写。

#### 旋钮 3：交叉收益递减（防全修无敌）

```
深耕型（一条路 40）：
  → 拿到里程碑质变能力（独占：如自炼凝神丹）
  → 基础收益 + 台阶跳跃 ≈ 总 +18%

全修型（三条路各 15）：
  → 三条路的基础被动收益
  → 碰不到任何里程碑门槛 → 无质变能力
  → 总 ≈ +15%

混合型（一条 30 + 一条 10）：
  → 接近一个里程碑 + 一条路的基础被动
  → 总 ≈ +16%
```

**结论**：深耕的总收益略高于全修，但更关键的是深耕有**独占质变能力**（新丹方/新阵法/新招式），
全修没有。里程碑是深耕的核心奖励。

### 4.3 蒙特卡洛校验（test/build.bal.js）

新建测试脚本，断言：

```
断言 1（等效时间律）：
  三种纯 build（剑道型/丹道型/阵法型）打同一章节 boss
  → 胜率落在同一个带内（如 55%~65%），差值 ≤ 10%

断言 2（深耕 > 全修）：
  深耕一条路的角色 vs 全修角色 打同一 boss
  → 深耕型胜率 ≥ 全修型（里程碑能力的价值）

断言 3（无绝对最优）：
  三种纯 build 各自至少有 1 个遭遇类型胜率最高
  → 剑道打硬战最强，丹道打消耗战最强，阵法打探索型最强

断言 4（全修不趋零）：
  全修型的总收益 > 任何单路的 60%
  → 全修可行但不是最优（不惩罚探索型玩家）
```

## 六、三条路的核心取舍示例

```
同一个韩立，同一年的 12 个月：

剑道型：闭关 10 月参研青元剑诀 → 7 层剑影分光
        + 2 月切磋练剑意
        → 血色禁地：正面硬闯封岳，剑芒+剑盾+分光

丹道型：百药园 6 月 + 采药 3 月 + 炼药 3 月
        → 药理 40+，自炼凝神丹/筑基丹增效
        → 血色禁地：靠丹药底牌堆续航，毒修路线

阵法型：制符 4 月 + 布阵练习 4 月 + 采买符纸 4 月
        → 阵法 30+，洞府聚灵阵 + 困足阵旗自产
        → 血色禁地：预布阵旗控场，诱敌入阵
```

**三条路不互斥但时间互斥**——你可以全练，但每条都浅；深耕一条，另两条只有基础水平。
这就是法环"属性点有限"在时间维度的翻译。

## 七、与既有系统的乘法关系

| 乘法组合 | 效果 |
|---------|------|
| 剑道 × 法宝轴 | 剑形法宝 + 高层剑影分光 = 分影数增加（technique-tiers §7.3） |
| 丹道 × 命途轴 | 高药理 = 可制特殊丹药救 NPC（fate-design 道岔的资源门槛） |
| 丹道 × 底牌轴 | 自炼增力丹 = 战前底牌多一张（pouch 系统） |
| 阵法 × 探索轴 | 阵旗 + 探索格 = 控场先手（exploremap preps） |
| 阵法 × 洞府轴 | 聚灵阵 × 灵泉 × 小绿瓶 = 三重闭关加成（乘性） |
| 剑道 × 丹道 | 高层剑术 + 增力丹 = 短期爆发极高（layerMul × 丹药 buff） |
| 丹道 × 阵法 | 药田产出 + 制符材料 = 共享采集经济 |
| 阵法 × 剑道 | 困阵困敌 + 剑影分光 = 控住后爆发（控+斩） |

## 八、落 balance.js 的接口预案

```js
// balance.js 新增（待实装时落地）

// 丹道加区：影响可携带底牌品质/数量
alchemyBonus(alchemyLevel) {
  // 对数递减 + 里程碑台阶
  const base = Math.log(1 + alchemyLevel * 0.08) * 0.2;
  const milestones = [
    { at: 20, bonus: 0.05 },  // 养元丹
    { at: 40, bonus: 0.08 },  // 凝神丹
    { at: 60, bonus: 0.10 },  // 增力丹
  ];
  const ms = milestones.filter(m => alchemyLevel >= m.at)
                        .reduce((sum, m) => sum + m.bonus, 0);
  return 1 + base + ms;
},

// 阵法加区：洞府修为加成 + 探索控场时长
formationBonus(formationLevel) {
  const base = Math.log(1 + formationLevel * 0.08) * 0.15;
  const milestones = [
    { at: 20, bonus: 0.04 },  // 自制困足旗
    { at: 30, bonus: 0.08 },  // 洞府聚灵阵
    { at: 50, bonus: 0.10 },  // 战场困阵
  ];
  const ms = milestones.filter(m => formationLevel >= m.at)
                        .reduce((sum, m) => sum + m.bonus, 0);
  return 1 + base + ms;
},

// 剑道已有 layerMul()，不重复
```

## 九、红线

1. **三条路不可有绝对最优解**——每次蒙特卡洛跑出某条路胜率偏高 5% 以上，必调参
2. **里程碑能力不可买到**——只能靠花时间肝，灵石买不到捷径（"时间是唯一通货"）
3. **考据优先**：能力名称/解锁顺序严格遵循动漫考据（剑芒/剑盾/剑影分光的层级不可调）
4. **乘法三律**：三条路的能力必须与已有系统相乘，不可成为孤立页签
5. **爽文契约**：任何一条路走到底都能通关——build 决定"怎么赢"，不决定"能不能赢"
