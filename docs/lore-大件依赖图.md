## 〇、核心模型：客观恒在 + 异闻预知层（七效菜单）+ 异闻录图鉴

### 0.1 客观恒在（最高原则）

**所有怪 / 材 / 大件入口都客观存在**，与"听没听过异闻"无关。异闻只改变"你知道多少、能拉来多少
助力 / 准备 / 赏金"，**绝不改变它存不存在**。墨蛟你可以探索直接撞见，也可以提前触发异闻先知其
弱点——但墨蛟客观就在那里。

- **妖王栖地 `beastHabitat`**：标了此旗的探索点（如 `houshan_explore` 七玄门后山深处）是妖王的
  客观栖地。**纵未听闻异闻，深处亦可能撞见**盘踞此地的妖王（已伏诛者排除），只是事先不知。
- **engine 实装**（`engine.js` `enterExplore`）：
  - 身负异闻（`s.beastRumor`）→ 深处 boss **名实一致** = 异闻那一头 + 预知层（弹"异闻在耳"语）；
  - 未闻异闻 → 按 `beastHabitatChance`（默认 0.3）从**未伏诛**异闻妖王池随机取一头注入深处，
    **不弹预知语**（撞见即知）；其余时候深处仍是寻常散修。
  - 已伏诛者（`s.slainBeasts[]`）退出栖地池，不再刷。
  - **非栖地点不受牵动**：血色禁地（`xueshi_jindi`）有自带 `bossEnemy:"mojiao"`，**不挂
    `beastHabitat`**，墨蛟照旧是剧情固定 boss（用 `flags.mojiao_slain`，**不在** `beastRumors` 池）。

### 0.2 异闻 = 可选「预知层」七效菜单（情报面纱 §104 的兑现，全部复用旧系统·零新引擎）

异闻是游戏早有的「情报面纱」（`bigitem-design.md` §104：L0 听说有此物 → L2 知道在谁手里 / 怎么炼）
的兑现。下面每条都是**可选叠加**——不触发=照样能撞见、照样掉链入口材，只是更险更盲。

| # | 效果 | 复用的旧系统 | 触发后 |
|---|---|---|---|
| ① | **指路**（定位·寻踪加速） | 风云录 clues + 舆图 | 线索逐条浮现、标注所在区域、缩短寻踪步数 |
| ② | **识弱**（弱点·出招情报） | element 克制系数 + 战斗意图 | 知五行弱点 / 狂暴阶段 → 战斗里转「已知破绽」（先手 / 趁虚窗口） |
| ③ | **召援同道**（一起讨伐） | 同道系统 side `kind:"ally"`（pacing §六 / ally-ai-design） | 牵出一个也在追这头妖王的同行者并肩一场（倒下=重伤退场非死亡） |
| ④ | **悬赏扬名**（委托·事后名声） | 委托 quests + 妖材经济 + 扬名时刻 | 伏诛后额外赏金（灵石/丹药/妖丹）+ 露脸入风云录 |
| ⑤ | **备战窗口**（先知→准备） | 爽文契约 + pacing 准备窗口 | 提前听闻=给调底牌的时间（买符/炼丹/借法器/约同道）；接 PR#27 §九击杀闭环 |
| ⑥ | **避坑择时**（风险情报） | clues 文案 + 遭遇配置 | 预警"有巢穴同伴/满月更强/守着幼崽"，让你选何时何地打 |
| ⑦ | **借物**（临时借法器/符丹） | 装备 / 消耗品 | 同道或委托人临时借你一件法器或塞几枚符丹，打完归还/消耗 |

**不画"传闻→大件"依赖边**：传闻是情报增强，不是获取门槛。大件的客观入口写在各自 `guide` 里。

### 0.3 异闻录（图鉴形式）

异闻录做成**图鉴**（复用人物图鉴/大件图鉴的渲染范式，乘法·零新引擎）：

- **触发 → 入录留痕；未触发 → 给一定量引导**（恒在原则下，未触发也提示"此地或有名堂"）。
- **三类条目**：①**妖王**（栖地客观存在的具名猎物）②**特殊材料**（复用进大件链入口，如墨蛟角/皮鳞）
  ③**重要情报**（剧情钩子/弱点/坊市风声）。
- 异闻**不必每地点都铺**，但**当前剧情可达地的配套不得留白**（见 AGENTS.md §一·6 推剧情即补全红线）。
- *（UI / 数据 schema 待「异闻扩充 PR」设计稿拍板后实装——本档先立模型，不预建未拍板的 UI。）*

  圆满回药庐「悟剑」得 `s.swordMastery`，大成解锁绝技「连环眨眼」（剑势上限+2）。

- **`keepsake` 唯一信物**（羁绊）：养交情到深厚/挚交，故人一次性回赠贴身之物（`s.keepsakes[]`），入图鉴留痕、不可转赠。

> **妖材→法宝链**（`bigitem-design.md` 妖材经济）：墨蛟=黄枫谷篇·血色禁地剧情固定 boss（**不在** `beastRumors`
