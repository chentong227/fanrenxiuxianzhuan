> 用户原话：「台词主要是要收敛，含蓄，留白，真正让观众震撼的永远是那个说不清道不明的
> 感受，而不是写出来的文字。」「凡人修仙传的核心就是收敛，也是中华传统文化的美——含蓄、留白。」
>
> 这把尺管**所有剧情旁白/选项回执（aside / text / choice.return / settleLedger echo 等玩家可见文本）**。
> 写新剧情、改旧剧情，一律先过这把尺。

## 一句话判据

> **旁白可以交代「发生了什么 / 韩立在盘算什么」，但不要替玩家定义「此刻该有什么感受 / 这件事的意义」。**
> 把眼泪留给玩家自己流——你把它先擦了，余味就没了。

## 违反模式（要改·收敛）

1. **替玩家总结意义的「尾句」**：情感节点结尾用旁白点题——「他变了/救他也是救自己/这便是XX劫/
   从此是两个人了」。→ **停在动作或画面上**，意义不说。
   - ✗「你只淡淡叮嘱他一句『莫再糟践了』——救他，也像在救当年的自己。」
   - ✓「你只淡淡叮嘱他一句『莫再糟践了』。」
2. **明说而非暗示（点名联想对象）**：直接报出「想起墨彩环」「想起张铁」。→ 用具体物象/地名/
   一张脸让玩家自己连线。
   - ✗「恍惚想起嘉元城里那个再也回不去的身影——墨彩环。」
   - ✓「恍了一恍——很多年前，嘉元城里也有过这样一张脸。」
3. **替玩家问出潜台词的反问**：「是不是也会是这般光景？」「这笔账，又该如何算？」→ 删去反问，留沉默。
4. **把表情/泪点写在脸上**：「你心里却空落落的，像替自己补了句迟到的话」「老泪纵横地谢了又谢」。
   → 不写表情，写一个克制的动作（转身、半晌没动、合上棋盒）。

## 保留（不动·这些不是煽情）

- **韩立的战术推演 / 藏拙判断**：人设核心（「正面硬拼非其对手，但修仙之争比谁算计深」）——是性格，不是替玩家抒情。
- **世界事实 / 信息交代**：「这便是乱星海」「结丹凌驾筑基之上」——传递信息，留。
- **分支状态钩子**：`if (s.flags.xxx)` 里解释前因后果的 aside——玩家需要这些信息。
- **动漫核定的高光独白**：顿悟偈语、经典台词原文——该说的就说（但只在「那一刻」说，别提前剧透）。
- **必要的因果交代**：settleLedger 点名出处（铁律3）——但措辞同样收敛，别把感受写满。

## 工作流（逐篇）

1. 按篇章读**情感重头戏节点**（夺舍/挚友死/离别/夺宝/坐化/顿悟），不是全文逐行。
2. 只动违反四模式的句子，疑似「保留」的不动（克制，不制造无意义改动）。
3. 每篇一批，跑 `node test/{journey,ledger.audit}.test.js`，分批 commit。
