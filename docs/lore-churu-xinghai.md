# 初入星海篇 · 设定圣经（实装用 lore）

> 2026-06-17 动漫年番考据核定（详证见 `docs/churu-xinghai-design.md`，本文件为实装精简版）。
> **红线：动漫版为唯一剧情/情感锚点**；原著仅补动漫未展开的大件/功法机制并标源。
> 主锚＝年番1《凡人修仙传》第四季**《初入星海》ep61~72** ＋《凡人星海飞驰》序章 ep73~76。
> 章节类型：新大陆层（world-architecture §4）——首次解锁**乱星海海图**，过场大章＋两段重头演出。
> 起点：再别天南篇通关（arc4_complete·章末落海）；终点：天星城**金丹大成**（realmTier 1→2·arc5_complete）。
> **章节边界（用户裁决·方案甲）**：一路做到结丹成功，群岛全在本篇。

## 一、脊柱（动漫年番原创线·≥2 源核定）

携曲魂借古传送阵落乱星海（跌境·毁阵断追）→ 登**魁星岛**（逆星盟乌丑登场）→ **镇妖台擂台**
帮顾家夺经商权、藏拙获居留 → **小寰岛**闭关重修至筑基后期巅峰（三转重元功·一转）→ 魁星城遇旧识
**文樯（文思月之父）**，为夺「降结丹门槛」的**降尘丹**同赴六连殿**镇妖大典** → 擂台与**冯三娘**等
团战**越级五阶婴鲤兽**（幼体堪比六阶）、以阵法困兽**极限斩杀**夺彩 → **大典惊变**：逆星盟乌丑勾结
妖修风希、六连殿一长老反水，炸开镇妖台、放出镇压百年的**上代妖兽之王·十级雷鹏**并打通内外星海
通道 → 雷鹏破封屠戮·踩双圣石像；**风希大战斩杀雷鹏、夺走雷鹏双翅（风雷翅之材料）**离场 →
**妙音门门主（紫灵之父）夫妇殉难**，韩立乱中**救下小紫灵（汪凝）**、斩**逆星盟古长老**脱身 →
**内星海防御大阵失效·乱星海大乱** → 韩立顺势远赴**外星海杀妖取丹**发家致富（全是妖丹·偶得噬金虫）→
（后期）**星宫大长老金魁出世·孤身示威极阴岛**（炸岛·星宫着手收复内星海）→ 返**天星城**苦修、
**首次结丹失败**演出 → 觅长生式渡劫 → **天星城金丹大成**（换新装·保留青袍伏笔）。

> ⚠ 已纠正错误：v0/v1 曾把魁星岛事变写成原著「六连殿出海围捕婴鲤兽·团灭·通缉」——那是**原著线**；
> 动漫**魔改为镇妖大典**，本篇一律以动漫为准。

## 三、大件与功法（机制·原著补充处已标）

- **三转重元功**（#2）：青元剑诀修满触发「散功重修」——techLayers 清零重升、但保留一份**真元精纯
  乘性印记**（zhuanImprint·每转 ×1.08~1.12·属性适当保留→「重修即变强」即时反馈）。**不动 balance.js**。
- **噬金虫四用法**（#5）：复用 `combat.js` 神雷 `chargeCost` **共享池**（charges.shijinchong·耗尽哑火）——
  附体 `shijin_fu` / 出战 `shijin_chao` / 变武器 `shijin_blade` / 变身外化身 `shijin_huashen` 四手同抽一池。
- **降尘丹**（#4）：镇妖大典「出力最大者」赏·**降低结丹门槛**——并入结丹资粮门槛（`bigRealmRites.core`）。
- **雪灵水 / 天火液**：结丹灵药（魁星城求购未果·外星海/天星城方得）。
- **结丹特殊晋级机制**（#4/#15·觅长生手感）：充实 `bigRealmRites.core`——require 加三转/大衍诀三层/妖丹×N/
  降尘丹/雪灵五行丹；consume 真实消耗；择时环境乘性；**首次脚本必败**（对照曲魂先结煞丹）→章末真·可玩渡劫。
- **大衍诀三层**（#7）：结丹「综合因素」之一。
- **青竹蜂云剑（本命）+ 天雷竹/金雷竹 + 银月**（#6）：本篇**只留钩子+传闻**——紫灵给的是**数千年天雷竹**
  （界三大神竹·白/蓝雷竹级），**金雷竹是韩立用小绿液催熟出的万年形态**（→6 根万年金雷竹→72 口青竹蜂云剑·
  银月器灵）；本命飞剑实装留下篇《星海飞驰》。
- **风雷翅**：本篇**仅出现材料**（风希斩雷鹏夺其双翅）；真正炼制＝**下篇外海风云**（韩立为采**伴妖草**误入
  风系领地被风希擒、被迫帮炼，趁机抢夺；雷遁 `fenglei` trait 之正典来源在彼落地）。
