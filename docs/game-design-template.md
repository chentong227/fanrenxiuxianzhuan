## 三、模块详解

### §A 真选择框架

#### 问题
几乎所有 choice 只有一个选项，"选择"只是确认键。

#### 解决方案

**规则**：每个篇章至少 2 个"真选择"节点，每个真选择必须满足：

1. **≥2 个可选选项**，每个选项有不同的 `effect` 或 `resolve`
2. **后果可见**：选择后至少在以下一个维度产生可感知差异：
   - **命途参数**（fate-design 道岔）
   - **物品/资源**（得/失不同）
   - **战斗难度**（后续战斗敌人强弱不同）
   - **叙事分支**（看到不同的剧情文本）
3. **不可撤销**：选择后设 flag，后续叙事引用该 flag

**选择类型矩阵**（每章至少覆盖 2 种）：

| 类型 | 示例 | 后果维度 |
|------|------|---------|
| 道德选择 | 忘尘丹：喂/不喂 | 命途参数+叙事分支 |
| 资源博弈 | 血色禁地：稳守/深入 | 物品数量+战斗难度 |
| 路线选择 | 洞府：灵泉眼/僻静谷 | 增益类型+扬名涟漪 |
| 战术选择 | 某战：正面强攻/迂回设伏 | 战斗难度+时间消耗 |
| 社交选择 | 对某NPC：坦诚/藏拙 | 羁绊参数+后续支援 |

**实装规格**：

```javascript
// story.js 选择节点模板
{
  id: "xxx_choice",
  choices: [
    {
      text: "选项A描述",
      hint: "后果提示（不给死答案，给方向暗示）",
      effect(s) {
        // 设置 flag / 给物品 / 改参数
        State.setFlag("choice_a");
        return { text: "选择A的叙事结果", kind: "good" };
      },
    },
    {
      text: "选项B描述",
      hint: "后果提示",
      effect(s) {
        State.setFlag("choice_b");
        return { text: "选择B的叙事结果", kind: "sys" };
      },
    },
  ],
}
```

**验收标准**：
- 玩家选 A 和选 B，后续游戏体验有可感知差异（至少一处文本/战斗/物品不同）
- 选择有 hint 但 hint 不暴露最优解

### §B 心魔战规格

#### 问题
结丹心魔劫一回合秒杀（80 HP vs 348 HP），"平生执念所化"比普通妖兽还脆。

#### 解决方案

**规则**：所有大境界心魔战必须满足以下规格：

1. **回合数 ≥ 5**：心魔不能被一回合秒杀。通过以下机制保证：
   - 心魔 HP = 玩家 HPMax × 1.5~2.0（不能低于玩家 HPMax）
   - 心魔每 2 回合回血一次（回血量 = HPMax × 5%）
   - 玩家开局灵力压半（spirit = spMax × 0.5），限制爆发

2. **三阶段心魔**（复用墨大夫三阶段模式）：
   - Phase 1：**执念之相**——玩家最重的业障具象（复用 `_demonFace()`），纯近战/法术对攻
   - Phase 2：**心魔反扑**——心魔获得新机制（回血/分身/护盾），须切换策略
   - Phase 3：**道心一击**——心魔血量见底时进入狂暴（攻击力×1.5），玩家须撑过最后一击

3. **心魔机制池**（每场心魔战至少选 2 个）：

| 机制 | 效果 | 应对策略 |
|------|------|---------|
| 回血 | 每2回合回5% HP | 须持续输出不能停 |
| 分身 | 召唤1个假身（50% HP，攻击力减半） | 须辨真假优先击杀假身 |
| 护盾 | 开局护盾=HP×0.3，破盾前减伤50% | 须破甲手段 |
| 反射 | 受到近战伤害时反弹30% | 须远程/法术输出 |
| 心惑 | 每3回合玩家随机一回合无法行动 | 须预留灵力应对 |
| 复活 | 首次击杀后复活50% HP（一次） | 须打两遍 |

4. **叙事绑定**：心魔的面孔和台词来自玩家真实的剧情记忆（`_demonFace()` 已实现），但须加入**当前篇章专属心魔**：
   - 结丹心魔：墨大夫之相（执念之始）+ 张铁之相（同袍之殇）+ 小妹之相（凡尘之绊）
   - 元婴心魔：南宫婉之相（情劫）+ 曲魂之相（造物之责）+ 紫灵之相（占有之念）

**实装规格**：

```javascript
// 心魔战模板
startDemonFight() {
  const s = State.data;
  const player = this.playerFighter();
  player.hp = s.hpMax; player.hpMax = s.hpMax;
  player.mp = Math.round(s.spMax * 0.5);  // 灵力压半

  const face = this._demonFace();  // 既有：业障具象
  const p1 = { /* 执念之相：face.name, HP=s.hpMax*1.2 */ };
  const p2 = { /* 心魔反扑：获得回血/分身/护盾之一 */ };
  const p3 = { /* 道心一击：攻击力×1.5，HP=剩余*0.5 */ };

  this._combat = new CombatAPI.Combat({
    player, enemies: [p1], waves: [[p2], [p3]],
    maxRounds: 12,
  });
  // ...
}
```

**验收标准**：
- 心魔战平均回合数 ≥ 5
- 玩家至少经历 2 个阶段
- 心魔的面孔和台词与玩家剧情记忆绑定

### §C survive 战差异化矩阵

#### 问题
全游戏 5+ 场 survive 战，解法完全相同（防御→结束回合）。

#### 解决方案

**规则**：每场 survive 战必须从以下矩阵中选择一个**专属机制**，不能纯"防御6回合"：

| 机制型 | 核心玩法 | 示例场景 | 已有系统复用 |
|--------|---------|---------|-------------|
| **守点型** | 保护一个固定点位（NPC/阵眼），敌人分波涌来 | 护山大阵·守阵眼 | sides[] + formation |
| **移动型** | 必须每回合移动（不能原地站），边打边退 | 护道断后·且战且退 | moveCap + 地形 |
| **限时型** | 回合数更少（3-4回合）但敌人更强，须主动击杀拖延 | 矿洞启阵·速战 | waves + objective |
| **资源型** | 须在 survive 期间收集场上散落的阵旗/道具 | 布阵·拾旗 | explore 拾取逻辑 |
| **保护型** | 保护一个弱NPC（如辛如音），NPC 死=失败 | 辛如音修阵 | sides[] + NPC HP |
| **反制型** | 须在 survive 期间给敌人叠 debuff（如毒/灼烧），叠满即胜 | 毒杀强敌 | dot + threshold |

**每场 survive 战的专属设计**：

| 现有战斗 | 当前机制 | 改造方案 |
|---------|---------|---------|
| 护山死守 | 防御6回合 | **守点型**：李化元在阵眼（固定位置），3个血侍分波扑来，玩家须拦截 |
| 护道断后 | 防御6回合 | **移动型**：每回合必须移动≥1格（原地站=被追上扣血），边打边退 |
| 矿洞启阵 | 防御6回合 | **保护型**：辛如音 HP=88 在场，她每回合被攻击，玩家须替她挡刀 |
| 燕家堡战王蝉 | 撑过血线 | **限时型**：3回合内须打出一定伤害（否则被秒杀），但不必击杀 |
| 皇宫拖时 | 防御6回合 | **资源型**：场上散落3面阵旗，须在6回合内拾齐3面（移动+拾取+防御） |

**实装规格**：

```javascript
// survive 战模板——以"保护型"为例
{
  objective: {
    kind: "survive",
    rounds: 6,
    protect: "side:0",  // 保护 side[0]（辛如音）
    failIfProtectDies: true,  // NPC 死=失败
    winLog: "阵启了！",
  },
}
```

**验收标准**：
- 同一篇章内不能有两场相同机制的 survive 战
- 每场 survive 战的解法不同于"每回合防御"

### §D 收集探索循环

#### 问题
关键道具全由剧情赠送，缺少"去哪里找、怎么凑"的玩家主动性。

#### 解决方案

**规则**：每个篇章至少 1 个"收集探索循环"，必须包含以下 4 步：

```
①情报 → ②探索 → ③获取 → ④转化
```

| 步骤 | 内容 | 系统复用 |
|------|------|---------|
| ①情报 | 从NPC/传闻/古籍得知某材料在某地 | 传闻系统 + NPC对话 |
| ②探索 | 亲自前往该地点，探索/战斗/解谜 | 舆图探索 + 遭遇战 |
| ③获取 | 击杀/采集/交易获得材料 | 战斗奖励 + 采集 + 坊市 |
| ④转化 | 材料交给巧匠/丹炉/自炼 → 法宝/丹药/功法 | 妖材成器链 + 炼丹 |

**每章收集循环设计**：

| 篇章 | 情报 | 探索 | 获取 | 转化 |
|------|------|------|------|------|
| 七玄门 | 墨大夫药谱暗示毒草 | 后山采集 | 毒草×N | 决战底牌 |
| 黄枫谷 | 禁地主药在中环以深 | 血色禁地舆图 | 主药+墨蛟材 | 乌龙夺+神风舟+阵图 |
| 魔道争锋 | 矿道深处有魔修藏宝 | 矿道箱庭探索 | 符宝/材料 | 战前备料 |
| 再别天南 | 坊市传闻绿煌剑在夺舍者手 | 嘉元城外遭遇 | 战胜夺取 | 直接装备 |
| 初入星海 | 妖丹可换资粮 | 外海猎妖（探索） | 妖丹×30 | 结丹耗材 |

**关键改造**：初入星海的结丹材料不能全由剧情赠送，改为：
- 降尘丹：须在魁星岛坊市用妖丹×10交换（玩家须先猎妖攒丹）
- 雪灵水：须在外海特定地点探索采集（舆图探索）
- 天火液：须击败特定妖兽（遭遇战）概率掉落
- 妖丹×30：须外海猎妖累积（已有循环，但数量须自己打够）

**验收标准**：
- 玩家至少有 1 个材料是"自己去探索/战斗获得的"，不是剧情自动给的
- 收集过程有"去哪里→怎么得→到手了"的完整体验

### §E 敌人设计六型

#### 问题
移动→贴脸→放剑芒适用于 90% 的战斗，缺少需要特定策略的敌人。

#### 解决方案

**规则**：每个篇章至少覆盖 3 种敌人型，全游戏覆盖全部 6 种：

| 型号 | 名称 | 核心机制 | 克制策略 | 已有系统 |
|------|------|---------|---------|---------|
| Ⅰ型 | **铁壁型** | 高护盾/高甲，正面打不动 | 破甲/毒/灼烧穿透 | shield + armor + dot |
| Ⅱ型 | **高闪型** | 高闪避，近战打不中 | 远程法术/必中技能/暴露debuff | dodge + range |
| Ⅲ型 | **召唤型** | 召唤小怪，杀不完 | 先杀本体/范围攻击 | waves + adds |
| Ⅳ型 | **回复型** | 每回合回血，消耗战打不赢 | 爆发输出/禁疗debuff | regen + burst |
| Ⅴ型 | **远程型** | 远程攻击，近身就跑 | 追击/封锁移动/远程对射 | range + move |
| Ⅵ型 | **狂暴型** | 血量越低攻击越高 | 控速/一波带走/留底牌收尾 | enrage + burst |

**现有敌人对照**：

| 敌人 | 当前型 | 应有型 | 改造 |
|------|--------|--------|------|
| 墨大夫 P1 | 普通 | Ⅰ型（毒掌近战） | 已达标 |
| 铁奴 P2 | 普通 | Ⅰ型（百毒不侵须强攻） | 已达标 |
| 余子童 P3 | 普通 | Ⅱ型（无形无质须镇魂） | 已达标 |
| 金光上人 | Ⅰ型（金钟罩40盾） | Ⅰ型 | 已达标·最佳实践 |
| 陆云风 | 普通 | Ⅵ型（血越低越疯） | 可改 |
| 墨蛟 | 普通 | Ⅳ型（回血）+Ⅵ型 | 已部分实现（婴鲤兽有P2回血） |
| 血侍×3 | 克隆 | Ⅰ型/Ⅱ型/Ⅴ型各一 | **须改：甲魁梧斧奴=Ⅰ型，乙枯瘦刺奴=Ⅱ型(高闪)，丙精悍链奴=Ⅴ型(远程链)** |
| 胥王假丹 | 高HP | Ⅳ型（回血）+Ⅵ型 | 可加回血机制 |
| 金背妖螂 | 普通 | Ⅴ型（远程镰+高机动） | 可改 |
| 夺舍者 | 普通 | Ⅲ型（召唤绿煌剑影） | 可改 |
| 婴鲤兽 | Ⅳ型（P2回血） | Ⅳ型 | 已达标·最佳实践 |
| 心魔劫 | 太弱 | Ⅳ型+Ⅵ型+分身 | **须改：见§B** |

**验收标准**：
- 每篇章至少 3 种敌人型
- 玩家不能用同一套打法通关所有战斗

### §F 友军指令系统

#### 问题
sides 系统的友军有 persona AI 但玩家无法给指令，"群战"变成了"看AI打"。

#### 解决方案

**规则**：当战场有 ≥1 个友军 side 时，每回合玩家可下达 1 条简令：

**简令池**（3选1，每回合选一次）：

| 简令 | 效果 | 适用场景 |
|------|------|---------|
| **集火** | 友军本回合攻击玩家当前目标（伤害×1.2） | 需要快速击杀某敌人 |
| **护援** | 友军本回合移动到玩家身边并防御（替玩家挡刀） | 玩家血量危险 |
| **自由** | 友军按自身 persona AI 行动（默认行为） | 不需要指挥 |

**实装规格**：

```javascript
// combat.js 新增：友军简令
// 每回合开始时，若有 sides，UI 显示三个简令按钮
// 玩家选择后设置 _sideOrder，友军 AI 执行时读取
Combat.prototype.setSideOrder = function(order) {
  this._sideOrder = order;  // "focus" | "protect" | "free"
};

// 友军 AI 执行时
Combat.prototype._sideAct = function(side) {
  const order = this._sideOrder || "free";
  if (order === "focus" && this._combatTarget != null) {
    // 攻击玩家当前目标，伤害×1.2
  } else if (order === "protect") {
    // 移动到玩家身边，防御
  } else {
    // 按 persona AI 行动（现有逻辑）
  }
};
```

**UI 设计**（手机端适配）：
- 战斗界面底部，回合开始时弹出三个小按钮：[集火] [护援] [自由]
- 选完后按钮消失，友军执行
- 不选=自由（3秒自动选free）

**验收标准**：
- 群战时玩家可以指挥友军"打谁/保谁"
- 简令有可感知的战术差异

### §G 高阶事件参与框架

#### 问题
风希/雷鹏等元婴级冲突是纯演出，玩家完全旁观，"大事件与我无关"。

#### 解决方案

**规则**：高阶事件（玩家无法正面参与的元婴+级冲突）必须给玩家一个"侧面参与"窗口：

| 参与型 | 玩家做什么 | 影响 | 示例 |
|--------|-----------|------|------|
| **拾遗型** | 大佬交战后，玩家在战场边缘拾取散落的宝物/材料 | 获得稀有材料 | 雷鹏陨落后拾雷羽 |
| **救人型** | 大佬交战波及无辜，玩家救人 | 羁绊+后续回报 | 风希战中救被困散修 |
| **破坏型** | 玩家破坏敌方阵眼/补给线，间接影响战局 | 战局倾斜 | 破坏逆星盟阵旗 |

| **诱敌型** | 玩家作为诱饵引开一方注意力 | 为友方创造机会 | 引开追兵让风希脱身 |

**初入星海改造**：

| 现有纯演出 | 改造方案 |
|-----------|---------|
| 雷鹏陨落 | **拾遗型**：雷鹏陨落后，玩家须在限定回合内冲入战场边缘拾取雷羽（限时探索） |

**验收标准**：

### §H 过渡章规格

#### 问题
燕家堡作为过渡章缺乏独立游戏价值。

#### 解决方案

**规则**：过渡章必须包含至少 1 个"独立游戏价值"：

| 价值型 | 内容 | 示例 |
|--------|------|------|
| **备战型** | 给玩家时间整理装备/学技能/买物资 | 燕家堡：战前坊市采购 |
| **探索型** | 一个小型可探索区域 | 燕家堡：堡内暗探（获取情报） |
| **收集型** | 一个小型收集循环 | 燕家堡：战前收集符纸/丹药 |
| **社交型** | 与NPC对话获取情报/羁绊 | 燕家堡：与董萱儿/墨彩环深谈 |

**燕家堡改造**：
- 战前加入"堡内自由探索"窗口（3-5个可点NPC/地点）
- 与董萱儿对话→获取战王蝉弱点情报（战斗中有额外提示）
- 与墨彩环对话→获得疗伤丹×2（战斗中可用）
- 堡内兵器架→可拾取一把临时符剑（战斗中额外技能）

**验收标准**：
- 过渡章有至少 1 个非"点对话→下一关"的可操作内容
- 玩家在过渡章能获得至少 1 项战斗增益

### §I 长时间跳跃参与框架

#### 问题
小寰岛闭关20年变成一行字，玩家完全不参与。

#### 解决方案

**规则**：长时间跳跃（≥12月）必须给玩家"参与窗口"：

**方案：分段跳跃 + 插曲选择**

```
闭关20年 → 分4段（每段5年）
每段开始：玩家选择本段重点
  - 苦修《三转重元功》（修为+多，心境-多）
  - 参研《大衍诀》（神识+多，修为+少）
  - 温养法宝（法宝熟练度+，修为+少）
  - 调息养心（心境回满，修为+少）
每段结束：闭关插曲（顿悟/走火/外界变故——已有 _seclusionInterlude）
```

**实装规格**：

```javascript
// 长时间跳跃参与模板
doLongSeclusion(totalMonths, segmentSize) {
  const segments = Math.ceil(totalMonths / segmentSize);
  for (let i = 0; i < segments; i++) {
    // 弹出选择：本段重点
    // 选项：苦修/参研/温养/调息
    // 各有不同的 cultivation/sense/mood/artifact 收益分配
    const choice = await this._seclusionChoice(i, segments);
    this.cultivate(segmentSize, choice);  // cultivate 接受 focus 参数
    // 插曲（已有）
    this._seclusionInterlude(segmentSize, gain);
  }
}
```

**初入星海改造**：
- 20年闭关改为4段×5年
- 每段选择重点：苦修/参研大衍诀/温养乌龙夺/调息
- 每段结束有插曲（顿悟/走火/外界变故）
- 玩家可以自己决定"这20年怎么分配"——修为多还是神识多还是法宝强

**验收标准**：
- 长时间跳跃中玩家至少做 2 次选择
- 不同选择导致不同的属性/技能分布

### §J 节奏图（锚帆曲线）

#### 规则
每个篇章必须画一张"锚帆曲线"，标注：

```
紧张度
  ↑
  │    ╱╲      ╱╲
  │   ╱  ╲    ╱  ╲     ← 锚（战斗/危机）
  │  ╱    ╲  ╱    ╲
  │ ╱      ╲╱      ╲
  │╱                ╲   ← 帆（探索/收集/休整）
  └──────────────────→ 时间
   入  探  战  帆  战  帆  BOSS
```

**要求**：
- 每两个"锚"（战斗/危机）之间必须有至少 1 个"帆"（探索/收集/休整）
- 不能连续 3 个"锚"（如再别天南的护山→护道→矿洞三连survive）
- 篇章末尾的 BOSS 战前必须有 1 个"帆"做备战窗口

**现有篇章节奏诊断**：

| 篇章 | 节奏 | 问题 |
|------|------|------|
| 七玄门 | 入→帆→锚→帆→锚(三阶段) | **达标** |
| 黄枫谷 | 入→帆→锚→帆→锚→帆→锚→帆→锚 | **达标·最佳** |
| 燕家堡 | 锚→锚→锚 | **不达标·三连锚无帆** |
| 魔道争锋 | 锚→锚→锚→锚→锚 | **不达标·五连锚无帆** |
| 再别天南 | 锚→锚→锚→帆→锚 | **不达标·三连锚** |
| 初入星海 | 锚→帆→锚→帆→锚→帆→锚 | **达标** |

**改造方向**：
- 燕家堡：战前加帆（堡内探索）
- 魔道争锋：矿道探索段加帆（已有箱庭感，须实装为可操作探索）
- 再别天南：护山→护道之间加帆（短暂休整/整理装备）
