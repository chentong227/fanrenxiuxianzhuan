# 强度物理学：境界乘区 × build 加区 + 特区

> 用户核心论断（2026-06-11 凌晨）：「元婴后期大修士为什么这么强？在游戏里怎么表现？
> 怎么设 build 和数值才能有这种效果？**因为有真，所以才爽。**
> 把剧情的爽落到 build 和数值上的平衡后的爽才是真的爽。」
>
> 本文是承重墙（一致感）的数值化实现，是人界篇全程的战力宪法。
> 配合 retention-design.md（一致感/大件依赖图）与 balance.js 使用。

## 一、原著四问的机制拆解（设计依据）

1. **元婴后期为何天南仅三人级别的强**：境界差是乘法且乘在五个维度——
   法力总量（池子×数倍）、神识（先手权/看破/压制对方法宝）、遁速（追得上=对方无不败权）、
   **法宝驱动门槛**（古宝唯元婴可驱，低境界得宝用不出，原著铁律）、
   神通维度（元婴出窍/瞬移等，低境界无应对=维度压制）。
   "仅三人"是生态学：寿元天花板+资源垄断+功法断层；活到顶点者**积累也是满配**。
2. **为何力压十几个中期**：元后基准≈中期×2.5（面板），更兼围攻方"协同折损"
   （各自为战/互相忌惮/不肯拼命，原著每场围攻战的写法）+大修士范围神通反多人。
3. **韩立元婴中期为何力敌元后**：原著答案就是一张 build 单——风雷翅（速度均势）、
   青竹蜂云剑×72+青元剑诀（行动经济）、辟邪神雷（条件特攻）、噬金虫（无视防御底牌）、
   大衍诀（神识超同阶段位）、炼体远超法修。每个子系统点到同阶上限之上，叠加≈一个小境界。
   注意精度：是"力敌"（能战/能保/能耗），不是"平推"；斩杀仍靠底牌时机。
4. **元后为何能抗化神三招**：保命底牌（档次外防御至宝+消耗性免死）+对方顾忌。
   跨大境界无"战胜窗口"，底牌只买"生存窗口"。

## 二、战力公式

```
战力 = 境界基准（乘区） × build同阶浮动（1.0 ~ 2.0） + 特区（条件触发）
```

### 乘区（境界 = 不可绕过的真）
- 灵力总量：每大境界 ×3~4（练气→筑基→结丹→元婴…）。
- 神识：每大境界跨段位（决定先手/看破意图/压制法宝）。
- 法宝驱动门槛：品阶硬卡（境界不足，宝物无法全力驱动甚至无法祭起）。
- 遁速基准：大境界跳变。
- 神通维度：每大境界解锁低阶无解的新动词（御器→遁术→出窍…）。

### 加区（build = 肝的数值出口，同阶浮动 1.0~2.0）
功法品阶 / 法宝数量与品质 / 灵宠 / 炼体 / 丹药底子——各有同阶上限，
全满 ≈ 高半个到一个小境界。**每个大件兑现都落在此区，可在面板上看到自己变强。**

### 特区（韩立式越级的四个合法通道）
| 通道 | 原著原型 | 机制形态 |
|---|---|---|
| 条件特攻 | 辟邪神雷克魔功 | 对特定敌种伤害×2~3，克制=合法以下克上 |
| 行动经济 | 蜂云剑阵/傀儡/噬金虫 | 多单位/多段攻击，一回合打出数回合输出 |
| 速度均势 | 风雷翅 | 遁速≥对方 → 可随时脱战（不败权） |
| 免死底牌 | 防御至宝/保命符箓 | 消耗性"生存窗口"，跨境界保命不保胜 |

### 越级公式（明牌告知玩家）
- 加区满配 + 特攻对路 + 底牌在手 → **力敌高一小境界**；
- 高两小境界 → 可保命、可逃脱、不可胜；
- 跨大境界 → 只能跑/苟/借力（免死底牌买生存窗口）。
- 金光上人战即此公式的既成原型（正面必败+毒/暗器特攻+底牌量定胜率），全游戏照此执行。

### 围攻折损（强者反多人的真实感）
多人围攻具名强者时：围攻方行动协同打折+忌惮（不肯用底牌）+强者范围神通；
使"一个元后力压十几个中期"在数值上可复算。

## 三、具名强者 = 乘区 × 满配积累，且配置可查看

天机榜/风云榜人物点开即完整 build（功法/法宝/神通/底牌/性格标签），参照觅长生 NPC 面板
（连"天劫成功率"都展示）。三重价值：强得可信（真）、强得可学（路线图）、
强得可垂涎（"他那把剑总有一天是我的"= 长期惦记）。
背景修士（npcsim）境界数据已真实，补 build 生成与展示层。

## 四、与既有系统的咬合
- 肝→大件兑现：大件=加区/特区的格子，兑现即面板可见的战力位移。
- 一致感：具名强者按本公式配置，剧情强=数值强。
- 爽文契约：乘区的"真"给胜利标价；特区给玩家合法越级通道；免死底牌+fail-forward
  保证压制不变成劝退。
- 扬名时刻：越级战胜利=名声大额兑付的法定场合。
- 突破三段式：大境界突破=乘区跳变，故收益巨大是数学事实而非演出修辞。

## 五、落地节奏
- 七玄门篇（现）：公式已隐性存在（金光上人战），把"越级公式"写进战前情报提示。
- 黄枫谷篇：乘区表定数（练气→筑基跳变）、风云榜+NPC build 展示、围攻折损入战斗引擎。
- 乱星海篇：特区四通道全面开花（蜂云剑/辟邪神雷/灵宠/风雷翅原型按动漫考据落地）。
