## 〇、核心理念（三句话）

1. **静态立绘的动作感 = 时间轴上的物理**：位移曲线（预备→突进→收势）+ 反作用（击退/倾斜/白闪）+ 打击停顿（hitstop）。
2. **特效的精品感 = 叙事结构**：预兆（酝酿威力）→ 爆发（1~3 帧的巅峰）→ 余韵（世界记住这一击）。同色粒子换皮 ≠ 差异化，**剪影唯一性**才是。
3. **大招 = 屏幕级事件**：压暗、聚气、白闪、镜头 punch、时间冻结——让全屏幕为这一击让路。

## 一、S1 · 动作手感引擎 v1（全局收益——所有战斗立刻"活"）

### 1.1 打击停顿（hitstop，最高优先）

- 命中瞬间冻结战场演出 60~120ms：轻击 60 / 重击·暴击 100 / 终结·大招 140。
- 实现：`UI._hitstop(ms)` —— `#axis-field` 加 `.hitstop` 类（所有单位 `animation-play-state: paused` + transition 暂停），
  同拍配受击白闪。格斗游戏手感的一半来自这一下。
- 红线：**只冻演出层不冻逻辑**；连续多段命中（多段技）只在首末拍停，不叠加成慢放。

### 1.2 攻击三拍（attacker 位移曲线）

| 拍 | 时长 | 动作 |
|----|------|------|
| 预备 | 150ms | 向后撤 8~12px、微沉 2px（蓄力感） |
| 突进 | 120ms | 朝目标方向快冲 24~36px（近战冲得远、施法只前倾 8px），ease-out |
| 收势 | 300ms | 缓慢归位，ease-in-out |

- 实现：CSS keyframes `atkLungeR`/`atkLungeL`（按朝向两套）；`flushCombatFx` 攻击拍给攻击者挂类。
- 远程/法术变体：`castPushR/L`——预备同款、"突进"改为前倾+扬手帧（配合 S3 姿态替换）。

### 1.3 受击反应（defender 反作用）

- 命中拍：白闪一帧（`filter: brightness(2.4)` 60ms）→ 击退 8~14px（背向攻击者）+ 倾斜 2~4° → 弹回。
- 暴击/重创：击退加倍 + 落地小尘环（已有 ring 复用）。
- 已有 `shake/hitflash` 保留，新反应叠加其上（方向化是新增量）。

### 1.4 死亡演出（已有 slaying/ink-burst 基础上补）

- 终结一击必带 hitstop 140ms + 镜头 punch（已有 `_camPunch`）；
- 人形敌补"跪倒下坠"位移（translateY + 倾斜 + 透明度），妖兽保留水墨溅散。

## 二、S2 · 三拍特效规范（神雷完全体 = 全游戏标杆模板）

### 2.1 三拍结构（一切大招必须走完）

```
预兆(0.4~0.8s)          爆发(瞬间)                余韵(1~2s)
天色/环境响应      →    白闪+hitstop+镜头punch  →  痕迹留存+粒子消散
"要来了"                "就是这一下"               "它真的发生过"
```

### 2.2 神雷·劈 完全体（shenlei_pi）

| 拍 | 演出 |
|----|------|
| 预兆 | 战场整体压暗 40%（overlay 渐入 0.5s）+ 顶部金云汇聚（canvas 金色云团脉动）+ 低频雷鸣先声（audio 新 recipe `thunderFar`）+ 韩立扬手姿态（S3 换图） |
| 爆发 | 金雷三层描边折线自天劈落（已有 `lightning({gold})`）+ **全屏白闪 2 帧** + hitstop 140ms + 镜头 punch + 目标白闪击退 |
| 余韵 | 目标脚下**焦痕 decal**（DOM 元素·战斗内留存）+ 金色余烬上飘 1.5s + 目标身上电弧噼啪三小闪 + 雷声长尾 |

- 克邪魔（×1.8 特攻）命中时：爆发拍额外一圈金色冲击环 + 战报点名"辟邪神雷，专诛邪魔！"。
- **此模板落地后，其余大招（乌龙夺/剑阵/虚天鼎）照三拍逐个翻新**（后续批次，不在本批强求）。

### 2.3 屏幕级组件（可复用件）

- `Fx.dimField(pct, ms)` 战场压暗层；`Fx.whiteFlash(frames)` 全屏白闪；`UI._decal(cell, kind)` 地面痕迹（焦痕/血渍/冰纹）。

## 四、S4 · 六极真魔功·六魔编排（温天仁战 = 演出天花板 + B 站 demo）

### 4.1 考据（2026-07-10 · ≥2 源互证：Bangumi 番组计划 / 起点百科 / 动漫 138 集解说×2）

- **温天仁**：结丹后期巅峰，"乱星海元婴之下第一人"，逆星盟魁首六道极圣亲传弟子。性骄纵张扬。
  **正典外貌：清秀斯文、约二十七八，麻衣、高冠、赤足，眉宇间隐有金芒**（⚠ v301 生成的"玄黑华袍"立绘不符——须重生成）。
  法宝：仿品八门金光镜、天阳鎏金针、四象蟠龙带。另修双修秘术引龙诀、化劫大法（不入战斗）。
- **六极真魔功**：施展后幻化**六具魔影分身，各司其职——攻击/防御/阵法/治疗/偷袭/幻术**（动画 138 集明演）。
- **韩立的正典解法**：拖久必败 → **必须先杀"治疗"分身**；胜负手=**金雷竹制品克一切邪魔**（辟邪神雷特攻），另用阴魔斩。
- **战斗结局**：正面苦斗**未分生死**——被鬼雾卷入阴冥之地（绝灵不可用法力），后在暴风山韩立以凡人武术杀之。
  ⇒ **本战归属《外海风云篇》**；现阶段以 `?demo=wentianren` 独立入口先行打样（demo 打到胜利=演出收卡），

## 四·五、名场面演出打磨（2026-07-10 用户新增任务线——"重要的情节的演出做好"）

> 用户原话："把重要的情节的演出做好，素材和台词和演出效果，特效等等。比如红尘劫我就担心效果很差，
> 一定要符合动漫的感觉。"——名场面不是"文字卡+一张 CG"，是**素材×台词×运镜×特效×音**五件套齐活。

### 标准（每个名场面过这五问）

1. **素材**：有专属 CG/场景图吗？CG 与情绪对位吗（竖版 _p 齐吗）？
2. **台词**：是动漫原台词/贴合动漫语气吗？（红尘劫遗书已是动漫原文——这是标杆）
3. **运镜**：用了 cutscene 的 shot 预设吗（pushIn/establish/shock…）？情绪节点有镜头呼应吗？
4. **特效**：fx 原语（flash/burst/lightning/ambient…）配到情绪拍上了吗？
5. **音**：bgm 切轨 + amb 环境床 + sfx 点缀齐吗？静默也是设计（坐化那一拍该静）。
