# 剧情设定圣经 · 七玄门篇

> **⚠ 2026-07-10 全线考据复核勘误（canon-audit-2026-07-10.md 为权威源·已实装）**：
> 本档两处勘误：①寒毒来历=夺舍之夜交手所中**魔银手之毒**（非长春功暗手·TMDB ep4+红袖 ep5）；②反杀后身份=伪造墨大夫回乡书信、以弟子身份接任药庐（「小韩大夫/韩神医」·原著65章+动漫5集），非扮成墨大夫本人。另金光上人战=公开死契血斗（符宝秒杀顾师叔→韩立收符诱其解金钟罩），此战名动全门=离门动因；离门前与厉飞雨当面话别。均已实装。


> 本文件是游戏剧情的"真值来源"。所有数据、事件、文案必须忠于此处的设定，不得擅自改动人物、功法、境界与因果。后续章节继续在此文件追加。
>
> 设定核对来源：RMJI 剧情维基（rmji.fandom.com）等公开剧情资料，已与动画七玄门篇对齐。

## 一、核心原则

0. **优先忠于动漫改编版**：当动漫与小说原著有出入时，**一律以动漫改编为准**（如功法获取经过）。
1. **忠于动画**：人物、功法、物品、因果关系不得篡改。
2. **七玄门篇全程韩立处于「练气期」**，绝不可在本篇突破到筑基。
3. **韩立资质平庸（四灵根/伪灵根）**，修炼缓慢，这是"靠苦修与万全准备弥补天资"主题的根基。
4. **韩立战胜墨大夫，靠的不是修为碾压，而是准备 + 机智 + 小绿瓶之利**。游戏机制必须体现这一点。

## 五、本篇剧情主线（完整脉络，按阶段，忠于动画/原著）

> 全篇分三幕：入门 → 夺舍危机 → 帮派之争。务必按此顺序与因果，不可错乱。

### 第一幕 · 入门（青牛镇 → 七玄门）
- **A0 青牛镇**：韩立生于青牛镇贫苦韩家，排行老二。三叔在七玄门做事，回乡时见韩立机灵，提议带他去参加七玄门入门选拔，以图改善家境。
- **A1 赴考**：韩立随三叔离乡，与同乡少年**张铁**结伴，前往七玄门参加入门测试。
- **A2 入门选拔**：二人资质皆非上佳，初试未过；凭一股韧劲获得补考机会，半年后再试得以入门（外门记名）。
- **A3 拜师墨大夫**：门中以医毒闻名的**墨大夫（墨居仁）**看中韩立与张铁，收为药童弟子，传授《长春功》，并按修炼层数赏银。

### 第二幕 · 夺舍危机（核心）
- **B1 习功结友**：韩立修《长春功》开始练气；结识好友**厉飞雨**（武学有成，赞韩立记性奇佳）。张铁无法引气入体，止步第一层，改修武体（象甲功）。
- **B2 得小绿瓶**：韩立偶得**神秘小绿瓶**，发现绿液可催熟草木，暗中培育灵药、偷偷服食加速修炼。
- **B3 暗修精进**：瞒着墨大夫修到**练气四层**，远超其预期。
- **B4 张铁之死**：张铁奉命外出后失踪（门中只道离门）。真相是被墨大夫与其幕后**余子童**残魂合谋掳杀，尸身炼成铁傀 →**铁奴/曲魂**。
- **B5 夺舍真相**：墨大夫体内附着修士**余子童**的残魂（早年被墨大夫下毒、以血魂咒附身）。余子童元神受损、夺不了墨大夫凡躯，遂养韩立、授长春功，把韩立身体炼成夺舍容器。
- **B6 反杀**：夺舍之夜，韩立以**眨眼剑法+催熟毒+暗器**毒杀墨大夫，被铁奴打倒；墨大夫死后余子童元神出窍夺舍，韩立以**功力（运功镇魂）**镇灭之。夺得遗物，收张铁尸傀为曲魂。

### 第三幕 · 帮派之争（金光上人，本篇高潮与收尾）
- **C0 隐姓蛰伏**：反杀后，韩立**顶替墨大夫的身份**，继续在门中做药师，低调修炼、积蓄底牌（毒、暗器、灵药），无人知他已是修士。数年过去。
- **C1 帮派冲突**：**野狼帮**（帮主**贾天龙**）为争夺周边富庶城镇的控制权，与七玄门屡屡冲突，互有死伤（前后十余次）。
- **C2 请来杀手**：贾天龙为对付七玄门的三位师叔（高手），重金请来一名修仙者——**金光上人**（来自青苓的矮胖和尚，会金符、剑符、金钟罩等术法）。
- **C3 师叔落败**：金光上人出手，轻易击败七玄门的强者，门派危在旦夕。
- **C4 韩立出手**：门中唯一也是修士的“药师韩立”暗中出手，以**毒、暗器与算计**击杀金光上人（硬拼非其对手，靠的是准备与偷袭），力挽狂澜，救下全门。
- **C5 夺宝离门**：韩立夺得金光上人的宝物——**升仙令、金符、剑符、金钟罩**等。凭升仙令，他得以离开七玄门，奔赴**黄枫谷**踏上筑基之路。

> 关键提醒（绝不可错）：
> - **厉飞雨不死**（韩立结婴回门时两家尚有后人）。
> - **墨大夫是凡人**，被余子童残魂附身、图谋夺舍；**张铁死后成曲魂**。
> - **金光上人是野狼帮（贾天龙）重金请来的修仙杀手**，矮胖和尚；韩立靠毒+暗器+算计杀之，夺**升仙令**等宝物。
> - 反杀墨大夫后，韩立**顶替墨大夫身份**继续蛰伏，才有后来的帮派之争。
> - 全篇**封顶练气期**；筑基是黄枫谷篇的事。

## 六、境界体系（全局，本篇只到练气数层）

练气期（一层~十三层） → 筑基期 → 结丹期 → 元婴期 → 化神 → ……（后续章节展开）

- 练气与筑基之间是巨大鸿沟，需**筑基丹 + 灵力圆满 + 良好状态**，否则成功率极低。
- 本篇封顶：**练气期**。不开放筑基突破。
- 动画/原著中练气共十三层；本篇做到练气数层即可，反杀墨大夫契机为练气四层，帮派之争时修为更进。

## 八、勘误与跨篇埋线（务必遵守，避免剧情错置）

> 以下为已确认的剧情归属，纠正早期实现中的错误。**这些内容不属于七玄门篇本体，严禁在七玄门篇出现。**

### 墨大夫的妻女 / 墨彩环（属于「嘉源城」线，七玄门篇之后）
> 来源：RMJI Fandom Wiki（Mo Juren / Mo Caihuan 词条），经梯子核对。

- **墨大夫即墨居仁（Mo Juren）**：本是兰州名医「鬼手」，**凡人**，年仅约 37 岁却显衰老。早年中毒，外出寻药途中遇一重伤修士**余子童（Yu Zhitong）**，二人争一株灵药，余子童垂死之际以血魂之术将残魂打入墨居仁体内。墨居仁受「夺命咒（血咒）」副作用而急速衰老；余子童授其"夺舍换身"之谋。后墨居仁遇同样遭算计的七玄门掌门，救其性命，受邀加入七玄门。
- **墨彩环（Mo Caihuan）是墨居仁与燕氏（Lady Yan）之女**，出身/活动于**嘉源城 · 墨府**。她**在第二卷、即韩立离开七玄门之后才登场**。
- 正确因果（嘉源城线）：韩立**中了毒**，为求解毒所需的**「温阳宝玉」**，假托"墨大夫弟子"身份上**墨府**，向墨家说明墨大夫死讯。墨家得知他是修士后与他做交易——韩立替墨家**铲除霸王庄的欧阳飞天**，换取温阳宝玉解毒。墨彩环初时还想算计韩立，韩立赠其「绕香丸」。
- 后续：墨家（野狼帮/蛟龙帮一系）败于彩虹门，燕氏与墨彩环逃亡、辗转燕灵堡谋生；多年后韩立途经，治好燕氏之疾。墨彩环终老于墨府（韩立赴乱星海八年后病逝）。

- **实现红线**：
  - 七玄门篇的 NPC 名册、剧情、人物图鉴**不得包含墨彩环、墨府、嘉源城、温阳宝玉、欧阳飞天、霸王庄、绕香丸**等——它们都属于离门后的「嘉源城线」。
  - 这些是**后续篇章**的钩子，待开发对应篇章时再实现。
  - 余子童 = Yu Zhitong；本篇可继续以"墨大夫体内的夺舍残魂（余子童）"统一呈现，但不展开嘉源城细节。
