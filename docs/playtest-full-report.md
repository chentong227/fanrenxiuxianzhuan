## 一、七玄门篇（stage 0→9）

### 1.1 剧情推进

**节点链**：青牛镇 → 入门选拔 → 拜墨大夫 → 同门之谊（结识厉飞雨）→ 神秘小绿瓶 → 暗藏锋芒（练气四层）→ 张铁之死 → 决战墨大夫（三阶段）

- 开场节奏极好：从凡人村落到修仙门槛，"小绿瓶"的引入是第一个"金手指揭晓"时刻。
- 张铁之死是第一个情感重击——"说好互相照应的"伙伴被炼成尸傀，叙事到位。
- **决战墨大夫三阶段**是全游戏最精心的战斗设计：
  - Phase 1：墨大夫本人（毒掌+腐骨毒针）
  - Phase 2：铁奴/张铁尸傀（百毒不侵，须正面强攻）
  - Phase 3：余子童元神（无形无质，唯镇魂可伤）
  - 每阶段有不同的克制逻辑，迫使玩家切换策略——全游戏唯一一场"必须动脑"的战斗。

### 1.2 自由度

- **低但有呼吸感**。入门选拔有选择分支（拜师方向），虽然最终都指向墨大夫，但"选"的动作本身给了玩家主体性。
- 小绿瓶培养灵草→吃道具的循环是第一个"玩家自主决策"系统：种什么、什么时候吃、要不要留着卖钱。

### 1.3 爽感

- **决战墨大夫是全游戏爽感峰值之一**。三阶段各有 introNote 告诉你克制思路，打赢后的"反杀"感极强。
- 扮猪吃虎机制在此战首次亮相：藏了多少层修为，开战那一刻全亮出来——"凡人韩立"的核心爽点。
- **缺点**：前期修炼节奏偏慢，练气四层前基本是纯叙事，战斗少。

### 1.4 收集感

- **首个收集循环成立**：小绿瓶 → 培养灵草 → 吃道具提升修为。每回合都有小正反馈。
- 毒草、暗器作为决战底牌——"准备得越多越能赢"的逻辑首次落地。

### 1.5 综合评价：**A-**

开局最好的篇章。三阶段决战至今仍是全游戏最佳战斗设计。小绿瓶收集循环、扮猪吃虎、张铁之死的情感冲击——三大支柱都立住了。缺点是前期节奏慢、自由度低。

## 二、黄枫谷篇（stage 10→~50）

### 2.1 剧情推进

**节点链**：入谷四连（被夺筑基丹）→ 百药园杂役 → 坊市归途杀陆云风救陈巧倩 → 忘尘丹选择 → 血色禁地（名额大会→五日采药→封岳狙杀→墨蛟深潭→血色之夜）→ 拜李化元为师 → 乌龙夺炼成 → 筑基 → 青元剑诀 → 洞府选择 → 元武国代工（齐云霄一炉三件）→ 叶师叔之报 → 篇终

- **内容最丰富的篇章**。四幕结构完整：立足（入谷杂役）→ 冒险（血色禁地）→ 蜕变（筑基+青元剑诀）→ 收束（叶师叔因果了结）。
- **血色之夜**是全游戏最好的叙事段落：墨蛟淫囊之毒→不能说的那一夜→"韩立。立碑的立。……我记下了。"——留白与余韵，仙侠言情最佳实践。
- **忘尘丹选择**是全游戏唯一一个真正有后果的分支：喂忘尘丹→她不记得你；不喂→她记得你（命途参数自此不同）。这个选择有重量。
- 陆云风之战是"同阶恶战"范本——为救人、为那两枚丹，动机清晰。

### 2.2 自由度

- **全篇最高**。
  - 血色禁地有"稳守外环 vs 深入中环"的选择（不同药量、不同风险）
  - 忘尘丹二选一有真实后果
  - 洞府选择（灵泉眼 vs 僻静谷）有不同增益
  - 元武国代工需要玩家主动北上（`where: "yuanwu"` 地点门禁）
  - 小绿瓶培养循环持续可用
- **但**：核心剧情仍是线性的，选择影响的是支线参数而非主线走向。

### 2.3 爽感

- **杀陆云风**：同阶碾压+救人+夺丹，一石三鸟。
- **墨蛟之战**：背靠背与南宫婉并肩作战，首个"男女并肩战boss"时刻。
- **筑基成功**：十九颗丹碎在丹田里，最后一颗成了——"拿命堆出来的"突破有重量感。
- **青元剑诀传授**：主修换代的里程碑感强。巨剑术"聚芒成剑、倾天斩落"视觉效果出色。
- **叶师叔之报**：夺丹之仇"世界替你收了"——因果账本结算的满足感到位。

### 2.4 收集感

- **全游戏最强**。
  - 小绿瓶培养循环（持续可用）
  - 血色禁地：主药×4/6、墨蛟角/鳞/皮/内丹
  - 乌龙夺（妖材成器链·首件）
  - 神风舟 + 颠倒五行阵基础版（齐云霄一炉三件）
  - 青元剑诀（主修换代）
  - 筑基丹×20（从被夺到夺回的完整弧线）
  - 洞府（灵泉眼/僻静谷）
  - 大衍诀残卷（伏笔·叶师叔遗物）
- **妖材→法宝链**是最佳收集设计：禁地猎妖→材料入手→巧匠代工→法宝成型，每一步都有"挣来"的感觉。

### 2.5 综合评价：**A**

内容最丰富、自由度最高、收集感最强的篇章。血色之夜的叙事、忘尘丹的选择、妖材成器链的收集——三个维度都有峰值表现。缺点是中段（百药园杂役期）节奏略平淡，血色禁地舆图探索尚未完全实装。

## 三、燕家堡之战（过渡章）

### 3.1 剧情推进

**节点链**：李化元调令 → 重逢墨彩环/结识董萱儿 → 战王蝉破阵（大BOSS）→ 逃出被强征入伍

- 短小精悍的过渡章，四节点强制链，无分支。
- 战王蝉作为"撑过血线即撤离"的生存战，叙事意图是"你打不过元婴级魔修，活着就是胜利"——仙凡有别的核心表达。
- 重逢墨彩环的情感节点好："可别又把人丢下不管"——呼应七玄门篇旧缘。

### 3.2 自由度

- **极低**。纯线性过渡，无选择。

### 3.3 爽感

- **低**。战王蝉战是"打不过就跑"的设计，爽感来自"活着出来"而非"击败boss"。忠于原著但体验被动。
- 董萱儿初登场有"名门之后俯视你"的张力，但此战无机会展示她的战力。

### 3.4 收集感

- **无**。过渡章不产出新收集物。

### 3.5 综合评价：**B-**

作为过渡章完成了任务——连接黄枫谷与魔道争锋，建立"天南变天"的紧迫感。但本身缺乏独立游戏价值，纯叙事驱动。

## 四、魔道争锋篇（含京城篇）

### 4.1 剧情推进

**节点链**：前线待命 → 矿道巡逻（武炫并肩）→ 血茧铁罗 → 王管事 → 皇宫三组对位群架（刘靖/宋蒙/钟卫娘）→ 拖时布阵战（傀儡蜥蜴+刘靖）→ 阵成决战（fieldCycle颠倒五行阵×六相→胥王假丹肉身→血凝五行丹复生神魂）

- 皇宫决战是全游戏最复杂的战斗编排：30格宽战场、三战区fronts声明式布局、fieldCycle六相循环、waves二阶段boss、sides复数化。
- **fieldCycle六相**是"阵法即战斗系统"的最佳实践：木缠足→火灼烧→金镜影→水心魔→土陷脚→万象星河（climax），每回合切换，suppress逐回合反噬boss。
- **但**：血侍同质化问题（palace-battle-fixme 已知待修），三战场分别战斗的意图在实装上打了折扣。

### 4.2 自由度

- **低**。全程线性，无分支选择。矿道探索有箱庭感但仍是脚本触发。

### 4.3 爽感

- **阵成决战**是全游戏第二爽的战斗（仅次于墨大夫三阶段）：fieldCycle逐回合压制+底牌齐发+同袍补刀，"毕其功于一役"的史诗感到位。
- 武炫并肩的巡逻战是"群阵练兵场"，"先斩领队=群势自溃"的战术有教学价值。
- **但**：血侍三连战数值偏低，缺乏挑战感；拖时战的"防御6回合"解法过于机械。

### 4.4 收集感

- **几乎没有**。此篇章不产出新法宝/功法/材料，纯剧情驱动。

### 4.5 综合评价：**B-**

剧情是骨架，战斗是肉，但缺少"凡人韩立"的算计感——玩家没有"准备→冒险→收获"的循环。血侍同质化是已知待修问题。

## 五、再别天南篇

### 5.1 剧情推进

**节点链**：曲魂炼化 → 金背妖螂 → 夺舍者 → 金鼓原群战 → 护山死守 → 护道断后 → 跌境 → 南宫婉赠灵石 → 辛如音殉阵 → 古传送阵启 → 乱星海

- 情感密度极高：李化元燃身护阵、南宫婉目送离别、辛如音泣血修阵——三场告别各有重量。
- 跌境演出（纯叙事，数值不变）是巧妙的"仙凡有别"表达。

### 5.2 自由度

- **低，但有呼吸感**。虽然仍是线性，但跌境后的"这口气迟早拿回来"给了玩家心理上的主体性。
- 金鼓原群战有 sides 系统（李化元/南宫婉/曲魂并肩），但玩家无法指挥友军。

### 5.3 爽感

- 金鼓原群战（4 敌人 + 3 友军 sides）是全篇最有"战场感"的战斗。
- **但**：连续三场 survive 战（护山、护道、矿洞）节奏重复，"防御 6 回合"的解法完全相同，到第三场已有疲劳感。
- 夺舍者战有"吸修"机制叙事，但战斗层面未体现（数值不变）。

### 5.4 收集感

- 获得绿煌剑、奇虫榜玉简——有"离别前的遗赠"意味，但无实装使用体验。
- 大挪移令作为关键道具贯穿剧情，有"物随人走"的连贯感。

### 5.5 综合评价：**B+**

情感最好的篇章。三场告别各有千秋，"再别"的主题贯穿始终。但 survive 战的重复设计和友军不可控是明显短板。

## 六、初入星海篇

### 6.1 剧情推进

**节点链**：落海斩妖 → 魁星岛 → 擂台藏拙 → 小寰岛闭关20年 → 文樯重逢 → 镇妖大典 → 婴鲤兽越级斩 → 雷鹏陨/风希取材 → 救紫灵 → 外海猎妖 → 天星城落户 → 结丹失败 → 结丹成功

- 四幕结构完整，"落难→立足→积蓄→突破"的弧线清晰。
- **亮点**：擂台藏拙（故意压境界演弱）是全游戏最"韩立"的叙事设计；结丹首败→再闯的"鲜有不败"设计忠于原著精神。
- **遗憾**：风希/乌丑/雷鹏的元婴级冲突是纯演出（脚本化群乱），玩家完全旁观，有"大事件与我无关"的割裂感。

### 6.2 自由度

- **中等**。小寰岛闭关20年是时间跳跃，玩家不参与每月决策；外海猎妖有"引妖→杀→剖丹"的循环但仍是脚本触发。
- 结丹前的资粮收集（降尘丹/雪灵水/天火液/妖丹×30）有"备料"感，但材料全由剧情赠送，无探索/交易/选择路径。

### 6.3 爽感

- 婴鲤兽越级斩杀（489 HP vs 320 HP）是全篇最有张力的战斗——phase 2 回血机制制造了"以为赢了结果没赢"的惊喜。
- 结丹心魔劫一回合秒杀（80 HP vs 348 HP，双法术连击）反而不太爽——心魔作为"平生执念所化"应该是最难的一关，结果比普通妖兽还脆。
- 擂台藏拙战（320 vs 96）有叙事趣味但战斗本身无挑战。

### 6.4 收集感

- **本篇第二强**。噬金虫+霓裳草的"引杀组合"、妖丹积累、降尘丹/雪灵水/天火液三件套——有"攒家底"的满足感。
- **但**：所有收集物都是剧情自动获得，玩家没有"去哪里找、怎么凑"的探索过程，削弱了"挣来"的感觉。

### 6.5 综合评价：**A-**

内容最丰富、节奏最好的篇章之一。四幕各有不同的体验重点，不像再别天南那样 survive 战扎堆。结丹心魔劫太弱是最大遗憾。

## 八、全局问题清单

### P0 · 严重破坏体验

1. **选择是假的**：几乎所有 choice 只有一个选项，"选择"只是确认键。如果要叫"选择"，至少给 2 个有后果的分支。
2. **心魔劫太弱**：作为"平生执念所化"的终极心战，一回合秒杀严重破坏叙事与玩法的一致性。
3. **survive 战机制单一**：全游戏 5+ 场 survive 战，解法完全相同（防御→结束回合），需要差异化机制。

### P1 · 明显短板

4. **收集无探索**：关键道具全由剧情赠送，缺少"去哪里找、怎么凑"的玩家主动性。
5. **战斗策略固化**：移动→贴脸→放剑芒的循环适用于 90% 的战斗，缺少需要特定策略的敌人。
6. **友军不可控**：sides 系统的友军有 persona AI 但玩家无法给指令，"群战"变成了"看 AI 打"。

### P2 · 体验不佳

7. **血侍同质化**：皇宫决战三血侍是克隆体，缺乏个体辨识度（已知待修）。
8. **元婴级事件纯旁观**：风希/雷鹏等高阶冲突是脚本演出，玩家无参与感。
9. **过渡章空洞**：燕家堡作为过渡章缺乏独立游戏价值。
10. **闭关20年时间跳跃**：玩家完全不参与，"20年苦修"变成了一行字。

## 九、亮点总结

1. **墨大夫三阶段战**：全游戏最佳战斗设计，每阶段有不同克制逻辑。
2. **血色之夜叙事**：留白与余韵的最佳实践，"韩立。立碑的立。"余味无穷。
3. **忘尘丹真实选择**：全游戏唯一有真实后果的分支。
4. **妖材→法宝链**：墨蛟角→乌龙夺的完整收集弧线。
5. **fieldCycle 阵法系统**："阵法即战斗系统"的创新设计。
6. **擂台藏拙**：全游戏最"韩立"的叙事时刻。
7. **结丹首败→再闯**：忠于原著"鲜有不败"精神的 fail-forward 设计。
8. **婴鲤兽 phase 2 回血**："以为赢了"的惊喜，战斗设计最佳实践。
9. **扮猪吃虎**：hidden realm reveal 机制，"凡人韩立"的核心爽点。
10. **因果账本**：夺丹之仇→叶师叔之报，"世界替你收了"的满足感。
