> 测试时间：2026-06-23  
> 测试方式：Playwright 自动化（iPhone 14 Pro Max 视口 430×932 DPR3）  
> 测试存档：storyStage=63（modao_e4_santuan），筑基初期，京城

## 一、改造概述

本次改造针对魔道争锋篇皇宫决战的三场连续战斗，引入三项差异化机制：

| 战斗 | 原玩法 | 改造后 |
|---|---|---|
| 三组对位群架 | 3个相同血侍 | **3种差异化血侍**（铁壁/高闪/远程） |
| 拖时布阵战 | 纯拖6回合 | **资源型 survive**：拾取3面阵旗可速胜 |
| 阵成决战 | fieldCycle 自动轮转 | **手动相位选择**：玩家每回合选一个相位 |

## 二、逐场体验

### 2.1 三组对位群架 — 血侍差异化

**验证结果：9/9 通过**

三个血侍现在有完全不同的战术定位：

- **斧奴（铁壁型）**：HP 180 / 甲 8 / 敏 6 / 速 10 / 移 1
  - 招式：血煞重斧（近身1格）、裂地斩（charge近身）
  - 体验：铜皮铁骨，普通攻击打上去像挠痒。需要破甲手段（毒/灼烧/穿甲法术）或绕过他先杀脆皮

- **刺奴（高闪型）**：HP 90 / 甲 0 / 敏 22 / 速 20 / 移 3
  - 招式：血影刺（1~2格 pierce）、鬼步连刺（近身）
  - 体验：鬼魅难中，闪避极高。需要必中手段（暴露/符箓灵光）或范围覆盖

- **链奴（远程型）**：HP 110 / 甲 2 / 敏 12 / 速 14 / 移 2
  - 招式：血链横扫（2~4格）、锁链绞杀（1~3格 pierce）、退步抽链（2~3格）
  - 体验：隔空放风筝，射程最远。需要追击/突进/封锁移动

**体验评价**：
- **差异化感**：明显。三个敌人名字、血量、甲、敏、移速、射程全不同，玩家一眼能看出"这个硬、那个快、那个远"
- **战术选择**：玩家需要决定先杀谁——脆皮高闪的刺奴血最少但最难命中；链奴远程骚扰烦人但中血中甲；斧奴最肉但近身才能打到人
- **同袍配合**：三战线 fronts 机制 + 刘靖/宋蒙/钟卫娘各挡一线，玩家居中策应，有"哪条线告急去哪边"的决策

**不足**：
- autoResolve AI 不会针对不同敌人选择不同策略（都用最高伤害技能），实际手操体验应更好
- 缺少 UI 上的敌人特性提示（如"高甲""高闪"标签），新手可能需要打一轮才知道

### 2.2 拖时布阵战 — 阵旗拾取（资源型 survive）

**验证结果：3/3 通过**

改造要点：场上散落3面阵旗（位置 3/8/12），玩家须移动到旗旁花一个主行动拾取。

- **拾齐3面 = 阵提前布成 = 速胜**
- **6回合未拾齐但活着 = 拖到阵成 = 险胜**
- **死了 = 败**

**体验评价**：
- **核心张力**：从"原地防御拖时间"变成"跑位拾旗 vs 躲刀"的博弈。每回合要决定：是跑去拾旗（花主行动+暴露在Boss攻击范围）还是稳一手防御
- **空间决策**：3面旗分散在 3/8/12 三个位置，玩家从 pos=1 出发，需要规划最优拾取路线
- **风险/收益**：拾旗花一个主行动（这回合打不了人），但3旗齐=提前2~3回合结束战斗，省下那几回合的受伤
- **双胜利条件**：拾齐速胜 vs 拖满险胜，给"手残"玩家留了后路，但鼓励主动拾旗（更快=更少受伤）

**不足**：
- autoResolve AI 不会拾旗（只会打/防），拖时战只能靠 survive 机制险胜。手操时拾旗体验更好
- 阵旗热点用的是 cave-hot 样式，图标显示"旗"字，视觉上不够醒目（可考虑专用阵旗图标）
- Boss HP 600/甲 7，玩家几乎打不动——这是对的（拖时战不该硬拼），但可能让玩家觉得"打了半天没效果"

### 2.3 阵成决战 — 手动相位选择

**验证结果：4/4 通过 + 4/4 手动选相位验证通过**

改造要点：真·颠倒五行阵6个相位从自动轮转改为玩家手动选择，每回合选一个未用过的相位。

6个相位：
1. **木·竹海缠足**：suppress 5% + 暴露 + 玩家闪避+5%
2. **火·焚天灼烧**：suppress 7%（最高单体压制）
3. **金·镜影分身**：suppress 5% + 暴露
4. **水·渊薮心魔**：suppress 5% + 玩家灵力+8
5. **土·沙葬陷脚**：suppress 6% + 暴露 + 玩家护盾+12
6. **万象星河·倒悬**：suppress 13% + 暴露（climax 重击）

**体验评价**：
- **玩家 agency**：从"被动看阵法自动轮转"变成"我选这一回合用哪个相位"。核心决策：什么时候用大招（万象星河 13% suppress）？是先用小相位攒暴露标记，还是直接开大？
- **资源管理**：6个相位只能各用一次（整场战斗），16回合的战斗意味着不是每回合都有相位可用——前6回合有阵法加持，后10回合靠自己+底牌
- **相位组合**：暴露相位（木/金/土/万象）叠在一起时，玩家攻击+30%伤害。可以选连续暴露相位创造爆发窗口
- **UI 可见性**：相位按钮在 combat console 中显示，已用的灰掉，当前回合激活的高亮。测试确认 UI 可见

**不足**：
- autoResolve AI 不会手动选相位（只用第一个），导致决战败北。手操时每回合选相位才是正确玩法
- 相位用完后（第7回合起）没有相位可选，战斗变成纯底牌+平砍，可能有"阵法用完了就无聊了"的感觉
- 缺少相位效果预览（鼠标悬停看详细效果），目前只显示名称

## 三、章节差异化评估

### 改造前 vs 改造后

| 维度 | 改造前 | 改造后 |
|---|---|---|
| **核心动词** | 三场都是"打" | 群架=对症下药 / 拖时=跑位拾旗 / 决战=相位编排 |
| **玩家自由度** | 几乎无选择（自动轮转/相同敌人/纯拖时） | 每场都有实质选择（先杀谁/拾不拾旗/用哪个相位） |
| **战术深度** | 浅（打就完事） | 中（差异化敌人+资源管理+相位组合） |
| **重玩价值** | 低（每局一样） | 中（不同相位顺序/不同击杀顺序=不同体验） |

### 自由模型三层

- **路径层**（Path）：三场战斗的顺序固定（群架→拖时→决战），但每场的解法开放
- **战术层**（Tactical）：
  - 群架：先杀谁？支援哪条线？
  - 拖时：拾旗路线规划？什么时候贪什么时候稳？
  - 决战：相位使用顺序？什么时候开万象星河？
- **叙事层**（Narrative）：刘靖生死分支（由前期情报决定）已有

## 五、待改进项

1. **autoResolve 不支持新机制**：AI 不会拾旗、不会选手动相位。建议给 autoResolve 加简单策略（拾旗优先/选最高 suppress 相位）
2. **敌人特性 UI 标签**：在敌人卡片上显示"高甲""高闪""远程"等标签，降低学习成本
3. **相位效果预览**：鼠标悬停相位按钮时显示详细效果（suppress 多少、有没有暴露、有没有玩家 buff）
4. **阵旗视觉**：专用阵旗图标/动画，区别于普通采集热点
5. **相位用完后的空窗期**：第7回合起无相位可选，可考虑"相位用完后给一个微弱常驻效果"避免后段战斗枯燥

---

## 六、总结

三项改造成功将魔道争锋篇皇宫决战从"三场差不多的打"变成"三种不同核心动词的战斗"：

- **群架**教玩家"对症下药"——不同敌人要用不同手段
- **拖时**教玩家"贪与稳的博弈"——拾旗提速 vs 防御求稳
- **决战**教玩家"资源编排"——6个相位各用一次，什么时候用什么是关键

改造全部复用既有系统（hotspots/sides/fronts/fieldCycle），没有引入新系统，符合乘法设计原则。
