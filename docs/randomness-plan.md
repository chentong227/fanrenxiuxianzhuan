# 随机性规划

> 原则：**韩立人设固定**（四灵根、青牛镇出身、谨慎隐忍的性格、主线命运），随机性一律不进角色本体。
> 随机放在**世界与过程**中——这正合"凡人"主题：天赋是定数，际遇是变数，靠经营变数逆天改命。

## 一、不可随机（固定）

- 主角身份/灵根/性格/初始六维基线
- 主线剧情走向与关键因果（拜师墨大夫、得小绿瓶、张铁成曲魂、反杀墨大夫、练气封顶…）
- 关键 NPC 的命运（厉飞雨不死等）

## 二、可随机（变数所在）

| 类别 | 随机内容 | 现状 | 备注 |
|------|---------|------|------|
| **每回合灵气** | 五行灵气在权重附近浮动 | ✅ 已实现 | 战斗临场决策的来源 |
| **战斗判定** | 命中/闪避/暴击/顿悟、敌人本回合意图 | ✅ 已实现 | 神识高可看穿意图 |
| **历练遭遇** | 地点遭遇表抽取（采药/遇敌/捡物/传闻） | ✅ 已实现 | 按地点权重 |
| **采集产出** | 灵草/毒草数量、是否额外掉落 | ✅ 已实现 | |
| **奇遇事件** | 低概率触发的支线小故事（带选择与后果） | ⬜ 待做 | 见下「奇遇系统」 |
| **市集刷新** | 集镇商品种类/价格浮动、偶现稀有货 | ⬜ 待做 | 偶尔出现暗器、灵药 |
| **小绿瓶变异** | 催熟时极小概率灵草变异成更高阶灵药 | ⬜ 待做 | 强化"金手指"惊喜感 |
| **突破微扰** | 突破心战中瓶颈心魔的招式/强度小幅浮动 | 部分 | 不破坏"准备决定结果"的大盘 |
| **掉落/战利品** | 战斗胜利的物品掉落 | ✅ 基础 | 后续可加稀有掉落表 |

## 三、奇遇系统（规划，下一步）

- 在「外出历练」中，除常规遭遇外，按低概率（受悟性/神识轻微影响）触发**奇遇事件**：
  - 拾遗：捡到残破功法/丹方/材料
  - 考验：偶遇高人留下的试炼（小战斗或抉择）
  - 抉择：带道德/心境后果的两难选择（影响心魔/心境，呼应韩立谨慎人设）
- 奇遇**不改主线**，只丰富过程与资源，且结果可正可负，强化"修仙世界凶险莫测"。
- 数据结构预留：`world.js` 增加 `encounters` 中 `kind: "fortune"`，事件表单列一个文件 `js/fortunes.js`（待做）。

## 四、随机的"可控性"原则

- 所有随机源可注入（`rng`），保证**测试可复现**（已在战斗引擎实现）。
- 关键平衡（如决战、突破成败）由"准备 + 属性"主导，随机只在边际波动，**不让运气凌驾于经营之上**——这是"凡人靠准备取胜"的底线。
- 蒙特卡洛测试持续校验：随机分布不破坏既定胜率梯度。
