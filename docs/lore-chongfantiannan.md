## 二、原著骨架（【原著·确证】·时间线第五卷「名震一方」）

按 `凡人修仙时间线.md` 原文，加入落云宗后主干事件（顺序为原著叙事序）：

1. **加入落云宗**，学会**血影遁**（招牌逃生/机动术）。
2. **追踪小狐狸 → 银月夺舍被"尸××"附身的小狐狸 → 银月得实体化身**（银月从器灵→有实体，重大伙伴线兑现）。
3. 比拼得到**明清灵目**修炼机会（神通线）。
4. **修成元婴**（＝动漫 156"结婴"）。
5. **收慕沛灵作侍妾**（关系/命途线；疑＝159 集"纳妾"）。
6. **灭付家满门·完成对辛如音的誓言**（旧账了结——见 §四待核：与游戏既有"再别天南篇"辛如音线的关系）。
7. **收服至木灵婴** + 修习**大庚剑阵**（剑道 build 线大件级）。
8. 给韩家送**噬金虫变幻的飞剑**（凡人亲情线·呼应"仙凡有别·陪伴窗口"）。
9. 涵云芝、柳玉追踪至木灵婴 → **第二次放过涵云芝、收柳玉** → 得**六翼霜蚣**（灵虫线）。
10. **练成第二元婴**（煞丹分身修成元婴＝双元婴，战力质变）。
11. 见**南陇侯**、取**仓坤遗宝**。
12. **去掩月宗抢南宫婉的婚**（好玩情节 #12：抓掩月宗管事冒充身份、搜魂发现管事也倾心南宫婉）——
    **南宫婉线的重大推进/兑现**（此前魔道/黄枫谷一路埋的正宫线）。

> 之后进入「与穆兰大战 / 边界之战」＝**慕兰之战篇（177+）**，不属本篇。

- 【待核】动漫呈现：小狐狸/尸××线的具体演出。
