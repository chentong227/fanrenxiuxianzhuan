## 〇、红线与原则（先定调）

1. **版权红线（必须守）**：动画原声（OST）有版权，**不扒、不直接复用原曲**——本仓库是
   公开 GitHub 仓（GitHub Pages 部署），扒原曲入库有侵权风险。用户「直接复用」的诉求按
   **「做到和动画一个调性的原创器乐」** 兑现：参考动画配乐的**乐器/调式/情绪**，生成神似但
   原创的曲子。气质可以无限接近，旋律必须是自己的。
2. **好听 > 一切**（用户：「只要游戏体验好」）：本轮的成败标准是**主观好听**，不是"有没有声音"。
   现有 9 轨用户明确不满意 → **目标是重制到用户点头**，而非补全。
3. **复用现有系统，不另起炉灶**（乘法三律）：播放引擎 audio.js 已成熟（合成 SFX + 合成兜底
   BGM + 9 轨文件 BGM + 静音持久化 + 文件缺失自动回退），生成管线 genmusic.js 已成熟
   （Lyria 3 出 30s 循环）。本轮**只做"内容提质 + 触发校验 + 混音打磨"**，不写新播放器。
4. **克制基调不变**（art-direction §一「夜读残卷」）：苍凉、孤独、克制、凶险；音是"气口"不是
   "轰炸"。BGM 音量极低垫底（现行 file 轨 vol≈0.3、合成轨更低），SFX 短促克制。

## 二、BGM 重制方案（核心）

> 思路：**同一套 9 轨定位不变，重写 prompt 提质 + 每轨多候选择优 + 质量门把关 + 混音统一**。

### 2.1 prompt 提质（genmusic.js `TRACKS`）
现有 prompt 偏"一句话气质"。重写为**结构化提示**，每轨锚定四要素，逼近动画配乐质感：
- **主奏乐器 + 编制**（如 daily：古琴独奏为主、箫远应、留白；boss：太鼓+低音弦+号角，渐强）；
- **调式/情绪**（宫/羽调、苍凉/肃杀/灵动；明确"无唢呐无铜管"等否定项防跑偏，combat 已有先例）；
- **速度 + 律动**（BPM 区间 + 鼓点疏密）；
- **循环友好**（首尾平滑、无明显段落断点、淡入淡出留尾）。
- ⚠ 不写任何"像《凡人修仙传》OST/某首曲名"的指令（避免诱导复制）；只描述**乐器与情绪**。

### 2.2 每轨多候选 + 择优（质量门的关键）
- 每轨生成 **N≥3 个候选**（`genmusic.js` 加 `--n` 或循环改名 `bgm_<id>_c1/c2/c3`），
  我**逐个试听 + 客观指标筛**，挑最佳一条转正为 `bgm_<id>.<ext>`，其余留 `assets/audio/_cand/` 备选。
- 上游限流（Lyria 偶发 429，AGENTS.md v98 教训）→ 脚本加**指数退避重试 + 断点续跑**（已生成的跳过）。

### 2.3 质量门（客观 + 主观双关，"把关"的落地）
**客观指标（脚本可测）**：
- 时长 ≈ 28~32s；
- **循环接缝**：首尾 ~200ms 互相关/能量差低于阈值（接不上的淘汰或加交叉淡化补尾）；
- **响度统一**：全轨归一到同一目标响度（如 -20 LUFS 量级，BGM 垫底用），避免轨间忽大忽小；
- 无削波（true peak < -1 dBFS）。

**主观指标（我试听 + 给用户试听卡）**：
- 是否"一耳朵就是凡人那个味儿"（乐器对、情绪对）；
- 循环 2~3 遍不腻、不出戏；
- 与场景气质契合（daily 要静得下来、boss 要压得住、sorrow 要哀而不伤）。

> **流程**：用户提供 `OPENROUTER_KEY`（临时即可，用完即弃）→ 我跑生成 → 出**试听包**
> （9 轨 × 最佳候选，附客观指标表）发用户 →（可现场试听对比）→ 用户点头的转正落库 → 落 main。
> 不满意的轨**单独重抽**（`onlyId` 已支持），不重跑全量。

### 2.4 混音与播放打磨（audio.js 侧，小改）
- **轨间响度**：file 轨 `vol` 按轨微调（boss 稍高、daily/tense 更低），或在生成侧已归一后统一 vol。
- **切轨淡入淡出**：`Sfx.bgm` 换轨时加 ~600ms crossfade（现在是硬切/停-起），避免突兀
  （战斗↔日常切换尤其明显）。**保持幂等**（同轨不重切）。
- **首次交互解锁**：浏览器 autoplay 策略——`AudioContext`/`<audio>` 需用户手势后才出声
  （现 `ac()` 已 resume）；确认进入即有 BGM 的首个手势点接对（点"开始"即起 daily/town）。
- **兜底合成轨**保留并也顺手调一调（万一某轨没生成，回退也别难听）。

## 七、环境床（AMB）= 程序合成，不用 Lyria（R2 实测裁决）

> 2026-06 实机反馈 §10 R2：`amb_night/firefly/candle` 听着是"旋律音乐"，不是虫鸣/烛火/夜风那种环境音效。

### 7.1 排查与证据
- `scripts/genambient.js` 的提示词早已写「field-recording / 无旋律 / 无节拍 / 无乐器」，产物仍像曲子。
- ffmpeg 频谱核验（`showspectrumpic` + `aspectralstats` 平坦度）：
  - 线上 `amb_candle.mp3` 底部有一条**阶梯式低音旋律线**（每 ~5.5s 重复）+ 规律节拍竖纹；`amb_night.mp3` 有持续音高 drone 带。
  - 谱平坦度（越低越"乐"）：amb_firefly 0.051 / amb_night 0.082 / amb_candle 0.105，对比 bgm_daily（纯乐）0.025；真实田野录音应在 ~0.3–0.6。三者均贴近音乐区。
- 用更狠的英文 hard-negative 提示词（no melody/notes/bass/chords/rhythm/beat/instruments）重抽候选：平坦度升到 0.12–0.18、有改善，但**仍残留低频旋律前奏 + 规律节拍**。
- 结论：`google/lyria-3-clip-preview` 本质是**生乐模型**，硬约束也压不掉旋律与节拍——出不了纯环境声。

### 7.2 裁决：环境床走 `audio.js` 程序合成兜底
- `audio.js` 的 `AMB` 引擎本就是**纯噪声床（滤波）+ 调度短噪事件**（虫鸣=带噪脉冲列、烛火噼啪、夜风、檐雨、市集远喧），**结构上不可能产生固定音高的旋律或节拍**，且可无限循环、零依赖、极低动态——正是"景不是曲"。
- 落地：`AMB_FILES = []`（文件优先名单置空）→ 所有环境床 id 直接走合成；移除 3 个旋律 `amb_*.mp3`。
- 强化（"强化程序合成兜底"）：调度去网格抖动（间隔随机 360–880ms）、夜虫层叠第二声部、远处虫鸣垫底床（faint 4.8kHz wash）。
- 质量核验：浏览器内 `OfflineAudioContext`/`MediaStreamDestination` 录样（`__FRXXZ_AUDIO_DEBUG__` 钩子）→ 频谱图确认无旋律线、无规律节拍。
- `genambient.js` 保留备用：提示词已改成 field-recording 硬否定版；日后若接入**真正的环境音/SFX 模型**，把对应 id 加回 `AMB_FILES` 即恢复"文件优先"。
- 备选（待用户定）：若要"真实田野录音"质感，需用户提供**可商用授权**的环境音效包（版权红线同 §〇）。
