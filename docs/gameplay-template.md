# 全游戏玩法模板（Gameplay Template）

> 2026-06-23 创建。本文档是**全游戏填空模板的最高级规范**——高于 chapter-template.md
> （管篇章配置）和 chapter-systems-manifest.md（管横轴系统推进），本文档管的是
> **每个玩法节点（剧情/战斗/探索/时间跳跃）的设计质量标准**。
>
> 目标：后续任何 agent 接手做新内容时，按本模板填空即可保证设计质量。
> 模板够好，填空就够好。

---

## 一、核心原则（不可违反）

1. **每个节点必须有玩家参与**——不允许纯叙事节点只有一个"继续"按钮。
   如果是叙事，给玩家一个有后果的选择（哪怕只是 flavor 后果）。
2. **每个选择必须有真实后果**——选择改变后续演出/难度/资源/命途，而非只是确认键。
3. **乘法优先**——新玩法用已有系统相乘得到，不立新系统（multiply-design 律一）。
4. **零教学**——新机制挂到修仙常识上，不弹教学窗（multiply-design 律二）。
5. **三层惦记不为空**——任何时刻玩家有远/中/近三层目标可追（multiply-design 律三）。
6. **败有所得**——战斗失败不卡死，给信息/给资源/给重试机会（爽文契约）。
7. **一致感**——剧情强=数值强，背景强者不归玩家管（authenticity-design）。

## 二、节点类型模板

### 2.1 剧情节点（Story Node）

**模板字段**：
```
id:           唯一标识
cond:         触发条件（flag + 地点 + 境界）
skipIf:       跳过条件（已完成的互斥）
title:        章节标题
objTitle:     目标标题
objHint:      目标提示（1~2 句，给方向不给答案）
text:         叙事文本（含 stage 演出）
choices:      选择项（见下）
onArrive:     到达时执行的副作用（设 flag、给资源、记里程碑）
```

**选择项设计规范**：

| 类型 | 最少选项数 | 后果要求 | 示例 |
|------|-----------|---------|------|
| 关键抉择 | 2~3 | 每个选项改变 flag/资源/命途 | 忘尘丹之择、情报三档 |
| 战略侧重 | 2~3 | 每个选项给不同的永久/临时增益 | 闭关20年三选一 |
| 情感确认 | 1 | 仅当纯叙事收束时允许，但必须配 stage 演出 | "都埋进血色雾气里" |
| 战斗入口 | 1~2 | 可选"正面打"或"另谋"（如有准备路径） | 金光上人：硬闯 vs 毒+暗器 |

**红线**：
- 连续 3 个以上纯单选节点 = 设计缺陷，必须插入至少一个多选节点
- 选择的 `effect(s)` 必须改变至少一个持久状态（flag/资源/属性/ledger）
- 选择文本要体现角色性格（韩立=谨慎藏拙），不可出戏

### 2.2 战斗节点（Combat Node）

**模板字段**：
```
enemyId:        敌人模板 key（WORLD.enemies）
或 inline:      内联敌人定义（剧情 boss）
metaType:       encounter/showdown/breakthrough/wanhunt/revenge/survive/journey/...
introNote:      敌情提示（开战时显示在战报中——战术解谜的"题面"）
canQuick:       是否允许速决（境界碾压时）
sides:          同道/灵宠/傀儡（侧位单位）
objective:      胜利条件（kill/survive/protect/collect）
waves:          波次配置（多阶段 boss）
fieldCycle:     阵法相位（如有）
```

**敌人设计规范**：

每个敌人必须回答以下五问（填空模板）：

| 字段 | 说明 | 示例 |
|------|------|------|
| `name` | 名称（有辨识度） | "白额吊睛虎" |
| `tactics` | AI 天赋（feral/cunning/guarded） | feral=兽性直扑，cunning=算计走位 |
| `elem` | 行属（用于五行克制） | jin/mu/shui/huo/tu |
| `introNote` | 战术提示（1~2 句，点出弱点和应对） | "金风裂爪天克你的木行道基——火符灼其金煞" |
| `attacks` | 招式表（2~4 招，各有 aim/kind/weight） | normal/charge/pierce + aim: lock/cell/zone |

**敌人原型分类**（确保策略多样性，不可全用同一型）：

| 原型 | 特征 | 玩家应对 | 已有实例 |
|------|------|---------|---------|
| 蛮兽型 | 高速/高伤/低智，扑咬+蓄力 | 闪避/打断/拉距离 | 灵狼、白额虎 |
| 甲坚型 | 高护甲/低机动，正面难破 | 破甲/毒/灼烧/绕背 | 铁背蜈蚣、银甲角蟒 |
| 法修型 | 缩后排/远程法术/灵力有限 | 耗蓝/突进/拉距离 | 散修、陆云风 |
| 高闪型 | 极高敏捷/近战打不中 | 远程/必中/暴露破绽 | 枯瘦刺奴 |
| 风筝型 | 远程/近身就退/持续磨血 | 追击封锁/远程对射 | 精悍链奴 |
| 守龟型 | 高护体/会重聚盾 | 毒续伤/破甲/耗蓝 | 金光上人 |
| 群阵型 | 头目+喽啰，头目在阵成 | 擒贼先擒王 | 魔修小队 |
| 追击型 | track 招式一步躲不开 | 两步外/打断/挡线 | 墨蛟、封岳 |
| 范围型 | zone 招式覆盖区间 | 拉出区间/分散站位 | 蜈蚣王、血煞兽 |
| 不死型 | 回血/复生/分身 | 先清分身/集火/phase | 心魔劫、婴鲤兽 |

**红线**：
- 同一章的普通遭遇不可全用同一原型——至少 2 种原型混搭
- boss 必须有 `introNote`（战术题面）
- 普通敌人也应有 `introNote`（P1-5 修复后已补全）
- `introNote` 要点出：行属克制关系 + 核心招式应对 + 推荐解法
- 越阶 boss 必须有底牌路径（消耗性底牌不吃驱动门槛折扣）

### 2.3 探索节点（Explore Node）

**模板字段**：
```
location:       地点 id
encounters:     遭遇表（weight + kind + enemy/reward）
beastRumor:     异闻妖王（听闻→深入→可战）
hotspots:       热点（战中可采集）
mines:          地雷/陷阱
zones:          区域划分
```

**探索设计规范**：

| 要素 | 要求 | 说明 |
|------|------|------|
| 遭遇多样性 | ≥3 种遭遇类型 | 不可只有"打怪"一种 |
| 传闻驱动 | 每个可探索区域至少 1 个异闻 | 传闻先行→深入可遇→剥取战利 |
| 环境参战 | 地点挂行属 | 木旺林/水旺溪/土旺洞/火旺丹房 |
| 随机源 | 奇遇+遭遇+市集刷新 | 确保每次探索有变化 |
| 收获保障 | 无聊之前必有收获 | 每次探索至少得灵草/材料/情报 |

**红线**：
- 仙门据点不可出现凡俗匪类遭遇（黄枫谷不遇野狼帮）
- 遭遇表按地点过滤，不可用通用池
- 探索产出必须与 Build 三路相乘（灵草→丹道，材料→法宝，情报→战斗）

### 2.4 时间跳跃节点（Timeskip Node）

**模板字段**：
```
id:             唯一标识
duration:       跳跃时长（月/年）
cond:           触发条件
text:           叙事压缩文本
choices:        侧重选择（至少 3 选 1）
onArrive:       副作用（设 flag、给增益、记里程碑）
```

**选择设计规范**：

时间跳跃必须给玩家**侧重选择**——20 年苦修不是一行字，而是"你把精力放在哪里"的决策：

| 侧重类型 | 增益方向 | 示例 |
|---------|---------|------|
| 苦修功法 | 修为/功法层/剑意 | "苦修剑诀——青元剑芒再淬一寸" |
| 磨砺战法 | 气血上限/体魄/熟练度 | "磨砺体魄——以曲魂为假想敌推演战法" |
| 澄心悟道 | 闭关增速/心境/道心 | "澄心悟道——打坐参悟，道心再澄一寸" |
| 炼丹积药 | 丹道熟练度/丹药库存 | "炼丹积药——以岛上灵草试手" |
| 制符备器 | 阵法熟练度/符箓库存 | "制符备器——纸上画符，以备不时" |

**红线**：
- 时间跳跃 ≥12 月必须有侧重选择（P2-10 修复后已实装）
- 选择增益必须是持久的（永久属性/乘性印记/熟练度），不可是一次性消耗品
- 增益幅度遵循 A2 标度尺——乘性或随境界缩放，严禁裸 +N 平铺
- 侧重选择与 Build 三路对齐——每个选项对应一条 build 路的推进

### 2.5 侧位/群战节点（Sides Combat Node）

**模板字段**：
```
sides:          侧位单位数组（ally/beast/corpse）
formation:      阵型（pack/line/spread）
fronts:         战线声明（多战场群架）
crossSupport:   跨线支援开关
turn:           镜头切换（多战场逐线拍）
```

**侧位设计规范**：

| 要素 | 要求 | 说明 |
|------|------|------|
| 简令系统 | 玩家可循环切换 4 种简令 | follow/attack/guard/retreat |
| 人格 AI | 每个侧位有 aggr/prot/kite 参数 | 决定不同行为倾向 |
| 境界压制 | mastery≥2 的同道自动行动 | 玩家无法指挥，但她会指挥你 |
| 仇恨分流 | 多侧位各有仇恨值 | 敌人不会只打玩家 |
| 挡刀机制 | 护主简令下侧位可代受攻击 | guard 简令的核心价值 |

**红线**：
- 群战必须有"群感"——不可只是"多几个友军各打各的"
- 侧位不可克隆——每个有名字、人格、行为差异
- 血侍类敌人必须有个体辨识度（P0-7 已修复：甲/乙/丙三型）
- 多战场群架必须可跨线支援（fronts + crossSupport）

## 三、篇章节奏模板（Pacing）

### 3.1 锚-帆模型

每个篇章由**锚点**（强叙事、必经、高张力）和**帆段**（自由探索、随机、低张力）交替组成：

```
篇章结构：
  锚①（开场·设定） → 帆①（驻地·探索/修炼） → 锚②（转折·冲突）
  → 帆②（备战/收集） → 锚③（高潮·boss 战） → 帆③（余韵·收束）
```

| 段落 | 占比 | 核心动词 | 玩家自由度 |
|------|------|---------|-----------|
| 锚 | 60% | 看/选/打 | 低（必经剧情） |
| 帆 | 40% | 探/练/攒 | 高（自由行动） |

**红线**：
- 连续 2 个锚点之间必须插入帆段（不可纯叙事跑火车）
- 帆段三层惦记不为空（远：前路栏 / 中：涟漪窗口 / 近：本月行动产出）
- 锚点的叙事张力递增——每章的锚③必须是全章最高潮

### 3.2 时间预算

```
本章总可用月数：N
├── 锚点消耗（不可省）：约 40%~50% × N
├── 帆段自由月数：约 50%~60% × N
│   ├── 纯修炼（涨修为）：至少 A 月才能突破
│   ├── Build 三路推进：深耕 1 条 + 浅尝另 1 条
│   └── 探索/奇遇/备牌：至少 B 月
└── 验证：自由月够深耕一条 build 路，不够全精通
```

## 四、选择质量审计表

每个选择节点填完此表，全部通过才可进入实装：

```
□ 这个选择有 ≥2 个选项？
□ 每个选项有明确的 effect（改变持久状态）？
□ 玩家能凭直觉/常识理解每个选项的含义？（零教学）
□ 选项文本符合角色性格（韩立=谨慎藏拙）？
□ 没有明显最优解（至少 2 个选项各有取舍）？
□ 选择后果在后续节点可见（不是选完就忘）？
□ 如果是时间跳跃，选择增益是持久的且乘性的？
```

## 五、战斗质量审计表

每个战斗节点填完此表，全部通过才可进入实装：

```
□ 敌人有 introNote（战术题面）？
□ 敌人原型已分类（非"万能型"）？
□ 敌人行属已标注（五行克制可用）？
□ 至少 2 种 build 解法可行（剑/丹/阵各有一条路）？
□ 越阶 boss 有底牌路径（消耗性底牌不吃驱动门槛折扣）？
□ 失败有 fail-forward（败有所得，不卡死）？
□ 胜利奖励与后续内容相乘（妖材→法宝/丹方→炼丹/情报→战斗）？
□ 同一章不连续出现同一原型的敌人？
```

## 六、篇章质量审计表

每章设计文档完成时填此表：

```
□ 锚-帆节奏：锚点与帆段交替，无连续纯叙事段
□ 选择质量：连续 ≤2 个单选节点后必须有多选节点
□ 战斗多样性：本章敌人原型 ≥2 种
□ 时间跳跃：≥12 月的跳跃有侧重选择
□ 横轴系统推进表 A~E 已填完（chapter-systems-manifest）
□ Build 三路与主线至少各 1 个乘法点
□ 因果账本：≥2 条种因 + ≥1 条收果
□ 时间窗口互斥：≥1 组
□ 三层惦记：帆段远/中/近三层不为空
□ 平衡审计四道全过（时间预算/因果链/乘法/等效时间律）
```
