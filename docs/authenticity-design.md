# 「真实修仙感」设计指针

> 综合两处调研：《觅长生》玩家评论 + 《凡人修仙传》口碑来源。
> 作为后续所有内容开发的"气质标尺"，确保我们做的是"真实修仙"，而非爽文升级。

## 一、调研结论：真实感从何而来

### 来自《觅长生》玩家评论
- **时间尺度**：闭关动辄数年数十年，"在洞府枯坐数百年参悟天地"。时间是修仙最核心的资源与代价。
- **代入感**：玩家"真的感觉在扮演武侠故事里的一个角色"。
- **抉择不可逆**：与人为善 or 杀人夺宝由你定；做了别的事就会错过某些事件/关键人物。
- **靠准备攻坚**：冲后期境界要"花很长时间准备、试很多次"。
- **要避免的差评**：事件太稀疏、世界显空、个别资源强到成为唯一解。

### 来自《凡人修仙传》口碑
- **"凡人流"鼻祖 · 无主角光环**：韩立四伪灵根，资质差，成就全靠挣扎，所以"真实"、所以来之不易。
- **务实的修炼抉择**：原著里韩立选"威力平庸但修炼快、易修"的功法（适配烂资质），而非贪强。作者刻意保持真实。
- **稳健谨慎是灵魂**：从不冒进、事事留后手（底牌）、能避则避、杀人必扬其灰。
- **孤独苦修**：一部"孤独修行的编年史"，在默默无闻中精进。
- **寿元压力**：练气/筑基期寿命有限，逼迫与时间赛跑。
- **靠底牌取胜**：毒、暗器、傀儡、算计、阵法——以弱胜强，而非蛮力碾压。
- **凶险**：一步踏错，万劫不复；散修如蝼蚁，朝生暮死。

## 三、本轮三个方向

1. **闭关插曲**：长闭关期间按概率插入随机事件——
   - 走火入魔（心魔暴涨/受伤，可能提前出关）
   - 顿悟（额外修为/悟性/灵力）
   - 外界变故（有人来访/门派有事，打断闭关）
   - 灵感枯滞（这段苦修收效甚微）
   体现"闭关是孤注一掷的赌博"，时间越久风险与收益越大。

2. **扩充奇遇与世界事件**：把奇遇从 5 个扩到十几个，覆盖更多地点；加入"世界局势"流动事件（野狼帮动向、门派公告、市井流言推动氛围），直接回应"世界空、事件稀疏"的差评。

3. **战斗演出打磨**：伤害飘字、暴击/中毒/破甲的视觉反馈、回合切换提示，让"靠算计取胜"的过程更有打击感与正反馈。

## 四、红线（不可违背）
- 韩立人设固定、资质平庸；随机只进世界与过程。
- 不做"捡到神功就无敌"的爽文逻辑；强大必须有代价、有铺垫。
- 平衡：靠准备与算计取胜，运气只在边际波动（蒙特卡洛持续校验）。

## 五、考据红线 + 可改点登记（动漫硬考据 vs 设计可动点）

> 2026-06-14 用户重申（原话）："我们的所有剧情必须严格符合动漫版原著，除了某些我可以更改的内容点
> （比如陈师姐能否结丹靠过程中的很多抉择这种）。我主要是担心你做的时候会出现幻觉或者按照小说原著做的问题。"
> 本节是**单一查阅点**：每个窗口开工前先看这里，分清"哪些必须照动漫、哪些是设计可动点"。

### 5.1 考据方法论（与 AGENTS.md「考据方法论」一致，此处为设计侧索引）
1. **动漫版为唯一剧情锚点**——绝不按小说原著、绝不凭模型记忆写设定。
2. **先 grep docs/ 既有考据**（lore-*.md / lore-departure.md / huangfeng-design.md / techniques-lore.md），再 ≥2 独立来源交叉核定。
3. **拿不准不臆造**——标记 `※待核实` 并直接问用户，不要自行编一个版本糊过去。
4. **两类内容分开标注**：`【动漫硬考据】`（不可乱编）vs `【设计可动点】`（用户授权可改）。
