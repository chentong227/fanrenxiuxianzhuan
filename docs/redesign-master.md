# 第一部分：分级制平衡方案

## 一、问题诊断：什么是"好招"概念，为什么要替换

### 1.1 现状

当前系统的伤害公式（`balance.js:spellPower`）：

```
spellPower = base × sourceMul(source) × realmScale(source, playerRealmTier) × gradeMul(grade) × layerMul
```

- `base` 是每个招式**拍脑袋定的固定值**：眨眼 15、火弹 24、金光砖 42、青元剑芒 30……
- `source` 分 martial/art/treasure 三类，各有标度曲线
- `grade` 是**功法品阶**（黄1/玄2/地3/天4），只作用于 art 类
- `realmScale` 按**玩家境界**缩放——招式本身没有级别

**问题**：金光砖 dmg=42 vs 火弹术 dmg=24，这个差异是"拍脑袋定的好招"——
没有系统性的理由解释为什么金光砖比火弹强一倍。用户指出：金光砖强是因为
**它是筑基期的符宝**，不是因为它是个"好招"。

### 1.2 现有 driveRealm 系统的局限

`driveRealm` 目前**只作用于 treasure 类**（法器/法宝），不覆盖 art 类（法术/符箓）。
金光砖的 `source: "art"`，没有 `driveRealm`，所以它不受越阶折扣/灵力倍增约束——
它只是被赋予了一个很高的 base=42。

用户的设计直觉是正确的：**所有手段都应该有级别**，不只是法宝。

## 二、新方案：统一 tier 制

### 2.1 核心思想

**每招/每件法宝/每张符/每个功法技都有一个 `tier` 字段**，表示它属于哪个大境界的产物：

| tier | 大境界 | 说明 |
|------|--------|------|
| 0 | 练气 | 凡人武学、低级法术、下品法器、普通符箓 |
| 1 | 筑基 | 中级法术、符宝、中品法器、玄阶功法战技 |
| 2 | 结丹 | 高级法术/秘术、法宝、上品法器、地阶功法战技 |
| 3 | 元婴 | 神通、古宝、天阶功法战技 |
| 4 | 化神 | 顶级神通、仙器 |

**招式威力 = base × tierBand(itemTier) × 驱动修正(playerRealm vs itemTier) × 其他乘子**

- `tierBand` 复用现有 `realmBand`：[1.0, 2.4, 5.5, 12, 26]
- **高 tier 招式天然威力大**——不需要拍 base 值来模拟"好招"
- **低阶修士用高 tier 招式** = 威力仍按 itemTier 缩放（自然强），但灵力消耗倍增
- **高阶修士用低 tier 招式** = 威力按 itemTier 缩放（自然弱），这就是"换招"的动力

### 2.2 新公式

```
spellPower(base, source, itemTier, playerRealmTier, playerLayer, grade, layerMul):
  // 1. 基础标度：按招式自身的 tier（不是玩家境界）
  tierScale = realmBand(itemTier)        // 练气1.0/筑基2.4/结丹5.5/...
  
  // 2. 驱动修正：玩家境界 vs 招式 tier
  //    达标：本命×1.35 / 非本命×1.0
  //    越阶：×0.7^gap（威能衰减）——但 tierScale 已经给了高 base，所以越阶用仍比同阶招强
  drive = driveMul(playerRealmTier, itemTier, isNatal, isConsumable, playerLayer)
  
  // 3. source 修正（武学不随 tier 成长——凡人武学永远是凡人武学）
  if source === "martial":
    tierScale = 1 + 0.05 * playerRealmTier   // 武学仍按玩家境界微涨
    drive = 1.0                                // 武学无驱动门槛
  elif source === "treasure":
    // 法器/法宝：tierScale 照用，drive 照用，不吃 gradeMul
  else:  // art
    tierScale *= gradeMul(grade)              // 功法品阶仍只作用于法术
    tierScale *= layerMul                     // 功法层数仍只作用于法术
  
  // 4. 最终
  return max(1, round(base × tierScale × drive))
```

### 2.3 灵力消耗：跨 tier 倍增

```
mpCost(spell, playerRealmTier, playerLayer):
  baseMp = spell.mp
  if source === "martial": return baseMp   // 武学零耗/低耗，无跨 tier
  gap = itemTier - playerRealmTier
  if gap <= 0: return baseMp               // 同阶或低阶：正常消耗
  return round(baseMp × 3^gap)             // 越阶：灵力×3/档（复用 driveMpMul）
```

**消耗性底牌（chargeCost）豁免**——符宝充能、噬金虫灵机等消耗品不受灵力倍增约束
（它们本身是有限资源，用完即止）。

### 2.4 用金光砖验证

| 参数 | 值 |
|------|-----|
| 金光砖 tier | 1（筑基符宝） |
| base dmg | 18（不再是 42） |
| 玩家 tier | 0（练气） |
| tierScale | realmBand(1) = 2.4 |
| drive gap | 1 - 0 = 1.0 |
| driveMul | 0.7^1.0 = 0.70 |
| **威力** | 18 × 2.4 × 0.70 = **30.2** |
| 灵力 | 6 × 3^1 = **18** |

对比当前：42 × 1.0 × 1.0 = 42，灵力 6。

**分析**：
- 新方案下金光砖在练气期打 30（旧方案 42）——略弱但仍远超练气法术（火弹 24）
- 灵力消耗 18（旧方案 6）——**三倍**，符合"筑基符宝由练气修士催动很贵"
- 这正好解决了用户反馈的"灵力消耗过低"问题
- 充能制（consume: jinguang_zhuan_charge）仍然限制次数

如果希望金光砖在练气期更猛（更贴合"符宝碾压练气"的体感），可以：
- 降低越阶威能衰减：0.7 → 0.8（gap=1 时 0.80 vs 0.70）
- 或调高 base：18 → 22（22 × 2.4 × 0.70 = 37）

### 2.6 与 grade（功法品阶）的关系

**现状**：`gradeMul` 只作用于 `source === "art"` 的招式。

**新方案**：`grade` 保留，但语义变为**功法品阶对法术的额外加成**——
它不再是"好招"的来源，而是"同 tier 功法有品阶差异"的微调：

- tier 决定招式的基础威力级别（×2.4 跨一档）
- grade 决定同 tier 内的微调（×1.0~1.6，黄→天）
- 两者相乘：一个天阶筑基功法战技 = base × 2.4 × 1.6 = base × 3.84
- 一个黄阶筑基功法战技 = base × 2.4 × 1.0 = base × 2.4

这样，**品阶差异仍在，但跨 tier 差异远大于同 tier 内的品阶差异**——
符合"筑基符宝碾压练气法术"的体感。

### 2.7 对存档的影响

**存档 schema 不变**——tier 是招式定义上的字段，不是存档字段。
`spellPower` 函数签名变化，但所有计算是读时进行的，不需要迁移存档。

  - 噬金·出战：3 × 5.5 × 0.7 = 12/段 × 3段 = 36（筑基期强力但灵力 6×3=18/次）
  - 结丹后：3 × 5.5 × 1.0 = 17/段 × 3段 = 50（达标后主战）
- **青竹蜂云剑 tier2**：结丹本命——
  - 4 × 5.5 × 1.35(本命) = 30/段 × 2段 = 60（结丹期主力，符合"本命法宝"体感）
- **辟邪神雷 tier2**：结丹级神通——
  - 6 × 5.5 × 1.0 = 33（克邪 ×1.8 = 59，对邪魔鬼物毁灭性打击）
- **结丹关**：trialHp=360, trialRounds=13——心魔劫闯过即金丹大成

## 五、灵力经济重调（呼应用户反馈）

### 5.1 问题

用户反馈："200灵力几乎够用十几回合，综合灵力压力不大。"

### 5.2 新方案下的灵力压力

| 招式 | 旧 MP | 新 MP（练气期用） | 新 MP（筑基期用） | 说明 |
|------|-------|-------------------|-------------------|------|
| 眨眼剑法 | 0 | 0 | 0 | 武学零耗，不变 |
| 火弹术 | 12 | 12 | 12 | 同阶法术，正常 |
| 金光砖 | 6 | **18** | 6 | 练气越阶催筑基符宝 ×3 |

- 练气期灵力池 ~118（十一层）：金光砖 18 MP/次 → 约 6 次（旧方案 18 次）
- 筑基期灵力池 ~190：绿煌剑 39 MP/次 → 约 4 次（杀手锏定位）
- **灵力管理成为战斗压力点** ✓

### 5.3 灵力恢复手段

- 凝息回元：+12 MP，但破绽+30%受击——赌局式回灵
- 回元丹：+40 MP，消耗品——续命的那口
- 聚灵阵旗：每回合+8 MP，持续5回合——阵地战续航
- 这些手段不变，但因为消耗上升，它们的价值自然提高

## 六、武学的定位（不变）

武学（martial）在新方案中保持特殊地位：
- **不随 tier 缩放**：`1 + 0.05 × playerRealmTier`——凡人武学永远是凡人武学
- **零耗/低耗**：贴身专属，灵力耗尽时的特解
- **无驱动门槛**：任何人都能用，但天花板低
- **相对退场**：高境界时武学伤害被法术/法宝拉开 → 玩家因"更优解"换招，非因"旧招清零"

这符合用户说的"元婴不用眨眼剑法打敌人"——不是因为眨眼归零了，而是因为有更好的选择。

# 附录：新旧公式对照速查

```
旧公式：
  spellPower = base × sourceMul × realmScale(source, playerTier) × gradeMul × layerMul
  - realmScale 按【玩家境界】缩放
  - driveMul 只对 treasure 生效
  - "好招"靠拍 base 值

新公式：
  spellPower = base × tierBand(itemTier) × driveMul(playerTier, itemTier) × gradeMul × layerMul
  - tierBand 按【招式自身 tier】缩放
  - driveMul 对所有 source 生效（martial 除外）
  - "好招"=高 tier 招式，tierBand 自然放大
  - 越阶用 = 威力仍强（tierBand 高）但灵力 ×3/档
```
