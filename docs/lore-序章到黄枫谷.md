# 剧情调研 · 序章（七玄门）→ 黄枫谷 之间的衔接

> 本文为**调研笔记**，不是最终脚本。来源：RMJI Fandom Wiki（rmji.fandom.com，经梯子核对 Han Li / Mo Juren / Mo Caihuan / Yellow Maple Valley / Li Huayuan / Dong Xuan 等词条）。
> 目的：把"七玄门 → 黄枫谷"中间被我们跳过的剧情补全，做成**有衔接感的连续旅程**，而不是章节制硬切。
> 设计红线同前：忠于动漫改编优先，人物/功法/因果不得编造；未确证处留白，标注「待核」。

## 一、宏观脉络（韩立此段的真实路线）

七玄门并非"通关即跳黄枫谷"。动漫/原著里中间有**一整段凡俗修仙界的历练**，是韩立从"练气小修"成长为"能进仙门"的关键过渡：

```
青牛镇(序章起点)
  → 七玄门(序章：拜师墨大夫→夺舍危机→帮派之争→金光上人→得升仙令)
  → 【离门】带着墨大夫(墨居仁)临终下的毒，踏入江湖求解药
  → 兰州 · 嘉源城(墨府/蛟龙帮一线)
       · 寻墨大夫妻女(燕氏、墨彩环)求解毒之物「温阳宝玉」
       · 替墨家出手，杀霸王庄欧阳飞天，换得温阳宝玉解毒
       · 卷入蛟龙帮(野狼帮余脉)与彩虹门的帮派之争
  → 太南小会(Great South Meeting，越国凡修/低阶修士的聚会/交易/选拔场)
  → 持「升仙令」入黄枫谷(越国七大派之一)，正式踏上筑基之路
  → 黄枫谷：血色试炼(Trial by Blood and Fire) → 攒灵药炼筑基丹 → 筑基
```

> 关键点：**升仙令(Writ of Immortal Ascension)** 是金光上人遗物（序章已得），它正是进黄枫谷的凭证——所以序章结尾埋的这条线是对的，衔接顺理成章。

## 三、黄枫谷篇关键设定（第一正章的真值锚点）

### 门派结构（忠于设定）
- **黄枫谷**：越国（State of Yue）「七大派」之一，位于太岳山脉；近千年仅出过一位元婴老祖 **凌虚（Ling Hu）**。
- 弟子分层（直接可做成游戏的身份/权限系统）：
  - **记名弟子（Honored Disciples）**：未服筑基丹，人数最多，干杂役、修为最浅。
  - **执事弟子（Consul Disciples）**：服了筑基丹但未能筑基者，长春类基础功法已至顶，管理记名弟子。
  - **筑基弟子（Foundation Establishment Disciples）**：真正的修仙者，可辟洞府独修，每年获资源/灵石，唯一义务是宗门有大敌时出力。
  - **管事（Stewards）**：筑基后自知无望结丹，转入内门管理。
- 重要长老/人物：掌门**钟青道**、太上长老**凌虚**、长老**洪夫(Hong Fu)**、**李化元(Li Huayuan，结丹长老，韩立之师)**、**雷万鹤(Lei Wanhe，长老)**。

### 韩立在黄枫谷的关键经历
- 持升仙令入谷，参加**血色试炼（Trial by Blood and Fire）**，靠采集足量灵药炼出数枚**筑基丹**，得以筑基（26岁筑基）。
- 在百药园（Hundred Medicine Garden）替马师叔(Martial Uncle Ma)打理药圃——延续序章"药童"的医药主题。
- 习得**青元剑诀（Azure Essence Sword Art）**：师父**李化元**所授/许，结合机缘所得书页而成（地阶剑修功法，散功重修提纯灵力）。
- 习得**大衍诀（Great Development Art）**：与**千竹教(devil dao)卧底**有关——**雷万鹤**救下韩立、击杀该卧底后，韩立事后捡得此诀（天阶神识功法）。
- **董萱儿(Dong Xuan'er)**：洪夫的弟子（实为其女，公开身份是师徒）。两位结丹长老（李化元、洪夫）商议把各自弟子**韩立与董萱儿配为道侣**，韩立对她无意。性子娇纵、惯于魅惑男弟子。后期身世大变（其父乃和合宗云路）。
- 后续大事：六大魔道宗门入侵越国（Devil Dao Invasion），黄枫谷等正道七派与之大战；凌虚老祖以计撤走精英弟子，**韩立等被当作弃子诱饵**留下——这是韩立对宗门寒心、日后独行的根源。

> 功法获取细节（青元剑诀=燕家堡/血色禁地杀封岳得书页；大衍诀=千竹教卧底/雷万鹤相救）已记于 `docs/techniques-lore.md` 与游戏 DATA.techniques，**与本调研一致**，继续沿用。

## 四、对"无章节割裂感"的设计建议（落地方向，待实现）

1. **不显式分章**：UI 不打"第二章"字样，而是用**地理位置的连续移动**自然过渡——离开七玄门 → 上路 → 嘉源城 → 太南小会 → 黄枫谷，全在同一张不断展开的大地图上推进。
2. **驱动力是"解毒"而非"换地图"**：序章结尾把墨大夫下毒这条线接上，玩家是"为了活命/解毒"才上路，顺势走完嘉源城，再"因升仙令"进黄枫谷。动机连贯。
3. **境界跨度对应大境界突破**：黄枫谷篇开放"练气→筑基"的大境界渡劫（机制已就位：`DATA.bigRealmRites.foundation` + 筑基丹）。筑基丹的来源正是血色试炼采药自炼——和序章小绿瓶催熟灵药的主题一脉相承。
4. **身份延续**：序章"药童"→ 黄枫谷"百药园打理药圃"，医药线不断；遁速体系在此开放第一件飞行法器（御风车）。
5. **chapters.js 已留好 huangfeng 占位**：realmTier=1（筑基），通关序章即解锁。嘉源城可作为 huangfeng 篇的"前段地图"，或独立一个轻量过场篇。
