# 审美审计门禁（Aesthetic Audit Gate）

> 2026-07-09 立项，用户裁决：**"得有一个审美审计，这才是游戏和换皮的区别。"**
> 定位：与 `audit-gate.md`（设计/数值门禁）平行的**观感门禁**——功能"能用"不算完，过审美审计才算完。
> 效力：P 系列精致冲刺（P1 第一小时 → P2 视听一致性 → P3 去文字墙 → P4 jank 清零）全部按本表验收；
> 此后任何新 UI/新演出/新界面，实装后必须走一遍 §二 的逐屏八问。

---

## 一、核心判断：换皮感从哪来

玩家在**前 15 分钟**形成"精致 or 换皮"的判决。判决依据不是内容量，而是：

| 信号 | 换皮手游 | 优秀独立游戏 |
|------|---------|-------------|
| 文字 | 系统裸文本、文字墙、开发术语外漏 | 每个字都被"排版"过，一次一口 |
| 反馈 | 点了没反应，或反应千篇一律 | 每次交互有独特的音+动+形 |
| 资产 | 风格混杂、裁切生硬、缺图黑屏 | 一眼一个世界，缺图也有优雅兜底 |
| 节奏 | 弹窗轰炸 / 干等 | 张弛有度，重要时刻有仪式感 |
| 时间 | "过了一月"一行字 | 天色、季节、钟声——时间有重量 |

## 二、逐屏八问（每屏截图对照，430×932 竖屏为准）

任何一屏（界面/弹窗/演出）过审须逐条回答，**任一条不过 = 记入 §四 jank 账本**：

1. **裸文本**：有没有开发术语（MVP/debug/id/英文变量名）或未排版的系统输出直接给玩家看？
2. **字号层级**：标题/正文/辅助字三级分明吗？同屏字号种类 ≤4 吗？
3. **呼吸感**：块与块之间的间距一致吗？有没有元素贴边、重叠、溢出？
4. **对齐**：可见元素是否落在同一套栅格上？有没有"差 2px"的错位？
5. **反馈**：这一屏每个可点元素，按下去有音吗？有视觉响应（按压态/涟漪/亮起）吗？
6. **动效节奏**：出场/退场有过渡吗？时长舒服吗（进 ≤0.4s / 出 ≤0.25s，重要仪式除外）？
7. **风格一致**：配色、图标、边框、圆角与全局水墨语言一致吗？此屏放进全游戏里违和吗？
8. **空态/极端态**：内容为空、超长文本、连点、慢网时，这一屏塌不塌？

## 三、专项标尺

### 3.1 文字呈现（P3 主攻）
- 单次呈现给玩家的连续文本 ≤3 行；超过必须分拍（剧情演出）或分卡（结算）。
- 行动结果优先「图标 + 一句话 + 数值跳动」，不写日志式长句。
- 禁用裸括号堆数值（"（心境+4，心魔-2，纹银-6）"→ 拆为浮动数值/结算行）。

### 3.2 声音（与 audio-design 咬合）
- 每类交互有专属音：确认/取消/翻页/开关弹窗/购买/获得/升级/警示，不允许全部共用 click。
- 重要仪式（突破/大件到手/章末）必须有专属声相，不与日常音混用。

### 3.3 时间可感知（D5，P3 主攻）
- 月轮转：顶栏月份变化要有可见的一拍（数字翻动/天色微移）。
- 年关与季节：至少「春夏秋冬」四档场景染色/粒子差异；跨年有一声钟。

### 3.4 资产一致性（P2 主攻）
- 立绘：脚/手完整、抠图边缘干净、朝向注册正确（art.js face 目检）。
- 场景：同篇章场景色调统一；缺图必须落在水墨渐变兜底上（不允许纯黑）。
- 图标：emoji 仅作过渡资产——同屏 emoji 密度 ≤3，长期以字符印章（吐/护/剑…）风格替代。

## 五、验收流程（每批必走）

1. 改动落地 → 手机视口（430×932）真开一局，走完受影响的屏。
2. 每屏截图 → 对 §二 八问逐条勾。
3. 新发现 jank → 补录 §四；本批目标内的 jank → 勾掉。
4. 回归测试全绿 → bump → push → 线上复核。
