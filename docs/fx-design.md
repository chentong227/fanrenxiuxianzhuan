## 一、动漫版招式视觉调研（特效的考据锚）

| 招式/体系 | 动漫视觉特征 | 配方落点 |
|---|---|---|
| 青元剑诀·剑芒 | **青色剑气束**，丈许长、瞬发、白炽刃头；与敌碰撞时**瓷器碎裂般的脆响与碎片** | 青绿连续光刃（ribbon draw-on）+ 瓷裂几何碎片（shard） |
| 青元剑诀·剑盾 | 青色剑环护体 | 双层青环扩散 + 环周灵尘 |
| 火蛇符 | 符化**活火蛇**，游走扑咬，实体化火焰 | 蛇形光带（wave 弹道）+ 咬合收口环 |
| 金光砖 | **金光一闪**、当头砸落，千钧之重 | 天降金光竖直光带 + 金色重爆 + 震屏 |
| 五行互克材质反应 | 剑气斩岩=瓷裂脆响；遇水系=白雾蒸腾（慕兰之战官方设定） | 克制命中时按双方行属加"材质反应"层（待做） |
| 武学（眨眼剑法） | 快、白、利——肉身路数无灵光特征 | 钢色交叉斩弧，金石迸溅 |
| 符箓共性 | 掷符→符纸燃化→法象成形 | 弹道前段细光（符纸飞），后段法象（蛇/冰/金光） |
| 雷法/风雷翅（后期） | 银蓝雷光、亚空间残影 | 天雷折线（lightning）+ 残影（待做） |

| 法术线条风 | 官方在高速斗法用"线条特效"做写实补充 | ribbon 光带正是此质感（细头白炽、尾部熄灭） |

**配色法度**：五行各有核心色/辉光色双色板（fx.js `ELEM_COLOR`）——
火橙金、水蓝白、金鎏金、木青碧、土赭黄、雷银蓝。同行属法术共享色板、不同招式
靠**形**区分（束/蛇/棱/环/弧/针），保证"一眼认出是什么招+是谁的招"。

## 二、引擎架构（手机优先）

- **三类绘制体**：粒子 parts（软光/线火花/几何碎片/环/全屏闪）、闪电折线 bolts、
  **连续光带 strokes**（draw-on：头部推进、尾部熄灭、到点短驻再散——法术"绸"的质感）。
- **辉光精灵图**：64px 白色软光斑 offscreen 预渲染一次，drawImage 缩放复用
  （比每粒子径向渐变快一个量级）；全程 `lighter` 加色混合。
- **性能红线（iPhone 14PM 主力、低端机兜底）**：
  - 粒子全场封顶 420、光带封顶 24；
  - 连续两帧 >34ms → 出粒减半（`_degraded`），回稳渐恢复；
  - 无活物 RAF 即停 + 清屏；DPR 封顶 2；**禁用 shadowBlur**（移动端性能杀手）；
  - 特效纯演出层：不进存档、不影响逻辑帧，掉帧只损美观不损操作。

## 六、青竹蜂云剑剑阵 + 辟邪神雷三连（v98 重点：金色雷 + 绕身剑阵）

> 用户裁决锚：**"做最好看的金色雷，金色的雷，很帅"**；法宝区是战斗演出重点
> （combat-arsenal §二·五 法宝三位制）。青竹蜂云剑=结丹本命法宝·**主攻位**，
> 辟邪神雷=其所蕴之雷术（charge 资源·"打一道少一道"）。考据：青竹蜂云剑 72 口齐射、
> 法宝技=威能×法力×神念（combat-tactics §一、combat-arsenal 结丹境界表）。

### 1. 绕身剑阵（DOM 主体 + canvas 引子，双层并存）
- **DOM 常驻阵列**：`qingzhu_jian.swordOrbit=true` → ui.js 渲染 `.au-swords`（10 把
  `<i class="sw"><b></b></i>`，CSS 椭圆轨道绕身旋舞）；`.au-swords.lei` = 缠雷态、
  `.au-swords.arc` = 常态。`UI.castOrbit()` 是通用协议（`.au-swords`/`.au-blades` 共用）：
  催动绕身阵列飞出袭敌。
- **canvas 引子** `Fx.swordRing(cx,cy,o)`：**真画剑形**（细长剑刃多边形+芯线+护手，
  非光块）；`*0.5` 压扁=俯视椭圆（透视绕身）；`depth` 前明后暗（绕到背面变淡）；
  `introK` 自内向外张开；`o.lei` → 偶发相邻剑间 `arc` 金弧（雷缠剑身）。
  定位=**出袭/应雷的瞬时脉冲**，剑环本体交给 DOM（注释明示，二者不重叠）。

### 2. 辟邪神雷=金色雷（雷电附魔重构的核心）
- **色板** `jinlei`（`#fff3c4`/`#ffb01e` 金芯白炽）——区别于 `lei` 的银蓝。
- **`lightning(x,y,{gold})`**：金色**三层描边**（外晕 `255,176,30` / 中 `255,214,90` /
  芯 `255,248,210`），`opts.bolt` 可自定三层色；金雷起点拉到天幕最高处（`-this._h*0.9`，
  "自天而降"），蓝雷沿用旧起点。**旧 lightning 单蓝色硬编码已参数化**（`b.bolt`）。
- **`arc(x0,y0,x1,y1,o)`**：两点间七段抖动金蛇——剑身雷缠 / 瞬移破口的零件。

### 3. 三式配方（RECIPES）+ charge 资源
| 招 | 演出 | 战斗（combat.js） |
|---|---|---|
| `shenlei_pi`·劈 | 天幕金闪(80ms 静)→自天劈落粗金雷柱→2~3 分支→命中金冲击环×2+金雷迸散+金闪+重震(13)→**残雷爬体**（4 道金弧在目标身上窜 600ms） | mp6+耗雷1，dmg34，`slays{ghost/demon:1.8}` |
| `shenlei_fujian`·附剑 | 金雷劈身（引子）→应雷迸放金环+一圈青芒；**剑成环交 DOM `leiRitual()`** | mp4+耗雷3，buff `leiEnchant:3`（主攻法宝缠雷 3 回合·+8 克邪） |
| `leidun`·雷遁 | **两段式瞬移**：原地金弧吞身+大金环**向内收缩**（被空间吞没）+竖直金光柱（消失帧）→落点 `leidun_out` 金光炸出（出现帧） | mp5+耗雷1，瞬发，`blinkMove`（本回合移动无视挡线+2 步） |

  UI `shenlei-strip`（劈/附/遁三键，`cur<=0` 置灰）挂在主攻法宝卡上。

### 4. 引擎接线（engine.js / ui.js）
- `shenlei_pi` → **二次确认择敌**（`UI.armSpell`，金框上膛→点敌确认）；
- `shenlei_fujian` → `UI.leiRitual()`（应雷仪式，`.au-swords` 切 `.lei` 缠金态）；
- `leidun` → toast"点亮起的格子，穿空而至"→落点 `Fx.RECIPES.leidun`(原地) + `leidun_out`(落点)。

### 5. 后续（与用户详聊的特效重构清单接口）
本系统已立"金色雷+真画剑形+两段式瞬移+缠剑金弧"的范式；下一批特效重构可复用：
`swordRing`（任意绕身飞剑/飞针阵）、`arc`（任意电弧/灵线连接）、`lightning({gold/bolt})`
（任意自定色天雷）、charge-strip（任意"有限次数底牌"的 UI 协议）。
