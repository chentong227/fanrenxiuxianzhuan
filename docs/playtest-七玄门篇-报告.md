## 1. 难度曲线（A）

- **突破系统做得好**：「尝试突破」给出透明成功率与逐项加成（修为火候 / 心怀资质 / 心境 / 心魔 / 灵力不济），可用养元丹提升，失败不损经脉。新手能理解"还差什么"。
- 各层修为上限明确（练气一层100 / 二层160 / 三层240 / 四层340…，见 `js/data.js` DATA.realms），目标清晰。
- 四灵根（韩立）cul 系数 0.9、突破无加成（`spiritRoots`），刻意"平庸天资靠苦修"，与设定相符——但放大了下方的繁琐度问题。

## 2. 节奏 / 繁琐度（B）— 主要痛点

- **闭关苦修拉锯（P1）**：闭关约 +13~15 修为/月，但心境(mood)掉得快，到阈值自动"走火"中断（实测每轮仅修 4~5 月就被打断），随后必须花一个月「打坐调息」回神，再闭关——`闭关→走火→打坐` 反复循环。把《长春功》从练气三层往上推，耗时以"年"计、操作高度重复。
- **高效路线缺指引（P1）**：游戏其实内置了更优且更贴设定的路径——后山采灵草 → 小绿瓶催熟 → **灵乳灵药（+60 修为/枚，不掉心境）**。两块地一轮≈闭关 3 倍效率且无走火。但天命/提示没有把这条路告诉玩家，新手极易一头扎进繁琐闭关。

> 建议（待与作者确认，默认不改）：在「暗修精进」天命提示里点一句"灵草入瓶催熟可炼灵乳大补修为"，或首次闭关走火后弹一次引导。

## 3. 缺道具 / 缺提示（C）

- 天命卡（暗修精进→练气四层）、限时机会（墨大夫期许，纹银赏）、异闻（白额吊睛虎 线索 3/3）展示清楚，"锚-帆"目标可见。
- 主要缺口同上：**小绿瓶高效冲层路线缺引导**。

## 4. 移动端 UI（D）

- 430×932 下，洞府行动按钮（闭关/突破/打坐/打理小瓶/炼药）、顶栏（舆图/系统）、底部三页签（见闻/行动/韩立）布局正常，未见文本溢出或点击区过小。
- 待补：横屏、弹窗（突破/炼药结算）、战斗界面在窄屏下的核对。

## 5. 美术 / 演出（E）— 含 v168 竖图核对

- **v168 场景竖图**：药庐、演武厅等场景背景为竖向 2:3，清晰、贴边，无方图硬 cover 的拉伸感——v168 目标达成（初步目视）。
- **小绿瓶 CG（bottle）**：竖屏下构图合适，未见明显方图裁切异常（像素级尺寸核对待补：CG 仍是 1024² 方图，`.story-bg` 用 cover，理论上在高窄屏会裁切，需实测严重程度）。
- 立绘：厉飞雨有情绪变体（笑），韩立/张铁/墨大夫侧栏立绘正常。
- 待核对 CG：`duoshe`（夺舍之夜）、`jinguang`、`departure`（升仙令）三张在 430 宽下的裁切/放大程度。

## 6. 战斗手感（F）

- 待测：`showdown 夺舍之夜`（三阶段：铁奴·百毒不侵 + 余子童·元神，需运功镇魂）、`jinguang_fight 暗算金光上人`。

## 7. Bug / 异常（G）

- 暂未见崩溃或卡死；控制台无红色报错（持续观察）。

## 8. 一致感 / 沉浸（H）

- 剧情走向与七玄门篇设定相符：青牛镇赴考→选拔→拜墨大夫→同门厉飞雨→得神秘小绿瓶。人物口吻、张铁停在练气一层（伏笔）、韩立藏功心声均到位。
- 后续将重点核对：张铁之死的因果、夺舍墨大夫的动机铺垫、金光上人与升仙令的衔接是否忠于动画（R2：以动画为准）。
