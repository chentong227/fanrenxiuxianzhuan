# 篇章差异化 × 自由度框架

> 核心问题：每个篇章玩起来到底有什么不同？玩家到底有多少自由？
> 本文不列问题清单，而是定义一套**篇章DNA**——每个篇章从结构上就必须不同。

---

## 一、自由度三层模型

自由度不是"有没有选择按钮"，而是玩家在三个层面有多少**真实控制权**：

| 层级 | 名称 | 玩家能控制什么 | 当前状态 | 目标 |
|------|------|---------------|---------|------|
| L1 | **路径自由** | 去哪里、什么时候去、以什么顺序 | 极低（地点门禁锁死） | 中（每章≥2个可选目的地） |
| L2 | **战术自由** | 用什么打法、带什么装备、怎么配技能 | 低（一套打法通杀） | 高（敌人逼你换策略） |
| L3 | **叙事自由** | 故事往哪走、NPC关系怎么发展 | 极低（单选项） | 中（关键节点≥2真分支） |

**原则**：不追求开放世界级自由，追求"凡人韩立式自由"——**算计的自由**。韩立的自由不是"想去哪去哪"，而是"在有限的牌里打出最优解"。游戏应该给玩家**有限的选项 + 真实的后果**。

---

## 二、篇章DNA——每章一个核心玩法动词

每个篇章有一个**核心动词**，决定这章"玩什么"。不同篇章的核心动词必须不同。

| 篇章 | 核心动词 | 玩家在干什么 | 自由度重心 |
|------|---------|------------|-----------|
| 七玄门 | **生存** | 弱者求生，藏拙自保 | L2战术（底牌准备） |
| 黄枫谷 | **经营** | 攒资源、攀关系、择机出手 | L1路径+L3叙事 |
| 燕家堡 | **侦察** | 战前情报收集，知己知彼 | L1路径（探索） |
| 魔道争锋 | **破阵** | 多战场协同，阵法vs反阵 | L2战术（阵法操控） |
| 再别天南 | **撤退** | 且战且退，保命保人 | L2战术（资源管理） |
| 初入星海 | **立足** | 从零扎根，发家致富 | L1路径+L2战术 |

**核心动词决定系统侧重**：

```
生存 → 底牌准备系统（毒草/暗器/藏修为）
经营 → 收集循环+社交+洞府
侦察 → 探索+情报+备战
破阵 → fieldCycle阵法+多战场sides
撤退 → survive差异化+资源消耗
立足 → 探索+交易+猎妖循环
```

## 三、每章自由度设计

### 七玄门：生存（L2战术自由）

**玩家在算计什么**：我手里这几张牌（毒草/暗器/修为），怎么准备才能打赢墨大夫？

**自由度来源**：
- 后山探索：每次去后山，随机遇到不同事件（采药/妖兽/厉飞雨/秘密），玩家选择去不去、去几次
- 底牌准备：毒草种类×数量影响决战Phase1难度，暗器数量影响Phase2效率，修为层数影响Phase3生存
- **决战前有一个"备战窗口"**：3天自由时间，每天选一个行动（采药/修炼/磨暗器/观察墨大夫），不同选择导致决战不同难度

**差异化**：这章的free在于"准备"，不在于"选择路径"。玩家在有限时间里分配精力——这是"凡人韩立"最核心的自由。

### 黄枫谷：经营（L1路径+L3叙事自由）

**玩家在算计什么**：在宗门里怎么站住脚、攒够资源、选对时机出手？

**自由度来源**：
- 药园差事：每月可选择"打理药园"（赚灵石+药理）/"闭关修炼"（涨修为）/"去坊市"（买卖+情报）——**时间互斥**，一个月只能做一件事
- 血色禁地：稳守vs深入（已有），加"组队选择"——选谁当队友影响战斗和后续羁绊
- 忘尘丹（已有·最佳实践）：全游戏唯一真选择，保留并作为标杆
- 洞府选择（已有）：灵泉眼vs僻静谷，不同增益
- **元武国代工**：玩家须主动北上（L1路径自由），且可选择"炼什么"——优先武器vs优先飞行法器vs优先阵图，资源不够全做须取舍

**差异化**：这章的free在于"经营节奏"——玩家自己决定每月干什么，像经营游戏一样分配时间。

### 燕家堡：侦察（L1路径自由）

**玩家在算计什么**：战王蝉有多强？我该怎么准备？

**自由度来源**：
- 堡内自由探索（3-5个可点地点）：
  - 兵器架→获取临时符剑
  - 药房→拾取疗伤丹
  - 望塔→观察战场地形（决战中有地形提示）
  - 与董萱儿对话→获取王蝉弱点（战斗introNote多一条）
  - 与墨彩环对话→获得额外补给
- **探索有代价**：每个地点花半天时间，3天只能去3-5个地方，须取舍
- 战前装备选择：带什么符、吃什么丹、用什么阵图

**差异化**：这章的free在于"信息收集"——玩家像侦察兵一样在战前做功课，准备越充分决战越轻松。

### 魔道争锋：破阵（L2战术自由）

**玩家在算计什么**：怎么在三战场之间分配战力？阵法什么时候启动？

**自由度来源**：
- 三血侍各型不同（Ⅰ铁壁/Ⅱ高闪/Ⅴ远程），须针对性配技能
- **阵法操控**：fieldCycle六相不是自动循环，玩家每回合**选择切换哪一相**（木缠足/火灼烧/金镜影/水心魔/土陷脚/万象星河），不同相对不同敌人效果不同
- 友军简令（§F）：集火/护援/自由，每回合一次
- 拖时战改为资源型：场上散落阵旗，须移动拾取+防御
- **矿道探索**（帆段）：可操作箱庭探索，拾取材料/符宝

**差异化**：这章的free在于"战术操控"——不是"贴脸放剑芒"，而是"切换阵法相位+指挥友军+拾取资源"。

### 再别天南：撤退（L2战术自由）

**玩家在算计什么**：我还有什么底牌？能撑到什么时候？什么时候用最后的资源？

**自由度来源**：
- 三场survive各有不同机制（守点/移动/保护），不能一套打法
- **资源消耗管理**：这章的战斗不回血/不回灵力（连续作战），玩家须决定"这场用多少底牌"——全用了下一场怎么办？
- 友军简令：指挥曲魂/南宫婉/陈巧倩
- **跌境选择**：跌境前可选择"保修为"（少跌但心魔高）或"保心境"（多跌但心魔低），影响后续星海篇开局

**差异化**：这章的free在于"资源管理"——连续作战不补给，每场战斗的"留多少底牌"是核心决策。

### 初入星海：立足（L1路径+L2战术自由）

**玩家在算计什么**：在陌生海域怎么从零开始攒家底？

**自由度来源**：
- **外海猎妖是可重复探索**：玩家选择去哪个海域（近海弱/外海强/深渊极险），不同海域不同妖兽不同材料
- 妖丹经济循环：猎妖→妖丹→坊市卖钱/换材料→买装备/丹药→猎更强的妖
- 结丹材料自己凑（§D）：降尘丹用妖丹换、雪灵水探索采集、天火液打特定boss掉
- 20年闭关分段选择（§I）：每5年选重点（苦修/参研/温养/调息）
- 擂台藏拙：选择"演多狼狈"（低风险低收益）vs"露半手"（高风险高收益）

**差异化**：这章的free在于"发家致富"——玩家自己决定猎妖路线、材料怎么分配、什么时候觉得"够了"去闯结丹。

## 四、自由度落地机制

### 机制1：月行动选择（L1路径）

每月玩家从行动池中选1个：

```
行动池（黄枫谷示例）：
  - 闭关修炼（修为+，心境-）
  - 药园差事（灵石+，药理+）
  - 坊市采购（买卖+情报）
  - 后山探索（灵草+，遭遇战）
  - 洞府布阵（阵法熟练度+）
  - 拜访NPC（羁绊+，情报+）
```

**关键**：这些不是新系统，是既有 `Engine.action()` 的扩展——把"rest/cultivate/adventure"扩展为篇章专属行动池。

### 机制2：备战窗口（L2战术）

每场重要战斗前给一个"备战窗口"（1-3天/月），玩家自由选择准备动作：

```
备战动作池：
  - 采集材料（制作临时道具）
  - 磨练技能（某技能熟练度+）
  - 侦察敌情（获取introNote提示）
  - 休息恢复（满血满灵力进战）
  - 布置陷阱（战场开局有debuff给敌人）
```

### 机制3：真选择节点（L3叙事）

每章≥2个真选择，用"选择类型矩阵"确保多样性：

| 章 | 选择1 | 选择2 | 类型 |
|---|-------|-------|------|
| 七玄门 | 厉飞雨求助：帮/不帮 | 备战重点：毒/暗器/修为 | 道德+资源 |
| 黄枫谷 | 忘尘丹（已有） | 血色禁地：稳守/深入 | 道德+资源 |
| 燕家堡 | 探索重点：兵器/情报/补给 | 战王蝉：硬撑/逃命 | 资源+战术 |
| 魔道争锋 | 矿道：深入搜宝/速通 | 阵法相位选择策略 | 资源+战术 |
| 再别天南 | 跌境：保修为/保心境 | 护道：保护谁优先 | 战术+道德 |
| 初入星海 | 擂台：演弱/露半手 | 结丹时机：备足就闯/再等等 | 风险+时机 |

## 五、篇章差异化验收

**每章必须回答3个问题，答案不能和别的章一样**：

1. **玩家这章在算计什么？**
2. **玩家这章的核心决策是什么？**
3. **玩家这章的"帆"（非战斗时段）在干什么？**

| 章 | 算计什么 | 核心决策 | 帆时段在干啥 |
|---|---------|---------|------------|
| 七玄门 | 底牌怎么准备 | 毒/暗器/修为分配 | 后山探索+采药 |
| 黄枫谷 | 时间怎么分配 | 每月做什么 | 药园+坊市+洞府 |
| 燕家堡 | 战前怎么侦察 | 探索哪些地点 | 堡内探索+NPC对话 |
| 魔道争锋 | 阵法怎么操控 | 切换哪一相 | 矿道探索+拾取 |
| 再别天南 | 底牌怎么省 | 留多少给下一场 | 无帆（连续撤退） |
| 初入星海 | 钱怎么赚 | 猎什么/换什么 | 外海猎妖+坊市交易 |

**再别天南的"无帆"是刻意的**——撤退就是连续作战没有喘息，这本身就是差异化。但须用survive机制差异化来补偿节奏压力。

---

## 六、总结

**篇章差异化的核心不是"加不同内容"，而是"让玩家在不同篇章做不同的决策"**：

- 七玄门：分配备牌（资源分配）
- 黄枫谷：分配时间（经营调度）
- 燕家堡：分配侦察（信息取舍）
- 魔道争锋：切换阵法（战术操控）
- 再别天南：省底牌（资源管理）
- 初入星海：选猎场（风险收益）

**自由度的核心不是"给更多选项"，而是"给有限选项+真实后果"**——韩立式的自由。
