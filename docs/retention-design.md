# 核心设计理念：「清晨开卷，见己成长」

> 用户原话（2026-06-10）：
> 「我很喜欢早上一醒来就打开某个游戏，看到自己在里面已经成长成什么样的样子，
> 这也是我以前爱玩氪金手游的原因。我希望这个游戏也能给我这种感觉，沉迷其中
> 一直游玩无法自拔，能看到自己花了很多心思做到了什么，能有什么很大的提升
> （比如说造出青竹蜂云剑、能用辟邪神雷，就是韩立质变的原因之一）。」

这是本游戏与"美术/剧情还原"并列的**第一设计支柱**。所有后续系统设计须回答：
**"它能不能让玩家明早醒来想打开看一眼？"**

## 一、拆解这种"感觉"的三个来源

1. **离开时仍在生长**（挂机魂）——世界和角色在你不在时继续动，回来第一眼是"收获"。
2. **投入有形化**（成果可见）——花的心思要变成看得见摸得着的东西：一把剑、一道雷、一层境界，而不是一串数字。
3. **质变时刻**（韩立式跃迁）——成长曲线不是平滑斜线，而是阶梯：某个大件到手的那一刻，
   战斗方式、可去之处、别人对你的态度**整体改变**。青竹蜂云剑/辟邪神雷之于韩立，
   是"从此我是另一个人"的节点。

## 一补、用户裁决（2026-06-10 深夜，最高优先级）

> 「我需要的就是这种**我攒的每一分都变成了看得见的东西**的感觉——肝难度/任务获取材料，
> 就像乱星海协助紫灵做了一个九死一生的任务回来拿到金雷竹一样。
> 至于离线闭关——**不认可**。一切会引起焦虑/打卡制的东西都不要存在。
> 纯单机应该以真正意义上的『爽』为主。」

由此修订：
- **废弃**：离线闭关、晨报卷轴等一切与真实时间挂钩的机制。不做体力、签到、限时。
- **主轴确立**：肝 → 大件兑现。核心循环 = **听闻 → 筹备 → 九死一生的攻坚 → 炼成 → 质变**。
- 单机之爽的定义：随时可以肝、肝必有回报、回报永久可见且改变玩法。

## 二、机制候选（按用户裁决修订）

### C. 质变里程碑体系（韩立式跃迁）——主轴，最高优先
质变 = 不只是数值，必须**新增一种"动词"**。七玄门篇与黄枫谷篇可落地的：
- 练气四层·神识外放：探索迷雾视野+1，可"探查"NPC 真实底细。
- 练气七层·御物初成：飞剑悬浮，战斗解锁"驭剑"指令（脱手攻击）。
- 筑基·辟谷+御器飞行：大地图移动耗时减半，解锁新地区。
- **大件锻造线**：青竹蜂云剑（集齐金精+竹芯+蜂晶分步炼制，每步有剧情）、
  辟邪神雷（机缘+功法双门槛）。拿到的当天，战斗 UI 多一颗新的"剑珠"——看得见的质变。
- 每个里程碑配**专属演出**（题字卡+CG+钟声），并永久记入「道途」年表。

### D. 道途年表（投入有形化）
- 一条竖向时间轴："第3年冬 突破练气四层""第7年春 炼成第一炉凝神丹"。
- 随时回看，成就感复利。亦是分享截图的天然素材。

### E. 可见的世界反馈
- 境界/名声达标后，NPC 称呼变化（"小子"→"道友"→"前辈"）、集镇商人主动让利、
  门中弟子见你行礼——让成长被"别人"确认。

## 二补、七玄门篇大件裁决（用户 2026-06-11：只做一件，忠于原著）

> 考据修正（用户纠错）：眨眼剑法是**厉飞雨所赠**（厉家武学，韩立凭长春功带来的
> 过目不忘与苦练反超厉飞雨本人）。获取是剧情一次性赠予——**链条不得做在"获取"上**。

选定：**《眨眼剑法》修行链**——肝的是"练成"，不是"收集"：

- **获取**：照旧由主线剧情厉飞雨相赠（不改动，忠于动漫）。
- **修行**：新增"剑意"熟练度，唯一来源是**真用剑**——演武厅切磋、历练遭遇战、
  探索凶兽战中每次施放眨眼剑法/连击积累剑意（际遇栏常驻"剑意 N/100"，明牌进度）。
- **瓶颈**：剑意满后须"悟剑"——闭关专项参悟（耗时数月+走火风险；失败剑意不清零，
  可调整心境再来）。原著韩立正是日夜苦练数年方至大成。
- **兑现**：大成专属演出（题字卡+钟声+年表入册）；解锁新招「连环眨眼」
  （剑势上限+2、连击新段）；角色卡新增"绝技"展示位；厉飞雨切磋时有专属感叹台词。
- 黄枫谷篇的超大件=筑基丹（原著本位：多方筹措、机缘与凶险并存），沿用同一循环骨架。

## 二补·二、突破=「准备难·过程难·收益巨大」（用户 2026-06-11 钦定，附调研）

> 用户论断：觅长生/原著突破最爽不在演出，而在**准备困难 + 过程困难 + 收益巨大**三位一体。
> 演出只是收尾的礼花，前面的"难"才是爽的本体。

### 调研实据

**觅长生·筑基（玩家攻略实证）**
- 准备难：突破前要囤 6–12 颗筑基丹（且吃到"耐药性"上限）、5–10 颗临时权重丹；
  筑基丹要靠炼丹（玄冰花+天灵果+幻心草+轻灵草），还得先把丹道练上去。
- 过程难：进入一个**九回合的五行灵气压缩小游戏**——用"运气术/聚气"凑同色压缩灵气，
  把进度推到 100。操作失误就失败（可读档重来）。
- 收益巨大：超过 100 的灵气每点转 2 点血量上限；筑基丹越多、压缩越好，上限越高。
  即"准备得越足，过程越稳，永久收益越大"。

**原著·韩立筑基（25 岁，地火之屋）**
- 准备难到要拿命换：四属性伪灵根，自知**两三颗筑基丹根本不够**，炼丹的灵药又几乎绝迹，
  只在血色禁地这种"练气期才能进、九死一生"的地方才有。于是冒死闯血色试炼取药，
  回来在地火之屋亲手炼制**大量**筑基丹，靠丹药堆量硬生生弥补资质。
- 过程难：禁地厮杀脱颖而出 + 自行炼丹（失败就前功尽弃）。
- 收益巨大：筑基成功 = 寿元翻倍、开洞府、得青元剑诀+青竹蜂云剑炼制之法+大衍诀——
  **一次质变直接打开整个黄枫谷篇的新世界**。

### 落到本游戏的突破改造（取代"只加演出"的旧设想）

突破从"攒够修为→掷骰子"升级为**三段式攻坚**，且越往后（大境界）越极致：

1. **准备难（资源门槛，明牌可备）**
   - 小境界：心境/灵力达标 + 可选服丹提升成功率（养元丹/凝神丹），丹要自己炼或换。
   - 大境界（筑基）：硬性消耗筑基丹 ≥N 颗；筑基丹靠"血色禁地"机缘取药 + 自炼。
     伪灵根（韩立）需求量更大——还原"资质差就得拿数量和准备硬填"。
   - 际遇栏常驻"筑基筹备：筑基丹 2/6、地火之精 0/1"——明牌进度，肝有方向。
2. **过程难（已有心魔劫战斗，强化为真考验）**
   - 准备越足 → 心魔劫道心(HP)越高、可战回合越多、瓶颈越薄（已有机制，调参强化）。
   - 失败有代价但不清空筹备（掉修为/重伤/心魔涨，但筑基丹按原著"成了才消耗"或部分留存），
     可舔伤再来——困难但不劝退，呼应觅长生"可读档重来"。
3. **收益巨大（质变，不是 +5）**
   - 寿元大涨、灵力上限跃升、**解锁新动词**（筑基→辟谷/御器飞行/新功法位）、
     开放新地区、NPC 改称"道友"、道途年表浓墨一笔 + 全屏演出+古钟。
   - 让玩家事后回想："我为这一下准备了好几个月，值。"

排期：本篇先把小境界突破的"备丹提率"做出来跑通手感；黄枫谷篇筑基做成第一个完整三段式超大件。

## 二补·四、路线裁决（用户 2026-06-11 钦定）：韩立主线 + build

**最终路线：韩立固定主线 + 流派 build，随机只进"过程"不进"因果"，未来做成明牌惦记。**

选择理由（三条）：
1. 用户的爽点全部是韩立专属叙事节点（金雷竹/青竹蜂云剑/辟邪神雷/协助紫灵/大战穆兰）——
   要的是"住进韩立的人生、亲手把每个质变肝出来"，随机主角给不了。
2. **已知的未来 = 最强牵引力**：原著党心里有完整愿望清单，主线只需把清单变进度条，
   每个大件都是"预售的爽点"。对原著党，凡人剧情不是剧透，是欲望地图。
3. 生存位：随机沙盒尽头是觅长生/鬼谷八荒（成熟、内容海量），硬拼是短板打长板；
   "凡人忠实可玩版"生态位目前空缺，考据红线在此即护城河。

从随机沙盒借来的三件法宝（与主线兼容）：
- **过程随机**：主线节点固定，节点间的路每周目不同（奇遇/NPC命途/资源分布）。
- **build 平行宇宙**：同一韩立，毒师/暗器/稳健是三种活法 = 原著党合法脑洞。
- **if 线进梦不进史**：「如果当年没杀墨大夫」做成心魔幻象/入梦支线，满足好奇，正史不动。

落地动作：道途年表向前延伸为「前路」——挂未解锁剪影（黄枫谷·筑基?? / 乱星海·金雷竹??），
把"已知的未来"变成可见的明牌惦记（氪金手游"下版本预告"的同款肌肉）。

目标范围：**完整可代入韩立视角走完人界篇**（七玄门→黄枫谷→乱星海→重返天南→…人界篇收束），
精品向，单机沉迷向。

## 二补·五、爽文契约（用户 2026-06-11 钦定的总纲，覆盖一切"难度"设计）

> 用户原话：「我想要体验韩立的人生是为了"爽"，而不是真的想考验自己能不能在修仙界活下来。」

**总原则：难是叙事的皮，爽是机制的核。世界嘴上喊凶险，手上对玩家慷慨。**
玩家永远是算计者，不是被算计者——游戏的职责是不断递给他"满屋子可以智取的对手"。

由此重写一切涉及"难"的设计：

1. **凶险演出化，失败向前走（fail-forward）**
   - 敌人的可怕写在台词与排场上（金钟罩不可破！），破法永远提前递到玩家手里（毒+暗器）。
   - 战败不是惩罚是铺垫：败退=看破对方招式（下次同敌+15%）、获得情报、触发疗伤剧情。
     重试无损，失败让你变强——韩立吃的每次亏都是学费，从不是绝路。
   - 真死亡只存在于剧情决战的叙事张力里，重试零代价。连败两次，暗中加成（韩立总有办法）。
2. **藏拙 = 扮猪吃虎引擎（不是生存策略，是打脸蓄势）**
   - 藏拙的回报不是"躲过危险"（焦虑），而是**揭示时刻**（爽文最核心爽点）：
     隐藏期积攒"蓄势"，关键战自选时机亮底牌——爆发加成 + 敌人专属失态台词
     （"什么?!你竟然已是练气七层——"）+ 入年表"扮猪吃虎"勋章。
   - 七玄门篇天然咬合：暗修瞒墨大夫本就是主线，夺舍之夜=史诗级打脸的预设舞台。
3. **资源"紧而不卡"**
   - 价格让你肉疼、肝有意义，但关键进度永远买得起——短缺是体感调味料，不是路障。
4. **以下克上是常态菜单**
   - 定期端上"按境界必输、靠准备必赢"的战局（决战墨大夫/金光上人即模板），
     让"我比他弱却赢了"成为重复供应的主食爽点。
5. **决策"好与更好"，不是"对与受罚"**
   - 稳健选择=踏实收益；大胆选择=更大收益+戏剧化的虚惊。选错的代价轻、选对的奖励重，
     决策的乐趣保留，决策的恐惧移除。

## 二补·六、一致感 = 名实一致 + 层级物理（用户 2026-06-11 凌晨洞察，调研证实）

> 用户原话：「觅长生的爽不是单纯来自难——NPC是活的，外海遇到的元婴后期是真的不强，
> 但有名有姓的白帝剑仙是真的强，剧情强，游戏里也强，强到难以战胜。」

### 调研实据
- **原著对手三层结构**（人界各境界严格成立）：高阶压制（炼气期的黄龙[筑基]/结丹期的极阴…
  打不过，躲/逃/借力）、同阶最强（封岳/越皇/温天仁/冰凤…势均力敌死战）、同阶其他（猎物）。
  韩立人设词条白纸黑字写着「擅长逃命」；"韩立逃"在年表中是高频常态。
- **觅长生**：全 NPC 流派配置表公开（67 流派），具名 NPC（明河剑仙等）与玩家同一套
  数值物理——剧情强=配置真的强，强度可被玩家验证。

### 设计定理
**扮猪吃虎的前提是世界上有真虎。** 一致感不是难度设计，是价值设计——
"打不动的名字"给强度坐标系定标，从而给玩家的每场胜利标价。
具名强者同时承担：敬畏感（世界比你大）、最高级惦记（"总有一天"）、
成长标尺（坐标系不动，位移才可测量：当年绕着走的名字，后篇平视）。

### 名实一致四件套（落地）
1. **三层对手按篇章配齐**：同阶杂鱼随机遇；同阶最强具名死战（夺舍之夜模板）；
   高阶压制具名且数值上真打不过（金光上人正面必败已是雏形，扩成体系）。
2. **威名先至**：强者名字在见面前反复入耳（风云录/闲谈/镖师夜话），
   见面时"剧情强"与"游戏强"同瞬兑现。
3. **强者在场感**：世界配几位"名宿"，不必可战，只是山。偶遇纯演出
   （山道遁光掠过，你躲树后仰望筑基修士御器而行）定义世界高度。
4. **逃跑=一等公民动词**：遁速决定逃脱率，逃≠输，= 韩立式聪明
   （fail-forward：保命+看破对方底细）。惹不起但跑得掉本身是爽，亦是风雷翅幻想的铺垫。

### 总循环（设计底盘收束）
真虎定价（一致感）→ 绕着走攒底牌（藏拙/经营）→ 时机到掀桌（打脸/以下克上）
→ 年表记一笔（成长可见）→ 抬头看下一座山（前路/惦记）。

## 二补·七、扬名时刻：名声是藏拙的对偶面（用户 2026-06-11 凌晨洞察）

> 用户原话：「韩立为什么在凝结元婴后被人称为是高潮？因为他开始正式敢抛头露面，
> 在穆兰大战大显身手。之前他以结丹力压长老救葡萄仙子也是爽点——**该爽的时候要爽**。」

藏拙不是终点，是**为扬名蓄势**。完整曲线：隐忍经营（藏）→ 关键时刻出手（亮）→
**世界的名声坐标系记住你**（扬）。三段缺一不可——只藏不扬是憋屈，只扬不藏是廉价。

设计要点：
1. **双名声值**：「显露名声」（世界以为你是谁）与「真实实力」分离，与藏拙引擎共用一套
   显露/真实境界数据。抛头露面的高光战会把名声一次性兑付。
2. **名声的世界回响**：名声每上台阶，NPC 称呼/态度/求见/让利/忌惮全联动
