# 属性系统 与 全局战斗平衡框架

> 目标：建立一套**贯穿全游戏**的属性 + 战斗平衡模型，让"凡人靠准备与算计胜强敌"成为可计算、可验证的机制，而非靠手调数值。

## 一、角色属性（六维 + 灵根）

| 属性 | 键 | 战斗作用 | 大世界作用 | 主要来源 |
|------|----|---------|-----------|---------|
| **灵根** | rootId | 决定每回合五行灵气的**种类/比例/总量** | 影响修炼速度、可习功法 | 出生命定 |
| **神识** | sense | **不是独立攻击**。比对手高→看穿其下回合意图(底牌)、命中/暴击加成、抗神魂/幻术；低→被对方看穿 | （大衍诀解锁后：探查、警戒、操控法器——后做） | 境界、功法、丹药 |
| **遁速** | speed | **出手顺序(先手)**：高者先动；差距大可抢先/多动。也提供闪避 | **赶路耗时**：越高耗时越少 | 身法功法、灵根、法器 |
| **悟性** | insight | 突破时削瓶颈更快、临场顿悟（额外灵气/暴击） | 习功法速度、炼丹成功率 | 出生 + 际遇 |
| **体魄** | body | 气血上限、抗物理 | 负重、抗劳损 | 炼体、苦修 |
| **道心** | mind | 突破/心战的"血条"，抗心魔 | 抗心境波动 | 历练、心境事件 |

> 神识与遁速都是**比较型/换算型**属性：神识看的是"我 vs 对手"的差值；遁速既换算战斗先手，又换算大世界耗时。

## 二、功力（gongli）—— 贯穿全局的"实力刻度"

定义一个统一的**功力值**，作为平衡的标尺：

```
功力 = 境界基数(realmPower) + 修为饱满度×层系数 + 神识×a + 体魄×b
```

- `realmPower` 按境界层级指数增长（练气→筑基→结丹…每个大境界一个台阶）。
- 功力用于：① 对神魂之敌（元神）的伤害换算（韩立"靠功力胜余子童"）；② 全局敌我强弱比较；③ 突破瓶颈的基准。

## 三、全局战斗平衡模型（DPS 竞速 + 准备乘区）

战斗本质是一场**竞速**：你能否在被磨死之前先磨死对手。

```
玩家有效DPS   = 灵气DPS(qiDPS) + 底牌DPS(prepDPS) + 连携/暴击加成
玩家可战回合  = 气血 / (敌有效DPS × (1-减伤))      // 减伤来自护体、闪避、遁速
击杀所需回合  = 敌气血 / 玩家有效DPS
胜：  击杀回合 < 可战回合
```

**关键设计——准备是独立于灵气预算的"额外伤害区"：**

- `qiDPS`：受每回合灵气总量**硬约束**（韩立四灵根总量低）。光靠灵气，DPS 有天花板。
- `prepDPS`：来自**底牌**(催熟的毒=持续伤害、暗器=爆发)，消耗灵气极少，伤害却在灵气预算**之外**。
- 因此：**准备越足 → 有效DPS 越能突破灵气天花板 → 才打得过血厚/高输出的强敌。**

### 难度档（敌人相对玩家功力的威胁比）

| 档位 | 敌DPS / 玩家可承受 | 设计意图 |
|------|------|---------|
| 寻常 | 0.6× | 灵气硬实力即可胜，练手 |
| 强敌 | 0.9× | 灵气勉强打平，准备能稳赢 |
| 关底/夺舍 | 1.2~1.4× | **光靠灵气必败，必须靠准备(毒+暗器)+算计** |

> 平衡校验目标（决战墨大夫为例）：
> - 充分准备：胜率 ≥ 80%
> - 一般准备：胜率 40~60%
> - 毫无准备：胜率 ≤ 15%
> 由 `test/showdown.bal.js` 蒙特卡洛验证，保证"准备决定胜负"的梯度成立。

### 防续航（杜绝"无限回血"破坏平衡）

- 回血(长春吐纳)**弱且耗灵气**：只够应急买一两回合，**净恢复 < 强敌DPS**，无法靠它耗死强敌。
- 强敌附带**持续伤害(毒/反噬)**或**破护体(pierce)**，使纯防守流走不通。

## 四、神识的战斗作用（比较型，非攻击）

- `senseAdv = 玩家神识 - 敌神识`
- `senseAdv > 0`：① 看穿敌人下回合**意图**(UI 显示，等于看底牌)；② 命中+、暴击率+；③ 抗神魂/幻术。
- `senseAdv < 0`：敌人看穿你，敌命中/暴击+。
- 对**元神(soulOnly)之敌**：肉身招式无效，唯有**运功镇魂(功力换算伤害)**可伤之；神识高则镇魂更准更狠。这对应"韩立靠功力(而非某个神识法术)胜余子童"。

## 五、遁速的作用

- 战斗：回合开始按双方遁速定**先手**；遁速远高→有概率抢一次额外行动；亦提供闪避(封顶45%)。
- 大世界：`赶路耗时 = 基础行程 × clamp(基准遁速 / 玩家遁速, 0.4, 1.5)`，越快越省时间(=省寿元)。

## 六、灵根的影响（不止战斗）

- 五行灵气的**种类/比例/总量**（韩立四灵根缺土、木旺、总量低）。
- 修炼速度系数、突破加成。
- 可修功法限制（缺某属性则该系功法事倍功半）。

## 七、悟性的影响

- 突破心战中**削瓶颈伤害加成**（悟性高，看得透瓶颈关窍）。
- 临场**顿悟**：每回合小概率额外灵气或必暴击。
- 习功法/炼丹速度（大世界）。

## 八、实现与验证

- `js/combat.js`：竞速模型、先手、神识意图、功力镇魂、防续航。
- `js/balance.js`：集中管理平衡公式与难度档（realmPower、威胁比、prepDPS 估算），全局复用，便于后续章节套用同一把尺子。
- 测试：
  - `test/combat.test.js`：机制单测。
  - `test/showdown.bal.js`：准备梯度胜率（核心平衡校验）。
  - `test/run.js`：全流程贯通。
- 后做：大衍诀的大世界神识玩法、更多功法/法器、筑基及以后章节套用本框架。
