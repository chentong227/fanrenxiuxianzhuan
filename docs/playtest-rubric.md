# Playtest 15 条评估标准（统一量表）

> 此后每个被测节点（剧情/战斗/探索/旅途/弹窗）都按这 15 条逐项过。
> 打分：✅ 通过 / ⚠ 有问题 / ❌ 严重 / —（不适用）。每条带"看什么"。
> 实机基准：iPhone 14 Pro Max（430×932, DPR3），Playwright MCP 真机操作 + 截图。

## A 类 · 功能正确性（不能错）
1. **无报错/无卡死** — console 无红字；点击有响应；不软锁（pendingEvent 能正常恢复）。
2. **状态正确推进** — storyStage/flags/realm/物品/月份按预期变化；选择有实际后果（写入账本/属性）。
3. **存读档一致** — 该节点存档后读档，进度/界面/剧情恢复一致，不丢不卡。
4. **交互可达** — 该点的所有按钮/选项/单位都能点到（≥44px 触控区，不被遮挡、不在画外够不到）。

## B 类 · UI/视觉（手机端）
5. **布局无溢出/无重叠** — 元素不出血、不互相压盖、不留大片空黑；安全区避让正确。
6. **立绘/CG/场景到位** — 该出现的美术资产出现且对得上说话人；无破图/裁切/张冠李戴/拦腰斩。
7. **文字可读** — 字号够大、不折行难看、正文与提示分层；长文本有节奏不糊成一片。
8. **即时反馈** — 每个操作后有清晰反馈（toast/见闻/数值变化/动效），玩家知道"刚发生了什么"。

## C 类 · 游戏性/节奏
9. **目标清晰** — 玩家随时知道"现在该干什么"（天命/限时/指引准确且与新 UI 一致）。
10. **节奏张弛** — 不拖沓（无意义空等）、不赶（信息量过载）；锚-帆节奏成立。
11. **选择有意义** — 选项不是换皮；不同选择有不同后果/收益/风险；不存在唯一正确解的伪选择。
12. **难度合理** — 战斗不无脑碾压也不莫名暴毙；fail-forward（败有所得/有退路）；越阶靠底牌。

## D 类 · 叙事/沉浸/考据
13. **剧情通顺** — 因果连贯、无前后矛盾；情感落点到位；过场/演出服务叙事。
14. **人设一致** — 角色言行符合其设定（韩立谨慎/万小山热心等）；无突兀转变。
15. **考据无硬伤** — 与动漫版锚点一致；时间线/手段/称谓不穿帮（拿不准回查 docs/lore-*）。

## 评测记录格式
每节点一张小表：
```
### <节点id> · <标题>（章节）
| # | 标 | 备注 |
（只记 ⚠/❌ 与亮点；全 ✅ 的条可省，但 1/2/3/5 必填结论）
```
