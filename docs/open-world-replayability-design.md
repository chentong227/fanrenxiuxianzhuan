# 开放世界重玩性设计：从线性剧情到「同世界不同局」

> 缘起：用户问——"一切资源一致，韩立人设固定，重开一局怎么玩出区别？像艾尔登法环那样。"
> 本文通读全部已有设计文档（world-architecture / fate-design / randomness-plan /
> retention-design / bigitem-design / power-design / multiply-design / technique-tiers /
> combat-arsenal / explore-redesign / balance-master / combat-design / roadmap）及
> engine.js / balance.js / data.js 核心代码后，给出完整方案。
>
> 设计原则：**零新系统**——全部复用已有引擎（乘法三律第一律）；
> 所有新机制必须能挂到修仙常识上（第二律）；节拍器三规不可破（第三律）。

## 〇、法环的"同资源不同局"到底在分化什么？

法环的每把体验不同，不靠素材差异，靠三件事：

| 分化维度 | 法环的做法 | 凡人对应物 |
|---------|-----------|-----------|
| **空间顺序自由** | 先利耶尼亚还是先盖利德 | **时间窗口互斥**——同一年有两件事，只够做一件 |
| **Build 路线互斥** | 魔法 vs 信仰 vs 肉搏，属性点有限 | **功法层数 × 时间取舍**——练剑的时间就不能练丹 |
| **信息迷雾** | 宝箱陷阱、隐藏 NPC | **修仙世界的信息不对称**——情报面纱 L0~L2 本身就是你设计过的 |

法环缺、凡人有的杀手锏：**800 年人生的时间压力**。法环角色不会老不会死于寿元，所以紧迫感来自空间（boss 挡路）。凡人的紧迫感来自时间（小妹会老、禁地会关、寿元会尽），**时间本身就是最强的分化引擎**——每个月只能做一件事，想做的事永远比时间多。

## 一、六层分化引擎（全部复用现有系统）

### 第 1 层：功法层数 × 时间 = Build 路线分化

你已经有 `s.techLayers[techId]` 和 `refineLayer` 了（engine.js:2489）——这是最天然的 Build 分化载体。当前问题：**闭关只涨修为，没有方向选择**。

**改法**（最小改动）：闭关弹窗增加「专修方向」选择——

```
你要闭关几个月？
├── 苦修《青元剑诀》（修为 + 功法层进度）
├── 参研丹道（修为 + 丹术熟练度）
├── 参研阵法（修为 + 阵法熟练度）
└── 纯修灵力（修为最大化，无专项进度）
```

**系统映射**：复用现有 `cultivate()` + `canRefineLayer()`，闭关月数同时推进主修功法层和专修方向。关键约束是**同一个月只能推一条轴**——12 个月练剑就不能练丹。

**重玩性来源**：
- 第一把：专修剑道 → 7 层剑影分光 → 血色禁地硬闯封岳
- 第二把：专修丹道 → 自制解毒散 → 血色禁地走毒修路线绕过封岳
- 第三把：专修阵法 → 布阵困敌 → 血色禁地用困阵消耗封岳

**实现成本**：`cultivate()` 加一个 `direction` 参数，复用 `refineLayer` 的月数消耗逻辑。`杂学熟练度` 已有雏形（roadmap 周期二·五提到）。balance.js 的 `layerMul` 已处理功法层对战力的影响。

**与现有设计的咬合**：
- technique-tiers §5.3 已定义"初入/中坚/巅峰"由主修功法层派生——**同是练气十一层，剑道巅峰 vs 丹道巅峰打法完全不同**
- bigitem-design 大件四问的"轴上每格喂什么"——功法层就是最标准的嗑瓜子轴
- power-design 的加区（build 同阶浮动 1.0~2.0）——功法层 + 专修方向正是加区的填充物

### 第 2 层：时间窗口互斥 = 「修仙者的取舍」

world-architecture §2.1 已经设计了三种锚（日历锚/地点锚/条件锚）。当前问题：**锚之间不互斥**——玩家有充足时间逐个完成所有锚。

**改法**：让 2~3 个日历锚的窗口**重叠**——

```
第 45 年冬：
  ├── 太南小会（买丹方的唯一机会，窗口 3 个月）
  ├── 青牛镇回乡（小妹生子，错过不可逆）
  └── 坊市异闻（菡云芝出现在黑市，限时）
```

三个月窗口，你只够赶一个地方。去太南就不能回乡。这不需要新系统——STORY 节点的 `cond` 加时间窗口判定 `s.year >= 45 && s.year <= 46`，超窗走 `skipIf` 补救径。

**与现有设计的咬合**：
- fate-design §1 命途三铁律第一条："道岔有窗口，窗口过了就是过了"——已经是你的设计原则
- world-architecture §2.2 帆的三重身份："备锚、经营、撞插曲"——窗口互斥让"备锚"本身变成真正的取舍
- 故人钟的"大跳跃前告别清单"——天然是窗口互斥的 UI 表达（"谁的沙漏等不到你回来？"）

**重玩性来源**：第一把去太南拿丹方；第二把回乡见小妹——不同的选择导致后续资源组合不同，连锁影响血色禁地的打法。

### 第 3 层：因果账本分化主线演出

world-architecture §3.2 已经设计了因果账本 `s.ledger`，fate-design 已经设计了道岔系统。当前问题：**主线节点还没有真正读账本来改变自己**。

**改法**：让关键主线节点"读账本的剧本"——

```js
// STORY 节点：燕家堡之战
{
  id: "yanjiabao_siege",
  playStage() {
    if (s.ledger.saved_chenqiaoqian) {
      // 陈家剑阵开了一角——战力+1 阵营、战前多一段陈家增援演出
      // "多亏当日官道上，你救了我家巧倩——陈家剑阵，借你一用！"
    }
    if (s.ledger.met_leiwanhe_early) {
      // 雷万鹤传来情报——敌方阵型已知，可选择突袭方向
    }
    if (s.ledger.spared_modao_spy) {
      // 你当年放走的可疑之人——如今带着魔修小队从侧翼包抄
    }
  }
}
```

**同一个燕家堡，因为你之前的选择，变成完全不同的战斗**。这不是新系统——你的 `checkStory()` + `flags` 已经是账本 v0（world-architecture §3.3 原话）。

**重玩性来源**：
- 救过陈巧倩 → 燕家堡有增援 → 但你少了一颗忘尘丹
- 放走魔道细作 → 血色禁地多一伙敌人 → 但集镇上你因此结识了一位散修线人
- 每条因果链至少有"近响 + 远雷"两次兑现

### 第 4 层：探索过程随机化

randomness-plan 已经规划了"可随机"的内容清单。当前 ⬜ 待做的三项就是重玩性的直接来源：

| 待做项 | 重玩性贡献 | 复用系统 |
|--------|-----------|---------|
| **奇遇事件**（`kind:"fortune"`） | 每局前 50 年遭遇不同 → 到黄枫谷时资源组合不同 | `fortunes.js` 事件表 + 现有 `encounters` 框架 |
| **市集刷新** | 每次太南小会摊位不同（关键大件保底） | 现有 `_shopPool` + 随机权重 |
| **小绿瓶变异** | 催熟低概率出高阶药 → 改变丹道路线 | 现有 `bottle` 状态 |

**关键约束**（randomness-plan §4 已定）：关键平衡由"准备 + 属性"主导，随机只在边际波动。**大件保底、主线不随机**——随机的是"世界和过程"，不是角色本体。

**重玩性来源**：
- 第一把太南小会买到寒冰符方 → 走冰系 build → 血色禁地利用水边场景加成
- 第二把太南小会买到火蛇符方 → 走火系 build → 利用元素克制打金行妖兽

---

### 第 5 层：NPC 命途分叉 × 交叉影响

fate-design 已经设计了完整的命途系统。当前问题：**各条命途线是独立的，互不影响**。法环的 NPC 线也是独立的；凡人可以做得更好——让道岔之间**互相消耗资源**。

**改法**：道岔的 `cost` 要吃同一个资源池——

```
陈巧倩线：医病需要「珍稀药材 ×3」+ 药理熟练度 ≥ 40
厉飞雨线：赠精元丹需要「珍稀药材 ×2」+ 你的一次闭关月
```

同一批珍稀药材，你不够给两个人。**救谁是真选择**——不是因为你不想救，是因为你的时间和资源在单周目里真的不够用。

**与现有设计的咬合**：
- fate-design §0 公理："救一人需倾力，救不了所有人"——已经是你的设计原则
- retention-design §一补 用户裁决："肝→大件兑现"——命途道岔的代价必须"疼"（bigitem 四段范式）

**重玩性来源**：
- 第一把：全力救陈巧倩（药材全给她）→ 燕家堡有陈家增援 → 但厉飞雨出走
- 第二把：全力扶持厉飞雨 → 厉飞雨成执法堂首座 → 回访七玄门时有不同演出
- 第三把：两边都不花资源 → 药材全用来自己筑基 → 个人战力最强但两条命途走默认（遗憾版）

---

### 第 6 层：探索路径分化（空间维度的"法环感"）

explore-redesign 已经有 L1 野外舆图层（9~12 地标节点 + 连线）。当前问题：**最优路径通常唯一**。

**改法**：利用灾厄钟 + 巡逻威胁 + 时间压力，让同一张图产生**多条有效路径**——

```
血色禁地舆图（5 日大限）：
  路线 A：正面推进（快但遇封岳巡逻 → 必战）
  路线 B：绕行药圃（慢 2 天但避开封岳 + 采到珍稀药材）
  路线 C：潜行暗道（需探知熟练度 ≥ 30 才能发现入口）
```

**三条路线通向同一个 boss，但到达时的状态完全不同**：
- A 路到达时药材少、可能受伤，但时间充裕
- B 路到达时药材丰富但只剩 2 天、必须速战
- C 路到达时消耗最小但需要提前肝探知（build 前置投入）

**实现**：复用现有 `ExploreMap` 引擎的节点+连线+巡逻+灾厄钟，只需在数据层增加隐藏节点（`cond: s.skills.探知 >= 30`）。

## 二、系统交叉矩阵：六层之间如何相乘

六层不是六个独立系统——它们彼此相乘，产生组合爆炸：

```
           功法层  窗口互斥  因果账本  过程随机  命途分叉  路径分化
功法层      ——     闭关时间    ——      ——      资源竞争   路径门槛
                  = 窗口代价                  = 谁能救   = 能力解锁
窗口互斥    ×       ——      选择写入    ——      窗口=     ——
                            账本              道岔窗口
因果账本    ——       ×       ——       奇遇写入   命途=     账本改地图
                                    账本      账本子集   （退潮变迁）
过程随机    ——       ——       ×       ——       随机遭遇   随机事件
                                             改变道岔   改变图上
                                             代价      资源分布
命途分叉    ×        ×        ×        ×       ——        命途结果
                                                       改变回访
路径分化    ×        ——       ×        ×        ×        ——
```

**举一个完整的乘法链**：
1. 你第一把专修丹道（层 1）→ 药理熟练度高
2. 太南小会与回乡窗口重叠，你选了太南（层 2）→ 买到丹方
3. 路上救了陈巧倩（层 3 因果）→ 账本记 `saved_chenqiaoqian`
4. 市集随机出了一批寒毒药材（层 4）→ 你因为丹道高能用上
5. 药材花在给陈巧倩治病上了（层 5 命途 × 层 1 资源竞争）→ 自己筑基丹差一味
6. 血色禁地只能走药圃绕行路线采最后一味药（层 6）→ 时间紧迫 + 最终 boss 打法变化

**同一个游戏、同一个韩立、同样的资源——完全不同的故事。**

## 三、与"功法层数界定初入/巅峰"的咬合

你提到已经有功法层数，想用"花时间修炼功法"来区分同境界的初入和巅峰。这正好是六层分化的**第一层核心**。具体展开：

### 3.1 现有基础

```js
// balance.js:160 — 已实装
layerMul(layer, maxLayers) {
  const t = clamp(((layer || 1) - 1) / (maxLayers - 1), 0, 1);
  return 1 + 0.3 * t;  // 入门 1.0 → 满层 1.3
}

// technique-tiers §5.3 — 已实装
State.realmStage(s)  // → "初入" / "中坚" / "巅峰"
```

### 3.2 扩展方向：多功法路线

当前韩立只有一条主修（长春功 → 青元剑诀）。扩展为**可选主修路线**后，功法层数成为 Build 的核心：

| 主修路线 | 层数解锁 | 战斗范式 | 闭关投入 |
|---------|---------|---------|---------|
| 青元剑诀（剑修） | 3 层剑芒 / 5 层剑盾 / 7 层剑影分光 | 多段连斩、法宝协同 | 重剑道 |
| 丹道深研 | 丹术 1~5 级 → 自炼各阶丹药 | 备牌充裕、底牌多 | 重丹道 |
| 阵法入门 | 阵法 1~3 级 → 布阵困敌 / 传送 | 控场、脱战 | 重阵法 |

**关键**：这不是"三个主角"——韩立永远是韩立（randomness-plan §1 不可随机：主角身份/灵根/性格固定）。区别是**你选择让他把有限的时间花在哪条路上**。原著韩立也是"什么都会一点，但每个阶段有侧重"——游戏化就是让玩家来做这个侧重选择。

### 3.3 功法层作为「大件链的入口」

bigitem-design 的四段范式（听闻 → 获取 → 开轴 → 轴上里程碑 → 通向下一个大件）中，功法层本身就是一根轴：

```
青元剑诀 1 层（入门）
  → 3 层 解锁剑芒（里程碑 + 年表 + 钟声）
  → 5 层 解锁剑盾（防御手段质变）
  → 7 层 解锁剑影分光（主输出法术）
  → 通向：绿煌剑让剑影分光"用处放大"（下一个大件的入口）
```

**重玩性**：第一把肝到 7 层剑影分光；第二把只练到 5 层剑盾就转去肝丹道——同一个功法，不同的"停在哪一层"，决定了你进入下一个篇章时的 build profile。

## 五、与法环的终极对比

```
法环的分化引擎            凡人的分化引擎
─────────────           ─────────────
空间顺序自由    ←→      时间窗口互斥
  （先去哪个区域）          （先做哪件事，另一件会过期）

Build 路线互斥  ←→      功法层数 × 专修方向
  （魔法/信仰/力量）        （剑/丹/阵，时间有限只够深耕一条）

信息迷雾       ←→      情报面纱 L0~L2
  （宝箱陷阱）             （敌人底细、传闻真假、市集内幕）

NPC 线性支线   ←→      命途道岔 × 资源竞争
  （各做各的不影响）        （救谁要花同一批药材——真选择）

无时间压力     ←→      800 年寿元 × 故人钟
  （不死不老）             （小妹会老、丹方会过期、窗口会关）
```

**凡人的杀手锏**：法环做不到的东西——**时间维度的取舍**。法环的角色不会老、不会死于寿元。凡人的紧迫感来自"每个月只能做一件事，而想做的事永远比时间多"——这个时间压力本身就是最强的分化引擎，因为它让每一次闭关方向选择、每一个窗口取舍都成为不可逆的真实决定。

## 六、一句话总结

**你不需要做新系统，需要做的是「编织」**：

```
现有系统              →    重玩性来源
───────────────────────────────────────
cultivate + techLayers →    Build 路线（练什么→怎么打）
passTime + 日历锚      →    时间窗口互斥（去A还是去B）
flags + ledger         →    因果分化（救谁→谁帮你）
fortune + 遭遇表       →    过程随机（每局不同遭遇组合）
fate 道岔 + 资源池     →    命途竞争（救一人需倾力，全救不可能）
ExploreMap + cond      →    路径分化（能力决定你能走哪条路）
```

六层编织在一起，同一个韩立、同一个世界——**每局都是不同的人生**。
