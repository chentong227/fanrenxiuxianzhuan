### 1.2 韩立打法的四个特征（系统必须支撑的"凡人味"）

1. **多手齐发**：飞剑+灵虫+傀儡+符宝+神通一齐招呼（"老魔围殴"）——
   战斗系统必须允许一回合打出多张牌 ✓（灵气池多动作模型已支持）
2. **预谋型战斗**：战前情报/备牌/布置的权重 ≥ 战中操作 ✓（情报面纱/底牌已支持）
3. **保命冗余**：永远留一手遁术与护盾（血影遁/玄天盾）——底牌轴需有"保命牌"类
4. **资源换强度**：符宝吃灵石、傀儡吃灵石、灵虫要喂——强力手段都有运营成本

|------|------|-----------|----------|----------------|

### 二·五、法宝三位制 + 悬浮祭出（v96 用户裁决，2026-06-13）

> 用户原话锚："法宝几乎无 CD 只考虑灵力消耗，设一个主法宝和一个防御法宝刚好排下；
> 其他法宝（如温天仁之战的如意花篮、血色披风）怎么生效？给我个建议。"
> 答案=**悬浮祭出**：原著"韩立同时驱使多件法宝靠的是神识"的机制化。

- **主法宝位（主）**：第一攻击法宝——占主行动驱使，威力=注入灵力（现行不变）；
- **护身法宝位（御）**：防御类法宝——占主行动展开（现行不变）；
- **悬浮位（祭）**：其余法宝点卡**祭起**（花一个主行动）→ 入场绕身悬浮，此后
  **每回合自动运转**（按法宝 float.auto 定义：如意花篮=花雨溅射最近敌/
  血色披风=自动补盾），同时**每回合抽灵力**（float.upkeep，3~5——"几乎无 CD、
  只看灵力"的资源化）；点卡**收回**不占行动。灵力不济=自动坠收+破绽（同凌空灵竭）。
- **悬浮数上限=神识档**（Balance.floatSlots）：基础 1 → 习得大衍诀 +1 → 结丹 +1
  →元婴 +1（"多法器并用吃神识"的字面落地——大衍诀的战斗意义由此兑现）；
- **敌我同规则**：敌修 build 可带 floats（黑煞教血侍的血茧/胥王黑血刀悬浮压场——
  魔道争锋篇兑现）；玩家可用打灵力（耗蓝）逼对方悬浮坠收。
- UI：法宝区=主/御两张大卡+悬浮法宝小卡（祭起中=金边呼吸+头顶绕身演出）。
| 结丹 | 固态金丹 | 高级法术、秘术、法器、**法宝**、古宝 | **法宝**（精血祭炼可收体内、日夜淬炼成长） | 本命法宝=可成长大件（青竹蜂云剑）；法宝技威力=本身威能×注入法力×神念 |
| 元婴+ | 元婴 | 神通、剑阵、第二元婴、傀儡军 | **神通**（大庚剑阵）+多线作战 | 神通轴开轴；侧位多带 |

**三条系统铁律**：
1. **威力=注入法力**：法器/法宝技随 qiLayer/境界成长陡于法术（御物是富人的武器——
   灵力雄厚者催动同一件法器威力更大）；修为不够强用高阶法宝发挥不出
   （考据：南宫婉压制至炼气期拿朱雀环被墨蛟压制——驱使门槛 minLayer 的依据）。
2. **神识=并用上限**：大衍诀类神识功法的战斗价值=同时操控多件法器
   （筑基后随神识解锁第二武器槽——roadmap 远期）。
3. **符宝=一次性法宝**：结丹修士所炼，威力堪比法宝但用两三次即废且递减
   （金光砖充能制 ✓ 正合考据）。

## 二、六轴模型（玩家 build 的完整空间）

```
            ┌─ 输出循环 ──────────┐      ┌─ 资源/爆发 ─────────┐
轴1 法术轴   功法灵技+五行克制      轴3 底牌轴  符箓/符宝/毒/暗器/保命牌
轴2 武学轴   剑势/毒刃（前期主力）   轴6 神通轴  辟邪神雷/剑阵（后期大招+特攻）
            └────────────────────┘      └────────────────────┘
            ┌─ 第二单位 ──────────┐      ┌─ 常驻成长 ─────────┐
轴4 侧位轴   尸傀→灵宠→傀儡        轴5 法宝轴  法器→本命法宝（青竹蜂云剑）
            └────────────────────┘      └────────────────────┘
```

| 轴 | 定位 | 解锁线 | 机制抽象 |
|----|------|--------|----------|
| 1 法术轴 | 核心循环：灵气池施法 | 七玄门起 | 已有 + 五行克制（element-design.md） |
| 2 武学轴 | 前期主力，筑基后渐贬值 | 七玄门 | 已有（剑势/淬毒/暗器）；阴冥之地回归一次 |
| 3 底牌轴 | 即用即弃的爆发与容错 | 七玄门后期（买符）→ 太南小会（自制符） | pouch 消耗品 + 符宝（带充能次数的大杀器） |
| 4 侧位轴 | 战场第二单位 | 七玄门尾声（尸傀 v0）→ 黄枫谷（**同道**：南宫婉并肩战首演）→ 魔道争锋（血玉蜘蛛=第一只灵宠；前线初炼傀儡——大衍诀后）→ 乱星海（啼魂兽/傀儡量产） | 侧位单位卡：每回合自动行动；尸傀耐打嘲讽 / 同道自主+简令 / 灵宠特性鲜明 / 傀儡灵石驱动 |
| 5 法宝轴 | 常驻装备 + 灵气催动强技 | 黄枫谷（入门法器）→ 结丹（本命法宝） | 装备位 + 专属强技；本命法宝随境界成长（大件链条主载体） |
| 6 神通轴 | 质变大招 + 特攻 | 乱星海起 | 高消耗终结技 + slays 特攻表（辟邪神雷克鬼魔） |

**轴间乘法**（设计审计：每轴必须与至少两根其他轴相乘）：
- 底牌×克制：火蛇符克金行道基（情报→备符→兑现）
- 侧位×底牌：尸傀挡刀回合 = 你安全甩符的窗口
- 法宝×法术：本命法宝吃功法行属加成（青竹蜂云剑×木行功法）
- 神通×特攻：辟邪神雷 slays ghost/demon——韩立战玄骨的系统依据
- 侧位×特攻：啼魂兽天生克鬼物（吞噬精魂）——灵宠也在 slays 表上

## 三、七玄门篇落地切片（本棒实装）

### 3.1 五行克制（轴1 升维）— element-design.md 全案
灵技 elem × 道基 attr，×1.25/×0.8；nature 特攻层（毒对尸鬼无效=一致感修复）。

### 3.2 火弹术（轴1 补全：玩家侧第一个火技）【v44 考据修正】
- 考据定稿：火弹术/御风诀/天眼术等小法术皆出自**《长春功》后篇**（八层以上所授）——
  太南小会上以丹药换得全本（动漫线）。~~神手谷残页自悟~~为原著线，已废。
- 游戏化：太南小会购得《长春功·后篇》→ 闭关研习 → 火弹术等入技能池
  （huo 2 灵气，中伤害，elem 火）——对金行敌人的本命答案。
  韩立四灵根火气薄（weights huo:1）→ 火弹术贵在克制不在频率，凝神转化攒火气成为真实操作。

### 3.3 符箓底牌（轴3 v1：买符时代）
- 火蛇符（elem 火）/ 寒冰符（elem 水）：集镇市场稀货+小算盘门路，1 灵气甩出，中高伤害。
- 本篇只能买不能制（制符术=太南小会后才解锁，考据红线）。
- 经济意义：灵根决定本命行属盘，符箓花钱补短板——穷靠本命，富靠符箓。

### 3.4 符宝金光砖（轴3 v1.5：第一件符宝 = 大件链条）
- 杀金光上人 → 战利品「金光砖」（符宝：充能 3 次，金系重击+破甲）。
- 大件四问：想要（决战遗赠/凶名既知）→ 准备（赢下决战本身）→
  代价（充能耗尽需灵石回充——资源换强度）→ 蜕变（底牌区常驻一张越级牌）。
- 爽文契约：杀手的凶器成为你的底牌，下次遇到强敌，你甩出的是金光上人的脸面。

### 3.5 侧位单位 v0：张铁尸傀（轴4 奠基 + 情感重器）
- 考据：墨大夫炼张铁为尸傀（铁奴），韩立夺曲魂幡后御使之——已有剧情 flag ✓。
- **【用户裁决 2026-06-16·统一】张铁=曲魂为同一存在**（旧档把"张铁尸傀"与"曲魂"分列，已作废）：
  张铁之魂即曲魂。线索链：七玄门尾声曲魂留墨府 → 京城篇 46 话杀胥王后埋"收回曲魂"钩 →
  再别天南寻回（被御灵宗夺舍者所夺，韩立胜）→ 服血凝五行丹**做成身外化身·可修炼** →
  靠**煞丹**至**假丹境**（差结丹一步、本质仍筑基巅峰，与结丹差距大）→ **战至玄骨篇被夺舍**
  （§1.1/§3.2 已记此线，本篇仅做下方 v0 侧位尸傀）。⚠ 煞丹/假丹境/辛如音红妆自爆等远线细节，
  写再别天南/玄骨篇前补 ≥2 源核实（precedent §3.9.1）。
- 机制：决战后解锁「携尸傀出战」（探索/遭遇战可带）；
  侧位单位卡：每回合自动攻击一次 + 被动嘲讽（30% 替你挡刀）；
  尸傀 nature=corpse：毒免疫、不知疲倦，战败仅"破损"（修复需阴属材料），不会永失。
- 情感设计：低概率触发微叙事（"幡下的身影出剑的姿势，依稀还是当年演武厅里那个少年"）；

### 3.7 符箓方案系统（制符 v2，2026-06-14 用户裁决·待定 C）

> 用户原话："符箓自己做要收集更多材料太麻烦了，尽量把已有的系统复用。符纸可以买，
> 解锁符箓方案（可以并入大件图鉴？）靠沟通/购买/战胜等等，这样方便制作。"
> 裁决：**不做绘画 UI、不做材料 grind**；复用现有系统，符箓制作="有方案 + 符纸 + 灵力即成"。

**三件套（全部复用现成机制）**：
1. **符纸 = 可买消耗品**：和现行火蛇符/寒冰符一样进市场（loadout.js `TALISMANS`/`TRUMPS` 已有买符即用的通货逻辑）。
   符纸是"空白载体"，本身不分属性——属性由"方案"决定。
2. **符箓方案/图谱 = 可解锁的配方**：靠**沟通 / 购买 / 战胜**获得（NPC 传授、坊市购谱、击败对手缴获）。
   **并入大件图鉴**（用户建议）——图鉴里每张"符箓方案"是一个条目，解锁=点亮，正好复用图鉴的"听闻→获取→点亮"
   节奏（bigitem-design 四段范式）。**不收集额外材料**。
3. **制作 = 有方案 + 符纸 + 灵力 → 成**：闭关/洞府里一步成符（可选成功率，受"制符术熟练度"杂学条影响，
   复用 retention 杂学熟练度引擎；**熟练度只影响成功率/产量，不引入新材料**）。无绘画、无连线小游戏。

**与旧设定的衔接（考据红线）**：原 §3.6/技能表里"制符=太南小会后（制符笔·菡云芝）"仍成立——
**太南小会=制符的解锁时点**（拿到制符笔=能开制符台）；本次只是把"做符"的**玩法**钉死为
"方案+符纸+灵力"，去掉材料收集与绘画交互。火蛇符/寒冰符这些既有买符照旧，制符 v2 让玩家能
**自产**已解锁方案的符。

**乘法校验（multiply-design 四问）**：①复用图鉴/市场/杂学/底牌四个旧系统相乘，**不立新系统**；
②符箓方案点亮即战力补短板（底牌×克制：缺火行→解锁火蛇符方案自产）；③解锁源多样（谈/买/打）喂"远中近惦记"。

## 四、侧位单位引擎（SideUnit）规格 v0

```
SideUnit = {
  id, name, kind: "corpse"|"pet"|"puppet",
  hp/hpMax,                 // 独立血条；归零=离场（尸傀破损/灵宠重伤退场，不永死）
  atk, atkName, elem, nature, slays,   // 攻击与克制全套（与 Fighter 同语言）
  guard: 0.3,               // 嘲讽率：替主人挡刀概率（尸傀高、灵宠低、傀儡中）
  upkeep,                   // 运营成本：尸傀=阴材修复 / 灵宠=喂食 / 傀儡=灵石驱动
  ai: "auto",               // v0 全自动；傀儡时代加简令（守/攻/停）
}
```
- 战斗循环挂接：玩家回合结束 → 侧位单位行动 → 敌方回合（敌人攻击时先掷 guard）。
- UI：战场玩家侧加一张窄卡（名/血条/上次动作）；无侧位时不渲染。
- 平衡：侧位=白送的输出+减伤 → 携带时敌方梯度按"+0.5 人"校准（蒙特卡洛单列）。

## 四·五、战斗手牌四区制 + 战场纵深语法（2026-06-12 用户裁决，v79 实装）

### 手牌四区制（"物/术/底牌/伙伴"一眼分开）
> v79 落定：**法宝法器区**（鎏金，区签竖排在网格内）→ **法术区**（同一张双排同滑
> 网格）→ **瞬发区**（窄排）→ **灵傀区**（侧位单位随身卡：名+血条+简令轮换
> 随→攻→守→撤，点卡即换）。未来灵宠/傀儡多带时，灵傀区横滑扩展。
- **法宝区**：装备 grantSpells 给的牌（鎏金缘+灵光印记 `.spell-btn.treasure`），
  催动时有专属演出（cc-treasure 金字+钟鸣）。**法宝可"收起"**——纳戒里的法器不必
  全部出战（`s.benchTreasures`，乾坤袋装备弹窗里收/出），元婴期不会被筑基期法器撑爆手牌。
- **法术区**：功法/武学牌，与法宝同一张**紧凑双排同滑网格**（grid 两行竖流横滑，
  一次手势两排齐动，划排内不划页面）。
- **瞬发区**：符箓/丹药/阵旗独立窄排（不占主行动的牌）。符箓自带**灵光锁敌**

  滚动条全部隐藏（scrollbar-width:none）。
- **紧凑档位（v83 硬紧凑，用户两催后落定）**：法术/瞬发牌 110/116px、印章 19px、
  字号 11/9px、字贴框（padding 1px 3px）；法宝牌大一号 126px 仍鎏金醒目。
  ⚠ 教训：≤640px 媒体查询里的旧覆盖（134px/28px）曾把紧凑改动整个吃掉——
  **改手牌尺寸必须连媒体查询一起查**。
