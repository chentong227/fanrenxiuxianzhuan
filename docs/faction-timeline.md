## 0. 结论速览（John 的修正成立）

- **势力是动态的**：四大势力不是开局就有、也不是同时一次结盟；它们在不同剧情阶段**先后**形成 / 重组。
- **「四个盟是慕兰入侵后才结盟」的精确版本**：
  - 正道盟、魔道六宗 = **传统强权**，开局（韩立离开天南前）就存在；
  - 九国盟 = 为**抗慕兰**而结（确与慕兰相关）；
  - 天道盟 = 为**抗正魔**而结，**韩立去乱星海之后**才出现；
  - 真正把四方拧成一股的**「天南联盟」（四方共御）= 慕兰大举入侵后才结**——这就是 John 记忆里的「四盟入侵后结盟」。
- 故叠加层必须按**当前剧情纪元**投影一张「势力快照」，而非固定色块。

> **本轮更新（以下条目以新章节为准，覆盖早期临时结论）**：
> - **§8 逐国剧情调研表**（18 国·主角到访/剧情存在度/各纪元归属，≥2 源）——取代 §7 早期对「无剧情小国」的粗略归类：**元武国、溪国、北凉国、东裕国（坠魔谷）、慕兰** 都有实质剧情、主角到访，**不是**「主角不去」的国。
> - **§9 多级势力叠加层**（L1 概览 / L2 国级主导势力 / L3 七派·六宗级 + 可访问宗门 + 动态）——把「势力」做成**贯穿各级、层深粒细**的叠加层（John 拍板）。
> - **§10 越/胥 定论 + L3 七派动态**（John 拍板：以动漫为主，越/胥对调）——§2/§4 中「越国＝home/七派」的表述按 §10 改为「**胥国**＝home/七派/可访问」，「**越国**＝不可访问剪影」。

## 3. 演化时间轴（纪元 epoch → flag）

> 每个纪元 = 一张势力快照。游戏当前实装阶段 = **七玄门篇 = 纪元 0**。后续纪元为未来篇章，先留 flag 钩子、默认关。

### 纪元 0 · 七玄门篇（当前游戏态 · 默认快照）
- **在场**：越国七派（中·当道）；魔道六宗（东邻天罗国）、正道盟（西邻风都国）两大传统强邻虎视；九国盟（远南·与慕兰边境拉锯）。
- **未在场**：天道盟（尚未组建）。
- **慕兰**：边境小规模拉锯（数年一小仗），未大举入侵。
- **背景**：七派趁正魔大战两败俱伤，结盟以雷霆之势逐正魔出越国，得一时太平（韩立此时为七玄门 / 黄枫谷弟子）。
- **flag**：默认（无）。

### 纪元 1 · 魔道入侵篇
- **触发**：魔道六宗全面攻越。
- **变动**：灵兽山倒戈归御灵宗 → 七派防线崩溃 → 黄枫谷 + 五派战败、携门人南撤九国盟势力范围、最终扎根**北凉国**；掩月宗撤北凉最西玲珑山。魔道全线控越国。
- **韩立**：被令狐老祖舍弃，凭「大挪移令」传送乱星海，离开天南。
- **flag**：`huangfeng_relocated`（已存在）／拟加 `modao_invasion`。

### 纪元 2 · 四大势力格局（乱星海篇期）
- **变动**：越国六派并入九国盟（九国盟实力大涨）；北方十几中小国组建**天道盟**（抗正魔）。
- **格局**：正道 / 魔道 / 天道盟 / 九国盟 四分天南，微妙平衡（正魔内斗无暇扩张、天道盟中立）。
- **flag**：拟加 `tiandao_formed`。

### 纪元 3 · 慕兰大举入侵 / 天南大战 / 天南联盟
- **触发**：慕兰法士大举入侵。
- **变动**：九国盟独木难支 → 拉四大势力结「**天南联盟**」共御（以九国盟为主、余三家为辅）；北凉边界筑「**天一石城**」据点；共动员宗门散修参战；维持百余年和平。
- **战后**：为防「突兀人」渔翁得利，与慕兰议和、划两国之地予慕兰居住，续联手御突兀。
- **flag**：拟加 `mulan_invasion` / `tiannan_alliance`。

> ⚠️ 纪元 1 / 3（魔道篇、慕兰篇）的**具体剧情内容受红线约束**——本稿只给框架与考据，内容待 John 修订定稿后填。

## 9. 多级势力叠加层设计（L1 / L2 / L3 · John 拍板）

> 关键认知（John 指出）：**势力 = 宗门的集合，而宗门在 L3 才出现**（胥国点进去才见黄枫谷/掩月宗/灵兽山…）。
> 故「势力」是一个**贯穿各级、层深粒细**的叠加层，不是 L2 单点功能。同一个 toggle，每级按它展示的节点粒度染色。

| 级别 | 节点粒度 | 势力粒度 | 内容 |
|------|---------|---------|------|
| **L1 人界** | 大域（天南/大晋…） | 一句概览 | 天南 node blurb 标「正道/魔道/天道盟/九国盟 割据」 |
| **L2 天南** | 国 | **大势力主导色**（4盟+七派+慕兰+中立） | canon 本就按主导势力描述国家（天罗=魔道老巢、风都=正道盟、溪国=天道盟、北凉=九国盟、胥国=七派）。整国色块＝「这国主要被谁控制」概览，**不代表国内每宗门都属它** |
| **L3 胥国（等可下钻国）** | 宗门据点 | **七派/六宗级**（非大联盟级） | 七派各宗逐个染色；**宗门是可访问节点**；动态演化（叛变/南迁/旧址）在这层最清楚 |

- **非破坏性**：L3 在现有水墨图（openContinent，资产 tiannan_map）上**叠一层染色/描边 + toggle**，不改底图。
- **toggle 一致**：L1/L2/L3 共用「势力」开关；开→染色+图例（只列当前纪元在场势力）+纪元标注（如「当前：七玄门篇」）；默认关=原视图。

**技术（承 §5）**：
- `WORLD.atlas.factions = { id→{name,color,edge,blurb} }`：`qipai/zhengdao/modao/jiuguo/tiandao/mulan` + `neutral`（中立不染或极淡）。L2/L3 共用此注册表（L3 的宗门也只落在这几个 id 上，如灵兽山叛后＝`modao`）。
- `WORLD.atlas.factionEpoch(s)`：读 `s.flags` → 0/1/2/3，默认 0。
- `factionAt(node, epoch)`：`node.factionByEpoch?.[epoch] ?? node.faction ?? null`（null=原色不染）。
- 渲染：openAtlas（L2）/ openContinent（L3）对每节点取 `factionAt(n, epoch)` → `.faction-<id>` class（L2 的 class 输出已埋在 ui.js）。
