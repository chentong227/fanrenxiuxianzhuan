## 二、三大支柱（本篇骨架）

### A. 风雷翅（大件·与青竹蜂云剑平级）

- **地位**（用户裁决）：本篇**核心大件**，与青竹蜂云剑同级；获取**跌宕起伏**。
- **形制与威能**（【确证·百度百科 + 衍生视频标题交叉】）：一对**风/雷双翼**飞行法宝
  （"左风右雷"），主打**极致遁速**（"一瞬三千里""一秒十万里"夸张化）——是韩立此后
  招牌的**逃跑流/跑路神器**（"把逃跑流玩到极致"）。对位青竹蜂云剑（攻）＝风雷翅（遁/机动）。
- **来历**（【确证·前篇埋 + 百科】）：与镇妖大典惊变的**雷鹏（十级妖王）**之翼同源；
  动漫线由**「贵人鸟」（鸟形妖修·疑即风希一系裂风兽线）正在炼制**，**韩立中途抢夺得手**
  （百科衍生条目明载"韩立抢夺风雷翅""贵人鸟要开始炼制风雷翅"）——**这正是"跌宕起伏"的实质**：
  不是白捡，是从炼制者手里夺来的。
- **入手集数**（【确证】）：132 集到手；**初期不善驾驭**（喜剧化"使脚刹"→后渐精通=成长弧）。
- **引擎兑现**（【确证·设定层】）：御「风雷翅」方解锁**雷遁穿空 / 战术飞行**——
  对应 combat.js `blink`（雷遁）+ `State.gearTrait("fenglei")` + 飞行阶梯"风雷翅时代"门槛
  （见 `flight-ladder-design.md`）。**本篇=风雷翅 driveRealm 门槛与雷遁机动的兑现处**。
- **【待核·细节】**：130 赴风希处做客 → 132 抢夺到手，中间风希/贵人鸟的立场与冲突如何展开？
  （风希"大善人"伪善面具几时揭破？抢夺是设局反夺还是趁乱夺？）

### B. 温天仁决战（元婴前巅峰·全游戏第一场顶尖大战）

- **温天仁**（【确证·前篇档】）：**六道极圣（万法门主）之徒·结丹后期（巅峰）**。
  初遇已在星海飞驰篇（虚天殿出殿·韩立持青易居士所赠青冥针**冒充其徒**蒙混过关）。
- **决战定位**（用户裁决）：**元婴以下第一人之争**——韩立结丹巅峰对温天仁结丹后期巅峰，
  全游戏迄今**绝对顶尖的一战**。情感/数值双高潮，须以"一致感锚点"最高规格设计。
- **【决战定位·已核】**（详见 §6.2 / §6.6 原著考据）：
  - **温天仁＝原著「六道传人」**，韩立本篇**将其击杀**（胜、对方死；非跨篇宿敌）。
  - **决战地＝「阴冥之地」**：鬼雾吸走后的下一小篇章，**所有人法力尽失、退回凡人**——
    全篇顶尖之战以**凡人肉身搏杀**收束，"凡人修仙"母题终极闭环。**特殊战斗模式**（脱离法力池/对阵轴）。
  - 与**元瑶还魂术**（复活妍丽）同段交织触发。
  - **【钩子·用户后补】**：动漫逐拍演出"复杂精彩"，细节待用户口述——**实装前必等此钩子**，本档不臆造。

### C. 银月（器灵·最重要伙伴之一）

- **承接**（【确证·前篇档】）：银月已于虚天殿以**狼首玉如意**形态入手（星海飞驰篇）。
- **本篇兑现**（【确证】）：149 集**银月化形登场**（人形·"小秘书"）——成为韩立最重要的
  灵宠/伙伴之一。与青竹蜂云剑（本命飞剑·银月本是剑灵设定线）的关系在此篇明朗。
- **【待核】**：银月化形的契机？与风雷翅/温天仁战的关系？战斗中的定位（侧位/辅助/器灵增幅）？

### 6.1 风雷翅（原著实锤·跌宕全程）

**原著版**（风希视角 + 时间线双证）：
1. **风希=九级裂风兽**，刚进阶「化形二阶」在洞府稳固形体。韩立（结丹）游历至其洞府附近礁石逗留，
   竟进洞**只取走几根草**（灵药），引起风希注意。
2. 风希本想杀他，但**正要炼制法宝「风雷翅」**（用一对**骨翅**+灵禽翅材料仿人类法宝装身上提速），
   **需木属性灵力稳固调和**——韩立恰是**主修木属性功法**，正合所需 → 风希**没杀他，反邀入洞做客**
   （风希平生第一次邀请人类修士）。
3. 风希以特制「**碧焰酒**」款待、助韩立突破瓶颈——**实则酒中暗注「混沌邪气」**胁迫其助炼，
   又种下「风灵劲」（催动即生不如死）双重控制。**韩立借酒之力真的突破到结丹后期**
   （＝动漫 130 集"去风大善人家做客**被迫进步**"的实义！"被迫"＝被下药胁迫，"进步"＝真破境）。
4. 风希另找**两个朋友**合炼，韩立只作木灵力来源。炼制中**韩立太狡猾、设计反制**：
   趁隙**杀死风希一个朋友**；风希有护身宝物杀不动，韩立见状**抢走风雷翅、逃入传送阵遁走**
   （＝132 集"抢夺风雷翅"+跌宕）。风希恢复后一路追杀，慢一步没追上，怒杀一个闯入的元婴修士泄愤。
5. **数百年后**（元婴后期）韩立才与风希再遇（移植龙鳞果树时），当面用风雷翅、**杀风希+金蛟王**——
   此为**远期**（原著第七卷），**非本篇**。

**动漫差距**：动漫把"贵人鸟炼制→韩立抢夺"作为 130~132 的喜剧+夺宝段（"使脚刹"不善驾驭为动漫加料）；
风希"大善人"伪善面具＝动漫强化的人设。**核心一致**：风雷翅是从风希手里**骗炼+抢夺+逃**得来，非白捡。

### 6.2 温天仁 = 原著「六道传人」（决战实锤）

**原著版**（时间线第四卷末）：韩立出虚天殿→行宫传送阵到外海→杀海妖/躲元婴追杀（假冒韩立引仇恨）
→拍卖会救文思月、得八级妖兽巢穴 →**遇九级妖修得风雷翅被追杀** → 从妙音门传送阵走
→ **「遇到了元瑶，施展还魂术，碰见了六道传人，打了一通」→「被鬼雾吸走了，杀死了六道传人」**
→ 离开鬼雾，和紫灵、梅小姐**传送到天南**（接第五卷「名震一方」·加入落云宗）。

**⇒ 实锤（含用户 2026-07-01 关键修正）**：
- **温天仁＝六道传人**（六道极圣一脉），韩立在本篇**确实将其杀死**（非跨篇宿敌）——用户"元婴以下第一人之争"成立，**结局＝韩立胜、六道传人死**。
- **决战场景＝「阴冥之地」**（用户核定）：韩立"被鬼雾吸走"后进入的**下一个小篇章**——
  **阴冥之地内所有人法力尽失、尽数退回凡人之躯**，温天仁的了结正是在此地达成。
  **⇒ 这是"凡人修仙"主题的终极回响**：全书顶尖的一战，双方却都被剥去修为、以**凡人肉身**相搏——
  韩立"以凡人之姿走完仙途"的母题，在此闭环。**战斗形态＝无法力的凡人搏杀**（与全篇修仙对阵轴迥异·
  设计上是独一份的特殊战斗模式）。
- **决战与「元瑶还魂术」同段发生**：元瑶施还魂术（复活妍丽线）→ 撞上六道传人 → 混战 → 鬼雾 →
  阴冥之地（众皆凡人）→ 韩立了结六道传人。**⇒ 元瑶还魂术线属本篇**（非重返天南）。
- **【钩子·用户后补】动漫具体演出**：用户明示"动漫的具体演出很复杂、很精彩"，**逐拍细节待用户后续口述**——
  本档先占位，不臆造。设计实装前必等此钩子兑现。

### 6.3 结婴时点（重要差距·影响篇章边界）

- **原著**：韩立**在第五卷「名震一方」（加入落云宗＝重返天南阶段）才修成元婴**，
  **不在外海风云段**。外海风云段韩立**全程结丹**。
- **动漫**：152 集见"结婴"标签，且部分片源把 152 归入**重返天南**（153~176）。
  **⇒ 大概率：外海风云章末仍结丹，结婴是重返天南的开篇**（与原著一致）。
  **本游戏取用**：外海风云篇**境界轴＝全程结丹后期（巅峰）**，**破元婴留作重返天南篇开篇**——
  与原著对齐，且让"温天仁决战"稳坐**结丹巅峰·元婴前第一战**的定位（用户裁决）。**§一境界轴据此修正**。

### 6.4 本篇其它原著锚点（时间线·可选入篇）
