# 武学 / 功法 / 法术 分级与平衡

> 忠于设定：凡人无灵根者以**武学**强身；修仙者以**功法**修炼、施展**法术/神通**。
> 武学层次最低，功法/法术远高于武学；功法之间亦有高下。眨眼剑法属凡人武学。

## 一、招式来源分类（source）

| 来源 | 说明 | 例子 | 强度基准 |
|------|------|------|---------|
| **martial（武学）** | 凡人武技，不耗或少耗灵力，廉价但威力有限；不随境界大幅成长 | 眨眼剑法、暗器飞针、（喂毒=淬毒手段） | 低 |
| **art（功法法术）** | 修仙功法所衍生的法术/神通，耗灵气，威力与境界/功法挂钩 | 长春吐纳、长春护体、运功镇魂；（后续）御剑术、傀儡术等 | 中~高 |

> 韩立七玄门篇的强，恰恰是"以凡人武学(剑法/暗器)+毒+算计"打修仙者，以弱胜强——这是设定的灵魂。武学弱，但配合准备能成事。

## 二、功法品阶（grade）

参照修仙界通行的四阶（黄/玄/地/天）外加凡品，越高越强、越难修、越难得：

| 品阶 grade | 含义 | 本作功法归属 |
|-----------|------|-------------|
| 0 凡品武学 | 凡人武技 | 眨眼剑法、暗器、淬毒等（非功法，单列为武学） |
| 1 黄阶 | 寻常练气功法 | **长春功**（黄阶下品，资质要求低、威力平庸——正合韩立，忠于"务实抉择"） |
| 2 玄阶 | 优秀功法 | （后续：黄枫谷一般传承功法） |
| 3 地阶 | 稀世功法 | **青元剑诀**（精元剑修，同阶越级而战） |
| 4 天阶 | 无上功法 | **大衍诀**（神识无上之法，分魂御傀） |

> 注意：长春功被设为**黄阶下品**正是凡人核心——韩立没有天阶资质，靠的是小绿瓶/准备/算计逆袭，而非一开始就抱着神功。

## 三、平衡模型（贯穿全局，写入 balance.js）

### 招式有效强度公式
```
招式有效输出 = 基础值
             × sourceMul(来源)         // 武学 0.8，法术 1.0
             × gradeMul(主修功法品阶)   // 黄1.0 玄1.15 地1.35 天1.6（仅作用于该功法衍生的"art"招式）
             × realmScale(境界)         // 法术随境界成长，武学几乎不随境界成长
```
- **武学**：`sourceMul=0.8`，且 `realmScale` 对武学近乎为 1（不随境界膨胀）→ 前期够用、后期落伍，符合"凡人武技终有上限"。
- **法术**：`sourceMul=1.0`，随境界与功法品阶成长 → 越往后，功法差距越拉开。
- **平衡红线**：同境界下，"高阶功法 + 充分准备" 应稳胜；但**低阶 + 神准备/神算计**仍有翻盘空间（毒、暗器、底牌），保留"凡人逆袭"的可能。

### 校验目标（蒙特卡洛）
- 同境界、同准备：地阶 > 玄阶 > 黄阶（胜率梯度明显）。
- 黄阶 + 充分底牌（毒/暗器） vs 玄阶 + 无准备：黄阶仍有 ≥ 35% 胜率（凡人逆袭的窗口）。
- 武学占比过高的配置，随境界提升相对走弱（鼓励后期换更高阶功法，呼应剧情换功法）。

## 四、实现要点
- 每个招式标 `source: "martial" | "art"`；`school` 关联功法。
- `balance.js` 提供 `spellPower(base, source, grade, realmTier)`，战斗统一调用。
- 武学不吃功法品阶加成；法术吃。
- 测试：`test/tier.bal.js` 蒙特卡洛验证品阶胜率梯度 + 凡人逆袭窗口。

## 五、功法层数轴 + 境界"初入/巅峰"（2026-06-14 用户裁决·待定 E：都要）

> 用户原话："境界越到后期，哪怕元婴初期也有初入和巅峰的区别……每个功法要到某个境界才能升下一层
> （如青元剑诀），那我到了元婴想把功法升到元婴级别，肯定要花时间（比如 5 层到 6 层），这个时间和
> 功法层次就是初入和巅峰的区别。功法的属性，以及功法解锁的能力也要设计清楚，包括青元剑诀的多个能力，
> 比如青元剑盾。"
> 裁决：**都要**——"又有大件延伸收益，又能区分同境界的区别，符合原著"。

### 5.1 现状与缺口（已读代码核定）
- **缺口①**：功法目前只有 `grade`（品阶），**没有"角色在该功法上修到第几层"的计数**。
  `loadout.learnTechnique` 一旦习得，`grantSpells` 里**所有招式一次性全给**——青元剑诀学会即同时拿到
  剑芒+剑盾，没有"3 层才出剑芒、5 层才出剑盾"的递进。眨眼剑法的"剑意"(swordIntent) 是唯一雏形。
- **缺口②**：`DATA.realms` 把练气拆成一层~十三层 13 个独立档，但**大境界（筑基+）没有初期/中期/后期/巅峰**
  子段——"元婴初入 vs 元婴巅峰"目前无从表达。

### 5.2 设计：一条**功法层数轴** `s.techLayers[techId]`
- 每门功法有自己的**最高层数**与**逐层解锁表**（unlock by layer）。习得=入门（第 1 层），之后**靠肝升层**。
- **升层成本**＝时间（闭关月数）＋修为消耗＋**门槛条件**（某境界才能继续往上、某机缘/秘药/口诀解禁后续层）。
  这正是"大件四段范式"的**可肝成长轴**（bigitem-design：开轴→里程碑→轴尽头接下一个大件）——
  功法升层就是一根标准的"嗑瓜子轴"。
- **层数解锁能力**（青元剑诀考据样板，combat-arsenal §轴1 + data.js 已锚定，**动漫硬考据**）：

  | 层 | 解锁 | 来源 |
  |----|------|------|
  | 3 层 | **青元剑芒**（qingyuan_jianmang，已在 grantSpells） | 动漫考据 |
  | 5 层 | **护体剑盾**（qingyuan_jiandun，已在 grantSpells） | 动漫考据 |
  | 7 层 | 剑影分光 | 动漫考据 |
  | 10 层 | 大庚剑阵（青竹蜂云剑相关，金页完整十三层） | 动漫考据 |

  > **改法**：`learnTechnique` 不再一次性灌全部 `grantSpells`；改为按 `s.techLayers[techId]` 达标才把对应招式
  > 纳入 `knownSkills`（升层时 `addKnownSkill`）。`grantSpells` 拆成 `layerUnlocks: { 3:[...], 5:[...] }`。
  > **设计可动点**：各层所需"修为/月数"是平衡数值，可调；**层→能力的考据映射不可乱编**（拿不准的层级能力标记问用户）。

### 5.3 大境界"初入↔巅峰"= 由主修功法层数**派生**
- 大境界（筑基/结丹/元婴…）内部分**初入 → 中坚 → 巅峰**三档（标签），**不再新增 realms 离散档**，
  而是**派生**自"主修功法在本境界区间内的升层进度"：刚突破=初入（功法层=本境界下限）；
  把主修功法肝到本境界的层数上限=巅峰。
- 既给玩家"元婴初入打不过元婴巅峰"的**实义**（功法层经下方乘区吃进战力），又是一根**可见的肝条**
  （天命栏/道途年表显示"元婴·初入 → 巅峰：青元剑诀 6/8 层"）。
- **派生而非硬编码**：`State.realmStage(s)` 读主修 `techLayers` 算出初入/中坚/巅峰，不污染 `DATA.realms`。

### 5.4 接战力（扩 spellPower，不破现有公式）
```
招式有效输出 = 基础值
             × sourceMul(来源)        // 武学 0.8，法术 1.0（不变）
             × gradeMul(主修功法品阶)  // 不变
             × realmScale(境界)        // 不变
             × layerMul(功法层进度)     // 新增：该功法层数轴的成长（初入→巅峰的连续档）
```
- `layerMul` 平缓单调（如 1.0→1.5 跨满层），保证"同境界同品阶，巅峰 > 初入"，但不喧宾夺主盖过品阶/境界。
- 武学不吃 `layerMul`（武学无功法层）。

### 5.5 状态与迁移
- 新字段 `s.techLayers = { [techId]: 层数 }`，**惰性初始化**（`s.techLayers = s.techLayers || {}`，
  已习得功法兜底为入门层）——沿用 swordIntent/firedFortunes 同款惰性模式，**免动 `_migrate` schema**。
- 老存档：已学功法默认给"可施展现有 spells 对应的最低达标层"，保证不退化（已装备招式不丢）。

### 5.6 验收
- 青元剑诀升到 3/5 层时，剑芒/剑盾**才**进技能池（之前学会但用不出）——肝有兑现。
- 同境界同品阶下，巅峰配置胜率 > 初入配置（`tier.bal.js` 增校验）；但梯度温和，不盖过品阶/境界差。
- 天命栏/年表能看到"境界·初入↔巅峰 + 主修功法层进度"；突破异象演出（接 cutscene-design.md）拍升层/质变。

## 七、剑影分光术 专项设计（2026-06-14 用户点名调研）

> 用户原话："青元剑诀还有剑影分光术，这个也是韩立比较重要的战斗技能……剑影分光术
> 这时候用处就比较大了（指夺得绿煌剑之后）。可以设计一下功能。剑影分光术不能设计成太后面的，
> 这个你调研下大概的剧情位置。"

### 7.1 剧情位置调研结论（**剑影分光术不晚**）
- **【动漫硬考据·已锁】** 剑影分光术 = **青元剑诀第 7 层解锁能力**，与 3 层剑芒 / 5 层剑盾 /
  10 层大庚剑阵同属青元剑诀逐层解锁表（combat-arsenal §1.1 黄枫谷行 + 本档 §5.2 已锚）。
- **青元剑诀的获取**：黄枫谷篇·筑基后，李化元赠**九层版**（含 3/5/7 层，即剑芒+剑盾+**剑影分光**），
  金色书页另藏完整十三层（10 层大庚剑阵在更后期）。
- **所以剑影分光术属于黄枫谷篇/筑基期内容**（周期五篇章 + 周期七 E 阶段把"层数轴"引擎落地后即可解锁），
  **不是后期能力**——满足用户"不能设计成太后面"。它在拿到绿煌剑（再别天南篇，见 combat-arsenal §3.9）
  之前就已可用，绿煌剑只是把它"用处放大"的法宝载体（§7.3）。

> 时间线一句话：**剑芒(3层·筑基初)→剑盾(5层)→剑影分光(7层·黄枫谷篇内可达)** … 大庚剑阵(10层·重返天南)。

### 7.2 战斗功能设计（**机制为设计可动点，须落地后蒙特卡洛校准**）
青元剑诀=精元剑修、御剑而战；"剑影分光"取意**一剑化多影、分光夺敌**。映射为青元剑诀的
**进阶御剑法术**（`source:"art"`、`elem:"mu"`、吃 grade/realm/layerMul 三系成长）：

- **形态 A·分影多段（单体爆发）**：一道剑光化数道剑影连斩同一目标，多段判定（每段独立吃克制/破甲）。
  打"厚甲单体"强（多段叠破甲），是剑盾(守)之外青元剑诀的**主输出法术**。
- **形态 B·分光扫敌（群体）**：剑影分散掠向多名敌人，每名轻伤——清群/逼退僚位、配合
  "撑回合/布阵"型战斗（魔道争锋皇宫战那种多目标场）。
- **二选一或随层进阶**（待定）：7 层先得**分影多段**；更高层（或绿煌剑加持）解锁/强化**分光扫敌**支。
- **分影数 = layerMul 与法宝档驱动**：层数越高、所御剑形法宝越强 → 分影越多/每影越狠
  （把 §5.4 的 `layerMul` 接到"分影数量"上，是层数轴最直观的可见成长）。
- **耗费与门槛**：中高灵力消耗 + cd（防无脑刷多段）；驱使门槛 minLayer=7（未达层用不出，接 §5.2 改法）。

### 7.3 与绿煌剑的协同（轴1 法术 × 轴5 法宝，乘法设计）
- 剑影分光术本身**用任意飞剑/剑形法器都能放**（黄枫谷入门剑器即可），但**威力随所御剑形法宝水涨船高**。
- 拿到**绿煌剑**（再别天南·第三主战法宝，combat-arsenal §3.9）后装入**主攻位**：剑影分光术以绿煌剑为
  引 → **分影数+1~2 / 每影威力 ×系数 / 专属演出**（绿剑分光）。这正是用户说的"绿煌剑到手后剑影分光
  用处就大了"的机制兑现——**法术挂法宝成长，不是新系统**（multiply-design）。
- 实现接口：`spellPower` 已有 `layerMul`（§5.4）；再读"主攻位法宝档/标签"给剑系法术一个
  `weaponSynergyMul`（剑形法宝越高阶越高）——敌我同规则（敌剑修也能吃自己的法宝协同）。

### 7.4 演出（接 cutscene/fx）
- 施放：群剑分影破空——复用/微调 fx 的 `swordWhoosh`/剑芒配方（fx-design §六剑阵范式）+
  audio 的 `swordWhoosh`/`leiCharge` 思路（audio-design §四）；分影=多道剑形引子错相位掠出。
- 绿煌剑加持版：剑影泛**碧光**（"绿煌"=绿色辉光），分影更密——一眼可见"换了把好剑"。

### 7.5 验收
- 青元剑诀 7 层解锁剑影分光（layerUnlocks{7:[...]}）；未达层学会也放不出。
- 多段/群扫两形态在战斗里手感分明（厚甲单体用分影多段、多敌用分光扫敌）。
- 装备绿煌剑后分影数/威力/演出可见增强（"法宝让老招式重新好用"的正反馈）。
- 平衡：剑影分光不盖过同境界品阶差；多段破甲不破"靠准备取胜"的红线（tier.bal/encounter.bal 校验）。
