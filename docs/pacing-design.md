# 节奏编排（锚-帆排期表 · 自由度的精确分配）

> 2026-06-11 用户裁决：篇章内容多——**必须跟剧情走的做好（强引导），
> 不需要跟剧情走的地方安排自由度**。本档案把 world-architecture §2 的锚-帆模型
> 落成每章的排期表，并立两条新公理。

---

## 一、强弱编排的判断标准

一段内容是"锚"（强引导）还是"帆"（自由），按三问判定：
1. **考据是否点名了顺序？**（动漫先后分明的→锚链固定顺序）
2. **错过是否伤害叙事？**（万小山之死不可错过→强制剧情；拜别可错过→地点锚，错过=平行人生）
3. **玩家此刻最想做的是不是它？**（解寒毒时玩家想要的就是宝玉→主线即欲望，做强不憋屈；
   等会期时玩家想自由→给帆）

## 二、锚的三种强度（实装语义）

| 强度 | 实装 | 例 |
|------|------|-----|
| **硬锚** | pendingEvent 剧情卡，不走完不能行动 | 墨府三幕、升仙大会、万小山之死 |
| **日历锚** | flags.xxx_due 记到期月；**天命栏倒计时**；到期+条件满足才触发 | 升仙大会"还有 N 月开"——等待期=帆 |
| **地点锚** | cond 含 location；去了才有，不去永远不发生 | 拜别回乡、探家 |

**日历锚两条铁律**：①倒计时永远可见（玩家不焦虑"我是不是错过了"）；
②等待期必须有事可做且有提示（"修炼/赶集度月皆可"——帆期不是空转）。

## 三、离门远行章排期表（已实装，体验基准）

```
arc_end(硬锚) → [帆：备货/回乡(地点锚·拜别)] → 嘉元城(硬锚×3幕，幕间客居=帆)
→ [帆：自由行动] → 太南小会(硬锚：万小山相迎) → [帆：赶集/修炼，买动触发青纹(硬锚)]
→ 日历锚立起：升仙大会 2 月后 → [帆：等待期——赶集/修炼/探山(同道首战，软触发)]
→ 升仙大会(硬锚链：落选→血案→复仇→入谷) → 黄枫谷篇启
```

节拍自查：硬锚从不连续超过 3 幕；两段硬锚之间必有帆；每段帆都有"可做之事"提示。

## 四、黄枫谷篇排期预案（驻地章——大帆时代）

```
入谷序列(硬锚：报到/夺丹恨点/领百药园差事) → 【百药园三年=本作最大的帆】
  帆内容：种植(偷种)/修炼(8~11层)/坊市/同门人情/杂学/小绿瓶——月月有产出
  帆内锚：日历锚=血色禁地开启(年级倒计时，常驻天命栏)；
          地点锚=坊市初访/辛如音结识/马师伯人情线；
          条件锚=长春功十一层(冲筑基的资格线)
→ 血色禁地(箱庭章硬锚) → 地火屋炼丹+筑基(硬锚) → 篇末
```

**驻地章公理**：帆期的"日子感"就是内容——绝不为赶主线压缩三年；
但天命栏永远亮着血色禁地的倒计时，玩家的每一月自由都在"为那一天攒"。

## 五、越阶生存公理（用户钦点，入 power-design 体系）

> 韩立的爽：**逃，是因为去了高阶的场合、面对高阶的敌人——收益巨大；
> 而回到同阶，他无敌。**

落地三则：
1. **主线大敌恒高阶**（+1~2 个段位）：金光上人（练气七 vs 你四五）、墨蛟（筑基级 vs 练气）、
   封岳（练气十三狙杀）——这些仗的"赢"包括智取、毒杀、并肩、**全身而退**；
   逃也是赢的一种（保命牌/遁术的价值所在）。
2. **同阶遭遇恒碾压**：复仇战（练气三层散修 vs 你六七层）就是设计基准——
   同阶战斗的看点是情感与演出，不是难度。蒙特卡洛锚点：同阶胜率 ≥90%。
3. **收益与阶差挂钩**：越阶场合的回报=大件级（升仙令/筑基丹/虚天殿宝物）；
   同阶场合的回报=资源级。玩家自然学会韩立的行为模式：往高处钻，靠准备活下来。

## 六、同道系统（伙伴作战）设计定稿

> 用户需求：伙伴作战（团战）。设计原则：复杂度不加，乘区爽度加。

- **架构**：复用侧位单位（side）引擎，`kind: "ally"`——零新系统。
  同道=有名有姓的人类同行者：自带 2~3 招（带权重+专属台词文案），
  每回合自动出手，低嘲讽率替你分担，**倒下是重伤退场不是死亡**。
- **与尸傀/灵宠的差异**：同道有人味（出招带台词、退场有遗言）、不可修缮不可豢养——
  **他们是剧情借给你的人，不是你的资产**。同屏一名（side 槽共享）。
- **首战=万小山**（已实装）：会期等待中搭伴探山，他的火球术、他肉痛甩出的符纸、
  他硬塞给你的六成分账——并肩过，他的死才有分量。这是同道系统的情感宣言：
  **团战功能首先是叙事装置，其次才是战力**。
- **路标**：血色禁地=南宫婉并肩（同阶压制版的她+墨蛟高阶战——越阶公理与同道系统
  在同一场仗里会师）；此后燕家堡、京城篇、魔道大战皆有同道位。
- **不做**：组队管理界面、同道养成、好感度——同道随剧情来去，如人生。
