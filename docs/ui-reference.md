# UI 参考笔记（觅长生截图拆解，用户提供 2026-06-11）

> 截图存于 assets/（c__Users_Administrator_...png 系列，11 张）。
> 本文是逐张提炼的"可取设计 → 我们的对应落点"。配合 art-direction.md 使用：
> 我们的视觉基调（夜读残卷）不变，取的是**信息结构与玩法形态**，不是配色。

## 一、突破演出模板（丹成/化婴 两张，最高价值）

觅长生结构：**全黑场 → 二字大题（丹成/化婴）→ 仙鹤纹饰 → 叙事文本（灵气涌入…结成七品混沌金丹）
→ 收益清单（气血+230、修炼速度+14%）→ 确定**。
化婴页还列出**新机制解锁**（"第二元神：元婴能单独修炼一门功法"）——收益清单含新动词。

→ 我们的突破成功页照此结构：黑场 + 二字题（筑基/结丹）+ 朱砂印 + 动漫向叙事
+ 收益逐条亮出（寿元+X / 辟谷 / 御器飞行 / 新功法位）+ 入道途年表。
品质分级照搬："七品/九品金丹"= 我们的"普通/完美筑基"（准备与过程表现决定品第）。

## 二、突破玩法 = 灵气系统复用（凝液成丹界面）

觅长生"凝液成丹"：剩余回合数 + 骰子 + 手牌（灵气牌）+ 快捷技能栏——
就是战斗系统换了个目标（把"敌人血条"换成"凝丹进度"）。

→ 我们突破"过程难"复用五行灵气珠战斗引擎：N 回合内用灵气珠驱动
「冲脉（推进度）/稳脉（防反噬）/压魔（清心魔干扰）」三类操作，
准备的丹药决定初始灵气与回合数。零新引擎，纯新皮+新数值。

## 三、天机榜：强者榜单实体化（名实一致的 UI 形态）

觅长生用一块石碑刻"天机榜"第一至第十（白鹿真人·金虹剑派长老…）——
世界强者有名有姓常驻可见，玩家攀榜即扬名。

→ 我们做「风云榜」：七玄门篇=门内高手榜+江湖人物榜（墨大夫/贾天龙/金光上人在列），
黄枫谷篇=越国修仙界榜。韩立名次变化 = 扬名时刻的可视化，与一致感/名声系统三位一体。

## 四、NPC 完整面板（名实一致的数据层）

觅长生 NPC 详情：立绘 + 装备3件 + 流派标注 + 功法图标网格 + 全属性
（年龄996/2137、天劫成功率12%、修为化神初期16%、性格孤僻、标签"杀技型正"）——
**NPC 与玩家完全同构**，强度可验证，这就是"剧情强=游戏强"的底层。

→ 我们的人物图鉴升级：具名 NPC 至少展示境界/功法/性格标签/关系，
背景修士（npcsim）已有真实境界数据，补展示层即可。

## 五、城市全景挂牌导航

天星城夜景全景：建筑上挂竖排木牌（星宫/问道楼/坊市/传送阵）即入口。

→ 我们的场景图钉已同源；黄枫谷篇门派全景图可升级为"挂牌式"子场所导航
（大殿/丹房/藏经阁/坊市），牌子是竖排的，比圆点图钉更有味道。

## 六、其他可取细节

- **顶部常驻倒计时**（"雷劫 剩余1000年"）：长期命运压力可见——我们寿元/限期任务
  已有，可强化为顶栏常驻的"天命"位。
- **NPC 来信送礼**（"兄弟服下后修为大增！"+领取按钮）：关系网的主动回馈——
  INTERACTIONS 已有"故人来访"，可加"传讯/寄物"形式，离线期间故人来信=打开游戏的惊喜。
- **战斗布局印证**：觅长生战斗=左右立绘对峙+顶部血条buff排+底部技能栏+右下五行灵气
  罗盘——与我们 build27 的战斗界面同构，方向确认正确；可取"buff图标排"补我们的状态可视化。
- **立绘位置印证**：他们的对话立绘也在对话框左上方探出——与用户钦定的站位一致。

## 七、不取

- 像素/手绘亮色系配色（我们坚持夜读残卷暗调）。
- 海量数字面板的密度（手机端容不下，信息分层简化）。
- 第367回合式的超长战斗节奏。
