## 一、情报面纱系统（build 可见的代价，不为难版）

## 二、操作浮动盘（公式给赔率，操作定胜负）

强度物理学补充条款：战力公式产出**赔率区间**，结局由战斗内操作浮动：
- 读招-应招博弈：神识料敌看破后的"正确应对"有显式奖励（伤害/减伤窗口）。
- 底牌时机窗口：蓄力/破绽回合打出特攻=倍增；时机感即操作感。
- 战后复盘一句话："本战关键手：第3回合的喂毒"——操作价值被看见、被归功。
- 操作好：上抬约半档（弱势盘可翻）；操作差：优势盘可翻车（fail-forward 兜底）。

## 三、暗流世界（我不动世界在动）

三层模拟 + 渗透链（拒绝系统通报，一切大事走有机渗透）：
- **凡尘层**（已有 npcsim）：背景修士命途。
- **风云层**（新）：具名强者间恩怨/争斗/陨落，低频按篇章节奏暗中推进。
- **涟漪层**（核心）：大事分解为时间差渗透链——
  `事件发生(玩家无感) → 一月后坊市流言(模糊) → 两月后风云录确证 → 三月后后果落地`
  后果落地形态：遗物入黑市 / 洞府无主 / 门派缉凶 / **传承现世=大件链入口** / 物价波动。
  玩家从"听到"到"摸到"，部分涟漪即机缘窗口（限时任务）。
- 红线沿用：主线人物因果不受随机层影响。

## 四、背景级强者三态模型（萨格拉斯命题）

> 用户：自小钟爱萨格拉斯式背景强者——几乎不出场，但世界的形状由其定义。
> 凡人对应：虚天殿主人、坠魔谷圣帝、各派化神老祖等（按动漫版考据选定名单）。

1. **传说态**（早期）：只存在于碑文/遗迹/老修士口中——"那位前辈当年一剑开了此山门"。
   其 build 自此刻起即真实配置存在（乘区×满配+独有神通），等待被逐层揭示。
2. **在场态**（中期）：远观/威压/庇护事件——大会上空一道遁光全场噤声；
   L3 神识探查被反震（"对方境界远超于你"）。不可战但真实在场=敬畏感主产地。
3. **可遭遇态**（篇章终局/隐藏条件）：真实开打，但跨大境界按强度物理学不可胜，
   故做成**生存挑战战**：目标=活过 N 回合/达成脱身条件（原著"元后抗化神三招"玩法化）。
   活着逃出=史诗胜利，年表浓墨："曾于化神老怪手下全身而退"。
   背景强者的承诺必须兑现，兑现形式忠于强度物理学。

衔接自由度：背景强者的"引力场"=自由玩法高级内容层——其需求扰动坊市价格、
其恩怨开放秘境窗口、其渡劫引发天地异象、其遗产构成大件链。不出场也在供给玩法。

## 五、事件总线（游戏行为 ↔ 剧情变动双向耦合）

- **行为→世界**：玩家行为打标签（突破/扬名/获宝/杀人/探秘），世界模拟订阅产出反应：
  筑基→门派待遇+对手警惕；持名宝被认出→觊觎事件入池；杀人未灭口→仇家线索累积。
- **世界→行为**：风云/涟漪事件产出"窗口任务"（陨落→无主药园限时采摘）。
- 红线：主线因果手写，总线只搅主线之外的水。
