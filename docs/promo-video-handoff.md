## §5 剪辑工序（剪映 / CapCut）

1. **建竖屏工程** 1080×1920、60fps；导入《不凡》音轨。
2. **自动踩点**：先对音乐打节拍点，把 §2 的段落分镜铺到时间轴。

4. **速度分层**：名场面演出用原速/慢放（让台词落地）；系统快剪用 1.25–1.5x（信息密度）。
5. **字幕**：竖屏必须有大字幕；名台词（"伪灵根""立碑的立"）字号大、停留够久。
6. **导出**：1080×1920，60fps，≥12Mbps。
- **剪辑红线**：①无缝那段绝不加转场（一镜到底，字幕点一句"注意，这里不读条"即可）；②前 3 秒上最强画面（金雷/CG），别用 logo 开场（杀完播率）；③金雷等 canvas 特效一律用录屏素材，不用截图。

## §9 逐镜脚本怎么写（执行 agent 照此产出，等同上一个 agent 会做的）

> 为什么文档不预先写死到秒：逐镜脚本和**录制 + 音频**耦合——秒数取决于你手里《不凡》音频的版本（片头曲短版 / 完整版时长不同）和你实际录出来的素材长度。所以**方法在这里，数字你边录边定**。按下面五步做，就能产出一张“逐镜表”＝逐镜脚本。

**第一步 · 给歌打时间戳（定锚点）**
- 把《不凡》音频拖进剪映 / Au，标出每句歌词的进入时间；**重点标死副歌「这一路破空」落在第几秒**——这是全片唯一主炸点（金雷）的锚。
- 同时标出：前奏结束、主歌进、预副歌进、副歌进、副歌后段、收尾这几个段界（对应 §2 的段落）。歌词 / 段落可查公开资料，但**精确到秒以你这版音频为准**（OP 短版与完整版时长不同）。

**第二步 · 录素材并量长度（备料）**
- 按 §3 的入口把每条素材录下来，逐条记录：**可用时长 + 最猛那一帧的位置**（金雷炸开帧、CG 定格帧、击杀帧、无缝触敌进战那一刻）。
- 金雷·劈多录几遍，挑炸开最干净的一条留作主炸点用。
