## 第一部分 · 调研报告：凡人的战斗到底长什么样

### 1. 战例实录（多源核定）

**练气期 · 封岳之战（范式标本）**
封岳装备组：黄罗伞（顶级防御法器——挡掉韩立全部法器攻击）+金色小刀符宝（一次性
爆发）+踏云靴（身法游击）。韩立：法器被伞免疫 → 土墙术周旋（法术=防御位）→
联合李雷云雷法牵制 → **天雷子**（一次性雷爆法宝）破伞秒杀 → 捡尸（踏云靴=跑路神装）。
→ **修士战力=装备组合；防御法器=必须用"硬解"打穿的墙；战利品=成长。**

**筑基期 · 多线作战**
金鼓原以傀儡群"吊打"魔修；强神识（大衍诀）可**同时操控多件法器**、
"使用同阶修士用不了的整套法器"；叶师叔之乱=颠倒五行阵（场域）+傀儡对傀儡。
→ **神识=并用上限；阵法=场域改写；傀儡=不耗自身法力的续航单位。**

**结丹期 · 法宝与灵虫**
元神成金丹方能炼化法宝（精血祭炼、收入体内、日夜淬炼成长）；修为不够则法宝
发挥不出（南宫婉压制至炼气持朱雀环被墨蛟压制）。青竹蜂云剑：结丹得天雷竹一小截
→ 小绿瓶育成万年金雷竹×6 → 批量炼 72 口木属飞剑（自带辟邪神雷克邪魔）。
→ **本命法宝=逐步淬炼的成长大件，威力=本身威能×注入法力×神念操纵。**

**元婴期 · 神通（大庚剑阵全解）**
36 柄半套阵越阶斩元婴中期巅峰四长老；72 柄完整阵令化神不能全身而退。
短板（游戏性金矿）：①按周天星斗布阵**前摇长、遇强攻被打断**（坠魔谷古魔不给时间，
韩立被迫弃阵换血魔剑）②物理剑丝**对无形元神无效**（鬼罗幡阴鬼需啼魂兽吞噬配合）
③**消耗巨大**：启动需大量灵石+法力，持续需聚灵阵，韩立曾"法力消耗过度，
连使用剑阵的念头都不敢起"。

**噬金虫 · 多形态外物的范本（用户点名，已查实原文）**
- **虫云**：群聚盘旋，侦察/缠斗/分食敌方手段（曾分食魔火）
- **兵刃形**："指挥三色噬金虫凝结成刀剑之类的简单东西"；自化**箭矢形**激射
- **虫甲术**（御灵宗秘术解锁）：虫群高速盘旋凝成全身战甲——防御在普通护甲之上，
  可随时溃散还原收回；虚天殿曾用它**隔绝自身灵力骗过禁制**（功能性用法）
- 克制链：血玉蜘蛛克噬金虫、玉木之物可困——**外物彼此也有克制**
→ **一个外物=一组形态；秘术法诀=形态解锁钥匙；熟练度=形态强度。**

### 2. 法力模型与恢复链（核定）

- 御风诀"不停消耗微量法力"（持续耗）；金光砖"笨重、消耗法力很大、血色禁地耗尽
  威能报废"；大庚剑阵巨耗——**一切手段共用一池法力**。
- **恢复链**（按品级）：
  | 手段 | 效果 | 游戏化 |
  |------|------|--------|
  | 万年灵乳 | 一小口**瞬间恢复全部法力**（万灵石难求一滴） | 顶级续航底牌（韩立"辅助神通"级——数量极稀的整管回蓝） |
  | 回元类丹药 | 战斗内回一截法力 | 常规续航底牌（占瞬发位） |
  | 灵眼之泉浸泡 | 短时恢复部分 | 场地恢复（特殊地点战斗的环境要素） |
  | 特殊体质同道 | 梅凝通玉凤髓之体助恢复 | 同道特性（续航型同道） |
  | 聚灵阵 | 支撑神通持续 | 阵法=续航场域 |
- **"耗尽靠武学"修正**：常态战斗法力见底=**该吃药、该逃、该认**——不是站桩打拳。
  武学的正典定位是**特殊场合的杀手锏**：阴冥之地全员法力被封时韩立以武术杀
  魔道第一传人温天仁；贴身偷袭；封灵环境。→ 游戏化：武学=封灵/贴身条件下的
  特解，平时是配菜不是保底循环。

### 3. 凡人战斗方式全图鉴（历次调研汇总）

| 类别 | 手段 | 战斗角色 |
|------|------|----------|
| 御物 | 法器（练气筑基）→法宝（结丹+）→古宝（威力大神通单一） | **输出主役**：常态御使（低耗）/全力催动（高耗爆发） |
| 防御 | 护身法器（黄罗伞）/护体法术/护甲（虫甲） | 减伤墙——对面必须破甲或硬解 |
| 瞬发 | 符箓（小法术卡）/符宝（一次性法宝，用两三次废且递减） | 不占主行动的爆发与功能 |
| 硬解 | 天雷子（雷爆）/金光砖（无视护身法器） | 打穿"墙"的钥匙，贵且有限 |
| 法术 | 五行小法术（土墙/火弹）/中级法术 | 控场、防御、补刀——非输出主役 |
| 多线 | 傀儡（有损耗，不耗主人法力）/灵虫灵宠（多形态）/第二元婴化身 | 续航与数量优势 |
| 场域 | 阵法（颠倒五行阵/聚灵阵/迷踪阵） | 改写战场规则（防御/续航/困敌） |
| 神通 | 剑阵/乾蓝冰焰/辟邪神雷（功法高层或奇物解锁） | 前摇长/条件苛/巨耗的胜负手 |
| 身法 | 罗烟步/御风诀/踏云靴/风雷翅 | 拉距、闪避、遁走 |
| 阴损 | 毒/暗器/透明丝线/偷袭 | 韩立特色——条件触发的高收益 |
| 神识 | 看穿/操控数量/神识攻击（大衍诀） | 并用上限+信息战 |
| 肉身 | 淬骨诀/明王诀（龙鳞果——万斤巨力） | 后期法体双修线 |

### 4. 敌人对称性（用户裁决）

修士敌人=与玩家同构的 build：装备组（攻击/防御/身法法器）+法力池+底牌（符宝）+
可能的傀儡灵宠+功法神通。封岳就是范本（伞+刀+靴）。
- 敌 build 可被情报面纱拆解（L2 买底细=知其装备组与解法）
- 敌法力可被消耗（**耗蓝是合法胜利路径**——毒拖回合、逼他全力催动、打掉他的傀儡）
- 敌崩溃点：法力见底→拼命（孤注一掷的全力催动）/遁走（追不追？）/求饶（杀不杀？）

## 第二部分 · 构想：凡人范式战斗系统 v2

### 核心循环（一句话）

**战前配组（装备/底牌/同道/傀儡）→ 战中资源战（法力对耗+读招拆解）→
战后成长（捡尸/淬炼/修复）。**

### A. 资源层

- **法力池**：一场战斗的总蓝量（不逐回合刷新）。功法层数定池深，境界质变跳档。
- 战内恢复：回元丹（瞬发底牌）/万年灵乳（稀世整管回蓝）/灵泉场地/凝息（弃攻回气，
  会被读招惩罚）。
- 耗尽状态：法器法术全哑火——选择只剩：吃药、遁走、（若有）傀儡灵宠继续打、认输。
  武学只在**封灵环境/贴身距离**条件下可用（特解，非保底）。

### B. 外物层（万物皆兵，多形态）

- 法器：**双模式**——御使（低耗常态攻击）/全力催动（高耗+冷却爆发）
- 法宝（结丹+）：可淬炼成长（蜂云剑 36→72→掺庚精）；威力=威能×注入法力
- **灵虫/灵宠多形态**（噬金虫范本）：虫云（缠斗）/兵刃（攻形态）/虫甲（防形态）——
  形态由秘术法诀解锁、熟练度升级；战斗中切形态=主行动
- **傀儡=有血条的消耗品**（用户裁决）：自带驱动不耗主人法力；血归零=破损
  （战后可修，材料+时间）；彻底击碎（过量伤害/特定敌技）=永失。批量携带，
  神识决定同场上限
- 符宝：威能次数制+递减（金光砖范本）；古宝：神通单一威力极大

### C. 战斗形式三案（用户点名重思考——含走格战棋）

凡人战斗的空间要素是真实存在的：法器互轰的**距离感**、踏云靴的**游击**、
阵法的**场域**、傀儡的**挡线**、剑阵布设的**阵地**、贴身偷袭的**近界**。

| 方案 | 形态 | 优势 | 劣势 | 工程 |
|------|------|------|------|------|
| 甲 · 改良站桩回合 | 现架构+法力池，空间抽象成"距离档"（贴身/近/远三档，移动占行动） | 工程最小，节奏最快（嗑瓜子友好） | 走位/包围/阵地感弱，多单位拥挤 | 2~3 版本 |
| 乙 · **对阵轴**（一维线式战棋） | 敌我单位排在一条横轴上（如 9~13 格）：移动±格、法器有射程、近战须贴格、阵法铺区间、剑阵占格蓄势、傀儡挡格、包围=两头夹 | **凡人味最足**（互轰对峙/拉距遁走/挡线/阵地全保留）；手机竖屏天然（横轴+下方手牌）；多单位（傀儡灵宠同道）有真实站位意义；单场时长可控 | 比甲工程大；纵向包抄表达不了 | 3~4 版本 |
| 丙 · 2D 走格战棋（大侠立志传式） | 完整棋盘+地形+寻路 | 空间表达最全 | 工程最大；竖屏小格操作差；单场战斗拉长，与月轮转嗑瓜子节奏冲突；AI 成本高 | 6+ 版本 |

**我的推荐：乙案「对阵轴」**——它是凡人范式的最小完备表达：
- 互轰对峙感：你和敌人隔着 4 格对射法器，他突进你拉距——"距离"成为每回合的真实决策
- 傀儡挡格=肉盾有了空间意义；同道站位=保护输出位；多敌=两头夹击的真实压力
- 阵法=往轴上铺区间（聚灵格/困敌格/迷踪格）——"布阵"看得见
- 剑阵类神通=原地蓄 N 回合（敌人会冲过来打断你——坠魔谷名场面的系统化）
- 贴身（相邻格）才可武学/偷袭——武学的"条件特解"定位有了空间语义
- 竖屏 UI：上方横轴战场，下方手牌行动——拇指操作完美

### D. 成长层（外物获得与淬炼=主轴）

换装（捡尸/坊市/战利）→ 本命法宝逐步淬炼（大件链）→ 灵宠形态树（秘术解锁）→
傀儡库（造/修/换代）→ 功法层数（池深+神通）→ 古宝收集（神通图鉴）。

### E. 保留资产

五行克制（行属与资源无关）、情报面纱、底牌经济、同道叙事、装备三槽与特性、
AI 读招意图、心魔具象、蒙特卡洛平衡管线（新轴：法力经济+距离经济）——全部平移进新形式。

### F. 分期路线（拍板后执行）

1. **P0 纸面**：对阵轴战斗规则书（格数/射程表/行动经济/AI 行为树）+ 纸面模拟跑平衡
2. **P1 引擎**：对阵轴战斗引擎（独立模块 combat2.js，无头可测）+ 蒙特卡洛重建
3. **P2 内容迁移**：现有敌人/技能/装备译入新规则（法力定价表）；UI 重做（轴+手牌）
4. **P3 切换**：全量替换（用户已拍板一步到位）+ 旧档兼容 + 全篇章回归
5. **P4 增量**：傀儡库/灵宠形态/阵法铺设/神通蓄势逐版本上线
