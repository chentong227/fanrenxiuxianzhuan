# 2.5D 纵深 · 前景框预设库（接入指南）

> 配套 `docs/staging-experience-design.md` §3 B1（分层视差）/ §10 R1。
> 目标：把"全屏滤镜 overlay"升级成有纵深的分层场景——**一行配置开 2.5D，不配＝单层背景零回归**。

## 一、怎么给一个地点加 2.5D（一行）

在 `js/world.js` 的地点对象里加 `env.depth`：

```js
// 例：演武厅 = 殿堂框、远雾偏淡
env: { depth: { fg: "hall", far: 0.32 } },
```

- `fg`  前景框预设名（见下表，必须在 `Env.FG_PRESETS` 内；不在表内＝不画框，仅保留远景气层）。
- `far` 远景雾强度 `0..1`（缺省 `0.5`），驱动远景气层（空气透视）的浓淡。

地点本就有 `env`（如 `phase/weather/amb/outdoor`）就并进去即可，例：

```js
env: { phase: "night", amb: "night", depth: { fg: "interior", far: 0.3 } },
```

不加 `env.depth` 的地点：`data-depth/data-fg` 留空 → CSS 不点亮远景/前景层 → 与改造前**逐像素一致**。

## 三、设计原则（改预设/加新预设时守住）

1. **前景框层不被染**：`.scene-fg` 压在染色/天气之上（z:3 > tint/weather z:2），时辰/天气只染中远景，近景框保持本色。
2. **差速漂移＝纵深**：远景气层慢漂、前景框层快漂（同向同时长 46s），静帧看不出、实机是缓慢推镜；勿做大幅位移（守 IP "只微动不糊脸"）。
3. **下淡衰减**：染色 `mask-image` 只盖中上部，保护下方近景（别糊脸、别压住玩家亲手出手那一层）。
4. **far 按"开阔度"取**：越室内/越近景遮挡 → far 越低（0.3）；越户外/越远天 → far 越高（0.6+）。
5. **粒子近大远小**：纵深地点的雪/雨在前景层叠"大而快"的近景粒子，远景仍走 `.scene-weather` 小粒子。
6. **无障碍**：`prefers-reduced-motion` 下漂移/落粒自动停，框/雾仍渲染（不靠动效传达信息）。

## 四、加一个新预设（如 `desert` / `snowfield`）

1. `css/style.css` 前景框区块加 `.scene-stage[data-fg="desert"] .scene-fg { background: …; filter: blur(.5px); }`（纯 CSS 渐变，参考既有预设）。
2. `js/env.js` 把 `"desert"` 加进 `FG_PRESETS` + `FG_PRESET_CN`。
3. `test/env.test.js` §8 的 `want` 清单同步（保证清单完整断言）。
4. 给一个代表地点配 `env.depth:{fg:"desert", far:…}`，实机看效果调参。
