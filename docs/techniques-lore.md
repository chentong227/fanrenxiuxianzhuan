## 二、各功法特性（机制映射，供后续篇章实现）

### 长春功（本篇唯一）
- 木属性练气功法，资质要求低（适配韩立四伪灵根）——契合"务实修炼抉择"。
- 五层：过目不忘（神识/悟性相关）。
- 战斗映射：吐纳回血、护体、凝神——已实现。

### 青元剑诀（黄枫谷篇·锁定）
- 精元剑修：以"反复散功重修、提纯灵力"为法门，故同阶可越级斗法（同境界中战力拔群）。
- 机制设想：解锁御剑类强力攻击；提升同境界战斗强度；修炼方式特殊（散功重修 = 一种风险/收益取舍）。
- 动漫获取：与董萱儿赴燕家堡前师父许之，结合血色禁地杀封岳所得书页而成。
- **本篇不可得。** 仅作埋线。

### 大衍诀（黄枫谷篇·锁定）
- 神识修炼：大幅强化神识，可分裂元神、操控傀儡。
- 机制设想：大幅提升「神识」属性 → 战斗看穿/命中/抗神魂全面增强；大世界探查、御使傀儡（曲魂等）。
- 对应玩家之前的设想："大衍诀让神识在大世界发挥作用"。
- 动漫获取：千竹教卧底潜伏黄枫谷，雷万鹤救韩立并击杀卧底后，韩立捡得。
- **本篇不可得。** 仅作远期埋线。

## 三、系统设计原则

1. **篇章锁定**：每门功法标 `arc`（所属篇章）与 `acquireCond`（获取条件）。未到篇章，绝不出现、不可学。
2. **务实抉择**（凡人核心）：功法各有取舍，非"学了就无敌"。强功法必有代价或门槛（资质、修为、修炼方式）。
3. **主修功法影响修炼**：主修功法决定修为增长方式、战斗招式池。
4. 七玄门篇：主修恒为《长春功》，不开放更换。其余功法在各自篇章按原著方式获取。
