## §0 需求回放（John 原话拆解）

1. **用真地图，按块解锁点亮**：以参考图为底，未解锁地块=暗/雾，踏到或剧情点亮则该块「亮起来」。
2. **字体要好看**：地名用书法/题字风格，不用系统默认黑体。
3. **底图不干净 → AI 生图洗图**：去水印（「边城玖女制图/出品」）、杂签，统一色调、补分层。生图**必须按原图参考**（不凭空造）。
4. **每级必须衔接**：世界→大陆→国/州→宗门城→据点，逐级钻取、点块进下级、面包屑回上级，位置连续不跳。
5. **前两级锁真实地理，第三级（国内）起可自创**：L1 世界图 + L2 天南图严格按参考图地理排布；L3（越国镜州…）及更下层才原创填充。
6. **落 agent 引导**：把这套规范写进 AGENTS.md / docs，保证换窗口一眼明白要做什么。
7. **类比**：整张人界图≈世界地图，天南≈中国的位置——据此估算各陆/国相对方位。
8. **（新增）朝向考据**：剧中黄枫谷似「往南逃、南遇慕兰」，但参考世界图里慕兰偏北——疑为观赏效果颠倒。**列稿前先调研是否颠倒**；若确为颠倒，按图施工、涉及方位的剧情也跟着图统一颠倒。→ 见 §7。

## §2 数据模型（在现有结构上扩展，不推倒）

### 2.1 现有（保留）
```
WORLD.atlas = { root, levels: { renjie:{kind:'world',nodes:[{id,name,to?,pos,reach?,silhouette?,desc}]},
                                 tiannan:{kind:'region',parent,nodes:[…]} } }
WORLD.continent = { name:'越国', atlasId:'yueguo', parent:'tiannan', map:'tiannan_map',
                    nodes:[{id,name,pos:{x,y},locs:[…],gate?,silhouette?,desc,months,danger}], routes:[…] }

渲染：UI.openAtlas(levelId) / UI.openContinent() / UI._atlasCrumbs(levelId)（面包屑已实现）
```

### 2.2 新增字段（区块 + 解锁 + 势力）

每个 atlas 节点（L1/L2/L3 块）扩展：
```js
{
  id, name, to?,                 // to=可下钻的子层 id（衔接，§9）
  poly: "x1,y1 x2,y2 …",         // 区块多边形（SVG points，% 坐标）——区域块状的核心
  label: { x, y },               // 题字锚点（块中心或留白处）
  unlock: (s) => bool,           // 解锁判定（默认 false=暗/雾；点亮见 §3）
  faction?: "qipai|modao|…",     // 势力归属标签（叠加层，§8，非第6级）
  desc, silhouette?              // 描述 / 远眺剪影（保留）
}
```
- **L4/L5 不加 poly**（保持点状/单屏）。
- `routes` 保留（L3/L4 据点间墨痕路线）。
- **解锁态**复用现成 `s.visitedNodes` / `s.flags`（见 §3），不新开存档字段（存档兼容零成本）。

### 2.3 层级 id 规划（衔接用，§9）
```
renjie(L1) ─to→ tiannan(L2) ─to→ yueguo(L3) ─to→ {jingzhou,jianzhou,lanzhou}(L3州)
   州(L3) ─to→ {qixuanmen@彩霞山, huangfeng, jiayuan}(L4城/宗) ─to→ {jiayuan_city_l1,…}(L5据点)
```

## §3 区块化与解锁点亮

### 3.1 区域块状（替换点状 pins）
- L1/L2/L3 每块 = 一个 `<polygon class="region-block">`（SVG，points 来自 `poly`），叠在 AI 洗净底图上。
- 整块可点：`onclick=UI._atlasPick(level,id)`（高亮+详情），块内「进入」按钮或双击下钻（§9）。
- 块内题字地名（§4）锚在 `label`。
- **仅 L4/L5 维持点状/单屏**（John 明示「除了第四第五级这种」）。

### 3.2 解锁点亮三态
| 态 | 触发 | 表现 |
|----|------|------|
| **暗/雾**（locked） | `unlock(s)===false` | 区块灰暗 + 雾罩 + 地名作「？？」或仅剪影；不可下钻，点击只给「道途未通/远观之地」 |
| **亮起**（unlocked） | 首次 `unlock(s)===true` | 该块去雾、上色「亮起来」（CSS transition 渐亮），地名题字浮现 |
| **当前**（here） | 玩家所在块 | 描金边/呼吸光晕 + 「·在此」 |

- `unlock` 判定来源（复用现成，不臆造）：`State.count('shengxian_ling')`、`s.flags.arc1_complete`、`s.flags.departure_complete`、`s.visitedNodes` 等。
- L1/L2 早期：仅「天南」亮，余皆雾（剪影+名）——符合 §一铁律「全图早见、远方=惦记」。
- 剧情推进点亮：剧情 flag 一翻→对应块 `unlock` 转真→自动亮（复用 `ExploreMap.flavor` 式 flag→投影）。

### 3.3 «??» 迷雾占位（承 §四·五·补 C）
未到剧情的块：位置在、轮廓在，名字/内容遮罩为「？？」，踏到/剧情揭示。先铺全骨架，内容随篇填。

## §4 字体方案（题字/书法，弃黑体）

- **地名/标题**：题字风格。优先**自带 webfont**（`@font-face` 引本地字体文件，离线可用、无外链依赖，契合「无构建无依赖」）。候选：开源楷体/行楷（如「ZCOOL 站酷系」可商用书法体、思源宋黑的宋体题字变体）——**择可商用授权者**，落 `assets/fonts/`。
- 退化链：`font-family: "题字体", "KaiTi", "STKaiti", serif;`（无字体文件时退化到系统楷体，仍非黑体）。
- 层级排印：L1 世界图地名最大、印章感；逐级递减；据点名小字。复用现有 `.atlas-title` / `.pin-label`，换字体族 + 描边/阴影使其「好看」。
- ⚠️ 字体文件须确认可商用授权再入库；授权不明的只用系统楷体退化，不冒险。

## §7 朝向 / 颠倒考据结论（§0.8 — 列稿前已调研，≥3 源）

### 7.1 调研结论（动漫为锚 + 原著/解说交叉）
1. **黄枫谷「往南逃」= canon 属实**（≥3 源：腾讯新闻 2025 / 忘语原著第三卷第346章「令狐老祖」/ 网易详解 2025）：
   魔道入侵→灵兽山叛归御灵宗→越国六派大败→**携门人撤离越国、远遁九国盟势力范围，黄枫谷最终在北凉国扎根**。九国盟在天南**南方**，黄枫谷在越国**北部**建州——故确是**自北向南撤**。
2. **「南遇慕兰」= canon 一致**（≥4 源：网易/潇湘书院/红袖/边城玖女图）：慕兰（天澜）草原**紧挨天南、位于天南与大晋之间**；慕兰法士入侵天南九国，南迁六派在九国盟一带与慕兰交战又折损大批。**边城玖女《天南地图》把慕兰/天澜草原画在最南（底部，九国盟之下）**。
3. **天南内部 canon 罗盘**（网易×2 + 边城玖女图）：**天道盟=北、魔道(天罗国)=东、正道盟(风都国)=西、九国盟=南**。
4. **彩色世界图确为「再定向」**：该图把**大晋摆在北、天南缩在东南角**，于是夹在两者之间的慕兰/天澜草原被画到了天南的**东北方（偏北）**——与 canon「慕兰在天南之南」相反。**John 的怀疑成立**：彩色世界图为「世界观赏」做了约 180° 的天南定向翻转。

### 7.2 关键洞察
- 两图的**拓扑邻接完全一致**：`越国(中) → 国盟 → 慕兰草原 → 大晋` 这条链在两图里顺序相同，**只是绝对罗盘标注不同**（canon 称该方向为「南」，彩色图把它转成「东北」）。
- **游戏里几乎还没有写过相关方位文字**（慕兰/魔道篇未实装，受「魔道篇待 John 修订」红线约束）——**现在定朝向约定几乎零成本、零重写**。

### 7.3 决策（写入稿，待 John 拍板）
推荐 **方案①（canon 主朝向，省重写）**：
- **以 canon 天南罗盘为游戏权威方位**（海北/慕兰南/魔道东/正道西/九国盟南）；L2 天南图用边城玖女 orientation（§6.2）。
- L1 世界图按彩色图的**观赏布局**呈现（大晋居北、天南东南），但**视其为「写意全景」，不据它推剧情方位**；以 L2 天南图为天南内部方位的唯一权威。
- 因下钻邻接链一致，玩家体验连续；且**未来剧情「黄枫谷南逃/南遇慕兰」原话照写、零改、与记忆/动漫一致**。

备选 **方案②（彩色图主朝向 + 翻转剧情，John 倾向）**：
- 一切以彩色世界图为准；L2 天南图**重定向**与之吻合；涉及方位的剧情文字（「南逃」等）**跟着图统一翻转**。
- 代价：需重定向 L2 天南图素材 + 今后写慕兰/魔道篇时把方位词反过来；好处：L1/L2 视觉与彩色图完全一致。
