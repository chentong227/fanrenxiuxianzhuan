## 二、剧情节点评价

### 2.1 入谷（hf_arrive · frame_211）

- 吴师叔接引——"升仙令入谷？少见"的台词体现了升仙令的稀缺性
- "丹领了就收进贴身袋，谷里不是人人都古道热肠"——伏笔夺丹
- **评价**：入谷仪式感好，吴师叔人设温暖（"萍水相逢，肯说这句话的，是个好人"）

### 2.2 夺丹（hf_duodan · frame_212~213）

- **全篇情感第一爆点**：陆云风当众抢丹→叶师叔"调解"实为强取→韩立被迫"成交"
- 叶师叔的灵压压制吴师叔（"筑基中期的灵压无声铺开"）——修仙界以实力说话的残酷
- "你把它的模样刻进了心里"——韩立的隐忍刻画精准
- **评价**：夺丹是黄枫谷篇的核心矛盾建立，叶师叔+陆云风的反派塑造到位

### 2.3 掌门殿（hf_zhangmen · frame_213）

- 讨公道无果——"实力为上。多谢掌门赐教"的冷台词
- "七玄门教过我一回，黄枫谷又教我一回——这一课，我记到筑基那天"——因果伏笔
- **评价**：掌门的"和稀泥"态度体现了宗门政治的复杂性

### 2.4 百药园（hf_yaoyuan · frame_214~215）

- 马师伯"刀子嘴豆腐心"人设——"夜里霜重，参苗记得盖草帘"
- 《百草谱》承接墨大夫线——"墨大夫的《百草谱》第三卷讲过"
- "药园、丹房、小绿瓶。三年——三年之内，我要让『筑基丹』四个字，重新回到我自己手里"——目标明确
- **评价**：百药园是"大帆时代"的起点，种药+修炼+攒家底的自由活动框架

### 2.5 陈巧倩救援（chen_rescue · frame_219~221）

- 陆云风欲杀陈巧倩灭口——"为攀高枝杀道侣灭口……这种东西也配修仙"
- 韩立心理挣扎："出手，是杀人灭口的死局开端；不出手，眼睁睁看人死"——呼应万小山之死
- **陆云风战斗**：HP=190，同阶（练气十一层）。金光砖85伤害+飞针18伤害，4回合击杀
- **评价**：陈巧倩线开启，陆云风之死是夺丹恩怨的阶段性了结

## 三、BUG 与体验问题（v218 全部修复 ✅）

### 3.1 ✅ 已修复：黄枫谷触发野狼帮喽啰遭遇战

**现象**：在黄枫谷修炼/度月时，随机遭遇战刷出"野狼帮喽啰"（HP=95）。黄枫谷是仙门洞天，不应有野狼帮敌人。

**根因**：`quests.js` 中 `wolf_raid` 任务到期未达练气六层时，`onFail` 无视地点强制触发野狼帮战斗。玩家入黄枫谷后任务仍可能未完成。

**修复**：`quests.js` `wolf_raid.onFail` 加 `departure_complete` flag 检查——已入仙门则不触发野狼帮夜袭，改为一句前尘总结。

### 3.2 ✅ 已修复：战斗 overlay 残留

**现象**：战斗胜利后 combat overlay 不清除，需刷新页面才能恢复。

**根因**：`UI.closeCombat()` 只隐藏 `combat-overlay`，未隐藏 `combat-outro`。当结算确认按钮未点击时 outro 残留。

**修复**：`ui.js` `closeCombat()` 增加 `const outro = this.el("combat-outro"); if (outro) outro.hidden = true;`。

### 3.3 ✅ 已修复：万小山死后立绘仍显示

**现象**：万小山被杀后，其立绘/NPC 条目仍正常显示。

**根因**：`world.js` 中万小山 cond 只检查 `wan_met`，不检查 `wan_avenged`。

**修复**：`world.js` 万小山 cond 改为 `(s) => s.flags.wan_met && !s.flags.wan_avenged`。

### 3.4 ✅ 已修复：灵力消耗过低

**现象**：200灵力几乎够用十几回合，主力输出几乎不耗灵力。

**修复**：`combat.js` 提高三法术灵力消耗：
- 暗器飞针 `feizhen`: mp 0→1（暗器需灵力催动）
- 金光砖 `jinguang_zhuan`: mp 2→3（符宝催动更费灵力）
- 火弹术 `huodan`: mp 10→12（法术消耗上调）
- 眨眼剑法/眨眼连击/连环眨眼保持 0 耗（武学特解定位不变）

### 3.5 ✅ 已修复：白玉蜘蛛图标太逼真

**现象**：用户朋友受不了蜘蛛图标。

**修复**：用 `scripts/gen-placeholder.js` 生成纯色占位图替换 4 个蜘蛛 PNG（baiyu_zhizhu/xueyu_zhizhu 的 portraits + battlers）。

### 3.6 P2 体验：修炼到练气十一层耗时过长（未修复·设计层面）

**现象**：从练气六层到练气十一层需要约 30 年游戏时间，大量时间花在闭关→心境恢复→闭关循环上。

**建议**：①提高低境界修炼效率 ②减少心境恢复时间 ③增加百药园差事/坊市等修为来源
