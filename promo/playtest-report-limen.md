## 一、篇章概览

离门远行篇是七玄门篇到黄枫谷篇之间的过渡章，覆盖韩立离开师门、独行江湖、初入修仙者世界的关键阶段。剧情链：

```
嘉元城·墨府（mo_arrive → mo_crisis → mo_resolve）
  → 太南谷·小会（wan_meet → qingwen_plot）
  → 搭伴探山（wan_hunt · 灵狼战）
  → 升仙大会（xianhui_open · 测灵台）
  → 万小山之死（wan_death · 复仇战）
  → 升仙令入谷（xianhui_end → 黄枫谷篇·启）
```

## 二、剧情节点逐一评价

### 2.1 墨府线（mo_arrive → mo_crisis → mo_resolve）

- **mo_arrive**（frame_176~178）：嘉元城抵达，墨彩环出场。立绘精美，"墨府"场景氛围好。韩立以小医生身份介入墨府，设定自然。
- **mo_crisis**（frame_183）：夜贼事件，"墨府·夜"场景切换到位。紧张感营造不错，但夜贼的描写略短。
- **mo_resolve**（frame_184~185）：暖阳宝玉解毒 + 曲魂抉择。**这是本篇情感最浓的段落**——墨彩环的嫁妆用来救她性命，韩立的心理挣扎写得好。曲魂去留选择（留府/同行）有分量感，"留曲魂驻守墨府"选项提示了后续燕家堡/京城篇的因果伏笔。

**评价**：墨府三段节奏紧凑，情感线（墨彩环）和因果线（曲魂）交织，是过渡章中质量最高的段落。

### 2.2 太南小会线（wan_meet → qingwen_plot）

- **wan_meet**（frame_187b~190）：万小山引路。太南谷·小会场景——修仙人集市的世界感扑面而来。万小山人设鲜明（圆脸带笑、热心散修），"散修三件事"台词记忆点强。陈巧倩惊鸿一瞥的伏笔自然。
- **qingwen_plot**（frame_191）：青纹道人黑手。韩立识破黑吃黑，与万小山联手脱险。节奏快，紧张感够。万小山"好险好险"的台词增加了角色厚度。

**评价**：太南小会是"初入修仙世界"的窗口，集市 UI（fair）让玩家有逛摊体验。万小山从路人到战友的转变自然。

### 2.3 搭伴探山（wan_hunt · 灵狼战）

- **wan_hunt**（frame_192~195）：会期将近，万小山约探山。灵狼战是**同道并肩系统首战**——万小山作为 AI 队友参战，有独立行动和台词。
- **战斗体验**：灵狼 HP=75，万小山贡献了部分输出（每回合约 15 点）。金光砖（42伤害）是主力输出。战斗节奏适中，2~3 回合解决。

**评价**：同道系统首秀，万小山 AI 行为合理（火球术攻击 + 台词互动）。但玩家无法控制队友行动，有时感觉队友输出不够稳定。

### 2.4 升仙大会（xianhui_open）

- **xianhui_open**（frame_196）：升仙大会 CG + 测灵台。"四灵根还来凑什么热闹"的嘲讽台词刺痛感强。南宫婉出场（结丹女修的俯视视角）是重要伏笔。韩立"退下高台"的选择体现了藏拙性格。

**评价**：升仙大会是修仙世界的"阶层展示"——测灵台上的屈辱感是后续奋斗的动力。CG 画面效果好。

### 2.5 万小山之死 + 复仇战（wan_death）

- **wan_death**（frame_197~199）：**全篇情感最高点**。万小山尸体描写（"眼睛还睁着，望着天"、"攥着半张没卖完的符纸"）极具冲击力。韩立"他叫万小山，记住这个名字"的台词冷到骨子里。
- **复仇战**：两名散修（刀疤 78HP + 瘦高 66HP）。战斗需要靠近（战场距离较远，移动消耗了前几回合）。金光砖 + 飞针组合输出足够。

**评价**：万小山之死是离门远行篇的情感锚——"心善的人活不长"的主题在此落地。复仇战节奏偏慢（移动占回合多），但胜利后的满足感强。

### 2.6 入谷（xianhui_end）

- **xianhui_end**（frame_200~201）："离门远行·终——黄枫谷篇·启"。升仙令到手，韩立踏入新篇章。转场仪式感好。

## 三、BUG 与体验问题

### 3.1 P0 BUG：combat flag 残留

**现象**：战斗胜利后 `State.data.combat` 保持 `true` 不清除，导致：
- 无法旅行（`travelTo` 和 `startJourney` 都检查 `if (s.combat) return`）
- `checkStory` 无法推进剧情
- UI 渲染异常（战斗 overlay 残留）

**复现**：灵狼战和复仇战胜利后都出现了此问题。

**根因**：战斗结算代码（`engine.js` ~4930行）在 `win` 分支中设置 flags 和 storyStage，但 `State.data.combat = false` 的清除可能依赖 `UI.renderAll()` 中的某个回调，手动清除 combat flag 后结算逻辑被跳过。

**修复建议**：在 `_combatEnd` 或 `playStage` 的战斗结算尾部强制 `State.data.combat = false; Engine._combat = null;`，不依赖 UI 回调。

### 3.2 P1 BUG：wan_meet onArrive 设置 flag 但 storyStage 不前进

**现象**：`travelTo('tainan_fair')` 触发 `checkStory`，`wan_meet` 的 `onArrive` 执行了 `setFlag('wan_met')`，但 `storyStage` 没有从 18 前进到 19。后续 `checkStory` 因为 `cond` 包含 `!wan_met` 返回 false，卡死。

**根因**：`playStage` 中 `onArrive` 执行后 `storyStage` 前进逻辑可能被 combat flag 残留打断。

**修复建议**：`playStage` 中 `onArrive` 执行后无条件 `s.storyStage += 1`，不依赖后续回调。

### 3.3 P2 体验：战场距离过大

复仇战战场 W=9 格宽，玩家从 pos=1 出发，敌人在 pos=13~14。需要 4~5 回合纯移动才能进入射程，战斗节奏拖沓。

**建议**：缩小复仇战战场宽度，或让玩家初始位置更靠近敌人。

### 3.4 P2 体验：金光砖冷却不透明

金光砖有 2 回合冷却，但 UI 上没有冷却指示器。玩家只能通过"尚在回气"的 toast 得知。

**建议**：法术按钮上显示冷却剩余回合数。

## 六、数值与节奏评估

- **篇章长度**：9 个剧情节点，约 4~5 年游戏时间（year 13 → year 14），节奏适中
- **战斗难度**：灵狼战（75HP）和复仇战（78+66HP）均为同阶战斗，金光砖（42伤）+ 飞针（22伤）组合足够应对
- **经济系统**：太南小会购物体验好，长春功后篇（灵石×5）是关键消费
- **时间等待**：升仙大会需等 2 个月（absMonth 169→171），度月过程略单调

---

## 七、总结

离门远行篇作为七玄门到黄枫谷的过渡章，质量超出预期：
- **情感线**（墨彩环 + 万小山）有起承转合
- **世界观**（太南小会 + 升仙大会）展示了修仙界的阶层与残酷
- **战斗**（灵狼战 + 复仇战）验证了同道系统和金光砖的爽感
- **主要问题**是 combat flag 残留的 P0 bug，严重影响游玩流畅度
